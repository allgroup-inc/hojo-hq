## ファイル

- `index.html` — テンプレート本体(`?ep=N` でエピソード切替。ブラウザでプレビュー可)
- `episodes.js` — エピソード文面データ
- `render-series.mjs` — 一括レンダラ(`node render-series.mjs <出力先> 1 2 3`)
- `fonts/` — グリフサブセット(SIL OFL。pyftsubsetでローカル生成)

## 新しいエピソードの追加手順

1. `data/fukugiiro/seido.json` で対象制度が **status: 検証済み** であることを確認(必須)
2. `episodes.js` に文面を追加。**DBの `target_household` / `how_to_apply` の言い回しをそのまま使う**
   (断定しない・金額は出さない=amount_noteが要確認のため)
3. 新しい漢字が増えたらフォントサブセットを再生成
   (`pyftsubset` で episodes.js+index.html の全文字を対象に)
4. `render-series.mjs` でレンダリング

## 掲載ルール(必読)

- **常設制度(deadline_type: 常時)だけを扱う**。締切がある制度を出すときは
  締切3層ルール(SNSは残り30日以上のみ)に従い、hojo-deadline-alert スキルで文面確認
- 金額・詳細は動画に書かない。「くわしくは公式ページで(要確認)」チップで統一
- 全エピソードに「※対象になるかの最終判断は各窓口で行われます」を必ず表示
- 無音(音・BGMは投稿時に遥さんがIG内音源等で追加)。キャプションはIG運用v2の型
  (1行目フック・タグ5個・プロフィールリンク誘導)+出荷ゲートを通す
