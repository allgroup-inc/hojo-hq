# もらいわすれ堂 ブランドアニメ「あかりの島」(60秒)

「もらいわすれ堂とは何か」を、説明ではなく物語で伝える1分のアニメーション。
沖縄の夜に散らばる無数の"あかり"(=制度)が、知られないまま眠っている。
案内のあかりがひとつの家に届き、あかりが集まり、空へのぼって三色の虹(ロゴ)になり、朝がくる。

- 仕様: 1080×1920(9:16)・30fps・60.0秒・H.264・音なし(音入れは公開時に別途)
- 出力名: `moraiwasuredo_anime_60s.mp4`
- 用途: Instagram リール / LINE VOOM / LPのヒーロー動画(音なしでも伝わる構成)

## 表現のルール(守り部チェック済みの範囲)
- 制度名・金額・締切は出さない(「200以上」は `data/fukugiiro/seido.json` の掲載件数225件に基づく。件数が200を下回ったら文言を直す)
- 「受け取れるかもしれない」「あかりが、あります」など断定しない言い回し
- 導線は「3分診断」のみ(CV単一)。LINEのURL直貼りなし
- ロゴは `docs/もらいわすれ堂_ロゴガイドv1.md` の確定形(虹と朝日)。虹の半径・位置は Canvas とDOMで完全一致させ、夜明けの溶け込みで切り替える
- 島の形は様式化した輪郭(地図としての正確さは目的にしない)

## 作り(決定的レンダリング)
- `index.html`: 文字と最終ロゴはDOM(CSSアニメ)、夜の世界(星・島・あかり・家・虹)は Canvas 2D。
  Canvas は `window.__seek(ms)` で任意の時刻を純粋関数として描くので、どのフレームも再現できる
- `render.mjs`: Playwright で全CSSアニメを一時停止→1/30秒ずつ `currentTime` と `__seek` を進めて撮影→ffmpeg(libx264, crf 19)
- フォント: `fonts/`(Shippori Mincho 600/700, Noto Sans JP 500 を本動画の文字だけにサブセット。SIL OFL)
- ブラウザで `index.html` を開くと通しで再生(プレビュー用)。`?render=1` を付けると静止し、レンダラ専用になる

```bash
npm i playwright-core ffmpeg-static   # 作業用ディレクトリで
NODE_PATH=<そのnode_modules> node render.mjs [出力.mp4]
```
所要: 約2.5分(1800フレーム)

## 変更のしかた
- 文言: `index.html` の各 `.slot` 内。`animation-delay` が表示開始秒、親 `.out` の delay が消える秒
- 尺・タイミング: `CAM`(カメラのキーフレーム)と各シーンの秒数は `draw(t)` 内の定数。合計は `window.FILM_DURATION`
- 色: `:root` のブランドトークンと `ARC_COL`(虹の三色はロゴガイド固定)
