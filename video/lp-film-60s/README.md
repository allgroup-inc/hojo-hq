# もらいわすれ堂 LP紹介ムービー(60秒・9:16)

LP(`site/fukugiiro/index.html`)の冒頭フィルムをそのまま絵コンテにした、
1080×1920・62秒のブランドムービー。ラストは公式ロゴ「虹と朝日」が
自ら描かれて完成し、「もらいわすれ堂」のワードマークで終わる。

構成(docs/もらいわすれ堂_LP紹介動画_生成プロンプト.md のマスタープロンプト準拠):

| 時間 | シーン |
|---|---|
| 0-8秒 | 夜の集落の灯り「146万人が、住んでいるのが沖縄です。」 |
| 8-15秒 | 三線「出会いを大事にし、伝統を紡ぐのが沖縄です。」 |
| 15-22秒 | ゆいまーる「困ったときは、助け合うのが沖縄です。」 |
| 22-28秒 | 朝焼けの海「なにより、美しいのが沖縄です。」 |
| 28-38秒 | 封筒「まだ眠っている“ささえ”があります」 |
| 38-50秒 | スマホでLP実画面(3分診断・無料・匿名・登録不要) |
| 50-62秒 | 漆喰明転→虹が自ら描かれる→朝日が咲く→「もらいわすれ堂」で完 |

## ファイル

- `index.html` — 動画の本体(全カットをCSSアニメーションで構成)。ブラウザで開けばプレビュー可
- `render.mjs` — 決定的レンダラ(全アニメーションを1フレームずつシークして撮影→H.264 MP4)
- `fonts/` — しっぽり明朝/Noto Sans JP のグリフサブセット(SIL OFL・同梱可)
- `lp-shot.png` — LP実画面のスクリーンショット(シーン6のスマホ内に表示)

## 再レンダリング手順

```bash
# 依存(任意の作業ディレクトリでOK)
npm i playwright-core ffmpeg-static
# 実行(CHROMIUMは環境のChromiumパスに合わせる)
NODE_PATH=./node_modules CHROMIUM=/opt/pw-browsers/chromium \
  node video/lp-film-60s/render.mjs 出力先.mp4
```

LPの文面・写真を差し替えたときは、`docs/もらいわすれ堂_LP紹介動画_生成プロンプト.md`
の手順で `lp-shot.png` を撮り直してから再レンダリングする。

## 注意(公開前に必ず)

- 現状は**無音**(85%が無音視聴のため全編テロップで成立する設計)。
  ナレーション・BGM(三線)・ラストの鈴の音は編集ソフトで後付けする
- 文言は正確性ルール準拠(断定しない)。**文面を変えるときは
  hojo-accuracy-check / 締切3層ルールに従うこと**
- SNS/LINEへ配信する際は出荷ゲート(`scripts/shipping_gate.py`)を通す
