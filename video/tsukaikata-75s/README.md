# もらいわすれ堂 使い方ムービー 第二弾(約118秒・9:16)

「しらべる → えらぶ → じゅんびする → みまもる」の4ステップで
システムの特徴を伝える動画(docs/もらいわすれ堂_使い方動画_生成プロンプト.md 準拠)。
画面はすべて実サイトのスクリーンショット。ラストは第一弾と同一の虹ロゴで完結。

| 時間 | シーン |
|---|---|
| 0-7秒 | 朝の食卓(タイトル「調べて、えらんで、準備するまで。」) |
| 6-21秒 | STEP1 しらべる: 3分診断に指がタップで答えていく(実画面) |
| 20-38秒 | STEP2 えらぶ: 診断結果13件をゆっくりスクロール→「申請準備シート」をタップ |
| 38-66秒 | STEP3 じゅんびする: 4段階(シートの表紙→5ステップに✓→①電話の台本→②持ち物リスト)でゆっくり |
| 65-84秒 | STEP4 みまもる: なぜLINE登録?を3枚でゆっくり(制度は変わる→お知らせ→約1か月前だから間に合う) |
| 83-100秒 | 「振り込まれました」のこえ: 柔らかい体験談風の吹き出し3種→実例→つぎの誰かの安心→ゆいまーる |
| 100-105秒 | まとめ: 4つのことばが順に灯る |
| 105-118秒 | 虹ロゴ(第一弾と同一)→「もらいわすれ堂」で完 |

## ファイル

- `index.html` — 動画本体(CSSアニメーション構成・ブラウザでプレビュー可)
- `render.mjs` — 決定的レンダラ(第一弾と同一)
- `sc_*.png` — 実サイトの画面収録(3分診断Q1/Q2/Q4・診断結果・準備シート)
- `fonts/` — グリフサブセット(SIL OFL)

## 再レンダリング / 画面の撮り直し

レンダリング手順は `video/lp-film-60s/README.md` と同じ。
サイトの文言・デザインを変えたときは、`site/` をローカルHTTPで配信して
sc_*.png を撮り直す(診断はJS駆動のため file:// では結果画面が出ない点に注意。
data/ を `site/data` にリンクするか同等のパスで配信する)。
