# Free-Time Detection Algorithm

## 入力
- `repId`: 営業マン ID (GUID)
- `date`: 対象日 (YYYY-MM-DD)
- `minDuration`: 最小アポイント長 (分、デフォルト 30)
- `travelTime`: 移動時間 (分、デフォルト 30)
- `breakTime`: 休憩時間 (分、デフォルト 60)

## 営業時間
- 営業開始: 09:00
- 営業終了: 18:00
- 休憩時間: 12:00-13:00 (固定1時間)

## アルゴリズム
1. 営業時間内の全体時間（9:00-18:00 = 540分）から、既存アポ + 移動時間 + 休憩を除く
2. 残りの時間を `minDuration` 単位で分割し、各スロットのスタート時間を抽出
3. スロット間の重複チェック（移動時間が十分か確認）

## 計算例
- 営業時間: 09:00-18:00 (540分)
- 既存アポ: 10:00-11:00, 14:00-14:30 (70分)
- 休憩: 12:00-13:00 (60分)
- 移動時間: 各アポ前後に 30分
- 最小枠: 30分

残り時間: 540 - 70 - 60 - (2アポ × 2移動 × 30) = 540 - 70 - 60 - 120 = 290分

利用可能スロット:
- 09:00-09:30 (前置バッファなし)
- 09:30-09:45 (アポ10:00前のため 09:30迄)
- 11:30-12:00 (アポ後、休憩前)
- 13:00-13:30 (休憩後、次アポ前バッファ)
- 13:30-14:00 (前置バッファなし)
- 14:55-18:00 (4時間以上の複数スロット)

## 実装の責任
- 既存アポとの重複チェック
- タイムゾーン対応（沖縄 JST）
- 移動時間の自動差引（エコシステム内のエリアごとに調整可能な将来仕様）
- 祝日チェック（初期 PoC は非対応、Phase 1 で追加）
