# glow-ma/wld02 — 世界の架け橋 相談企業KPIの集計(開発・テスト段階)

- `wld02Kpi.js`: 週次KPIの計算だけを行う関数(台帳を触らない)。テストは `tests/glow_ma_wld02Kpi.test.mjs`
- ここは `glow-ma/src/` の外なので、main へマージしても台帳のスクリプトへは反映されない(`glow-ma-deploy.yml` は `glow-ma/src/**` だけを見る)
- 決裁記録と設計書は非公開リポジトリ(glow-docs-private)にある。数え方の決まりは `wld02Kpi.js` の冒頭に要点を書いた

本番へ進めるときの順番(それぞれ別に承認を得る):

1. 設計書のレビュー(v1)
2. 過去の企業IDの名寄せ照合(読み取りのみ・1回。結果は非公開側に置き、hojo-hq には件数だけ書く)
3. テスト用の台帳で確認
4. 本番台帳への反映(4つのタブを作る。既存の列は変えない)— 台帳の自動処理の承認切れ(失敗台帳 FK-008)の恒久対策が済んでから。このとき `wld02Kpi.js` を `glow-ma/src/` へ移す
5. 毎週月曜の自動実行の登録
