# /token-budget-advisor

トークン消費の可視化・予算管理コマンド

## 使用場面
- Claude Code Remote セッションのトークン使用量を確認したいとき
- 複数セッション・複数エージェント実行時の総コスト把握
- 月間予算内に収まっているか確認
- 高額セッションのボトルネック特定

## 実行方法
チャットに `/token-budget-advisor` と入力して実行

## 効果
1. **現在のセッションのトークン消費を可視化**
   - Input tokens (プロンプトキャッシュ命中含む)
   - Output tokens
   - Cache write/read token数
   - 推定費用（USD/JPY）

2. **複数セッション比較**
   - セッション別の消費ランキング
   - 異常なトークン使用パターンの検出
   - キャッシュ効率の確認

3. **予測と警告**
   - 月間予算トレンド
   - 予測される月末費用
   - 予算超過時の警告

## hojo-hq での活用例

前回の監査で $36,093（52セッション）の高額費用が判明しました。本コマンドを定期実行することで：
- **Decision 2**: 高頻度 Routine 削減時に、削減後の効果を定量化
- **Decision 3**: Phase 1 Routine のワンタイム化が月額費用に与える影響を数値化
- **継続管理**: 21セッション Archive 後の月額トレンド追跡

## 推奨実行頻度
- **週1回**: 週次レポ作成時（毎週金曜 16:00 JST）
- **大規模実行前**: 複数エージェント・ワークフロー実行の前（予算確認）
- **異常検知**: トークン消費が急増した場合（原因分析）

## 注意点
- 実行には Claude Code Remote の権限が必要
- Prompt caching TTL (1時間) を超えると cache_read tokens がリセット
- マルチAI連携（Claude + Gemini）時は、各AIの費用を別途確認
