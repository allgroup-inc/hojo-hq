# ブランド設計・ビジュアルアイデンティティ（hojo-hq 専用版）

「色を選んで」と言われて、適当に選ぶのが一番危ない。
色・フォント・トーンは「誰に何を感じさせたいのか」から逆算する。
このスキルは、hojo-hq の各事業のブランドガイドラインを管理し、
新規資料・LP・アプリ UI を「どのブランドで」「どのトーンで」作るのかを決める手順。

## Stage 1: 事業ごとのブランド確認

### **事業 A: 沖縄企業のミカタ（株式会社 GLOW）**

**対象顧客**: 沖縄の中小経営者・企業（B2B）

**ブランド戦略**:
```
名称: 沖縄企業のミカタ
タグライン: 補助金・助成金の情報で、沖縄の企業にあかりを。
位置づけ: 「専門用語を優しく翻訳する」提案者（家計の見直しやさんと同じポジション）
```

**ビジュアル設定**（CLAUDE.md より）:
```
配色（決定の理由）:
  主色: ネイビー #00335C
    └─ 理由: 「信頼」「安定」「官公庁の透明性」を表現
           （補助金・助成金は公的な制度だから）
  
  副色: オレンジ #F88800
    └─ 理由: 「活力」「沖縄の太陽」「行動喚起」
           （経営者に『今すぐ申請できる』という前向きさを伝える）

フォント:
  日本語: Meiryo（Windows 標準）
  Web: Noto Sans JP（Google Fonts）
    └─ 理由: 読みやすさ、信頼性、サイズ調整時の見栄え

トーン:
  文体: 「専門用語をやさしく翻訳」
  例（NG → OK）:
    NG: 「交付対象事業に該当する場合のみ申請可能」
    OK: 「補助金がもらえる企業は、こんな企業です」
  
  説明の仕方: 「背景 → なぜこれが大切なのか → 次のステップ」
  強調の仕方: ALL CAPS や ！！！ は使わない。句点で区切る
  
  トーン値:
    親しみやすさ: ★★★☆☆ （専門性を損なわない程度）
    信頼度: ★★★★★ （官公庁情報を扱うため）
    行動喚起: ★★★★☆ （『やってみよう』という気持ちに）
```

**適用場面**:
```
✅ 使う
  • ミカタ の LP・診断ツール・LINE ポスト
  • 士業・商工会向けの提携資料
  • 週次レポ（ミカタ運用データ）
  
❌ 使わない
  • 家計の見直しやさん資料（別ブランド）
  • KAKEHASHI など内部システム（別ブランド）
  • glow-ma など M&A 営業資料（glow-docs-private の別色）
```

### **事業 B: もらいわすれ堂（株式会社フクギイロ）**

**対象顧客**: 沖縄県民（一般世帯向け B2C）

**ブランド戦略**:
```
名称: もらいわすれ堂
タグライン: あなたが受け取るまで、いっしょに。
位置づけ: 「受け取り漏れを防ぐ伴走者」（人間的で温かい）
```

**ビジュアル設定**（CLAUDE.md より）:
```
配色（決定の理由）:
  主色: 朱 #B9502F
    └─ 理由: 「沖縄らしさ」「温かみ」「親しみやすさ」
           （B2C 向けで、心理的距離を近くしたい）
  
  副色: 黄 #F2B705
    └─ 理由: 「希望」「サポート」「一緒にやろう」の親友感
  
  背景: 漆喰 #FFFBF4
    └─ 理由: 「自然」「沖縄の壁」「清潔感」
           （個人情報を預ける安心感）
  
  本文: 墨 #1F2A2E
    └─ 理由: 読みやすさ、温かみ

フォント:
  日本語: 丸ゴシック系
    └─ 理由: 「親しみやすさ」「敷居の低さ」
           （高齢層が『自分でもできる』と感じる親友感）

トーン:
  文体: 「やさしい日本語」「主語は『あなた』」「断定しない」
  例（NG → OK）:
    NG: 「給付金受給支援サービス」
    OK: 「あなたが受け取れる給付金を、一緒に探します」
  
  説明の仕方: 「なぜこれが大切なのか → あなたはどうですか → 次のステップ」
  強調の仕方: 「〜かもしれません」「〜できます」で前向きに
  
  トーン値:
    親しみやすさ: ★★★★★ （心理的距離を近く）
    信頼度: ★★★★☆ （公的情報だが『怖い』印象は避ける）
    行動喚起: ★★★★☆ （『やってみようかな』と思わせる）
```

**適用場面**:
```
✅ 使う
  • もらいわすれ堂 の診断ツール・LINE 配信
  • 県民向けの PR 資料
  • note 記事（県民啓発）
  
❌ 使わない
  • ミカタ（企業向け）の資料
  • glow-ma など営業システム（内部向け）
```

### **事業 C: KAKEHASHI システム（enLife 社内向け）**

**対象ユーザー**: enLife の営業マン・管理者（内部向け B2E）

**ブランド戦略**:
```
名称: KAKEHASHI（橋 = 顧客と保険をつなぐ）
位置づけ: 「営業の判断をサポート」（機械的ではなく、人間的）
```

**ビジュアル設定**:
```
配色（決定の理由）:
  主色: 深い青 #003D82
    └─ 理由: 「営業の信頼性」「落ち着き」「プロ感」
  
  副色: ライムグリーン #7BC400
    └─ 理由: 「行動完了」「OK」「続ける」という信号
  
  背景: オフホワイト #F5F5F5
    └─ 理由: 「疲れないデザイン」（営業マンが 1 日中使う）

フォント:
  日本語: Meiryo（Windows 標準）
    └─ 理由: 営業所の PC で必ず表示される

トーン:
  文体: 「短く、即座に判断できる」
  例（NG → OK）:
    NG: 「顧客の現在の保険補償範囲と照らし合わせた場合の推奨商品は以下の通りです」
    OK: 「勧める商品: 医療保険（理由: 現在ない）」
  
  説明の仕方: 「判断すべき事実 → 推奨アクション → 次のステップ」
  強調の仕方: 赤（警告）・緑（OK）で判断を視覚化
  
  トーン値:
    親しみやすさ: ★★★☆☆ （営業効率が最優先）
    信頼度: ★★★★★ （誤った判断は許されない）
    行動喚起: ★★★★★ （『今すぐ顧客に電話』を促す）
```

**適用場面**:
```
✅ 使う
  • KAKEHASHI アプリの UI・画面
  • 営業マン向けのポップアップ通知
  • 営業指数ダッシュボード
  
❌ 使わない
  • 顧客向けの資料・説明（別ブランド不要）
  • enLife のコーポレートサイト（本社ブランド）
```

## Stage 2: ペルソナ別の「配色心理」調整

同じミカタの LP でも、相手によって色のニュアンスを変える必要がない。
むしろ「信頼できるネイビー」は全セグメント共通。

ただし、**トーン値は変わる**:

```
セグメント別のトーン調整:

セグメント A（会計士・商工会）:
  配色: ネイビー + オレンジ（そのまま）
  文体: 専門用語を使い、簡潔に
  トーン値: 親しみやすさ ★★★☆☆ 信頼 ★★★★★
  
セグメント B（補助金初心者の経営者）:
  配色: ネイビー + オレンジ（そのまま）
  文体: 専門用語をやさしく翻訳
  トーン値: 親しみやすさ ★★★★☆ 信頼 ★★★★☆
  
セグメント C（定期的な顧客）:
  配色: ネイビー + オレンジ（背景をやや明るく）
  文体: 『新しい制度が 3 つあります』と簡潔に
  トーン値: 親しみやすさ ★★★☆☆ 信頼 ★★★★★（信頼が再優先）
```

**色そのものは変えない。使い方（余白・サイズ・透明度）で調整する**

## Stage 3: 新規資料・LP 作成時の「色選びチェック」

新しい LP・プレゼン資料を作るとき、このチェックリストを通す：

```
□ これは『どの事業の色』ですか？
  └─ ミカタ（ネイビー×オレンジ）/ もらいわすれ堂（朱×黄）/ KAKEHASHI（青×緑）

□ 対象顧客は『誰』ですか？
  └─ ペルソナが決まると、トーン値が決まる
  
□ 『なぜこの色か』を 1 文で言えますか？
  └─ 言えなければ、根拠のない色選び

□ この配色で『何を感じさせたいのか』
  ├─ 信頼？ → ネイビー
  ├─ 親しみやすさ？ → 暖色系
  ├─ 行動喚起？ → 副色を強調
  └─ 落ち着き？ → 背景色を明るく、テキストは濃く
```

## Stage 5: 『テンプレ感を出さない』ための色の使い方

### **NG パターン**

```
❌ 全要素を統一色で塗る
   「ヘッダー = 青、サイドバー = 青、ボタン = 青」
   → 単調で、どこをクリックすればいいか分からない

❌ 主色と副色を 50:50 で使う
   「左半分オレンジ、右半分ネイビー」
   → バナナ分け（安っぽい）

❌ グラデーション乱用
   「上から下に色が変わる」
   → 2010 年代のデザイン、古臭い
```

### **OK パターン**

```
✅ 色の「役割」を決める
   • ネイビー = 信頼（本文、見出し、重要な情報）
   • オレンジ = 行動（ボタン、CTA）
   • グレー = 補足（説明文、注記）
   
✅ 余白と色のバランス
   「色よりも余白が多い」のが美しい
   
✅ 色の濃淡で情報の重さを表現
   「最重要 = 濃い色」「参考情報 = 薄い色」
```

---

## 注意点

- ❌ 「きれいだから」という理由で色を変えない
- ✅ 「なぜこの色か」を顧客心理から説明できるまで、決定しない
- ❌ 事業ごとのブランド色を混ぜない（ミカタ資料にもらいわすれ堂の黄を使わない）
- ✅ 月 1 回、「この色選びは理由があるか」を見直す（ブランド流出防止）
- ❌ 「色が古い」という理由で変える（ブランド統一が崩れる）
- ✅ トレンド色は使わない。ブランド色を守る
