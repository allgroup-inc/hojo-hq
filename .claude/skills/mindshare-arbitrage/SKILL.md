# Mindshareアービトラージ(コンテンツ発見〜投稿の仕組み化)

SNS・note等のコンテンツ制作(ネタ探し・生成・投稿)を仕組み化するときに使う。
「バズはセンスより、見つける仕組みで再現しやすくなる」という考え方に基づく。

> ALLGROUP共通スキル(hojo-hqを本店として複数リポジトリで共有)。

## 核心: Mindshareアービトラージとは

ある場所(プラットフォーム/言語圏/コミュニティ)で伸びた型や考え方を、
まだそれが届いていない別の場所の"言語"に合わせて再構成すること。

```
発見(プラットフォームAで見つける)
  → 翻訳(別プラットフォーム向けに言い換える)
    → 投稿(新しい観客に届ける)
      → 大量の再生・反応を獲得
```

各プラットフォームは独立していて、良いアイデアが他の場に届いていないことに
多くの人が気づいていない。そのギャップを突く。

### 翻訳の方向の例
| 元 | 先 | 変換の仕方 |
|---|---|---|
| TikTok | LinkedIn | カジュアルなバズを、学びのある実務投稿へ |
| YouTube | X | 長い解説を、短く鋭い要点に再構成 |
| 英語圏 | 日本語圏 | 海外の新しい流れを先回りで届ける |
| ニッチコミュニティ | メインストリーム | 専門知を、広く伝わる形に変える |

hojo-hqでの応用例: 他県の補助金メディア/士業の発信(ニッチ)→沖縄の経営者向けSNS(メインストリーム)、
海外のAI活用事例(英語圏)→沖縄の中小企業向け解説(日本語圏)、など。

### 差をつける5つのポイント(丸パクリとの違い)
1. **最初に見つける** — スピードが命
2. **自分の言葉で翻訳する** — 丸パクリは信用を失う
3. **価値を足す** — 補足・整理・視点を加える
4. **一貫した声で発信する** — CLAUDE.mdのトーン(専門用語をやさしく翻訳)を保つ
5. **品質で勝つ** — 読みやすさ・正確さ・フックを磨く(→ `humanizer` スキルで仕上げる)

## 6段パイプライン

| 段階 | 内容 | 人が関わるか |
|---|---|---|
| ① 発見(Discovery) | AIがトレンド候補を見つけてスコア化 | しない |
| ② レビュー | AIの提案を確認し、残すか判断する | **する(唯一の入口ゲート)** |
| ③ 生成(Generation) | アイデアを各プラットフォーム向けの文章にする | しない |
| ④ スライド化 | テキストをSNS画像/カルーセルにする | しない |
| ⑤ 承認・投稿 | 公開前の最終チェック、投稿実行 | **する(唯一の出口ゲート)** |
| ⑥ 分析・学習 | 反応データを次回の選定に反映 | しない |

人が関わるのは②(残すか判断)と⑤(公開前チェック)の**2箇所だけ**。
それ以外は仕組みで自動化する(→ `resilient-agent-design` の「AIへ渡すのは判断だけ」
「各工程に完了条件を持たせる」原則と同じ設計)。

### ① 発見(Discovery)の設計
- 収集元: YouTube/X/TikTok/changelog等(このリポジトリに`last30days`スキルがあれば代替可能)
- スコア = 新しさ × エンゲージメント
- 重複は除外して保存(状態を外部保存する原則と同じ)
- 動画は文字起こしも取得しておく
- 定期実行(例: 毎朝6時)して、朝には候補一覧ができている状態にする

### ② レビュー(人の判断)の設計
- スコア順に候補を確認、キープ/スキップ/お気に入りの3択で素早く判断
- 所要時間の目安を決めておく(例: 5〜10分)
- 原則: **「全部作る」のではなく「作る価値があるものだけ」を通す**

### ③ 生成(Generation)の設計
1. NotebookLM等でリサーチ補強(裏付け・事例・トレンドを補強)
2. 1つのアイデアから各プラットフォーム向けに生成(X=短文、LinkedIn=専門性、
   ブログ/note=深掘りなど、媒体ごとに最適な切り口・長さ・トーンで)
3. **writer → humanizer → critic の3段ループ**: 書く→人間らしくする→批評・改善を
   繰り返し、読みやすく説得力のある文章に磨き上げる(このリポジトリに`humanizer`
   スキルがあれば、この工程で明示的に呼ぶ)
4. "自分の声"プロファイルを反映(過去の投稿・口調・CLAUDE.mdのトーン指定をもとに、
   あなたらしい言葉遣いを自然に反映する)
5. 各原稿はフック・正確さ・簡潔さをチェック(事実情報が絡む場合は、このリポジトリの
   正確性チェック系・締切表現ルール系のスキルがあれば、それらとの整合も必ず確認する)

### ④〜⑥ スライド化・承認投稿・分析学習
- スライド化: テキストをデザインテンプレートに沿って画像/カルーセル化
  (→ このリポジトリに`carousel-writer`等のスキルがあれば連携)
- 承認・投稿: プレビュー確認後に各SNSへ。このリポジトリで定められたCV
  (コンバージョン導線)が単一なら、他のCVを紛れ込ませない
- 分析・学習: 反応データを次回の「発見」の重み付けに反映する

## 使うときの結論
1. トレンドを「発見」する(仕組みで見つける)
2. あなたの言葉に「翻訳」する(丸パクリしない、価値を足す)
3. 仕組みで「継続」する(人は判断ゲート2箇所だけに集中する)
