# Humanizer(AIっぽさを消す仕上げチェック)

沖縄企業のミカタ/もらいわすれ堂の対外文面(SNS投稿・LINE配信・サイトコピー・お知らせ)を
書き終えた/直し終えた最後に必ず通す仕上げスキル。CLAUDE.mdのトーン
「専門用語をやさしく翻訳する、家計の見直しやさんと同じ立ち位置」を実現するための
最終チェックとして使う。

## AIっぽさのサイン(見つけたら直す)

- 定型の書き出し: 「〜って知っていましたか?」「実は、」「今回は〜についてご紹介します」
- 定型の締め: 「ぜひチェックしてみてください!」「お気軽にご相談ください!」を毎回同じ形で使う
- 箇条書きの多用・見出しの機械的な三段構成(結論→理由→まとめ)をSNS投稿にまで持ち込む
- 絵文字・「!」の過剰な連打、意味のない強調(**太字**の多用)
- 「〜と言えるでしょう」「〜かもしれません」など、断定を避ける曖昧な語尾の連発
- ダッシュ(—)や「まさに」「そんな」といった、話し言葉では使わない書き言葉的な接続
- 情報を全部盛り込もうとして一文が長くなる、または逆に短文を機械的に並べる

## チェック手順

1. 声に出して読んで、不自然に感じる箇所(人が実際にはこう言わない、という箇所)を探す
2. 上記の定型フレーズ・締めが使われていないか確認し、使われていたら具体的な言い回しに置き換える
3. 一文の長さ・語尾にばらつきを持たせる(全部「です・ます」で終わらせない、体言止めや問いかけを混ぜる)
4. 絵文字・強調は本当に必要な1箇所だけに絞る
5. **締切・金額・要件など事実情報は書き換えの過程で変えない**(→ `hojo-accuracy-check` / `hojo-deadline-alert` の内容と矛盾していないか最後に必ず確認する)

## やってはいけないこと

- 自然さを優先して、締切3層ルールや「約1か月前から」表現を崩す
- 事実確認済みの数値・締切表現を、語感を良くするために変更する
- テンプレ化を避けるあまり、CVがLINE登録であることを曖昧にする
