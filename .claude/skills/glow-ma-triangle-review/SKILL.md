# 三名体制ディスカッション(トライアングル体制) — glow-ma版

`glow-ma`(GLOW M&A・不動産・法人保険の企業リレーション管理システム)で、
スコアリングモデル・掘り起こしアラートの閾値・提案順序・紹介パートナーとの
料率や逆紹介の取り決めなど、意思決定を伴う検討をまとめるときは、
CLAUDE.md憲法の三名体制(全チーム共通ルール)で議論を構成する。

対象となる典型的な論点の例:
- スコアリングの重み付け(属性スコア・流入ルートボーナス・反応スコアの配分)
- ランク別の標準接触サイクル日数・掘り起こしアラートの閾値
- 保険/経営相談→M&A・不動産という提案順序の適用可否(紹介ルートでの例外扱いなど)
- 紹介パートナーへの紹介料率・逆紹介の条件
- 名寄せ・データ突合のルール変更

## 3役(すべての議論をこの3視点で行う)

- **スイシン(推進)**: 案を前に進める立場。狙い・期待効果・実行手順を出す。
- **ウタガイ(懐疑・反対必須)**: 必ず反対・懸念を出す。リスク・前提の穴・失敗パターンを挙げる。
- **ベッカイ(別解・前提を疑う)**: そもそもの前提を疑い、別の選択肢や枠組みを提示する。

## 議事のまとめ方(この形で出力する)

```
## 論点: <検討テーマ>

### スイシン(推進)
- <推進理由・実行案>

### ウタガイ(懐疑)  ← 空欄不可
- <反対理由・リスク・懸念>

### ベッカイ(別解)
- <前提への疑問・別案>

### 結論(裁定)
- 採否: <採用 / 不採用 / 保留・上申>
- 理由: <3役を踏まえた採否理由>
- 見直し期限: <最長6ヶ月。期限切れは自動で再議論>
```

## 無効になる議事(差し戻し条件)

- **ウタガイ役の反対理由が記録されていない議事は無効**(結論ごと差し戻す)。
- 裁定者は議論の当事者にならない。
- 3役が割れて確信が持てない案件は、たかしくん(GLOW実務)経由で小柳さんへ上申する。
- **予算・提携条件(紹介料率等)・最終決裁は小柳さん。エージェントは提案まで**(CLAUDE.md絶対ルール5)。
