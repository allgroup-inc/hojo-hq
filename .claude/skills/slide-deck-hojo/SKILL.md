# スライド製作（PowerPoint / Figma）— hojo-hq 専用版

## 準備：writing-plans-hojo との連携確認

```
writing-plans-hojo で決まったもの:
  ✓ 構成（何ページか、各ページの内容）
  ✓ メッセージ（1 スライド 1 メッセージ）
  ✓ 読み手（誰に見せるのか）

slide-deck-hojo で確定するもの:
  • レイアウト（左右どちらに配置するか）
  • ビジュアル（写真 / グラフ / アイコン）
  • アニメーション（次に何を見ればいいか）
  • テンプレ感の排除
```

---

## Stage 1: スライドマスター設定（最初に 1 回だけ）

### **PowerPoint の場合**

```
1. [表示] → [スライドマスター]
2. レイアウトを 4 つ定義:
   • タイトルスライド
   • 本文スライド（左画像、右テキスト）
   • 本文スライド（右画像、左テキスト）
   • セクション分割スライド

3. 色・フォント・余白を統一:
   • 背景色: 白（ミカタなら背景は淡い青 #F5F8FB でもOK）
   • フォント: Meiryo 11pt（本文）
   • 見出し: 28pt bold
   • 余白: 上下左右 40px 最小
   • ロゴ: 右下に小さく
```

---

## Stage 2: スライド別ガイド

### **スライド 1: タイトルスライド**

```
┌──────────────────────────┐
│                          │
│                          │
│    【タイトル】          │
│    【タイトルを説明】    │
│                          │
│    小柳さん              │
│    2026-10-02            │
│                          │
└──────────────────────────┘

ポイント:
  • 『何を決める資料か』が一目で分かる
  • 背景色は brand color（ミカタなら淡い青）
  • 文字色: ネイビー（白背景に対して十分なコントラスト）
  • 左下に日付・作成者
```

### **スライド 2-N: 本文スライド**

```
┌──────────────────────────┐
│【見出し（28pt bold）】   │
│━━━━━━━━━━━━━━━━         │
│                          │
│ [写真 or 図]             │
│  50% の幅                │
│                          │
│  本文（11pt）            │
│  • 箇条書き 3 行まで     │
│  • 詳しくは補足スライド  │
│                          │
└──────────────────────────┘

ルール:
  • 1 スライド = 1 メッセージ（見出しで言い切る）
  • 文字は 5 行以下（読める量に）
  • ビジュアルは写真 or グラフ（アイコンは脇役）
  • 『次はどこを見るか』を矢印で示す
```

### **スライド N+1: 補足スライド**

```
本編で「詳しくは補足」と書いたら、末尾に補足スライドを置く

例: 成功事例の詳細、Q&A、用語集

┌──────────────────────────┐
│【補足】【成功事例 詳細】 │
│━━━━━━━━━━━━━━━━        │
│ 表（4 行 × 3 列）         │
│                          │
│ 〇〇事務所の例:           │
│ • 導入前: 紹介 5 件/月   │
│ • 導入後: 8 件/月        │
│ • 増加分: +3 件/月       │
│ • 売上: 約 150 万円増    │
└──────────────────────────┘
```

## Stage 3: ビジュアル（写真・グラフ・アイコン）

### **写真の選び方**

✅ **OK**:
```
• 実際の顧客・営業マン（顔が見える）
• ビジネスシーン（デスク、対面の様子）
• スクリーンショット（アプリ UI、実行結果）
```

❌ **NG**:
```
• ストック写真（「success」で検索した人物）
• 不自然なポーズ・表情
• 複数の写真をコラージュ（AI が作った感）
```

### **グラフの使い方**

```
❌ NG: 「成長グラフ」という一般的なグラフを貼る

✅ OK: 実際のデータを Excel から抽出
      • 横軸: 月（2026-08 〜 2026-09）
      • 縦軸: 紹介件数
      • 線の色: ブランド色（オレンジ）
      • グリッドラインなし（シンプル）
```

### **アイコンの使い方**

```
アイコンは『補足』、本メッセージではない

✅ OK:
  「3 ステップで解決」
    ① 診断 [アイコン: チェックマーク]
    ② 相談 [アイコン: 電話]
    ③ 申請 [アイコン: 書類]

❌ NG:
  [大きな笑顔アイコン] 「Happy な未来」
  ← アイコンが主、メッセージが脇役
```

## Stage 4: テンプレ感を消す（配置・アニメーション）

### **配置（左右交互）**

```
❌ NG: 全スライド「左テキスト、右画像」

✅ OK:
  スライド 2: 左画像、右テキスト
  スライド 3: 左テキスト、右グラフ
  スライド 4: 左アイコン 3 つ、右説明
  
  → 読む人が「次は配置が変わる」という動きを感じ、退屈しない
```

### **アニメーション（最小限）**

```
❌ NG:
  • 全要素が回転しながら出現
  • 派手な効果音
  • 次々と出現して、読む人が追い付けない

✅ OK:
  • 見出しが最初に出現（0.5 秒）
  • クリックで本文が出現（0.3 秒）
  • さらにクリックで画像が出現
  → 「読む人がコントロール」している感覚
```

## Stage 5: 色・フォント・トーンの確認（最終ゲート）

```
□ ブランド色が正しいか（design-system-hojo）
  └─ ミカタ = ネイビー + オレンジ
  └─ もらいわすれ堂 = 朱 + 黄
  └─ KAKEHASHI = 青 + グリーン

□ フォントが統一されているか
  └─ 見出し: Meiryo 28pt bold
  └─ 本文: Meiryo 11pt regular
  └─ 数値: 同じ（14pt にして少し強調）

□ 文体が統一されているか
  └─ ミカタ「専門用語をやさしく」
  └─ もらいわすれ堂「主語は『あなた』」
  └─ KAKEHASHI「簡潔」

□ 『テンプレ感』がないか（taste-skill）
  └─ 全スライド同じ配置ではないか
  └─ 意味のないアイコンが乱発されていないか
  └─ 色が『安っぽく』見えていないか
```

## Stage 6: 出力・共有

### **PowerPoint**

```
• ファイル名: ミカタ_プレゼン資料_2026-10-02.pptx
• 保存形式: PPTX（互換性重視）
• 共有先: Google Drive / OneDrive（編集権限を指定）
• 配布前に必ず: 顧客情報・個人情報がないか確認
```

### **PDF 化（印刷・配布用）**

```
• PowerPoint → [ファイル] → [エクスポート] → [PDF]
• ファイル名: ミカタ_プレゼン資料_2026-10-02.pdf
• 注意: PDF になると『アニメーションが失われる』
       → アニメーションなしの『印刷用バージョン』を想定
```

## チェックリスト（最終確認）

```
□ タイトルスライドで『何を決める資料』か分かるか
□ 1 スライド 1 メッセージ（見出しが完結文）
□ 文字が 5 行以下に収まっているか
□ ビジュアルが『何を説明しているのか』明確か
□ 配置が単調（全同じ）ではないか
□ 色が brand color か（混ぜていないか）
□ 数値に『出典』が付いているか
□ 顧客情報・個人情報が入っていないか
□ ページ数は目安の範囲か（決裁 1 ページ / 営業 5-8 / 説明 3-5）
□ 『AI が作った感』がないか（確信をもって言える配置か）
```
