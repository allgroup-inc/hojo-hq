# もらいわすれ堂：Instagram投稿ガイド

**目的**: 週1-2回の安定した投稿で、もらいわすれ堂の診断ツールを認知・拡散。事例を通じて「知ってるか知らないかだけで人生が変わる」というメッセージを伝える

**スタイル**: 素人らしく。フィルターなし、手書きテキスト、スクリーンショット、背景は日常風景。完璧な企業発表ではなく「本当に困った人が解決した」実感を優先

---

## テンプレート A: 「知らなかった制度でもらえた型」

### 使い分け
- **対象**: 「まったく知らなかった制度を発見」して受給成功した事例
- **効果**: 「えっ、こんな制度があるの？」という驚きと「自分も該当するかも」という行動動機付け
- **頻度**: 月に3-4件程度が理想

### 記入例

```
【衝撃】こんな制度があるなんて
知りませんでした 😲

「もらいわすれ堂」で診断したら
児童手当の振込が止まってることに
気付きました。

【すぐに申請】
準備シートで「何を揃えるか」が
分かって、書類を集めて提出。

【結果】
✅ 4ヶ月分さかのぼって受給
✅ 毎月 1.5 万円の児童手当が再開
✅ 年間 18 万円の増加！

---

ホント、知ってるか知らないか
だけで、こんなに変わるんです。

沖縄の親たちに
「申請忘れがないか確認して」
って言いたい。

診断は 3 分。
やってみてください。

👉 [moradou.jp/shindan]

#沖縄応援 #もらいわすれ堂
#児童手当 #知らなかった #家計助かる
```

### ポイント
- 「衝撃」「すぐに」「結果」の3段構成で時間軸を明確に
- ✅ チェックマークで成果を視覚化
- 金額を「毎月」「年間」で複数の見方を提示
- 最後に「同じ立場の人へのメッセージ」を一言
- ハッシュタグは制度名を必ず含める

---

## テンプレート B: 「困ったことを正直に型」

### 使い分け
- **対象**: 「ここが困った、でも解決できた」という準備・申請プロセスの実例
- **効果**: 「他の人も同じことで詰まってる」という共感→行動をサポート
- **頻度**: 月に2-3件程度

### 記入例

```
【本気で困ってた】
娘が高校生になってお金が...
と思ってたら、こういう制度が
あるんですね。

準備シートのおかげで
「何が必要か」が分かって
申請まで進めました。

【ちょっと楽になった】
奨学給付金：△△ 万円
（申請して受給成功）

---

「制度がある」ことを知ると
知らないでは全然違う。

高校生・大学生の
親御さんは特に確認した方がいいです。

わからなかったら相談してください。
LINEでサポートします。

👉 診断してみる：[moradou.jp/shindan]
👉 LINEで相談：[line.me/...]

#奨学給付金 #子育て支援 #沖縄
#教育費 #制度を知ろう
```

### ポイント
- 「困ってた」→「解決できた」の転換を明確に
- 成果は「〇〇万円」と具体的に（金額範囲でもOK）
- 「同じことで困ってる人へのメッセージ」を強調
- LINE登録への導線を自然に含める

---

## テンプレート C: 「数字で伝える型」

### 使い分え
- **対象**: 複数制度の受給で「トータルいくらもらえたか」を具体的に示す事例
- **効果**: 「こんなに受け取れるんだ」という可処分所得向上の実感
- **頻度**: 月に1-2件程度（インパクトが大きい）

### 記入例

```
【年間いくらもらえるか】

診断したら
あてはまる制度が 8 件。

実際に申請した結果：
▪️ 児童手当：月 1.5 万円
▪️ 奨学給付金：年 12 万円
▪️ 生活支援：1 回 20 万円

合計：年約 68 万円 💰

---

知らなかったら、
この 68 万円は
受け取ってなかった。

もらいわすれ堂で
診断しなかったら、
ずっと気づかなかった。

あなたは？
3分で診断できます。

👉 [moradou.jp/shindan]

#給付金 #生活が楽に #沖縄県民
#児童手当 #奨学給付金
```

### ポイント
- 金額を「月」「年」「1回」など複数の単位で提示して実感を広げる
- 「年約XX万円」という視点で年収換算の感覚を与える
- 「知らなかった場合」と「知った場合」の対比を強調
- 読者への直接的な呼びかけ（「あなたは？」）で行動を促す

## ハッシュタグ戦略

### 【沖縄・地域】
`#沖縄応援` `#沖縄` `#沖縄県民` `#沖縄暮らし` `#うちなあぐち`

### 【個人向け補助金・給付金】
`#補助金` `#給付金` `#助成金` `#制度を知ろう` `#お金の話` `#生活費助かる` `#家計助かる`

### 【子育て・教育】
`#児童手当` `#奨学給付金` `#子育て支援` `#教育費` `#高校生の親` `#保育料` `#出産育児一時金`

### 【生活支援】
`#生活支援` `#困った時には` `#沖縄で暮らす` `#生活が楽に` `#申請忘れ`

### 【ブランド】
`#もらいわすれ堂` `#沖縄企業のミカタ` `#あかりの島`

### 【インタラクション】
`#シェアしてほしい` `#DM待ってます` `#相談受付中`

### 使用ルール
- **合計 6-10個程度**（多すぎない。10個を超えないこと）
- **投稿の主軸テーマ**：`#給付金` や `#児童手当` など制度名必須（1-2個）
- **地域タグ**：`#沖縄県民` など（1個）
- **カテゴリタグ**：子育て/教育/生活支援など（2-3個）
- **ブランド**：`#もらいわすれ堂`（1個）

### 投稿ごとのタグ構成例

**テンプレート A（児童手当）の場合**：


**テンプレート C（複数制度）の場合**：

## 投稿品質チェックリスト（簡易版）

投稿前に毎回確認してください。

### 【個人情報】
- [ ] 氏名は同意内容と一致（氏名/名字/匿名）
- [ ] 住所・電話・メール等は含まない
- [ ] 金額は幅を持たせてある（「約XX万円」）
- [ ] 本人の最終確認は取った

- [ ] 制度名は正確（seido.json 確認）

- [ ] 「絶対」「必ず」等の断定表現なし
- [ ] 素人らしさを維持（完璧な企業発表ではない）
- [ ] 共感・応援のトーンが感じられる

### 【技術】
- [ ] タイポ・誤字なし
- [ ] ハッシュタグ 6-10個程度
- [ ] 画像 1-3枚（文章メイン）

## 投稿後の計測

### 【記録すべき数字】（投稿1週間後）
- **リーチ数**（何人に見られたか）
- **いいね・保存数**（エンゲージメント）
- **クリック数**（moradou.jp へのリンク遷移）

### 【月次分析】
- テンプレート A / B / C のうち、どれが最もリーチを取ったか
- 「いいね」が多い制度は？（需要の高い制度）
- ハッシュタグのどれが流入を取ったか

### 【改善サイクル】
- リーチが低い投稿は「時間帯」「ハッシュタグ」を調整して再投稿検討
- 反応が良い制度テーマは翌月の事例収集で優先度 UP

## 特記事項

### 素人らしさの維持
- 写真はフィルターなし、自然光で撮影
- テキストは手書き風フォントも OK
- インスタで「一般ユーザーが投稿してる」感覚を大事に

### 投稿間隔
- 週1-2回（毎週水曜 20:00 を軸に、土日 10:00 も活用）
- 月に 4-8件 を目安

### リンク管理
- moradou.jp/shindan へのリンクは毎投稿に含める
- utm パラメータで Instagram からの流入を計測（Instagram_organic）

### 反応が薄い時の対策
1. ハッシュタグの「合計数」を確認（7個に揃える）
2. 投稿時間を変える（20:00 → 土日 10:00 へシフト）
3. テンプレートを変更（A が続いてたら B や C を優先）
4. 事例の「困り」が共感されてるか確認（テーマを変える）
