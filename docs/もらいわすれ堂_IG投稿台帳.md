## 運用ルール(2026-10-06〜)
1. 依頼メールを送る前に、この台帳で「投稿済み・修正済み」を除外する。除外できていない依頼は送らない
2. 制度に触れる投稿・動画は、**投稿直前に**最新の公式一次情報(自治体差のあるものは沖縄県・県内市町村のページ)と最終版を照合してから渡す。照合日と照合者を台帳に書く
3. 遥さんからの「◯番 完了」「修正しました」の報告が来たら、その日のうちにこの台帳へ転記する
4. 休日をはさむ依頼に翌日期限をつけない
5. 台帳の機械化: `scripts/ig_check.py`(Graph APIで実投稿を取得)の Secrets(IG_ACCESS_TOKEN / IG_USER_ID)が設定されれば、投稿済み一覧を自動で突き合わせられる(docs/人間タスク_IG常時チェック_トークン設定.md)。それまでは手入力
