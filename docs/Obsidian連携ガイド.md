# Obsidian連携ガイド — 決定事項が「自動で」溜まる仕組み

最終更新: 2026-09-07 / 見直し期限: 2027-03-07

## 結論(仕組みの考え方)

チャットの会話そのものをObsidianへ写そうとすると、必ず手作業と漏れが出ます。
代わりに、**「チャットで決まったこと・作ったものは、必ずGitHubの文書
(議事・連携メモ・部品庫など)に落とす」という既存ルールを溜まる側の本体**にし、
Obsidianはそれを**自動で写す鏡**にします。

```
チャット(❶〜❺ほか)
   ↓ 決定・学び・仕組みは文書に落とす(既にルール化済み)
GitHubリポジトリ(hojo-hq / glow-docs-private / kakei-crm)
   ↓ 自動で同期(下の手順で設定)
Obsidian(小柳さんの手元。全部をまとめて検索・閲覧)
```

こうすると、**Obsidian側の作業はゼロ**。議事が1本増えるたび、週次レポが
自動生成されるたび、Obsidianに勝手に反映されます。

## 初回セットアップ(1回だけ・30分目安)

1. パソコンに Git をインストール(済みなら飛ばす)
2. まとめ用フォルダを1つ作る(例: `ALLGROUP保管庫`)
3. その中にリポジトリを取得する:
   - `git clone https://github.com/allgroup-inc/hojo-hq.git`(ミカタ+もらいわすれ堂)
   - `git clone https://github.com/allgroup-inc/glow-docs-private.git`(GLOW機密)
   - `git clone https://github.com/allgroup-inc/kakei-crm.git`(家計側。必要なら)
4. Obsidianで「保管庫(Vault)を開く」→ `ALLGROUP保管庫` フォルダを指定
5. Obsidianのコミュニティプラグイン **「Git」** を入れ、
   「自動プル(auto pull)」を10〜30分間隔に設定
   → 以後、新しい議事・レポ・部品が自動でObsidianに現れる

※ 3のprivateリポジトリはGitHubのログイン(トークン)が必要。つまずいたら
   このチャットで「Obsidian設定の途中で止まった」と言ってもらえれば案内します。

## Obsidianでの入口(ここから辿る)

- `hojo-hq/docs/全体マップ.md` — 何がどこにあるかの索引
- `hojo-hq/docs/部品庫.md` — 再利用できる仕組みのカタログ
- `hojo-hq/CLAUDE.md` — 憲法(ルール・体制・再発防止メモ)
- 議事は `議事_` で、連携メモは `連携メモ_` で検索すれば日付順に全部出る

## 「自動で溜まる」を保つための唯一のルール

**チャットで大事なことが決まったら、そのチャットの担当AIに
「これを docs/ に議事(または連携メモ)として残してプッシュして」と一言頼む。**

- 本リポジトリ側のセッションは既にこの運用(議事30本以上が蓄積済み)
- リポジトリ外のチャット(❷❸❹など)は、会話内にしか残っていない決定が
  あり得る。**月1回、各チャットに「今月の決定事項を議事化して連携メモで
  送って」と頼むのが漏れ防止の定期便**(下の棚卸しと同時にやると楽)

## 反映されているかの確認(棚卸し・月1)

1. Obsidianで `議事_` を検索し、今月の日付の議事があるか見る
2. 各チャット(❷❸❹・山梨など)に「今月決めたことで docs/ に無いものは?」と聞く
3. 無かったものを議事化してもらう → 自動でObsidianに入る
4. 既存のObsidianメモ(手書き分)のうち、事業の決定・仕組みに当たるものは
   docs/ 側へ移す(正本は常にGitHub側。Obsidianは鏡に徹する)

## してはいけないこと

- Obsidian側だけに決定事項を書く(鏡に書いても元には映らない。正本はGitHub)
- 機密(顧客情報・営業数値・M&A戦略)を公開側 hojo-hq のフォルダに置く
  (Obsidianの保管庫内でも、必ず glow-docs-private のフォルダ側に置く)
