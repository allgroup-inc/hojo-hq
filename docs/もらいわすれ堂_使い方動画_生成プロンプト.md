# もらいわすれ堂 使い方動画(第二弾)生成プロンプト v1

作成: 2026-08-25 / 用途: 「しらべる→えらぶ→じゅんびする」の流れとシステムの特徴を
やさしく伝える約75秒の動画。ラストは第一弾と同じ虹ロゴ(虹と朝日が自ら描かれて
「もらいわすれ堂」で完成)で締める。

第一弾(ブランドムービー)が「なぜ」を伝える動画なのに対し、第二弾は「どう使うか」の動画。

## 伝えるシステムの特徴(このプロンプトの骨子)

1. **3分でもらい忘れ診断** — 質問に答えるだけ。無料・匿名・登録不要
2. **確認できた制度だけを掲載** — 断定せず「(要確認)」表示、原文リンクつき(正確性最優先)
3. **申請準備シート** — 窓口に行く前の準備が1枚に。「①まず電話(ムダ足をなくす)」
   「②持ち物チェックリスト」「③窓口での会話(このとおりでOK)」の5ステップ
4. **LINEで締切を見守る** — **「締切の約1か月前から」お知らせ**(※「7日前アラート」とは絶対に書かない)

## 注意(第一弾と共通)

- AI動画生成は日本語文字・UIを正しく描けない。**画面の中身は実サイトの画面収録
  (`site/fukugiiro/shindan/`・`kit/`各ページ)を合成**し、テロップ・ロゴは編集で重ねる
- ラストのロゴカットは `video/lp-film-60s/index.html` のS7(公式ロゴSVGの
  stroke-dasharrayアニメ)をそのまま流用するのが最も正確
- 文言は断定しない(「〜かもしれません」)。締切表現は「約1か月前から」で統一

## A. マスタープロンプト(約75秒・9:16)

```
沖縄の家庭のやわらかい朝を舞台にした、約75秒のサービス使い方ムービー。
実写風+画面キャプチャ合成。あたたかい漆喰色(#FFFBF4)基調、カメラはすべてスロー。
ナレーションは落ち着いた女性の声。BGMは三線の音色を含む静かなアコースティック。

[0-6秒] 朝の食卓。湯気の立つお茶とスマホ。手がスマホをゆっくり取る。
タイトル「調べて、えらんで、準備するまで。— もらいわすれ堂の使い方」

[6-18秒] <STEP1 しらべる>
スマホ画面に「3分でもらい忘れ診断」。お住まいの市町村や家族のことなど、
やさしい質問にゆっくりタップで答えていき、進捗バーがすこしずつ進む。
テロップ「質問に答えるだけ。あなたの世帯の“もらい忘れ”候補がわかるかもしれません」
「無料 ・ 匿名 ・ 登録不要」

[18-30秒] <STEP2 えらぶ>
診断結果に、候補の制度カードがならぶ。指がゆっくりスクロールして、
ひとつのカード(例: こども医療費助成)を選んでタップ。
制度ページには「(要確認)」の表示と、市町村の原文ページへのリンク。
テロップ「確認できた制度だけを掲載しています」「断定はしません。最後はかならず原文へ」

[30-46秒] <STEP3 じゅんびする>
画面に「申請準備シート」。「申請までの5ステップ」がゆっくり映る:
「① まず電話(ムダ足をなくす近道)」→ 電話をかける手元のカット。
「② 持ち物チェックリスト」→ チェックボックスにひとつずつ✓が付いていく。
「③ 窓口での会話(このとおりでOK)」→ 台本をなぞる指。
テロップ「窓口に行く前の準備が、1枚のシートに」

[46-56秒] <STEP4 みまもる>
テーブルに置かれたスマホに、やさしい通知のイメージ。
テロップ「締切の約1か月前から、LINEでお知らせ」
「『振り込まれました』の報告が、つぎの誰かの安心になります」

[56-60秒] <まとめ>
漆喰色の画面に4つのことばが順に灯る:
「しらべる」「えらぶ」「じゅんびする」「みまもる」

[60-75秒] <ラスト(第一弾と同一)>
漆喰色 #FFFBF4 に明転。虹のアーチが左から右へ自ら描かれる
(外から珊瑚 #D2694A、陽 #F2C14E、海 #6FAEA4 の3本)。
描き終わると右肩に花びらの朝日(#F5CE6E+中心 #F2C14E)がぽっと咲く。
「とどけ、沖縄のみらいへ。」がふわり、最後に明朝体・赤瓦色(#B9502F)の
ワードマーク「もらいわすれ堂」が現れて静止。2秒ホールドで終わり。
ナレーション「あなたが受け取るまで、いっしょに。もらいわすれ堂です。」
```

## D. 仕様メモ

- 長さ: 約75秒 / 9:16(1080×1920)・16:9書き出しも可 / 全編テロップ必須(無音視聴対応)
- 画面収録の対象: `shindan/`(質問→結果)・結果からの制度ページ・`kit/`の準備シート
  (①電話 ②持ち物 ③会話 の見出しが映る位置)
- 音: 三線アコースティック+ラストに小さな鈴。STEP切替に紙をめくるような効き音
- 禁止: 「締切7日前」表現 / 金額・締切の断定 / LINE以外のCV導線
- 制作は第一弾と同じ仕組み(`video/` 配下にHTML+決定的レンダラ)で実装可能
