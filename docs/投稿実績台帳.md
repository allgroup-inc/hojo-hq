## ステータス

- ✅ 完全照合済み: 制度DBと照合完了。出典URLも最新確認

## 全投稿リスト(整理中)

投稿台帳の完成まで、各投稿の整理は以下に従う:
1. docs/点検_IG投稿済みの照合状況.md から投稿リストを抽出
2. 各投稿について、対応する制度IDを検索・特定
3. 制度DBの出典URL + 照合日時 + 検証状態を記入
4. 矛盾・古い情報があれば「要確認」にマーク
