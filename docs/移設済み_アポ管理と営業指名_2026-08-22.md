# 移設済み: アポ管理システム(家計のポっ)/ お客様から営業指名(面談予約表)

2026-08-22、この2つを本リポジトリ(**公開**)から
**`allgroup-inc/kakei-crm`(非公開)の `apps/appointment/`** へ移設した。

## 理由

顧客の個人情報を扱うシステムは、会社のメンバー以外が見られる状態にしない
(2026-08-22 小柳さん決定。`kakei-crm/CLAUDE.md` 絶対ルール7)。

この2つは「家計の見直しやさん」(株式会社enLife)の営業システムであり、
沖縄企業のミカタ(株式会社GLOW)の案件ではない。本リポジトリはミカタの公開リポジトリのため、
置き場所として適切でなかった。

## 移設したもの

| 移設前(このリポジトリ) | 移設後 |
|---|---|
| `apo-kanri/src/` `dist/` `README.md` `guide.html` | `kakei-crm` の `apps/appointment/` 同名 |
| `tests/apo_kanri_*.test.mjs`(9本) | `apps/appointment/tests/` |
| `scripts/build_apo_bundle.mjs` | `apps/appointment/scripts/` |
| `.github/workflows/apo-kanri-ci.yml` | `.github/workflows/appointment-ci.yml` |
| `docs/家計のポっ_*` `docs/面談予約表_*` `docs/アポ管理アプリ_*` ほか議事・設計15本 | `kakei-crm/docs/appointment/` |

移設先でテスト88件すべてパスを確認済み。

## 本番投入をする人へ

手順書は **`kakei-crm/docs/appointment/家計のポっ_本番投入手順書.md`** にある。
手順は変わっていない。GitHubのURLだけ新しい場所に差し替え済みで、
非公開リポジトリでもログインしていればこれまでどおり開ける。

## 記録として残っていること

本リポジトリの `docs/決裁キュー.md` などに、移設前のパス表記で書かれた過去の決裁記録が残っている。
記録を後から書き換えるといつ何を決めたかが追えなくなるため、そのままにしてある。
読み替え表は `kakei-crm/docs/appointment/README.md` にある。

なお、**移設しても過去の公開履歴・フォーク・キャッシュは消えない**。
履歴の書き換えまで行うかは未決(`kakei-crm/docs/議事_20260822_軸の設立と集約方針.md` 決定7)。
