# 事業紹介動画 台本 v2(TTSペース調整版)

- 作成日: 2026-07-28
- 経緯: v1(`事業紹介動画_台本v1.md`)をローカルTTS(Kokoro, 日本語女声jf_alpha)で検証したところ、
  自然な速度では1.7文字/秒程度と非常に遅く、v1の全文(約360文字)を読むと170秒超になることが判明。
  HeyGenクラウドTTSは環境のネットワークポリシーで接続不可のため使用できない。
  対応として、(1)台本を約30%圧縮、(2)TTS速度を1.4倍に調整、(3)動画尺を60秒→約90秒に許容、
  の3つを組み合わせて対応する(小柳さんへの選択肢提示の上で承認済み)。
- 変更していないもの: 締切表現「約1か月前から」(hojo-deadline-alertルール)、タグライン全文、
  CV(LINE登録の1点のみ)、変動する実数値を書かない方針(hojo-accuracy-checkルール)。
  これらは一字一句そのまま維持。圧縮したのは説明の言い回しのみ。
- ステータス: v1を置き換える現行版。三名体制レビューの結論(採否・見直し期限)はv1から継承。
