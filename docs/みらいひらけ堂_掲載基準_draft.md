# みらいひらけ堂 掲載基準(ドラフト v1・守り部審査/小柳さん決裁待ち)

- 作成日: 2026-09-06 / 決裁後はサイトの /about で**全文公開**する(順位・掲載の透明性が本サービスの信用の核)
- 対象: 沖縄の子ども向け無料学習支援 検索サービス「みらいひらけ堂」(運営: 株式会社フクギイロ)

## 1. 掲載できるサービスの条件(すべて満たす)

1. **無料であること**: 完全無料/一部無料/条件付き無料のいずれか。「無料体験のみで本体は有料」の塾・教材は掲載しない。あとから高額教材等の販売につながる「無料商法」は掲載しない
2. **団体の実在確認**: 次のいずれかを満たす — (a) 法人番号がある (b) 自治体の事業・登録団体である (c) 公式サイト+確認できる活動実績2年以上 (d) 信頼できる後援・助成(国・自治体・主要財団)がある
3. **公式サイト・連絡先が機能している**(URL死活チェック通過)
4. **勧誘目的でない**: 宗教・政治・マルチ商法等への勧誘を目的としない
5. **一次情報で内容確認済み**: 対象・料金・申込方法を公式情報と照合済み(不明項目は「要確認」表示で掲載可。ただし料金が「要確認」のものは掲載保留)
6. **個人が単独で子どもと接触する形態は原則掲載しない**。例外は、運営団体による本人確認/保護者同意の仕組み/オンライン面談の記録ルール/相談窓口 の4点を確認できた場合のみ

## 2. 順位・表示のルール

- 並び順は公開している「おすすめ度」の計算式のみで決める(設計書§11)。**金銭・関係性で順位を変えない。広告枠は存在しない**
- 「×沖縄から利用不可」は検索結果に出さない(参考枠に分離)
- 「△条件次第」「?要確認」は隠さず表示し、確認方法を案内する

## 3. 掲載の手続き

- レコードの状態は draft → verified(検証部の原文照合済み)→ published(守り部審査済み)の3段階。**公開されるのは published のみ**
- 却下時は理由を記録し、依頼者に通知する
- 掲載後も、通報・苦情があれば守り部が再審査し、審査中は非表示にできる

## 4. 取り下げ・鮮度のルール

- last_verified から180日を超えて再確認できないサービスは非表示(要再確認リストへ)
- 募集終了が確認されたら recruitment_status を即日更新(24時間以内)

## 5. 撤退・縮退基準(ウタガイ指摘による。決裁事項)

「古い情報で子どもを振り回すくらいなら畳む」を仕組みにする:

- **黄色信号**: 鮮度KPI(最終確認60日以内の割合)が**80%を2か月連続で下回った**ら、新規掲載を止めて既存の再確認に全工数を回す
- **赤信号**: 60%を下回ったら、published全件を一時非表示にし「更新休止中」を表示。体制を立て直せる見込みがなければ小柳さん決裁でサービス終了(終了時は掲載団体に通知し、サイトに移行案内を出す)

## 6. 子どもの安全・プライバシー(サイト側)

- 会員登録なし・氏名/住所/電話/メール不要。検索条件は端末内処理でサーバーに送らない
- 広告トラッキング・行動追跡を導入しない(集計はCookieレスのページ数のみ)
- 問い合わせ・情報提供フォームに子ども本人の個人情報を書かないよう明記する
