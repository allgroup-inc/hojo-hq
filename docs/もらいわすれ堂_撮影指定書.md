# もらいわすれ堂 世界観フィルム 撮影指定書(v1・2026-08-07)

LP冒頭の「世界観フィルム」(8シーン)の実写素材を集めるための指定書。
サイト側は差し替えるだけの構造になっているため、**素材が届いた順に1シーンずつ反映できる**。
撮影はスマホで十分(横向き・可能なら4K・手ブレはゆっくりパンのみ)。動画は各10〜20秒・無音でよい。

## 調達ルート(どれでも可・混在OK)
- **A. フリー素材(0円)**: Pexels / Pixabay / 沖縄県フォトライブラリ等。商用可・クレジット不要のものだけ使う(守り部ルール)
- **B. 自前撮影(0〜数万円)**: たかしくん・関係者のスマホ/ドローン。「本物の沖縄の日常」が撮れる
- **C. プロ発注(目安10〜30万円)**: 地元ビデオグラファーに半日。この指定書をそのまま渡せば見積もりが取れる

## 笑顔の壁の写真(最重要)
- 枚数: **最低8枚、理想20枚**(子ども・お母さん・お父さん・おじい・おばあ・家族をまんべんなく)
- 条件: 縦位置または正方形 / 顔がはっきり / 自然な笑顔(カメラ目線でなくてよい)/ 逆光NG
- 送り方: このチャットに直接送信、または共有Googleドライブへ(届き次第はめ込み)

## フリー写真の入手リスト(PCで15分・たかしくん向け)
制作環境からは写真サイトに接続できないため、下記を普通のPCでダウンロード → Googleドライブへ(1ファイル10MB以下)。翌日の素材ウォッチが自動ではめ込む。
1. [Pexels](https://www.pexels.com/ja-jp/)(登録不要・商用可・クレジット不要)で検索: 「沖縄 夜景」「okinawa beach sunrise」「japanese family smile」「grandmother smile japan」「children smiling asia」
2. [写真AC](https://www.photo-ac.com/)(無料登録・商用可)で検索: 「沖縄 集落」「エイサー」「三線」「おばあ 笑顔」
3. 各ファイルの**ライセンス表記(商用可/クレジット要否)をメモしてドライブの同フォルダにテキストで残す**(守り部ルール)
4. 人物写真は「モデルリリース(被写体の同意)あり」表記のものだけ選ぶ
※現在サイトには自作イラストのポートレートが入っており、写真が届いた枠から順に実写へ置き換わる。

## 肖像権・同意(守り部ルール・必須)
1. 写る人(未成年は保護者)から**ウェブサイト掲載への同意を書面またはLINEの文面で取得**し、記録を残す
2. 同意の記録は非公開(リポジトリ・チャットに個人名を書かない。管理は提携部)
3. フリー素材はライセンス(商用可・改変可・クレジット要否)をシーンごとに記録する
4. 撮影で第三者が写り込んだ場合は、ぼかすか使わない

## 技術仕様(サイト側)
- 動画: MP4(H.264)+ 可能ならWebM併置 / 1080p / 10〜20秒ループ / 無音 / **1本3〜5MBまで圧縮**(ffmpeg指定は実装側で対応)
- 写真: JPG / 長辺1200pxあれば十分(実装側で圧縮)
- 低速回線・省データ設定では静止画に自動フォールバック(実装済みの方針)
