# もらいわすれ堂 世界観フィルム 撮影指定書(v1・2026-08-07)

LP冒頭の「世界観フィルム」(8シーン)の実写素材を集めるための指定書。
サイト側は差し替えるだけの構造になっているため、**素材が届いた順に1シーンずつ反映できる**。
撮影はスマホで十分(横向き・可能なら4K・手ブレはゆっくりパンのみ)。動画は各10〜20秒・無音でよい。

## 調達ルート(どれでも可・混在OK)
- **A. フリー素材(0円)**: Pexels / Pixabay / 沖縄県フォトライブラリ等。商用可・クレジット不要のものだけ使う(守り部ルール)
- **B. 自前撮影(0〜数万円)**: たかしくん・関係者のスマホ/ドローン。「本物の沖縄の日常」が撮れる
- **C. プロ発注(目安10〜30万円)**: 地元ビデオグラファーに半日。この指定書をそのまま渡せば見積もりが取れる

- 送り方: このチャットに直接送信、または共有Googleドライブへ(届き次第はめ込み)

4. 人物写真は「モデルリリース(被写体の同意)あり」表記のものだけ選ぶ

1. 写る人(未成年は保護者)から**ウェブサイト掲載への同意を書面またはLINEの文面で取得**し、記録を残す
2. 同意の記録は非公開(リポジトリ・チャットに個人名を書かない。管理は提携部)
3. フリー素材はライセンス(商用可・改変可・クレジット要否)をシーンごとに記録する
4. 撮影で第三者が写り込んだ場合は、ぼかすか使わない

## 技術仕様(サイト側)
