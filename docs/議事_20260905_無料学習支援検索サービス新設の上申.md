# 議事: 無料学習支援検索サービス(仮称: まなびのミカタ)新設の上申

- 日付: 2026-09-05
- 関連文書: docs/企画_無料学習支援検索サービス設計_20260905.md
- 種別: 小柳さん決裁が要る事項(新事業立ち上げ・体制・掲載方針)→ 三名体制議事が必須

## 論点: 沖縄の子ども向け・無料学習支援の検索サービスを新設するか

### スイシン(推進)
- 「知らなかったから使えなかった」教育格差は実在し、情報の橋渡しだけで解決余地が大きい。全国の無料支援の大半はオンラインで沖縄から利用可能なのに、当事者に届いていない。
- hojo-hq の既存資産(収集→Claude整形→静的公開→死活監視のパイプライン、検証部・守り部の審査体制)をほぼそのまま流用でき、**追加費用ほぼ0円・3か月でMVP公開**が現実的。
- 非営利・公益の取り組みはグループ(GLOW/ミカタ)の信頼・認知に波及し、学校・自治体・士業との関係構築(提携部の活動)にも間接的に効く。
- 個人情報を取らない設計(登録不要・端末内検索)にすれば、子ども向けでもプライバシーリスクを最小化できる。

### ウタガイ(懐疑)  ← 空欄不可
- **リソース分散の懸念**: 本体KGI(LINE登録1,000社・出口転換月10件)が勝負の時期に、収益ゼロの新事業へ収集部・検証部・守り部の工数(立ち上げ期 週5〜8時間)を割くのは、KGI進捗が計画未達の場合に正当化できない。着手判断の前に本体KPIの現在地を確認すべき。
- **鮮度維持は想像より重い**: 教育支援は募集の開始・終了が頻繁で、古い情報のまま放置すると「頼ったのに募集が終わっていた」と子どもを振り回す。これは絶対ルール1(正確性最優先)への違反であり、**中途半端に運営するくらいなら作らない方がまし**。撤退基準(鮮度KPIを割ったら縮退)を先に決めるべき。
- **子ども向け特有の安全リスク**: 掲載団体で万一トラブル(不適切な接触・無料商法等)が起きれば、紹介したこちらの責任が問われ、グループ全体のレピュテーションに波及する。審査基準の運用が形骸化しないかの監査設計が先。
- **既存類似との差別化が未検証**: 自治体の支援一覧、こども家庭庁や大手NPOのまとめ、無料塾ネットワーク等が既にある。「質問型×沖縄から使えるか」の切り口が本当に未充足かは、公開前に競合調査で裏取りすべき(思い込みで作らない)。
- **本リポジトリはPUBLIC**: 設計書段階は問題ないが、運用開始後の団体審査メモ・却下理由・連絡先などは非公開側(glow-docs-private 等)に置く運用を最初から決めておかないと、機密区分ルール違反が起きる。

### ベッカイ(別解)
- **案A: 新サイトを作らず、既存の大手(カタリバ・キッズドア等)へ「沖縄から使えるか」情報を提供する側に回る**。開発ゼロで目的の一部を達成できる。ただし「質問型検索」「沖縄軸の一覧性」は実現できない。
- **案B: フクギイロ(もらいわすれ堂)の子ども版コーナーとして統合する**。B2Cブランド・制度DB資産の共有と整合的で、新ブランド立ち上げコストが不要。ただし「もらいわすれ」の文脈は福祉色があり、「貧困だから使うサイトと感じさせない」という本企画の核と衝突する懸念。
- **案C: まず"サイトなし"で検証する**。スプレッドシート+印刷リストを子ども食堂・SSW経由で配り、実際に使われるか(問い合わせが来るか)を1か月試してから開発着手する。最小の学習コストで「届くのか」を検証できる。

### 結論(部門長の裁定)
- 採否: **保留・上申**(新事業立ち上げ・体制・掲載方針はすべて小柳さん決裁事項のため、設計書を添えて上申)
- 理由: スイシンの言う資産流用・低コストは事実で、設計書のMVPは実行可能。一方ウタガイの「本体KGIの現在地確認」「撤退基準の事前設定」「競合調査」は着手前に潰すべき正当な指摘であり、ベッカイ案C(サイトなし検証)は本開発の前段として低コストで組み込める。よって「設計は完了・着手は決裁待ち」とし、決裁時に (1)本体KPI現在地 (2)撤退基準 (3)案Cを先行させるか を併せて判断いただく。
