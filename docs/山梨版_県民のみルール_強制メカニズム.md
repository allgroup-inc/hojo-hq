# 山梨版「県民のみ」ルール — 強制メカニズム

**基本原則**: もらいわすれ堂・山梨版は「山梨県民が受けられる制度のみ」を掲載。他県の制度が混ざることは絶対に許さない。

このドキュメントは、その強制メカニズムを 3 層で説明します。

## 1. ビルド時の強制ゲート (`build_yamanashi.py`)

### メカニズム: `_assert_no_okinawa()` 検証関数

**場所**: `scripts/yamanashi/build_yamanashi.py:145-156`

```python
def _assert_no_okinawa(item):
    """山梨版に沖縄の内容が混ざるのを止める。"""
    blob = json.dumps(item, ensure_ascii=False)
    assert "沖縄" not in blob, f'{item["id"]}: 内容に「沖縄」が含まれる'
    url = (item.get("source_url") or "").lower()
    assert "okinawa" not in url, f'{item["id"]}: 出典URLが沖縄ドメイン({url})'
```

**実行箇所**:
1. 国の制度(全国)- 62行目: `for i in nat: _assert_no_okinawa(i)`
2. 県の制度 - 166-168行目: `_assert_no_okinawa(i)` + `assert i["area"] == "山梨県"`
3. 市町村の制度 - 171-172行目: `_assert_no_okinawa(i)` + ドメイン照合

**チェック内容**:
- ✓ 制度名・説明文に「沖縄」の文字がないこと
- ✓ source_url が `okinawa` ドメインでないこと
- ✓ JSON全体で「沖縄」が含まれていないこと

**発動タイミング**: `python scripts/yamanashi/build_yamanashi.py` 実行時
- 違反が見つかると AssertionError で即座にビルド失敗
- GitHub Actions Step 8 で自動検知・CI赤化

## 2. データ構造による強制フィルター

### Tier 1: 全国制度 + 県制度のみ

**build_yamanashi.py:159-162**
```python
src = json.load(open(os.path.join(BASE,"data","fukugiiro","seido.json")))
items = src["items"]
nat = [dict(i) for i in items if i.get("area") == "全国"]  # ← 全国のみフィルター
```

- Okinawa版の `seido.json` から読込時に **"全国" だけ** を抽出
- **県別・市町村別の他県データは読み込まない**（元のデータに無いため混ざり不可）

### Tier 2: A区分市町村のみ

**build_yamanashi.py:99-113**
```python
A_MUNI_DOMAINS = {
    "北杜市": "www.city.hokuto.yamanashi.jp",
    "富士河口湖町": "www.town.fujikawaguchiko.lg.jp",
    # ... (計8市町村)
}
```

**build_yamanashi.py:126-129**
```python
for seed in YMN_MUNI_SEEDS:
    area = it["area"]
    assert area in A_MUNI_DOMAINS, f'{it["id"]}: A区分外の市町村({area})'
    host = urllib.parse.urlparse(it["source_url"]).netloc
    assert host == A_MUNI_DOMAINS[area], f'{it["id"]}: 出典ドメイン不一致({host})'
```

- **ホワイトリスト方式**: 許可されたドメイン以外の市町村データは絶対に受け付けない
- ドメイン照合で、A区分以外の市町村や他県の市町村を自動シャット
- seed データが A_MUNI_DOMAINS に無ければビルド失敗

## 3. 検証フェーズ検査 (`kensho_yamanashi.py`)

### メカニズム: 事後検証

**場所**: `scripts/yamanashi/kensho_yamanashi.py`
**実行**: GitHub Actions Step 9（毎日06:00 / 18:00 JST）

**チェック内容**:
```python
ALLOWED_MUNIS = {"北杜市", "富士河口湖町", "南アルプス市", ...}
allowed = {"全国", "山梨県"} | ALLOWED_MUNIS

for it in items:
    area = it.get("area", "")
    assert area in allowed  # ← area フィールドが許可リスト内か
    assert "沖縄" not in json.dumps(it)  # ← 内容に沖縄が無いか
    assert "okinawa" not in url.lower()  # ← ドメインが沖縄では無いか
```

**出力**:
- `docs/山梨版_突合レポート.md` — 人間が確認する検証レポート
- `data/yamanashi/kensho_summary.json` — 機械が読む検証結果

**失敗時の動作**:
- `continue-on-error: true` のため、ワークフロー自体は続く
- ただし **レポートに ✗ 違反が記録される**
- 次の日次検証でも同じ違反が出ると、検証部がアラート

## 4. 二次防止: 手作業での誤送出

### シード管理によるエスケープ防止

**山梨県種子**: `scripts/yamanashi/seeds_yamanashi.py`
- 県レベルの制度は **手動でシード登録** のみ
- 各シードは守り部審査済み (`docs/守り部審査記録_山梨版_2026-09-20.md`)
- **新しい制度を足すには、必ずシードを通す** → 審査カテゴリが決まる

**市町村種子**: `scripts/yamanashi/seeds_yamanashi_muni.py`
- **同じくホワイトリスト方式**
- A区分 8市町村のみが `seeds_yamanashi_muni.py` に定義可能
- B区分・論点対象市町村は **意図的に種子ファイルを別ける** (tier 2 保留)

## 5. 設計上の安全性

| チェック層 | 対象 | 方式 | 失敗時 | 備考 |
|-----------|------|------|--------|------|
| **ビルドゲート** | 全国+県+市町村 | assert(沖縄チェック) | ビルド中断 | 最強防ぎ |
| **データフィルター** | 全国 | area=="全国" 抽出 | 他県読み込まず | そもそも源を限定 |
| **ホワイトリスト** | 市町村ドメイン | A_MUNI_DOMAINS | ビルド失敗 | 知らないドメインは NG |
| **事後検証** | 全項目 | JSON/URL走査 | レポート ✗ | 人間が日次確認 |
| **シード統制** | 県+市町村 | 手動登録のみ | 新規追加不可 | 意図的追加のみ |

## 7. 違反検知時の対応フロー

### ケース 1: ビルド失敗(Step 8 赤化)
→ `AssertionError` が出る → 原因を確認 → シード or 手作業エラーを修正

### ケース 2: 検証レポート ✗(Step 9 でレポート NG)
→ `docs/山梨版_突合レポート.md` に詳細が出力 → 検証部が翌日確認 → 修正判断

### ケース 3: 手動でのシード追加時
1. `seeds_yamanashi.py` or `seeds_yamanashi_muni.py` を編集
2. `area="山梨県"` 確認
3. source_url が pref.yamanashi.jp or 許可ドメインか確認
4. 内容に「沖縄」が無いか確認
5. `python scripts/yamanashi/build_yamanashi.py` でビルドテスト
6. **ビルド成功後に PR を出す** (失敗では merge 不可)

## まとめ

もらいわすれ堂・山梨版の「県民のみ」ルール は、以下の **5 段階の防ぎ** で実装:

1. **ビルドゲート**: 沖縄混入を AssertionError で即座に落とす
2. **データフィルター**: 源の段階で全国のみ抽出
3. **ホワイトリスト**: 市町村は許可されたドメインのみ
4. **事後検証**: 日次で全項目をスキャン
5. **シード統制**: 新規追加は手動・審査済みのみ

**誰が**どの環節でチェックを逃しても、次の環節で必ず引っ掛かる仕組みになっています。
