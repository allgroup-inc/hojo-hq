ヤンバルクイナ 試作三案

プロンプト集の10方向から、まず出すべき3本をベクターで起こしました。すべて同じ素体（黒い面・白い眉線・腹の横縞・朱の嘴と脚）を共有しているので、どれを選んでも同じキャラクターとして展開できます。

方向 03

ゆるキャラ・着ぐるみ型

いちばん潰しが効く一本。太い輪郭と4色構成で、遠目でも小サイズでも判別できます。配布ステッカー、のぼり、商工会や自治体との協業まで、そのまま持っていける体裁です。差し色をネイビーとオレンジに差し替えれば、企業のミカタ文脈にも寄せられます。

方向 04

脱力・自虐型

「飛べない」という、この鳥だけが生まれつき持っている欠点を正面から使う一本。愛されるキャラは例外なく隙を持っています。ここが当たるとしたらこの案です。コピーが主役になるので、絵は余白を空けて、言葉に主役を渡す設計にしています。

方向 09

カレッジロゴ型

Tシャツとして単価を取れるのはこの系統。頭部だけの紋章にして版数を3色に抑えているので、シルク印刷にもキャップの刺繍にも落ちます。文字は生成AIに描かせず、パスとして持っているため破綻しません。地名は KUNIGAMI / OKINAWA などに差し替え可能です。

次の一手

  • 3案のうち、先に進める1本（複数可）。ここが決まれば表情シート9種とポーズシートに展開します。
  • 名前。クイナん / トコトコ / やんばるん / クーイ のいずれか、または別案。3〜4音が覚えられる上限です。
  • ステッカーを先に出すか、Tシャツを先に出すか。ステッカーのほうが原価も検証コストも低く、反応を見てからTシャツに回せます。

商品化の前に必ず。国頭村・沖縄県・環境省などの既存ヤンバルクイナ公式マスコットと酷似していないか画像検索で目視確認し、名称を本格運用するなら J-PlatPat で先行商標を確認してください。ヤンバルクイナは国の天然記念物・絶滅危惧種のため、轢死を想起させる表現（走る絵に車を併置するなど）は避けています。
