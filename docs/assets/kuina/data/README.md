## 文字について(要確認)

04a・04b の「キョッ」は **すべてアウトライン化済み**です。フォントがない環境でも字形が崩れません。

ただし字形には **IPAゴシック** を使用しています。汎用の本文書体なので、Tシャツの主役としては線が細く、やや素っ気ない印象です。

**最終稿では、選定した見出し書体に差し替えることを推奨します。** 想定していたのは「太めの、やや圧縮された、筆の勢いのある書体」です。差し替える場合は、その書体を持っている環境でアウトライン化してから SVG のパスを置き換えてください。

> IPAフォントライセンスは、作成した作品の利用そのものを制限しません。ただし書体を選び直すかどうかは、見た目の判断として一度検討してください。

## 印刷時のチェック

- [ ] **5cmに縮小して潰れないか**。特に 05a の図鑑は要素が小さく、横 100mm を下回ると雛の目が潰れます
- [ ] **ダイカットの白フチ**は SVG に含まれていません。印刷所側で 2〜3mm のオフセットを指定してください
- [ ] **04a / 04b は2色**。シルクスクリーンなら1版で刷れます。ここがいちばん原価が低いです
- [ ] **09c のたてがみ**は花に見えるという指摘が出ています。房を角ばらせる修正案が保留中です

## 権利・表現上の注意

1. 商品化の前に、国頭村・沖縄県・環境省などの**既存ヤンバルクイナ公式マスコットと酷似していないか**、画像検索で目視確認してください
2. ヤンバルクイナは国の天然記念物・絶滅危惧IA類です。轢死を想起させる表現は使わないでください
3. 名称を本格運用する場合は J-PlatPat で先行商標を確認してください

## 追加: カレッジロゴ(09 / COLLEGE)顔サイズ違い

中央の顔を大きくしたバージョン。3段階を用意しています。**推奨は「大」**です。

| ファイル | 顔の半径 | 倍率 | 特徴 |
|---|---|---|---|
| `kuina-09-college-orig` | 42 | 1.00 | 元。余白が広く、遠目では紺の円に見える |
| `kuina-09-college-L` | 54 | 1.29 | バランス型。文字と顔が拮抗する |
| `kuina-09-college-XL` | 62 | **1.48** | **推奨。20mmまで顔が判別できる** |

比較画像: `kuina-09-college-比較.png`

顔を大きくするにあたり、外周の要素も連動して調整しています。

- `YANBARU` の文字を外側へ逃がし、サイズを 26 → 23 → 21 と縮小
- 内側のリングを r=102 → 104 → 107 へ拡大
- バナーを 180 → 178 → 174 へ上げ、顔の下端と干渉しないよう調整

### 拡大して発覚した不具合(修正済み)

元のサイズでは見えていませんでしたが、**白い眉線が黒い面からはみ出して頭の生成り部分と融合**していました。黒い面を `rx35 ry28` → `rx37 ry30` に広げ、眉線を内側に収めて分離しています。瞳も少し大きくし、中心をずらして「眼鏡」に見えないようにしました。

この修正は3ファイルすべてに反映済みです。元サイズ(`orig`)も修正後のものです。

**PNG**: 各 1200 × 1200 px(300dpi で 102mm 角)。刺繍やキャップに使う場合は SVG から書き出し直してください。

## 追加: F.C. なし版 / 足跡入り

「KUINA F.C.」の F.C. を外した版。**推奨は A2(足跡 両脇)**です。

| ファイル | バナー | 顔 | 備考 |
|---|---|---|---|
| `kuina-09-college-XL-kuina` | `KUINA` | r=62 | A. 文字だけ。いちばん素直 |
| `kuina-09-college-L-kuina` | `KUINA` | r=54 | A の中サイズ |
| `kuina-09-college-XL-kuina-feet2` | `🐾 KUINA 🐾` | r=62 | **A2. 推奨。左右対称で紋章として収まる** |
| `kuina-09-college-L-kuina-feet2` | `🐾 KUINA 🐾` | r=54 | A2 の中サイズ |
| `kuina-09-college-XL-kuina-feet1` | `KUINA 🐾` | r=62 | A3. 足跡は右のみ。動きが出る |
| `kuina-09-college-XL-nobanner` | なし | **r=68** | B. バナーを外し顔をさらに拡大 |

比較画像: `kuina-09-college-FC無し比較.png`

### 設計メモ

- **足跡は 案10「不在」と同じ三本指の形**です。ロゴとステッカーで同じ記号を使うことで、別々の商品がひと続きのシリーズに見えます
- 足跡を入れるにあたりバナーを幅 116 → **152** に広げ、文字の字間を 9 → 7 に詰めています。バナーを広げても紺の円の内側に収まるので、縁からはみ出しません
- A3(右のみ)は文字を左に 9 ずらして、足跡込みで中心が揃うようにしています
- **B(バナーなし)は顔を r=68 まで拡大**しています。下半分が空くぶん、顔を大きくして重心を取っています

### 縮小耐性

比較画像の左下に A2 を 40mm・20mm 相当まで縮小したものを置いています。20mm では `KUINA` の文字と足跡は潰れますが、**顔と紺の円は残ります**。ピンバッジやキャップの刺繍まで想定するなら A2 か B です。
