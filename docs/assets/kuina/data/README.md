## 文字について(要確認)

04a・04b の「キョッ」は **すべてアウトライン化済み**です。フォントがない環境でも字形が崩れません。

ただし字形には **IPAゴシック** を使用しています。汎用の本文書体なので、Tシャツの主役としては線が細く、やや素っ気ない印象です。

**最終稿では、選定した見出し書体に差し替えることを推奨します。** 想定していたのは「太めの、やや圧縮された、筆の勢いのある書体」です。差し替える場合は、その書体を持っている環境でアウトライン化してから SVG のパスを置き換えてください。

> IPAフォントライセンスは、作成した作品の利用そのものを制限しません。ただし書体を選び直すかどうかは、見た目の判断として一度検討してください。

## 印刷時のチェック

- [ ] **5cmに縮小して潰れないか**。特に 05a の図鑑は要素が小さく、横 100mm を下回ると雛の目が潰れます

## 修正: バナー文字の中央合わせ(全ファイルに反映)

`KUINA` が足跡の中点よりわずかに左へずれていました。原因は **字間(letter-spacing)が最後の文字の後ろにも入る** ためです。`text-anchor="middle"` は「字間を含んだ幅」を中央に合わせるので、見た目の文字列は字間の半分だけ左に寄ります。

字間の半分(足跡版なら 3.5)を右へ戻して補正しました。同じ理由で上部の `YANBARU` も左にずれていたため、`startOffset` を 50% → **50.73%** に調整しています。

**この補正はカレッジロゴの全ファイルに反映済み**です。検証画像: `kuina-09-college-KUINA中央補正.png`

### 2階調にした理由

明るいターコイズに生成り `#F4EAD5` を直接乗せると、**明度差が足りず文字と眉線が沈みます**(コントラスト比 約2.1)。そこで面と輪郭を分けました。

| 役割 | 色 |
|---|---|
| 面(円の地) | `#218F87` ターコイズ |
| 輪郭・顔の面・瞳 | `#0B403C` 深緑がかった濃いティール |
| 文字・眉線・リング | `#F4EAD5` 生成り |
| 嘴・バナー | `#E8760E` オレンジ |

比較画像のいちばん右が単階調(輪郭も面と同色)です。顔が地に溶けて輪郭が消えているのが分かります。**2階調にすることで、明るいターコイズのまま顔のコントラストを保てます。**

## 背景について(2026-08-17 変更)

**全ファイルの背景を白 `#FFFFFF` にしました。** SVG・PNG ともにです。ダウンロードして開いたときに、地が抜けて見えないようにするためです。

SVG では `<rect id="bg" ... fill="#FFFFFF"/>` という1行が白地の実体です。

### 透過が必要になったら

**ステッカーのダイカットや、白以外のTシャツに刷る場合は透過が必要です。** そのときは SVG をテキストエディタで開き、`id="bg"` の行を1行削除してください。それだけで元の透過に戻ります。

```
  <rect id="bg" x="0" y="0" width="240" height="240" fill="#FFFFFF"/>   ← この行を消す
```

透過版の PNG が必要な場合は書き出し直しますので、言ってください。

> 印刷所に渡すときは、**白地のままだと「白い四角」として刷られる可能性があります**。ダイカットや濃色ボディに乗せる入稿では、必ず透過版を使ってください。

## 修正: 全ファイルの余白を揃えた(2026-08-17)

**「切れている」箇所を目視ではなく実測で洗い出しました。** ヘッドレスブラウザで各ファイルの実描画範囲(ストローク込み)を測り、viewBox との差を全25点について計算しています。

### やったこと(全25点)
