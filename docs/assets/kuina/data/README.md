## 文字について(要確認)

04a・04b の「キョッ」は **すべてアウトライン化済み**です。フォントがない環境でも字形が崩れません。

ただし字形には **IPAゴシック** を使用しています。汎用の本文書体なので、Tシャツの主役としては線が細く、やや素っ気ない印象です。

**最終稿では、選定した見出し書体に差し替えることを推奨します。** 想定していたのは「太めの、やや圧縮された、筆の勢いのある書体」です。差し替える場合は、その書体を持っている環境でアウトライン化してから SVG のパスを置き換えてください。

> IPAフォントライセンスは、作成した作品の利用そのものを制限しません。ただし書体を選び直すかどうかは、見た目の判断として一度検討してください。

## 印刷時のチェック

- [ ] **5cmに縮小して潰れないか**。特に 05a の図鑑は要素が小さく、横 100mm を下回ると雛の目が潰れます
- [ ] **ダイカットの白フチ**は SVG に含まれていません。印刷所側で 2〜3mm のオフセットを指定してください
- [ ] **04a / 04b は2色**。シルクスクリーンなら1版で刷れます。ここがいちばん原価が低いです
- [ ] **09c のたてがみ**は花に見えるという指摘が出ています。房を角ばらせる修正案が保留中です
