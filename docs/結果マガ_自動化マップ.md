## 人間(小柳さん)に残る作業(週合計 約15分)
1. LINEが届いたらnoteに貼って公開する(金曜の無料ログ5分・8日/22日の有料記事10分)
2. 月曜に「ビュー数と売上」のスクショをチャットへ(この2つはnote管理画面にしか無く、APIでも取れない)

URLをチャットへ貼る作業・X告知の起動・週次点検・素材補充は**すべて不要になった**(2026-09-21〜)。

## ツヅル(チャット)に残る作業
- 月曜にスクショを受け取り、ビュー・売上をKPI台帳に記録し、4点締めで報告する(数字の解釈は人間+AIの仕事)
- 8日・22日の有料記事の公開前検品(出典・名義・有料ライン)
- 判定日・見直し期限の執行(次回: 10月中旬=無料ログ4本でピックアップ0なら抽選仮説を棄却)

## 機械ガード(生成物が世に出る前に必ず通る)
- 数字の実数照合(台帳に無い数字=生成失敗)/ 禁止語 / 名義分離(小柳・ミカタ・ALLGROUP等)/ 丸数字ID / プレースホルダー / 1日1本(同日重複)/ 時刻窓
- 公開記録・X告知のべき等性(already・x_post_url)。二重起動しても二重投稿しない
- 失敗は必ずLINEへ(🚨)。成功に見える失敗(沈黙)は週次ヘルスが拾う
