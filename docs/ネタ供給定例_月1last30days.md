# ネタ供給定例(月1・last30days方式) — 2026-08-07 制定

SNS・note・LINE配信のネタを「制度データの機械生成」だけでなく、
**経営者がいま実際に話していること**から供給する月1定例。
`.claude/skills/last30days`(直近30日の実会話リサーチ)と
`.claude/skills/mindshare-arbitrage`(①発見→②レビュー)を使う。

## 運用(毎月第1営業日)

1. **実行**: 技術部がClaudeセッションで実施(このリポジトリを開いて「今月のネタ供給定例を実行して」)
   - リサーチ観点: 補助金・資金繰り・人手不足・事業承継・価格転嫁 × 中小企業/沖縄
   - 検索対象: Web・X・YouTube・業界メディア等の直近30日
2. **出力**: `posts/neta/YYYY-MM.md` に5〜8本。各ネタに 出典URL / 推奨フォーマット
   (通常投稿・カルーセル・note・LINE配信) / 担当部 を明記
3. **レビュー(人間ゲート=mindshareパイプライン②)**: SNS部・note編集部が
   採用ネタを選ぶ。**事実(制度名・金額・締切)を使う場合は必ず原文照合**(hojo-accuracy-check)
4. **反映**: 採用ネタは generate_sns.py のテーマ・カルーセル・note下書き(tanpatsu)・
   LINE配信文面へ。文面の仕上げは humanizer 必須

## ルール
- ネタ帳は「候補」であり、そのまま投稿しない(レビュー→原文照合→承認ゲートを通す)
- 締切3層ルール・CV単一・誇大表現禁止は通常運用と同一
- 12ヶ月分たまったら古い月から削除(posts/neta/は直近12ファイルまで)
