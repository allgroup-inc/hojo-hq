管理メンバー の皆様

お疲れ様です。

先日デモ画面で確定いただいた「顧客カルテ画面」について、
実装の準備が整いました。

以下の内容で、システムを作る予定です。
「OK」か「修正点がある」かを、簡単にお知らせいただけますでしょうか？

---

## 【タブ1】契約情報タブ

以下の情報を、1人の顧客ごとに表示します：

✓ 契約者・被保険者の名前、生年月日、住所、電話番号
✓ 商品名、証券番号、申込番号
✓ 保険料（月々、年間）、ANP（営業成績）
✓ 申込日、契約日、受渡日
✓ 特約（追加の保障内容）

データは保全QCMから自動で流入します。
変更があれば、QCM側で更新します。

→ この内容で OK ですか？修正点があれば教えてください。

---

## 【タブ2】意向把握・告知内容タブ

以下の情報を、管理メンバーが手入力で記録します：

✓ 面談の記録（いつ、誰と話したか）
✓ 意向把握シート（顧客の希望・懸念点）
✓ 健康告知の状況（告知方法、提出先等）
✓ 社内用メモ（不備チェック、判定結果等）

※告知内容タブ（要配慮情報）は、今は表示しません。
　法務確認後に実装します。

→ この内容で OK ですか？修正点があれば教えてください。

---

## 【タブ3】受け渡し・管理タブ

以下の情報を管理します：

書類の受け渡し・配送:
✓ 受渡日、運送会社、受渡票番号

書類・不備の確認:
✓ 初回引き落とし不備、その他不備
✓ 必要な書類（意向確認書、申込書等）がそろっているか

管理ステータス:
✓ 3段階（未処理 → 進行中 → 完了）

QA・後確認:
✓ QA確認済みか、後確認の予定日

募集・計上:
✓ 募集月、成績計上月

QCM連携:
✓ 基本情報（受渡日など）はQCMから自動で流入
✓ 不備チェックや確認状況は、管理側で手入力

→ この内容で OK ですか？修正点があれば教えてください。

---

## 【タブ4】対応記録タブ

顧客との接触内容を、時系列で表示します：

✓ 接触日時、手段（電話・訪問・メール等）
✓ 対応者、対応内容
✓ 目的（アポ・商談・保全等）

このデータは、既に社内システムに保存されているもので、
自動的に表示されます。

→ この内容で OK ですか？修正点があれば教えてください。

---

## 【チャット機能】

管理メンバーと保全QCM（担当者）が、
リアルタイムでメッセージをやり取りできるようにします：

管理側:
✓ QCMからのメッセージ（「不備が見つかった」等）を受け取る
✓ QCMへ返信する（「確認完了」「対応しました」等）

QCM側:
✓ 同じく管理側からのメッセージを受け取る

※実装は今後で、最初のバージョン（10月中旬）では
　シンプルなメッセージ機能を用意する予定です。

→ この方向性で OK ですか？修正点があれば教えてください。

```

```
