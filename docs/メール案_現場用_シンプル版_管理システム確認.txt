管理メンバー の皆様

お疲れ様です。

先日デモ画面で確定いただいた「顧客カルテ画面」について、
実装の準備が整いました。

以下の内容で、システムを作る予定です。
「OK」か「修正点がある」かを、簡単にお知らせいただけますでしょうか？

---

## 【タブ1】契約情報タブ

以下の情報を、1人の顧客ごとに表示します：

✓ 契約者・被保険者の名前、生年月日、住所、電話番号
✓ 商品名、証券番号、申込番号
✓ 保険料（月々、年間）、ANP（営業成績）
✓ 申込日、契約日、受渡日
✓ 特約（追加の保障内容）

データは保全QCMから自動で流入します。
変更があれば、QCM側で更新します。

→ この内容で OK ですか？修正点があれば教えてください。

---

## 【タブ2】意向把握・告知内容タブ

※このタブは「準備中」と表示されます。
今後の実装で、管理メンバーが記録する予定です。

告知内容（要配慮情報）は、法務確認後に実装します。

→ この進め方で OK ですか？何か質問あれば教えてください。

---

## 【タブ3】受け渡し・管理タブ

保全QCMから自動で流入する情報を表示します：

✓ 受渡日（いつ書類を受け取ったか）
✓ 運送会社（配送業者名）
✓ 受渡票番号（配送追跡番号）

詳しい不備チェックや管理ステータスなどは、
今後のバージョンアップで加えます。

QCM連携:
✓ 基本情報（受渡日など）はQCMから自動で流入
✓ 管理メンバーの手入力は最小限に

→ この内容で OK ですか？修正点があれば教えてください。

---

## 【タブ4】対応記録タブ

顧客との接触内容を、時系列で表示します：

✓ 接触日時、手段（電話・訪問・メール等）
✓ 対応者、対応内容
✓ 目的（アポ・商談・保全等）

このデータは、既に社内システムに保存されているもので、
自動的に表示されます。

→ この内容で OK ですか？修正点があれば教えてください。

---

## 【チャット機能】

管理メンバーと保全QCM（担当者）が、
リアルタイムでメッセージをやり取りできるようにします：

管理側:
✓ QCMからのメッセージ（「不備が見つかった」等）を受け取る
✓ QCMへ返信する（「確認完了」「対応しました」等）

QCM側:
✓ 同じく管理側からのメッセージを受け取る

※実装は今後で、最初のバージョン（10月中旬）では
　シンプルなメッセージ機能を用意する予定です。

→ この方向性で OK ですか？修正点があれば教えてください。
