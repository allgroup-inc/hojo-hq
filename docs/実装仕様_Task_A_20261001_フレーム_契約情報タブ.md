## 🔧 技術仕様

### API 呼び出し

**エンドポイント**: `GET /api/customers/dossier`

**リクエスト**:
```javascript
const url = `/api/customers/dossier?id=${encodeURIComponent(customerId)}`;
fetch(url, {
    headers: { 'Content-Type': 'application/json' }
});
```

**レスポンス**（該当部分）:
```json
{
  "customer_id": "KM-XXXXXX",
  "last_name": "山田",
  "first_name": "太郎",
  "address": "東京都千代田区",
  "contracts": [
    {
      "policy_number": "POL-123456",
      "carrier": "ネイティブ生命",
      "product": "終身保険",
      "settled_date": "2026-01-15"
    }
  ]
}
```

### HTML 構造

**ヘッダー**:
- 顧客ID
- 契約者名（姓 + 名）
- 住所

**Tab 1 コンテンツ**:
```html
<table>
  <thead>
    <tr><th>証券番号</th><th>保険会社</th><th>商品</th><th>成立日</th></tr>
  </thead>
  <tbody>
    <!-- 各契約ごとに1行 -->
  </tbody>
</table>
```

### JS ロジック

**初期化フロー**:
1. URL パラメータから `id` を取得
2. `API_CLIENT.getCustomerDossier(id)` を呼び出し
3. レスポンスに基づいて画面をレンダリング
4. エラー時は `showError()` で表示

**データマッピング**:
```javascript
contract.policy_number || contract.raw        // 証券番号
contract.carrier || contract.insurer          // 保険会社
contract.product                              // 商品
contract.settled_date || contract.settled_on  // 成立日
```

### CSS スタイル

- **カラースキーム**: EnLife ゴールド #F6C83E、インク #241F14、クリーム #FFFBF4
- **レイアウト**: CSS Grid（タブレット以下で2列折り返し）
- **テーブル**: ストライプなし、ホバー時背景色変更
