**当面の想定:**

```javascript
// 想定される実装パターン

// パターン A: セッション Cookie（同一ドメイン）

  showError("ログインしてください");
}

// パターン B: URL トークン

  showError("認証情報がありません");
}

// パターン C: API トークン（Authorization ヘッダー）
```
