## 背景

GLOW営業管理システムの Phase 11 として、以下3つの自動連携機能を実装予定です：
- LINE Official Account からの問い合わせ数・傾向を自動取得・表示
- Instagram ビジネスアカウントのメトリクス（フォロワー、エンゲージメント）を自動取得・表示
- QRコード発行数・アクセス履歴の自動追跡

これらの機能を最適に導入するため、現在の営業プロセス・運用方法についてヒアリングさせていただきたく、本フォームをお送りしております。

### Q1. LINE Official Account からの問い合わせ管理（必須）

**現在、LINE Official Account（公式LINEアカウント）での問い合わせ管理はどのような方法で行われていますか？**

<details>
<summary>選択肢（複数選択可）</summary>

- [ ] **管理画面** : LINE Official Account 管理画面（manager.line.biz）で一元管理している

- [ ] **Slack** : LINE からのメッセージを Slack に転送している
- [ ] **Google Forms** : Google Form に直結させて回答を自動記録している
- [ ] **スプレッドシート** : LINE チャットボットから Google Sheets に自動送信している

</details>

- 月間平均問い合わせ数は？ (例: 50件/月)

### Q3. QRコード運用・アクセス追跡（必須）

**QRコードの発行・アクセス追跡は現在どのような方法で行われていますか？**

<details>
<summary>選択肢（複数選択可）</summary>

- [ ] **未実装** : 現在 QRコード を使用していない
- [ ] **汎用 QRコード生成** : 汎用 QRコード生成ツール（QR Coder など）を使用している
- [ ] **短縮URL** : Bitly や TinyURL などで短縮URL と アクセス数を追跡している
- [ ] **Google Analytics** : Google Analytics 内で QRコード 経由のアクセスを追跡している
- [ ] **カスタム解析** : 自社開発の追跡システムを使用している
- [ ] **その他** : （説明してください）

</details>

**補足:**
- 年間発行枚数は？ (例: 5,000枚)
- QRコード の用途は？ (例: 紙DM / カタログ / イベント)
- アクセス追跡は どのようなデータを記録していますか？ (例: アクセス日時 / 企業ID / デバイス)
- 誰がQRコード発行・管理を行っていますか？
