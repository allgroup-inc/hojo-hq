# IG Template 2: Triage Flow

**Created:** 2026-09-28

## Template Overview

Single-page Instagram template (1080×1350px) for promoting subsidy/support programs with 3-step service flow.

**Design Elements:**
- Navy #00335C → Orange #F88800 gradient (top to bottom)
- Title: "沖縄県の中小企業へ 無料デジタル化サポート" (80pt bold, white)
- 3-step flow: 相談 → 診断 → 実装 (with icons and connecting arrows)
- Editable phone field: Freephone "0570-XXXXXX"
- Editable QR code: 150×150px (bottom right)
- White text throughout
- Text shadow for readability

## How to Use

1. **Customize Title:** Edit the title text to match the specific subsidy/program name
2. **Update Phone Number:** Replace "0570-XXXXXX" with actual program contact number
3. **Replace QR Code:** Upload your QR code image (LINEbot friend-add endpoint)
4. **Export:** Use browser "Print to PDF" (Ctrl+P / Cmd+P) to export as PDF
