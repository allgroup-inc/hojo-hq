## Technical Notes

### Canvas Size Rationale
- 1080×1350px: Instagram carousel standard (4:5 aspect ratio)
- Provides optimal mobile viewing experience
- Compatible with Canva's preset dimensions

### Font Selection
- **Meiryo**: Preferred for Japanese text clarity
- **Noto Sans JP**: Acceptable web alternative (better browser support)
- Both fonts available in Canva's font library

### Color Psychology
- **Navy #00335C**: Trust, professionalism, brand consistency
- **Orange #F88800**: Energy, urgency, call-to-action appeal
- High contrast ensures accessibility

### Accessibility Standards
- WCAG AA compliant color contrast (4.5:1 minimum for normal text)
- All text must be selectable (not in images)
- PDF exports maintain text selectability

## Troubleshooting

### Issue: Text Overflow on Long Industry Names
**Solution**: Reduce font size to 20pt or abbreviate industry name

### Issue: Colors Don't Match
**Solution**: Verify hex codes in color picker:
- Navy: #00335C (not #003366 or similar)
- Orange: #F88800 (not #FF8800 or #F89000)

### Issue: PDF Export is Blurry
**Solution**: 
1. Re-export with "High Quality" setting
2. Ensure 300 DPI is selected
3. Verify image assets are high resolution

### Issue: Canva Font Not Showing Correctly
**Solution**: 
1. Check if Meiryo is available in your Canva account
2. If not, use Noto Sans JP (nearest equivalent)
3. Maintain font weights (Bold for headings, Regular for body)
