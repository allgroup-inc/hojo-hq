# 議事: LINE締切アラートで扱う公募の範囲

## なぜ(背景)

2026-11-24、LINE締切アラートの出荷ゲート再点検(PR #640)で、配信下書きの対象18件を調べた。

- 18件すべてが国(jGrants)の公募で、沖縄県・県内市町村の制度は0件
- 6件は調査・委託・研究開発の公募(例: 技術(特許)動向調査、量子コンピュータ次世代機の開発)。補助金ではなく、沖縄の中小企業がそのまま申し込む性質のものではない
- 「大企業向け(901名以上)」や「上限250億円」の公募も含まれていた
- 沖縄の中小企業がそのまま使いやすいのは、小規模事業者持続化補助金など少数

LINEは登録者(沖縄の経営者)に直接届く。関係の薄い公募を並べると、本当に使える公募が埋もれ、通知を読まれなくなる。

小柳さん決裁(2026-11-24): 「推奨で進めてください。すべて一任します」「承認します」(推奨案: 沖縄県・県内市町村の制度と、国の制度のうち中小企業・小規模事業者向けに絞り、調査・委託・研究開発は外す)。

## 前提

- 対象は LINE配信の下書き(`posts/line/alerts_latest.md`・`data/line_alerts.json`)だけ。サイトの制度一覧・検索・診断からは1件も消さない
- 配信は人(LINE部)が下書きをコピーして行う。この変更は送信を増やさない
- 判定に使えるのは jGrants の項目(名称・事業名・従業員要件・上限額)だけ。業種の項目(target_biz)は空のことが多く使えない

## 代替案

1. 何もしない(全国の公募をすべて並べる)
2. 沖縄県・県内市町村の制度だけにする
3. 推奨案: 沖縄・事業承継の制度はすべて扱い、全国の公募から「調査・委託・研究開発」「大企業向け(301名以上の従業員要件)」「上限10億円以上」を外す

## 三名体制の議論

### スイシン(推進)
- 案3なら、今日の18件は10件になり、沖縄の中小企業が申し込める公募が上に来る。登録者にとって「読む価値のある通知」になり、LINE登録の価値(締切アラート)が上がる
- 判定の語と閾値を定数にまとめ、自己テストで正例・負例を固定するので、あとから直しやすい

### ウタガイ(懐疑・反対)
1. 名称の語(「調査」「実証」など)で外すと、中小企業が使える補助金まで外す恐れがある。例: 「〇〇実証事業補助金」が中小企業向けのこともある
2. 「上限10億円以上」は、中小企業も申し込める枠を持つ大型の補助金(例: 枠ごとに上限が違うもの)を外してしまう。上限額は事業全体の最大値で、個社の目安ではない
3. 外した公募が見えなくなると、判定の誤りに誰も気づけない。「LINEで扱わない」は静かな脱落になりうる
4. 沖縄の制度が締切つきで少ない(今日の窓に0件)ため、絞った結果として LINE で知らせる件数自体が少なくなり、配信の機会が減る

### ベッカイ(別解・前提を疑う)
- そもそも「件数を並べる」配信より、登録者の業種・規模で出し分けるほうが筋がよい。ただし LINE の属性(業種・規模)はまだ集めていないため、今は採れない
- 判定を名称に頼らず、jGrants の「利用目的」「対象業種」を使えれば精度が上がる。収集側の項目追加が必要で、別件にする

## 結論(部門長の裁定)

- 採否: 採用(案3)
- 理由: 案1は関係の薄い公募が通知を埋め、案2は今日の窓で0件になり配信の価値が下がる。案3は、ウタガイの指摘を次のとおり受け止めたうえで採る
  - 指摘1・2: 外す条件は狭くとる(「研究開発」「技術開発」「調査」「委託」「実証」のどれかを名称または事業名に含むもの、従業員要件が301名以上、上限10億円以上)。沖縄県・県内市町村・事業承継の制度は、語や金額にかかわらず必ず扱う
  - 指摘3: 外した件数を理由別に、配信下書きの冒頭に毎日書く(「LINEで扱わない公募: 調査・委託・研究開発 N件 …」)。サイトの一覧には残るので、利用者が探せなくなることはない
  - 指摘4: 見直し時に、LINE で知らせた件数と、外した公募のうち実際に中小企業が使えたものがあったかを確かめる
- 見直し期限: 2027-05-24(最長6か月)。外した公募のうち中小企業向けのものが見つかったら、期限前でも条件を直す
