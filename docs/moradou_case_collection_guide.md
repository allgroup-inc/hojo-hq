# もらいわすれ堂：事例収集フロー・Notionテンプレート構築ガイド

**目的**: 沖縄県民の「実際に制度を受給して生活が楽になった」実例を、ヒアリング → 記録 → 投稿確認 の3段階で収集・管理する

**タイムライン**: Week 1（10月23日）からヒアリング開始。月10件を目安に累積

---

## Part 1: ヒアリング質問票

### 【初回接触時（電話 / メール）】

1. **「制度を受給された事例をお持ちですか？」**
2. **「その経験を、同じような沖縄県民へのメッセージとして公開することは可能ですか？」**
   - ✅ OK → 詳細ヒアリングへ進む
   - ❌ NG → 終了。感謝の言葉を伝える

---

### 【詳細ヒアリング（15分。音声メモ + テキストメモ）】

#### 📌 背景（2分）

- **Q1. お名前**  
  公開可能な呼び方をお教えください。例：「田中さん」

- **Q2. 家族構成**  
  子どもの人数・年齢、親の扶養など。例：「小学1年と4年の子がいます」「両親を扶養しています」

- **Q3. 当時どんなお金の悩みがあったか**  
  具体的な困りをお聞かせください。  
  例：「保育料が毎月5万円かかっていた」「高校の教育費が足りない」「生活費が苦しかった」

#### 💡 発見（3分）

- **Q4. この制度をどうやって知りましたか？**  
  例：「もらいわすれ堂のサイトで診断してみた」「〇〇さんから聞いた」「商工会の職員に勧められた」

- **Q5. 制度を知る前に、他の方法で探していましたか？**  
  例：「ネットで補助金を検索していた」「特に探していなかった」

- **Q6. もらいわすれ堂を見つけたときの感情**  
  例：「こんなものがあるのか」「ようやく見つけた」「助かった」

#### 📋 申請プロセス（5分）

- **Q7. 準備で最も困ったことは？**  
  例：「書類の集め方がわからなかった」「何が必要か分からなかった」

- **Q8. 書類作成で分からなかった点は？**  
  具体例をお聞かせください。

- **Q9. 相談窓口に問い合わせましたか？ 対応はどうでしたか？**  
  例：「〇〇市役所に電話した、対応は丁寧だった」「返答が遅かった」

- **Q10. 士業さんに相談しましたか？ 役に立ちましたか？**  
  例：「社労士に相談した、書き方を指導してくれた」

#### 🎯 成果（2分）

- **Q11. 実際に受給できましたか？ 金額は？**  
  匿名の場合：「月1万円程度」「年20万円程度」など幅を持たせてOK

- **Q12. 受給後、何が変わりましたか？**  
  例：「心理的に安心できた」「子どもの教育にお金をかけられるようになった」「毎月の生活が楽になった」

- **Q13. もし同じような沖縄県民へ一言メッセージを書くなら、何と言いたいですか？**  
  例：「制度があることを知るだけで人生が変わります」

#### ✅ 掲載確認（3分）

- **Q14. この内容を Instagram で紹介することは OK ですか？**

- **Q15. 氏名は明かしてもいいですか？ それとも匿名がいいですか？**  
  選択肢：「氏名を明かす」「名字のみ」「完全匿名」

- **Q16. 掲載前に「こんな風に書いてもいいか」という確認、もう一度させてもらえますか？**  
  事例を記事化する際の最終確認が必須

**対象制度**：_______________

#### 【個人情報保護】（※ すべて□にチェック必須）

- [ ] 本人から掲載許可を再度確認した
- [ ] 氏名の表記が同意内容と一致している（氏名/名字のみ/匿名）
- [ ] 住所・電話番号・メールアドレス等は含まない
- [ ] 金額は「約XX万円」など幅を持たせてある（正確な金額ではない）
- [ ] 掲載前に本人に「こういう記事で紹介します」と読み聞かせ・メール送付した

#### 【事実確認】（※ すべて□にチェック必須）

- [ ] 制度名は正確（seido.json と照合）
- [ ] 受給額は本人へのヒアリングと一致
- [ ] 申請日や受給日は本人が確認した（推測で書いていない）
- [ ] 「生活が楽になった」「子どもの教育費が確保できた」等の成果は本人の言葉を引用

#### 【法務・トーン確認】

- [ ] 「絶対」「必ず」等の断定表現がない（可能性・期待値のみ）
- [ ] 特定の士業を「推奨」していない（選択肢を複数提示）
- [ ] 制度の詳細は記事で説明していない（詳細は公式サイトへのリンク）
- [ ] 素人らしいトーンを維持（完璧な企業発表ではない）

#### 【品質確認】

- [ ] タイポ・誤字がない
- [ ] ハッシュタグが5-10個程度（多すぎない）
- [ ] 画像が1-3枚（文章メインで見やすい）
- [ ] リンク（診断ページ、相談窓口）が有効

#### 【最終判定】

- ✅ OK → そのまま投稿
- 🔄 修正後OK → 下記修正内容を反映後に再チェック
- ❌ 不適切 → 本人に相談し修正または掲載中止

## Part 5: 運用フロー（周次）

### Week 1（即座）
1. 提携先（士業・商工会・金融機関）へ「受給成功の事例を紹介させてもらいたい」と打診
2. LINE・メール過去ログから許可を得た上で対象者をリストアップ
3. 初回接触電話/メール（5-10件を目標）
4. 詳細ヒアリング実施（1件あたり15分）

### 毎週
1. ヒアリング完了した事例を Notion に記録
2. テンプレート A/B/C のいずれでいくか判定
3. 投稿下書き作成 → 投稿前確認チェック実施
4. Instagram に投稿（週1-2回）

### 月次
1. 累積ヒアリング件数を確認（目標：月10件）
2. 投稿のリーチ・エンゲージメント数を記録
3. 診断ツール流入への影響を GA4 で確認

## 特記事項

**個人情報の極秘性**:
- ヒアリング記録は Notion に保管。完全匿名のコピーのみを記事化
- 掲載前の「再確認」は必須。「勝手に書かれた」というトラブルを防ぐため

**透明性と信頼**:
- 素人らしさを維持。完璧な企業プレリリースではなく「本当に困った人が解決した」ストーリーを強調
- 数字は幅を持たせる。正確な金額よりも「こんなお金が手に入った」という実感を重視

**事例の真実性**:
- 実際に受給成功した事例のみ。進行中や不認可案件は含めない
- 自治体サイトやヒアリング記録で事実確認を必ず行う
