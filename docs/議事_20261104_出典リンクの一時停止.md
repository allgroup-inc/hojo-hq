# 議事: 公式ページが無い(404/410)出典のリンクだけを一時停止する

## なぜ(背景)

2026-11-04 の収集(PR #566 統合後の初回)で、児童扶養手当の出典 `https://www.pref.okinawa.lg.jp/kyoiku/kosodate/1008226/1008243/index.html` が HTTP 404 と記録された(`data/fukugiiro/publish_status.json`)。同じURLを出典にしている `fk-ken-hitorioya-sodan`(沖縄県 ひとり親家庭支援)は、到達性の確認を省く設定のため公開され続け、診断ページ・トップ・申請準備シート・場面別ページから、開けない公式ページへリンクしている(絶対ルール1に関わる)。

小柳さん承認(2026-11-04): 404/410 が確認された公式出典は、制度自体は削除せず、出典リンクのみ一時的に無効にする。「公式ページを確認中」と表示し、制度が終了したと誤解されない文面にする。404/410 未確認のURLは推測で変更しない。正しい公式URLを原文確認後に復旧できるようにする。既存の制度データと公開更新の安全装置を維持する。

## 前提

- 正しい公式URLは、作業環境から県・国のサイトに接続できないため原文で確かめられていない(調査記録は PR #569 で追加)
- 404 を確かめたのは上の1URLだけ。同じ階層の `…/1008243/1026858.html`(`fk-ken-kouto-shokugyo-kunren`)は未確認
- 収集は、到達性を確かめるシードについて HTTP ステータスを記録している(PR #566)

## 代替案

1. 制度を掲載から外す: 制度は残っている可能性が高く、利用者が受け取れる制度を見落とす。小柳さんの方針で不採用
2. 推測で新しいURLに差し替える: 絶対ルール1に反する。不採用
3. リンクを残して注意書きだけ足す: 開けないリンクを押させることになる。不採用
4. **出典リンクだけを止め、「公式ページを確認中」と表示する(採用)**

## 三名体制の議論

- **スイシン(推進)**: 制度は残したまま、開けないリンクだけを止められる。止める対象は収集で 404/410 を確かめたURLだけで、シードの `source_url` を直せば次の収集で自動的にリンクが戻る。生成ページは、印の無い制度については1バイトも変わらない(現行データで確認)
- **ウタガイ(懐疑・反対理由。必須)**:
  1. 404 は一時的なこともある(サイトの作業中など)。その回だけリンクが消える
  2. 「制度が終わったという意味ではありません」と書くが、本当に制度が終わっていた場合は誤った安心を与える
  3. 止めた状態が長く続くと、要確認のまま放置される。リンクが無いぶん、利用者は自分で探す手間が増える
  4. 確定分の記録(`CONFIRMED_DEAD`)を手で持つことになり、外し忘れが起きうる
- **ベッカイ(別解・前提を疑う)**: リンクを止める代わりに、県のトップページや「ひとり親家庭支援」の上位ページに案内する方法もある。ただし上位ページのURLも原文で確かめていないので、今は採れない

## 裁定

採用する。指摘1は、その回の収集で開けた(HTTP 200)URLは記録があっても止めず、503・タイムアウトでは止めない。404 は次の収集で開ければ自動で戻る。指摘2は、文面を「制度が終わったという意味ではありません」(表示の意味の説明)にとどめ、「制度は続いています」とは断定しない。内容と申請は窓口で確かめるよう案内し、状態は「要確認」のまま変えない。指摘3は、止めた制度を収集ログの警告に毎回出し、出典の修正(PR #569 の後続)を急ぐ。指摘4は、記録に根拠(日時・制度・記録の所在)を必須とし、シードのURLを直せば別のURLになるため記録が残っていても効かない。ベッカイ案は、上位ページを原文で確かめられたら再検討する。

## 見直し条件

- 見直し期限: 2027-05-04
- 止めている制度が30日以上続いたら、出典の修正が止まっていないかを再議論する
- 404/410 以外(403 の遮断など)でも止めたくなったら、再議論する(遮断はページが無いことを意味しない)
