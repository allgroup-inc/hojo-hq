# KachiTalk品質管理ダッシュボード セットアップガイド

**概要**: KachiTalkの通話ログを6段階営業プロセスチェックリストに対応させ、各営業マンの品質分析＆売上相関を可視化

**対象営業マン (8名)**:
- 前原　芳乃
- 奈須　章
- 下地　健太
- 幸良　妃奈代
- 徳元　孝樹
- 喜納　礼奈
- 名嘉山　望
- 狩俣　亜希乃

**対象期間**: 8月・9月

---

## システム概要

### 目的
各営業マンの通話内容が、下記の6段階営業プロセスにどの程度対応しているかを可視化し、売上(KPI実績)との相関を分析する。

### 6段階営業プロセス

| # | プロセス | 目的 | 重点ポイント |
|---|---|---|---|
| ① | アプローチ（名乗り） | 顧客との信頼構築・緊張緩和 | 丁寧な自己紹介・話しかけ |
| ② | ヒアリング | 顧客の問題・ニーズ把握 | 過去データのおさらい・課題聞き取り |
| ③ | 提案 | 顧客ニーズに合致した提案 | ご意向に沿った保障内容か確認 |
| ④ | クロージング | 申込への案内・促進 | 申込手続きの説明・同意取得 |
| ⑤ | 申込・契約 | 申込手続き実行 | 契約書署名・捺印完了 |
| ⑥ | 紹介入手 | 紹介顧客獲得 | 知人・親戚の紹介予約 |

### 管理シート構成

```
Google Sheet: 営業品質管理（エンライフ）
├─ 統合ダッシュボード★: すべての分析結果を1枚で確認（最初に見るシート）
├─ カチトークログ: 通話ログの6段階チェックリスト記録
├─ 品質分析: 営業マン別の分析サマリー（詳細データ）
├─ チェックリスト合致度: 6段階の実施率一覧表
├─ 成績相関分析: 品質スコア×売上KPI相関
└─ サマリー: 簡易ダッシュボード

★統合ダッシュボード: 
  - チーム全体の平均スコアと総通話件数
  - 全営業マンの品質スコア・評価・実施率をランキング表示
  - ⑤申込・⑥紹介の実施率による改善優先度分析
  - 色分けで瞬時に課題を把握可能
```

## セットアップ手順

### ステップ1: Google Sheetの初期化

#### 1-1. 新規 Google Sheet を作成
1. Google Drive を開く
2. **「新規」→「Google Sheets」** をクリック
3. タイトル: `営業品質管理（エンライフ）`

#### 1-2. GAS コードを追加
1. メニュー: **拡張機能 → Apps Script**
2. エディタが開く → 既存のコード（あれば）を確認
3. **新規ファイル**をクリック → **スクリプト**を選択
4. ファイル名: `KachiTalkQualityAnalyzer`
5. `enlife/src/KachiTalkQualityAnalyzer.gs` の全コードをコピーして貼り付け
6. **Ctrl+S** (Mac: Cmd+S) で保存

#### 1-3. シートを初期化
1. 関数選択: **`ensureKachiTalkAnalysisTabs`**
2. **▶実行** をクリック
3. 権限確認 → **許可**
4. 実行ログ: `✓ KachiTalk分析タブの初期化完了`
5. Google Sheet を確認 → 7つのシートタブが表示される:
   - **カチトークログ** (ログ入力用)
   - **品質分析** (分析結果)
   - **チェックリスト合致度** (6段階の実施率)
   - **成績相関分析** (品質 × 売上)
   - **サマリー** (ダッシュボード)
   - **統合ダッシュボード** (全データ1枚表示) ★推奨
   - **営業成績データ** (訪問記録・スコア) ← NEW

### ステップ5: KPI相関分析

#### 5-1. 相関分析シートを更新
1. Apps Script: **`buildCorrelationAnalysis`** 実行
2. 「成績相関分析」シートが更新される
   - 品質スコア × 8月ANP実績 × 8月契約件数
   - 品質スコア × 9月ANP実績 × 9月契約件数
   - 改善領域（質×売上が低い部分）

#### 5-2. 相関パターンの読み方

**パターン①: 品質高×売上高（理想）**
- 営業マン: 品質スコア80以上 かつ 9月ANP成績トップ層
- 対応: このメンバーの話し方を他メンバーへ共有

**パターン②: 品質高×売上低（潜在能力あり）**
- 営業マン: 品質スコア80以上 だが 9月ANP成績がボトム層
- 改善点: 紹介入手(⑥)の実施率が低い可能性 → クロージング後のアクションが足りない
- 対応: 紹介獲得の仕組み強化

**パターン③: 品質低×売上高（属人性が高い）**
- 営業マン: 品質スコア70未満 だが 売上は良好
- 改善点: ③提案や④クロージングをスキップしている可能性
- 対応: 標準プロセスの厳格化（将来の持続性向上）

**パターン④: 品質低×売上低（要改善）**
- 営業マン: 品質スコア70未満 かつ 売上も低い
- 対応: 優先順位 高。①②③④の基本5項目の定着支援

## 運用フロー

### 毎月の実行スケジュール（例）

```
月末最終営業日
├─ KachiTalk管理画面からログをエクスポート
├─ CSV を「カチトークログ」に入力
└─ 下地・小柳さんへ報告 → レビュー

翌月初（月初3営業日以内）
├─ Apps Script で analyzeKachiTalkQuality("当月") 実行
├─ buildCorrelationAnalysis() で相関分析更新
├─ 「サマリー」ダッシュボード確認
└─ 改善点リスト（⑥実施率低い など）をミーティング共有
```

### 品質スコアの計算式

```
品質スコア = (実施ステップ数 / 6) × 80 + (通話時間 / 20分) × 20

例)
- 通話A: ①②③④⑤は実施、⑥未実施、時間18分
  = (5/6) × 80 + (18/20) × 20 = 66.7 + 18 = 84.7点

- 通話B: ①②④⑤は実施、③③の提案スキップ、⑥未実施、時間15分
  = (4/6) × 80 + (15/20) × 20 = 53.3 + 15 = 68.3点
```

### 評価基準

| スコア | 評価 | 対応 |
|---|---|---|
| 85以上 | 優秀 | このメンバーのやり方を他メンバーへ展開 |
| 70～84 | 良好 | 弱点領域（⑥実施率 など）を強化 |
| 60～69 | 要改善 | ①②③④の基本ステップの定着支援 |
| 60未満 | 要指導 | 上司同席での通話指導 |

## トラブルシューティング

### 「カチトークログシートが見つからない」
**原因**: ensureKachiTalkAnalysisTabs() が実行されていない
**対策**:
1. Apps Script エディタで ensureKachiTalkAnalysisTabs() を再度実行
2. Google Sheet をリロード

### 「データが反映されない（品質分析が空白）」
**原因 1**: カチトークログシートにデータがない
**対策**: 「カチトークログ」タブを確認し、CSVデータが入力されているか確認

**原因 2**: チェックリスト列の形式が違う
**対策**: 「①アプローチ_実施」列に「○」(またはTRUE)が入力されているか確認

### 「営業マン名が認識されない」
**原因**: スペースの形式が違う（全角スペース vs 半角スペース）
**対策**: 営業マン名をコピーして確認:
```
正しい: 「前原　芳乃」（全角スペース1個）
誤り:   「前原  芳乃」（全角スペース2個）
```

### 「相関分析がエラーになる」
**原因**: KPI分析シートが存在しない
**対応**: 
1. 営業成績管理システムでKPI分析シートを作成
2. その後 buildCorrelationAnalysis() を実行
