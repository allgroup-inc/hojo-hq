# 議事: 申請準備シート「印刷できない人」対応(2026-08-17・小柳さん発案)

背景: 申請準備シート(kit/ 176ページ)は「印刷して窓口へ」前提。プリンターがない世帯
(スマホのみ・高齢・ひとり親など、本来いちばん届けたい層)が置き去りという指摘。
案A=スマホ完結モード、案B=コンビニ印刷手順、の採否と実装範囲を裁定する。

## 論点: 案A(スマホ完結)・案B(コンビニ印刷手順)の採否と実装範囲

### スイシン(推進)
- 監査の結果、チェックのタップ保存・メモは実装済みで、足りないのは「言葉」と「導線」:
  ①「印刷できなくても大丈夫・この画面を見せればOK」の明示 ②窓口セリフのワンタップコピー
  ③シートをコピーしてLINEに残す導線 ④コンビニ印刷の平易な手順。どれもジェネレーター
  1箇所の修正で176ページに一括反映でき、費用ゼロ・保守も軽い
- ③はCV単一と同方向(コピー→LINEに貼る→受け皿応答が反応→登録の自然な後押し)。
  診断結果コピーで実証済みの型の再利用

### ウタガイ(懐疑)  ← 空欄不可
- **反対理由1(PII)**: 「シートをコピー」にメモ欄(電話番号・窓口名等の個人メモ)や
  チェック状態まで含めると、利用者が意図せず個人情報をLINEに貼るのを助長しかねない。
  コピーは定型文(制度名・持ち物例・セリフ・URL)のみに限定すべき
- **反対理由2(正確性)**: コンビニ印刷の料金・アプリ名・手順は変わりうる。「20円」と
  断定して古くなれば信頼を損なう。目安表記+公式サービスへのリンク+「変わることが
  あります」の非断定が必須
- **反対理由3(現場)**: 「画面を見せればOK」と言い切ると、窓口によっては紙を求められ
  た場合に利用者ががっかりする。「紙とおなじように使えます(あなたのメモ代わり)」の
  トーンに抑え、コンビニ印刷手順とセットで逃げ道を残すこと

### ベッカイ(別解)
- 前提を疑う: そもそも「シート」という紙のメタファーが印刷前提を生んでいる。長期的には
  「LINEで準備シートを受け取る」(トークン開通後の配信)が本命で、サイト側は中継点。
  今回の実装はその布石として、コピー文言をLINE貼り付けで読みやすい形に設計しておく
- 「電波の悪い窓口で開けない」問題はコピー保存(オフラインで見られる)が実質解。
  アプリ化・PDF自動生成などの大掛かりな案は不要

### 結論(部門長の裁定)
- 採否: **案A・案Bとも採用**。実装範囲はスイシン案の①〜④、ただしウタガイの3条件を全て反映:
  コピーは定型文のみ(メモ・チェック状態は含めない)/料金・手順は目安+公式リンク+非断定/
  「見せればOK」は控えめなトーンにしコンビニ手順を併記
- 理由: 費用ゼロで最も置き去りの層に届く。PII・正確性・現場トーンの懸念は実装条件で解消できる
- 見直し期限: 2026-11-17(LINEトークン開通後に「LINEで受け取る」配信版を再検討。
  コンビニ手順の料金・アプリ名もこの時点で再照合)
