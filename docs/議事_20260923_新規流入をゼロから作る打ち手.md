# 議事: もらいわすれ堂の新規流入をゼロから作る打ち手の選定(2026-09-23)

小柳さん指示(2026-09-23)「既存顧客基盤は使わない。別で新規で増やすために何をすべきか」。
起案にあたり、**推測ではなく実際の検索結果とデータで前提を確かめた**。

裁定は提案。最終決裁は小柳さん(絶対ルール5)。

## 調べて分かった前提(ここが議論の土台)

### 1. 「制度名×自治体」の検索では官公庁に勝てない

実際に「那覇市 こども医療費助成 申請方法 持ち物」を検索した結果、**上位9件のうち8件が
官公庁サイト**(那覇市・沖縄県・沖縄市)。残り1件も保育園のサイト。

これは正しい状態でもある。その質問への最良の答えは公式ページだから。
**いまの420ページ(市町村41×制度261)は、この勝てないクエリを狙っている。**

### 2. 「もらえるお金 一覧」は全国規模のアグリゲータが先行

「沖縄 もらえるお金 一覧 給付金」の上位は、補助金ポータル / スマート補助金 / 弥生 /
補助金エージェント / ミラサポなど全国サービス。中でも **家計簿アプリZaimの
「わたしの給付金」は、世帯構成から受給可能性を出す = 3分診断と同じ機能**で、
既存ユーザー基盤とドメイン権威を持っている。

### 3. ドメインが構造的に不利

`allgroup-inc.github.io/hojo-hq/fukugiiro/` — 共有サブドメインのサブディレクトリ。
給付金情報は YMYL(お金と生活に直結)で、検索エンジンが権威を最も厳しく見る領域。
**最も権威が要る分野で、最も弱い土台に立っている。**

### 4. 差別化になりうる「併給」の情報を持っていない

`combine_note`(併給の可否)はスキーマにあり拡充ループも指示しているが、
**261件中0件。一度も埋まっていない。**

### 5. 実績としてのSNS

13投稿・フォロワー0。「投稿すれば届く」は成立していない。

## 論点: この土台で、新規流入をどう作るか

### スイシン(推進)

- **SNSの発見面(リール)はドメイン権威が要らない。** 検索と違い、フォロワー0でも
  レコメンドに乗りうる。13投稿という制作資産と、回せる担当(遥さん)が既にいる
- **併給情報を埋めれば、官公庁もアグリゲータも書かない情報になる。**
  官公庁は自分の制度しか書かない。アグリゲータは全国一律で沖縄の組み合わせを持たない
- SEOは捨てるのではなく、**勝てるクエリに絞り直す**。離島・小規模自治体は
  公式ページが薄く、競合も少ない

### ウタガイ(懐疑)  ← 反対理由

- **反対理由1: 「リールなら届く」は仮説で、実績は逆。** 13投稿してフォロワー0という
  実測がある。発見面に乗る保証はどこにもない。「今度はうまくいく」と考える根拠が無い
- **反対理由2: 併給情報は正確性のリスクが極めて高い。** 「両方もらえます」と書いて
  実は併給調整で減額される、あるいは片方しか受けられない場合、**絶対ルール1違反そのもの**。
  官公庁が書かないのは縦割りだからではなく、**自分の所管外を断定できないから**かもしれない。
  差別化になる情報ほど、間違えたときの損害が大きい
- **反対理由3: 独自ドメインを取っても、勝てないクエリを狙っている限り意味がない。**
  土台の改善とコンテンツの方向は別問題。順番を間違えると費用だけかかる
- **反対理由4: そもそも❶「月1万人」が現実的か。** 沖縄県の世帯はおよそ60万。
  月1万人は**県内世帯の1.7%が毎月訪れる**計算。全国アグリゲータが先行し、官公庁が
  上位を占める検索環境で、権威のないドメインから到達する道筋が描けない

### ベッカイ(別解)

- **前提を疑う: ❶を主目標として追うのをやめる。** 4目標の定義では
  **❷(受給報告)が北極星で、❶は分母にすぎない**。分母を1万人にしなくても❷は増やせる。
  1万人に薄く触るより、**100人に深く届いて10人が受給するほうが❷に効く**
- **検索でもSNSでもなく、人がすでに集まっている「第三者の面」を借りる。**
  保育園・小児科の待合、社会福祉協議会、民生委員、ママ向けLINEオープンチャット。
  これは小柳さんが除外した「既存顧客基盤」ではなく、**第三者の面**
- この案は新規ではない。**議事_20260811 で紙チラシと民生委員向けワンペーパーが
  既に提案され、費用決裁待ちのまま6週間止まっている**
- 別の枠組み: 沖縄のローカルメディア(新聞・フリーペーパー・地域FM)への情報提供。
  「県民が受け取り忘れている制度」は報道価値があり、掲載は無料になりうる

---

## 結論(提案・上申)

- **採否: ❶を主目標として追う方針を「保留・上申」。❷から逆算する方針を提案**

理由:
- ウタガイの反対理由4は、調べた4つの前提すべてと整合する。**月1万人へ到達する道筋を、
  いまの土台では誰も描けていない。**描けない目標を追い続けると、打ち手が
  「とりあえず広げる」に流れる(実際、420ページは勝てないクエリに向いている)
- ベッカイの「❷から逆算」は、事業の定義そのものと一致する。❷が北極星だと
  自分たちで決めている
- スイシンのSNS案は否定しないが、ウタガイの反対理由1(実績が逆)が重い。
  **単独の主軸にはしない**

### 進める順(提案)

1. **第三者の面を借りる**(ベッカイ採用・最優先)
   議事_20260811 の紙チラシ・民生委員ワンペーパーの決裁を、改めて上申する。
   **6週間止まっている案件を動かすのが、新しい案を足すより先**
2. **SEOを勝てるクエリへ絞り直す**(こちらで実装可能・費用ゼロ)
   「制度名×自治体」から、官公庁が構造的に書けない横断型へ。
   離島・小規模自治体、ライフイベント横断、手続きの順番
3. **併給情報は慎重に扱う**(ウタガイ反対理由2を採用)
   埋めること自体は差別化になるが、**断定しない・「要確認」前提**を崩さない。
   原文で併給可否が明記されている制度に限って記載する
4. **独自ドメインは2が進んでから**(ウタガイ反対理由3を採用)
   コンテンツの方向を直す前にドメインを移しても、費用だけかかる
5. **SNSは主軸にせず、2の受け皿として継続**
