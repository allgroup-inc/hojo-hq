## 位置づけ

家計の見直しやさん(QCM / kakei-crm)の保全業務と並行して、**管理メンバー向けの「管理画面」**を hojo-hq 内に構築する。保全で契約化と同時に、管理側へ情報が流れ、管理メンバーが顧客カルテを一元管理できるシステム。

---

## システム構成図

```
┌─────────────────────┐
│  申込み・診断       │ (hojo-hq)
│  (既存システム)     │
└──────────┬──────────┘
           │
    ┌──────▼──────────────────────┐
    │                             │
┌───▼────────────────┐  ┌────────▼──────┐
│ 管理画面           │  │ QCM/保全      │
│ (新規・hojo-hq)    │◄─┤ (kakei-crm)   │
│                    │  │               │
│ ・顧客カルテ管理   │  │ ・保全業務    │
│ ・入出力フロー     │  │ ・営業CRM     │
│ ・ログ・権限       │  │               │
└───────────────────┘  └───────────────┘
           ▲
           │ (管理メンバーのみ)
    ┌──────┴──────┐
    │ 管理メンバー │
    └─────────────┘
```

**データフロー:**
- 保全(QCM)で契約化 → 同時に管理画面へ情報連携
- 管理画面での操作 → QCMへ反映（双方向）

## 現場要件（管理メンバー確認済み・2026-09-26）

### 📋 記録・蓄積する情報（顧客カルテ）

前回「顧客に関わる全ての情報とデータ」で定義済み：
- 基本情報（名前、連絡先、家族構成など）
- 申し込みから契約までの流れ
- 現在の保障内容（保険種・保障額・月々の保険料）
- お客さんの希望・懸念点
- 面談の記録（いつ、誰と、何を話したか）
- 提案した内容
- 対応の記録（電話・メール・訪問等）
- 変更履歴（担当者変更・段階変更等）

### 🖥️ 管理画面の機能要件

#### A. システム基盤（優先度: ⭐️ **必須** — 管理画面OPEN時点で実装必須）

| 要件 | 説明 | 詳細 |
|---|---|---|
| **アクセスログ** | 誰が、いつ、何をしたか | 全操作の記録。CSV出力可能 |
| **パスワード定期変更** | セキュリティ | 定期的な変更を強制 |
| **上書き改ざん防止** | 監査対応 | 初回入力日時を常に記録。更新履歴を追記のみ |
| **バックアップ** | 障害対応 | エラー時のデータ復旧用。定期的に実施 |

#### B. 管理画面固有機能（優先度: 🔄 **第2フェーズ** — 1-2ヶ月以内）

| 要件 | 説明 | 詳細 |
|---|---|---|
| **申し込み控えからの自動入力** | 業務効率化 | 申し込み時の情報を自動取得 |
| **ブランク検索（空白検索）** | 検索機能 | 現在のシステムでできないので対応必須 |
| **項目追加対応** | カスタマイズ対応 | 運用中に項目を追加・プルダウン追加可能にする |
| **パートナー統一化** | 組織対応 | パートナーも同じシステムで管理 |
| **家族管理（枝番）** | 家族単位の管理 | 本人: 2000、家族: 2000-1, 2000-2 等 |

#### C. AI・分析機能（優先度: 🔮 **将来検討** — 3-6ヶ月以降）

| 要件 | 説明 | 詳細 |
|---|---|---|
| **不備自動チェック** | AI活用 | 入力不備を自動検出 |
| **個人情報一致確認** | 品質保証 | 申し込み控えとシステムの個人情報が一致するか確認 |
| **解約率・継続率分析+指導** | 営業分析 | AI が個人ごと・全体に指導 |
| **苦情対応文書自動作成** | 効率化 | 苦情発生時、各保険会社フォーマットで自動作成 |

#### D. 組織機能（優先度: 🔄 **第2フェーズ** — 運用ルール確定後）

| 要件 | 説明 | 詳細 |
|---|---|---|
| **ランキング自動計算** | 営業可視化 | 社内イントラネットで対面部隊の成績ランキング等を自動計算 |

### 🔐 権限・セキュリティ

- **表示対象**: 管理メンバーのみ（営業・その他は見えない）
- **要配慮情報**: 権限なしユーザーには完全に非表示
- **監査対応**: アクセスログで全操作を追跡可能

### 🔗 QCM(kakei-crm)との連携

**QCM側から管理画面へ流す情報:**
- 顧客基本情報（契約化時）
- 保障内容（契約時・更新時）
- 担当者情報（変更時）

**管理画面からQCM側へ反映させる情報:**
- 顧客カルテの更新（メモ・対応記録等）
- 家族情報の追加（枝番管理）

## CRM画面(営業向け)への追加要件

管理画面が見えない営業向けCRM画面に、以下を追加：

- **既契約の口座情報**（銀行名・支店名など）
- **既往症**: ❌ 管理画面からの反映は不可（ルール理由）→ 営業画面からのみ入力
