### スイシン(推進)
- 4チャネル(既存基盤300 / SNS300 / 紹介200 / 検索200)それぞれに担当が割当済み。三名体制・監査・失敗台帳・ニドナシ機構でガバナンスは既に高水準。「達成確率設計」の5ループ(計器盤・リード供給・早期警報・学習・決裁)で"外れたら戻る"構造も設計済み。**体制の"面"は足りており、あとは実行あるのみ**。

### ウタガイ(懐疑) ← 空欄不可
1. **真の制約は組織カバレッジではない**。台帳が示すとおりAI実装は完成、止まっているのは人間(決裁・15〜30分作業・人選)。器を増やしても分母(登録数)は動かない。むしろ登録0社の段階で17エージェント+三名体制+監査+ニドナシ機構は**ガバナンス過多**の懸念。
2. **エンジニアリング(技術部)の担当エージェントが不在**。LIFF/GAS/CI/計測など作業は極めて技術的なのに、agentロスターに技術部の"主"がいない(egakuはデザイン)。実装の主語が曖昧=「決裁済みなのに着工されない」滞留の温床。
3. **CVR(診断→LINE 30%)を専任で回すオーナーが不在**。CROはPDCA時に外部レビュアーで単発対応しただけ。1,000社は「流入×CVR」で決まるのに、CVRを毎週改善し続ける常設の主がいない。
4. **検索流入200社のオーナーが実質不在**。CLAUDE.mdは「SNS部+収集部」に割当てるがSEOは別技能。marketingskills(ai-seo/seo-audit/programmatic-seo)は入ったが**回す人がいない**。
5. **紹介200社が提携部1人(musubu)に集中**。士業・商工会・金融機関は別ドメイン。1担当で200社は過負荷で、最も"人依存"のチャネルが最も薄い。
6. **フォーカス崩壊リスク**。launch未完(LINE中身未設定=受給報告経路ゼロ)なのに、収益化・出口・法人サブスク等"先"の設計に手が広がっている。北極星がゼロのまま外周が厚くなる。

### ベッカイ(別解)
- そもそも「部門を足す/見直す」枠組みが正しいか。登録0の今に必要なのは組織図ではなく、**「週1決裁バッチ × 3つの成長ループ(供給・CVR・紹介)を回す最小構成」への一時的スリム化**。監査・ニドナシ・三名体制は資産だが、初回トラクションが出るまでは**軽量モード**で運用する。
- 別解2: 不足技能(エンジニア/CRO/SEO/BD)は**新エージェント新設ではなく、既存エージェントへ明確なKPIオーナーシップを付与+vendorスキル(marketingskills)を武器として割当てる**方が速い。器を増やすより責任を尖らせる。

### 結論(裁定)
- **採否: 一部採用**。「部門追加」ではなく「①責任(KPIオーナー)の明確化 ②初回トラクションまでガバナンス軽量運用 ③北極星へのフォーカス固定」で対応する。
- 理由: 面のカバレッジは足りている。真の制約は決裁・人間実行。新設は最小(技術部オーナーの"明示"のみ)、不足技能はKPIオーナー任命+スキル割当で埋める、登録0→100社まではガバナンスを軽く保つ。
- **上申事項(小柳さん決裁)**: 技術部オーナーの正式化(現状たかしくん+AI技術部の実体を"部門"として明記するか)。
- 見直し期限: 2026-11-02。

## 2. ルールの明文化(曖昧さを残さない)

### 2.1 判断基準(意思決定の優先順)
1. **正確性最優先**(絶対ルール1): 締切・金額・要件は原文URL照合。不明は「要確認」表示・断定禁止(`hojo-accuracy-check`)。
2. **北極星 > KGI > その他**: 「実受給報告の経路開通」→「LINE登録1,000社に近づくか」→それ以外、の順。迷ったらこの順で切る。
3. **CV単一**(絶対ルール4): 導線はLINE登録のみ。lin.ee直貼り禁止・必ず `/go/<チャネル>/` 経由。他CV追加は小柳さん決裁。
4. **量と質の両輪**: 登録は経営者/企業を主カウント。個人・学生は別カウント(akari判断原則)。

### 2.2 承認フロー(3層で固定)
| レベル | 対象 | 承認 | 記録 |
|---|---|---|---|
| **L1(自動運転)** | 定型のデータ更新・検証・内部作業・非公開の実装 | AI即実行 | 週次サンプリング3件を三役再点検 |
| **L2(公開・配信・送付)** | サイト公開/SNS・LINE配信/対外メール/PR | 三役短評(各1行・ウタガイ必須)を添付しAI実行→**事後報告** | 議事 or コミットログ |
| **L3(不可逆・重要)** | 予算・提携・掲載方針・法務グレー・PII実データ・外部送信の重大なもの | **小柳さん決裁**(採用/不採用/保留+理由1行) | 決裁キュー |

- 本タスク指示による事前承認範囲: **L1・L2 は本指示をもって承認済みとして進めてよい**(コミット・PR作成・マージ・計画内の文書化を含む)。**L3 と不可逆・影響大は一言報告してから**。

### 2.3 品質基準(公開前ゲート)
- 正確性: `hojo-accuracy-check`(原文照合・要確認・断定禁止)。
- 締切表現: `hojo-deadline-alert`(3層ルール=30日以上SNSのみ/7〜29日LINE個別/7日未満は次回予告。利用者向けは「締切の約1か月前から」で統一。**「締切7日前アラート」は誤りとして排除**)。
- 文面: `humanizer`(AIっぽさ除去・憲法トーン=専門用語をやさしく翻訳。事実情報・CV導線は変えない)。
- 法務: `mamori`(robots/規約=守り部事前承認のみクロール、資格業務は情報提供・士業紹介まで、PIIは公開repoに置かない)。
- 技術: 公開前に check_lp + validate + e2e グリーン。マージ前に競合一覧確認→マーカーgrep→全検査(失敗台帳 FK-001/FK-002 の是正手順)。

### 2.4 エスカレーション条件(迷ったら上げる)
- 三役が割れ確信が持てない → 統括経由でたかしくん・小柳さんへ上申。
- **即上申(待たない)**: 不可逆な操作 / 法務・資格のグレー / PII実データの取扱い / 景表法リスク表現。
- **早期警報(閾値割れ→決裁キュー自動起票)**: LINE登録が週20社未満2週連続 / SNS投稿12本で流入ゼロ / 決裁レイテンシ最古14日超 / 月次解約3%超 / 診断→登録CVRがベースライン割れ。
- 誤情報発見時は kansa/検証の緊急権限で該当1件を即「要確認」化(事後48h以内に三役レビュー)。

### 2.5 決裁レイテンシ最小化(唯一の最大変数)
- 毎朝の「決裁便」+週90分の決裁バッチ(カレンダー固定枠)。決裁は3択返信(採用/不採用/保留+理由1行)。

## 6. 成功事例・ベンチマーク(深いリサーチの反映)

一次情報・競合実例・業界データを調査し、計画に反映(手順8・9)。

### 6.1 収益構造は「補助金ポータル型」が国内で実証済み
- **補助金ポータル(Wizグループ)**: 月間**約100万UU**の無料メディアで集客 → 士業向けサブスク「士業ポータル」**月額11,000円(税込)**で送客。=本事業の出口1と**同型モデルが日本で成立**している。
- **ミツモア型**: 補助金専門家マッチングで**成約課金 16.5〜38.5%** or 応募課金。
- **本事業の優位**: 間に**LINEを挟む**ため、締切アラートで**繰り返し送客**できる継続資産を持つ(ポータルの単発問い合わせ型に対する差別化)。
- → 収益モデルは「**無料メディア(沖縄特化)で集客 → 士業に月額掲載/定額送客料で送客**」を基本線に据える。

### 6.2 送客の適法性(mamori・E3で固定)
- 助成金の代理申請=社労士独占、補助金の書類作成代行=行政書士独占。**本事業は申請代行をせず「情報提供+紹介」に徹する**(絶対ルール3と整合)。
- 対価は「**掲載料/月額/定額送客料**」形式に固定すれば非弁提携に抵触しない(ポータル月額課金・ミツモア成約課金が現に成立)。**避けるべきは「案件別の成功報酬を紹介者が受け取る」レベニューシェア**。→ E3の弁護士確認はこの1点を軸に。
- 送客価値の裏付け: 申請コンサル相場は**着手金5〜30万+成功報酬10〜15%**。士業側の1件売上が数十万円規模のため、月額でも定額送客でも成立。

### 6.3 診断は補助金と相性最良のリードマグネット(C・CVR30%の射程)
- 全業界平均CVR約1.82%に対し、**診断は「選択肢が多く自分に合うものが分からない商材(補助金・保険等)」で特に有効**。「3分診断→結果はLINEで受け取り+締切アラート」で**登録を必然化**できるため、KPI「診断→LINE30%」は設計次第で到達可能。
- 実例: コピー変更だけでCVR約30%改善、半年〜1年でCVR2〜3倍の事例。既製ツール「**診断クラウド ヨミトル**」等で内製工数を圧縮する選択肢。
- → C2のA/Bは「結果画面のCTAをLINE登録に一本化・パーソナライズ感」を軸に。

### 6.4 1,000友だち/12ヶ月は多チャネル合算で現実的
