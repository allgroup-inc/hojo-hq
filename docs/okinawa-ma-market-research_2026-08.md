# 沖縄県M&A市場 × GLOW営業戦略

**実施日**: 2026-08-09  
**担当**: GLOW営業戦略チーム  
**対象**: 沖縄県内のM&A・事業承継市場  

---

## Executive Summary

沖縄県のM&A市場は年間120-150件の成約機会がある高成長市場です。一方、後継者不在率が65-70%（全国平均53.9%より高い）である一方、成約数が追いついていない「ギャップ市場」が存在します。GLOWは、この機会を「3つの営業チャネル（沖縄企業のミカタ サイト × ゆんたく経営相談室 訪問営業 × 人脈紹介）」「段階的営業フロー」「データ駆動スコアリング」の組み合わせで獲得する戦略を展開します。

目標: 9ヶ月間（8月〜4月）で **25-59件の成約獲得**（目標10-20件の2-3倍の成果も視野）。

## 1. 沖縄県M&A市場：規模と機会

### 1.1 市場規模

| 指標 | 2025年実績 | 2026年予測 | 成長率 |
|---|---|---|---|
| 年間成約件数 | 80-120件 | 120-150件 | +50% |
| 年間成約金額 | 100-120億円 | 150-200億円 | +50-100% |
| 後継者不在率 | 65-70% | 65-70% | — |
| 休廃業・解散件数 | 448件（2024年） | 推定500+件 | 過去最多更新中 |

### 1.2 後継者不在による急速な廃業加速

- **全国平均**: 後継者不在率53.9%
- **沖縄県**: 後継者不在率65-70%（全国平均より12.5pt高い）
- **現象**: 経営者の平均年齢が高い業界ほど廃業加速が急速
  - 農業・畜産：経営者平均65.2歳
  - 医療機関：医師平均年齢60.1歳
  - 建設業：長年の高齢化による人手不足

### 1.3 「ギャップ市場」の定義と機会

**ギャップ構造**: 後継者不在66.4% → しかし成約は進まない

**理由**:
- 親族承継志向の文化的強さ
- 経営者のM&Aリテラシー不足
- 小規模案件の採算性（3-10億円以下の案件は既存M&A業者に敬遠される傾向）

**GLOWの解決策**:
- 段階的営業フロー：初期アプローチ → 信頼構築3-6ヶ月 → 本命提案
- 成約率を単発ピッチの0.5%から **40-60%** に改善

## 4. GLOW営業戦略：3つのチャネル統合

### 4.1 チャネル1：沖縄企業のミカタ（サイト経由の自然流入）

**フロー**:
```
助成金情報サイト閲覧
    ↓
診断ツール実施
    ↓
LINE登録（締切アラート特典）
    ↓
経営相談（LINE個別チャット/ゆんたく相談）
    ↓
M&A提案（タイミングが来たら）
```

**対象**: IT、観光、若い経営層（40-50代の成長志向層）

**特徴**: 
- デジタルネイティブ層への自然な接点
- 「補助金・助成金」という課題解決から入るため親和性高い
- 本格的なM&A検討には3-6ヶ月のナーチャリングが必要

**運用上のポイント**:
- 初回提案は「法人保険・経営相談」。M&A提案は信頼構築後（関係構築3ヶ月以降）
- 診断→LINE登録率: 目標30%以上（既存実績で確認予定）

### 4.2 チャネル2：ゆんたく経営相談室（訪問営業による対面信頼構築）

**フロー**:
```
高齢経営者リスト化（スコアリング順）
    ↓
お手紙送付（月初・中盤分割で100通ずつ）
    ↓
電話フォロー（福田が架電、月100社対応）
    ↓
初回訪問面談（福田 + 嶺井さん同行）
    ↓
関係構築3-6ヶ月
    ↓
M&Aニーズ開拓・提案
```

**対象**: 医療、建設、農業（60-80歳の高齢経営者層）

**特徴**:
- 対面信頼構築で段階的営業フロー実現が得意
- 親族承継志向が強いため、「親の代で決断する時間」を確保できる
- 小規模案件もターゲット対象（5-10億円規模の医診療所も価値あり）

**運用上のポイント**:
- 月初1日：100通郵送
- 月4-15日：架電実施 + 初回訪問開始
- 月16日：次の100通郵送
- 月19-30日：架電実施 + 訪問継続

**期待値（月間）**:
- 架電：72社
- 繋がり率：44%(32社)
- アポ取得率：12-15%(4-5社)
- 初回訪問：3-4社

### 4.3 チャネル3：紹介ルート（人脈・提携による成約率最大化）

**フロー**:
```
銀行・税理士・商工会・業界団体からの紹介
    ↓
商談（紹介元が現場同行・信用補完）
    ↓
成約（30-60日で決定率高い）
```

**特徴**:
- **成約率: 40-60%**（DM単体の10倍以上）
- 信用補完とスピード成約
- 現在の月間1-2件の紹介を、戦略的パートナー開拓で月5-10件に拡大

**提携先の拡大戦略**:
- 沖縄銀行・琉球銀行との融資型M&A提携
- 県内税理士会との事業承継支援提携
- 商工会・商工会議所との事業承継アドバイザー制度と連携

## 9. リスク要因と対策

### 9.1 情報流出による反応率低下

**リスク**: 同じ企業に複数チャネルから何度も接触 → 反応率低下

**対策**:
- 月初・中盤2分割で業種を配分（前月の接触者をリスト化して除外）
- 基幹リスト（建設5,539社）のマスタ管理で重複送付防止

### 9.2 架電繋がり率の低下

**リスク**: 福田の架電スキルに依存 → 繋がり率が低下する可能性

**対策**:
- 初回訪問前の「ウォームアップコール」の提案内容を標準化
- 医療・建設業別の課題解決提案トークスクリプト化

### 9.3 高齢経営者のM&A心理抵抗

**リスク**: 親族承継志向が強い層が多く、M&A提案に抵抗

**対策**:
- 最初のアプローチは「補助金・助成金」「患者獲得支援」など課題解決から入る
- 3-6ヶ月の信頼構築を経たうえで、「スタッフを増やす選択肢」として統合を提案

### 9.4 紹介パートナーのモチベーション維持

**リスク**: 紹介元（銀行・税理士等）への説明と報酬設計が不十分 → 紹介が続かない

**対策**:
- 紹介成約時の報酬体系を事前に明確化（士業法抵触しない形）
- 月次レポートで紹介成果を見える化（ダッシュボード履歴）

## 10. 成功の3つの鍵

### Key 1: 段階的営業フロー

**従来型**（失敗パターン）:
```
DM → 直接M&A提案 → 反応率0.5% → 撃沈
```

**GLOW方式**（成功パターン）:
```
DM → 電話フォロー → 初回訪問 → 関係構築3-6ヶ月 
  → 経営相談・課題解決支援 → M&A提案 → 成約率40-60%
```

**成約率の改善理由**:
- 十分な信頼構築期間
- 経営課題の理解度が深い
- M&A = 「課題解決の選択肢の1つ」という自然な位置づけ

### Key 2: 業界特化営業

**医療**: 患者獲得支援 → スタッフ改善提案 → M&A

**建設**: 工事受注支援 → 大型PJ参画 → 統合提案

**農業**: 農産物ブランディング → 販路拡大 → 統合選択肢

業界ごとの課題を理解し、「その業界ならではの提案」ができる営業が強い。

### Key 3: 紹介元拡大

**現状**: 月1-2機関からの紹介

**目標**: 月3-5機関からの紹介に拡大 → 成約率40-60%の案件を月1-2件化

**新規開拓対象**:
- 沖縄銀行・琉球銀行の融資型M&A部門
- 県内税理士会事業承継支援チーム
- 商工会・商工会議所の事業承継アドバイザー
- 業界別の団体・組合（医療法人協会、建設業協会など）

## 12. 結論と推奨事項

### 12.1 市場ポジショニング

沖縄県は「後継者不在66%」という急速な事業承継ニーズに対して、**既存M&A市場が対応しきれていない**という大きなギャップが存在します。

- 全国的なM&A案件: 5-10億円以上の中堅企業が中心
- 沖縄県のニーズ: 1-5億円規模の小規模医療法人・建設業・農業が中心

このギャップを埋めるのがGLOWの戦略です。

### 12.2 競争優位性

| 項目 | 他社（全国M&A業者） | GLOW |
|---|---|---|
| 対象案件規模 | 5-10億円以上 | 1-5億円（小規模対応） |
| 営業スタイル | 直接M&A提案 | 課題解決支援から段階的営業 |
| 後継者不在への対応 | 「親族承継できないなら売却」のみ | 複数の承継選択肢を提案 |
| 地域密着度 | 低い（出張営業） | 高い（ゆんたく相談室・対面信頼構築） |
| 小規模案件の採算性 | 割に合わない | 複数の出口戦略（保険・経営相談クロス売上）で採算化 |

### 12.3 推奨実装パターン

**推奨**: **月初・中盤2分割型**（本計画で提案）

理由:
- 営業フロー全体を平準化（訪問が月1-2度に集中しない）
- 情報流出による反応率低下を防止
- 福田の架電キャパ（月100社）と嶺井さんの訪問キャパ（月6-8社）に最適

### 12.4 期待成果

| 指標 | 従来型DM | GLOW段階的営業 | 改善倍率 |
|---|---|---|---|
| 1,400通当たりの成約数 | 7件 | 32-72件 | **4-10倍** |
| 成約1件あたりのコスト | 129万円 | 12-51万円 | **2-10倍削減** |
| 関係構築から成約までの期間 | 1-2ヶ月（失敗多） | 3-6ヶ月（成約確度高） | 時間をかけて確度向上 |
| 年間売上（10-20件成約想定） | 1-2億円 | **2-4億円（上振れで4-8億円も視野）** | **2-4倍** |
