## 本編プロンプト(新規制作・大改修用)

```
あなたは「みらいひらけ堂」のLPを作るデザイナー兼ライターです。
以下のルールをすべて守って、静的HTML1ファイルのLPを作って(直して)ください。

【サービスの正体】
- みらいひらけ堂: 沖縄の小学生〜高校生が「無料で学べる場所・サービス・制度」を
  4つの質問でさがせる検索サイト。運営は株式会社フクギイロ(非営利目的の無料サービス)
- 姉妹サービス「もらいわすれ堂」(給付金のもらい忘れ診断)に続く「堂シリーズ」の2つ目

【いちばん伝えたい価値観(サイト全体の背骨)】
1. 子どものみらいの可能性は、さまざまな体験からひらく。
   学校の勉強だけが学びではない。本・ものづくり・大人との対話・好きなこと探し・
   体験やイベント、ぜんぶが「みらいの扉」
2. ささえてくれる人たちがいる。
   NPO・先生・大学生・ボランティア・県や市・図書館が、無料の「まなびば」や制度を
   ひらいてくれている。このサイトはその入口をひとつにまとめる場所
3. お金をかける道も、かけない道も、どちらも尊重する。
   塾や教材にお金をかけて可能性をひらくのも大切な選択。ただしこのサイトに載せるのは
   無料(一部無料・条件付き無料を含む)の情報だけ。「お金をかけられなくても、
   ひらける扉はたくさんある」と伝える。有料サービスの掲載や広告は絶対にしない

【ブランド(堂シリーズ共通)】
- ロゴの文法: 朱#B9502F の角丸タイル(rx23%)に漆喰#FFFBF4 の丸ゴシック2段組み
  (みら/堂)+右上に黄#F2B705 の丸バッジ(白フチ3px)。
  もらいわすれ堂のバッジは「1」(通知)、みらいひらけ堂は「↗」(ひらいていく方向)
- 配色: 朱#B9502F(主役)/黄#F2B705(強調)/漆喰#FFFBF4系の生成り背景/墨#1F2A2E(本文)
  ※実装ではフクギイロ「島の陽だまり」パレット(--sand #FBF5EC 等)と調和させる
- フォント: 見出しは明朝(Shippori Mincho)、本文はNoto Sans JP
- フッターに「運営: 株式会社フクギイロ」と姉妹サービスへのリンクを必ず置く
- 「沖縄企業のミカタ」(株式会社GLOW)とは別サービス。名前を混ぜない

【文章のトーン(もらいわすれ堂と同じ憲法)】
1. やさしい日本語。小学5年生が読める。専門用語には言い換えを添える
   (例:「住民税非課税世帯(家の収入が一定以下の家庭)」)
2. 事実は断定しない(「〜の可能性があります」「要確認」)。
   ただし寄り添いは断定する(「途中でやめても大丈夫」「わからなくても大丈夫」)
3. 主語は「あなた」。運営の自慢をしない。子どもを「支援の対象」ではなく
   「可能性の主人公」として書く。かわいそう・貧困といった言葉は使わない
4. 絵文字は控えめ。行政情報の信頼感をこわさない

【ページ構成(上から順に)】
1. ヘッダー: ロゴ(assets/logo.svg)
2. ヒーロー: 「むりょうで べんきょうできる ばしょが みつかる」+
   大ボタン「あなたに合う無料の勉強サービスを探す(4つの質問・1分)」+
   3つの約束(登録なし/名前も住所もいらない/無料の情報だけ)
3. 価値観セクション(3ブロック):
   ①みらいは、いろんな扉からひらく(体験の例をチップで並べる)
   ②ささえてくれる人が、こんなにいる(NPO・先生・自治体・図書館の存在)
   ③お金をかける道も、かけない道も(有料の選択も尊重しつつ、ここは無料の入口)
4. 検索(4問: 学年→やりたい勉強→方法→おうちのこと)→結果は
   「おすすめ度+なぜおすすめかの理由」を必ず表示(ブラックボックスにしない)
5. このサイトについて: 掲載ルールと計算方法は全文公開する方針を明記
6. フッター: 運営表記+姉妹サービスリンク

【絶対に守ること(禁止事項)】
- ログイン・会員登録・個人情報の入力欄を作らない。回答はブラウザ内だけで処理し
  サーバーに送らない。トラッキング・広告・計測タグを勝手に足さない
- 掲載情報はすべて「出典URL+最終確認日」つき。確認できないことは「要確認」と書き、
  断定しない。「申しこむ前に必ず公式サイトで確認」の一文を必ず添える
- データは ../data/miraihirake/services.json を読み、review_status が
  "published" のものだけ表示する(下書き・未審査を表に出さない)
- 検索エンジン非公開(noindex)の状態は、公開判定が出るまで勝手に外さない
- 技術は静的HTML+CSS+素のJavaScript 1ファイル。フレームワーク・ビルド不要。
  スマホ最優先(max-width 640px 中央寄せ)。word-break等のレイアウトCSSは見出し限定

【出力】
- 完成したHTML1ファイル(コメントで「なぜそうしたか」を要所に残す)
- 変えた点と、判断に迷った点の一覧(迷った点は勝手に決めず選択肢で示す)
```

## 世界観フィルム(始まりのストーリー)用プロンプト

```
みらいひらけ堂のトップに置く「世界観フィルム」(スクロールで進む始まりのストーリー)を
作って(直して)ください。もらいわすれ堂トップのフィルム(site/fukugiiro/ の
「夜→朝」構成)と同じ文法で、堂シリーズとして統一します。

【物語の流れ(5シーン・夜→朝の1本のグラデーション)】
S1 夜・星空: 「どの子にも、ひらくのを待っている みらいがある。」(星を見上げる子どもの影絵)
S2 未明: 「学びは、教室の中だけじゃない。」(本・ものづくり・星…好きなことはぜんぶ扉)
S3 夜明け前: 「ささえてくれる人が、こんなにいる。」(光の差す扉へ、大人と子どもの影絵)
S4 朝焼け: 「知らなかった」というだけで、ひらかれない扉がある →
   お金をかけてもかけなくても、ひらける扉はある → 一人ひらくたび沖縄のみらいは明るくなる
S5 朝: ロゴの現れ(朱タイル→文字→黄バッジ→「↗」が描かれる)+「ひらけ、みらい。」+
   CTA「あなたの扉を さがしにいく」(検索へスクロール)

【作りかた】
- まず影絵+光の絵コンテで実装し、写真は「差し替え枠」(.photoback)を用意しておく
- 必ず「スキップして探す →」の固定リンクを置く(物語を強制しない)
- prefers-reduced-motion と JSなし環境では、動きなしで全文が読めること
- 計測タグは入れない(このサイトはトラッキングなしが約束)

【写真プラン(差し替え用。守り部ルール)】
- 子どもの顔は写さない: うしろ姿・手元・影・遠景のみ。顔が写る写真は保護者の
  書面同意がない限り使わない(同意があっても本サイトでは原則使わない)
- 撮りたい/集めたい写真: ①沖縄の星空・夜の集落の灯り ②本をめくる手元
  ③工作・プログラミングの手元 ④図書館や教室のうしろ姿・風景 ⑤朝焼けの海
- フリー素材を使う場合はライセンス(商用可・クレジット要否)を確認して記録する
- 写真の追加はコミット前に守り部の確認を通す(公開リポジトリのため)
```

## 補足(このリポジトリでの運用)

- LPの文言・デザイン変更は可逆なので議事任意。ただし**掲載方針(無料のみ等)や公開範囲を変える変更は小柳さん決裁+議事必須**
- 対外公開の前は、通常どおり公開判定(沖縄○のpublished 70件以上+UX確認)と `scripts/shipping_gate.py` 系の規律に従う
- ロゴはv0(エージェント作成の出発点)。エガク(デザイン)の月次リファインとみがきの会の審査対象
