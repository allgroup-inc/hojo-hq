# 議事: note新路線の選定(ミカタ・沖縄・補助金から離れた汎用テーマ×収益化×全自動)

- 日付: 2026-08-09
- 起案: 小柳さん指示「出す記事関係を全て見直して、今までやってきた内容(ミカタや沖縄、助成金や補助金)から離れて、世の中でバズって収益化が見込めるものを探して全自動させる様にして」
- 前提: 別チャットで走る kekka_mag(結果マガ=ビジネス実例研究×X販売)とは**全く別の形**にする(2026-08-09 小柳さん明示)
- 形式: 三名体制(スイシン/ウタガイ/ベッカイ)。裁定はnote編集部門長、最終決裁は小柳さん

## 事前リサーチ(2026-08-09 実施)

- note市場ではAI活用ジャンルが前年比+268.6%と最大成長。SNS運用+258.7%、副業+179.0%が続く
- メンバーシップ売上は前年比+81.3%で急成長。実用ノウハウ系有料記事の平均単価は1,842円
- 売れる型は「実際にやってみた」「失敗も含めて全部公開」の実証型。抽象ノウハウは値崩れ傾向
- 出典: note公式の約30万件有料記事分析(PR TIMES)、note収益化ラボほか2026年上半期の複数調査記事

## 論点: 新路線のジャンル・形式を何にするか

候補:
- A案「うごくAIレシピ」: AI自動化レシピ+プロンプトを、**公開前にCIで実際に実行し、実行ログ付きで配布**する週2回刊
- B案「数字の雑学」: 公的統計から意外な数字を発掘するデータ雑学(無料バズ→メンバーシップ)
- C案「行動経済学図鑑」: 論文ベースの「使える法則」連載

### スイシン(推進)

- A案を推す。最大成長ジャンル(AI活用+268%)のど真ん中で、平均単価1,842円と収益性も市場実証済み
- うちの独自資産がそのまま差別化になる: GitHub Actions+Claude API+検証文化。**全プロンプトを公開前に機械実行し、生の実行ログを紙面に載せる**運用は、手作業のプロンプト販売者には構造的に真似しづらい
- 「実証型が売れる」という市場の型に、体験談の捏造なしで乗れる唯一の形(実際に動かした結果だけを載せる=絶対ルール1と完全整合)
- 生成→検証→記事組版→通知まで全自動化でき、人間は「読んで貼って公開」だけになる

### ウタガイ(懐疑) ※空欄不可

- **プロンプト集は最激戦区で値崩れ済み**。無料プロンプトが無限に転がる中、有料で買う理由を毎号立証し続けられるのか
- 検証に使えるAPIはClaudeのみ。読者の主流はChatGPTであり、「Claudeで動いた」ことしか保証できない。**表記を誤ると誇大表示**になる(検証環境の明記を機械強制すべき)
- 市場は「この人にしか書けない体験」に金を払う方向。顔のない自動生成メディアは、匿名運営のハンデを負う
- kekka_mag側の記事⑪「AI導入研究」と外形が近く見える恐れ。**分離宣言を規程に明文化しないと、後で「同じことを2つのチャットでやっている」事故になる**
- 「全自動」と言ってもnoteに投稿APIはなく公開は人力のまま。小柳さんへの報告で「全自動=生成と検証まで」と正確に伝えるべき
- 週2回刊は在庫が捌ける前に積み上がる恐れ。公開が止まったら自動生成だけが空回りする(未公開在庫の監視を週報に入れるべき)

### ベッカイ(別解)

- そもそも「ジャンルで戦う」前提を疑う。飽和市場で勝つ変数はジャンルではなく**形式**。売り物を「情報」から「動く成果物+検証ログ」に変えるA案は、実はジャンル選択ではなく形式の発明であり、そこに賭けるべき
- B案(数字の雑学)は、単体では収益化が弱いがバズ装置としては優秀。**将来のX集客フックとしてA案の無料部に「今週の数字」を混ぜる**余地を残す
- 完全新アカウントで立ち上げるなら、ブランドは「AIが書いた」ことを隠すのではなく**「機械が検証した」ことを名乗る**方が匿名ハンデを強みに反転できる(=検証ログこそが「この媒体にしか書けないもの」)

### 結論(部門長の裁定)

- 採否: **A案「うごくAIレシピ」を採用**(B・C案は不採用。ただしB案の「数字フック」はA案無料部への部分採用を将来検討)
- 理由: 最大成長ジャンル×市場実証済みの「実証型」に、捏造なしで乗れる唯一の形式。差別化の核(CI実行検証)がうちの既存インフラの延長にあり、全自動化と正確性最優先を両立できる。ウタガイの懸念は以下の設計で機械的に封じる:
  1. **検証環境の明記を機械強制**: 記事テンプレに「検証はClaude(claude-opus-5)で実施」を必須文言としてバリデーション(欠落したら生成失敗扱い)
  2. **誇大表現の禁止**: BANNED_WORDS(必ず/絶対/誰でも/楽して/確実に稼)+成果断定の免責を必須文言化
  3. **kekka_magとの分離を規程に明文化**: 実例研究ジャーナリズム(kekka)vs 動くレシピ配布(こちら)。tanpatsu・kekka_*系ファイルへのハンズオフを宣言
  4. **未公開在庫の監視**: 週次レポに未公開本数を表示し、4本以上で生成ペース見直しを警告
- 併せて裁定: 旧ミカタnoteライン(週刊定点観測 note-draft.yml / AI編集長週報 note-members.yml)は**定期実行を停止**(workflow_dispatchのみ残す・可逆)。月刊白書 monthly-report.yml はパートナー版(士業配布)に実需があるため継続、note有料版の公開は保留のまま
- 価格・アカウント開設・公開開始の最終決裁: 小柳さん(単発980円スタート→実売を見て1,480〜1,980円へ、の提案を添える)
