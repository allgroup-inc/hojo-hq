# glow-ma 訪問・面談ログの記録方法(担当者向け)

最終更新: 2026-10-30 / 担当: ❶システム関係全般

訪問や面談の内容は、**声で残すだけ**で台帳(GLOW企業リレーション台帳)に記録できます。
記録の入口は2つあり、どちらも同じ流れで処理されます。

| | 入口① LINEから送る | 入口② ドライブに入れる |
|---|---|---|
| 向いている場面 | 訪問直後の口頭メモ、短めの録音 | 長い面談を録音アプリでまるごと録ったとき |
| 送り方 | GLOW実務チーム専用のLINE公式アカウントのトークに、**ボイスメッセージ**を送る。録音アプリのファイル(M4A/AAC/MP3/WAV/OGG)を**ファイルとして送る**こともできる | Googleドライブの「**GLOW音声ログ受付**」フォルダ(「共有アイテム」に表示)に、録音ファイルをアップロードする |
| 長さの目安 | ボイスメッセージはLINE側の制限あり(長時間・スリープ中は止まることがある)。ファイルで送る場合は **50MBまで**(AACなら約40分) | **制限なし**(1時間を超えるWAVも可。大きいファイルは分割して処理する) |
| 対応形式 | ボイスメッセージ / M4A・AAC・MP3・WAV・OGG | WAV・AAC・M4A・MP3・OGG・FLAC・AIFF |

## 送ったあとの流れ(入口①②共通)

1. LINEに受付の返事が届きます(入口①はすぐに「録音、届きました。少々お待ちください。」、入口②は数分以内に「録音ファイル「…」を受け付けました」)。長い録音は文字起こしに数分〜十数分かかります。
2. 文字起こしと要約ができると、LINEに**確認のボタン**が届きます。
   - どの会社の話か(候補から選ぶ/新しい会社として登録)
   - 内容(対応の種類・要約・次にやること)
3. ボタンで**確定**すると、次の2か所に記録されます。
   - 「対応履歴ログ」タブに1行
   - 企業マスタの「**関係メモ**」欄の先頭に、要約が追記されます
     (例:「【日付 訪問(録音)】要約… ▶次: …」。入口①で送ったものは「(LINE音声)」と表示)

確定ボタンを押すまでは台帳に書き込まれません。会社や内容が違っていたら、ボタンで直してから確定してください。

- **会社名は文字で送っても大丈夫です**(2026-10-28〜)。確認待ちのあいだにLINEで「株式会社◯◯」と送ると、その会社で最終確認の画面に進みます。候補が複数あれば選ぶボタンが、台帳に無ければ新しい会社として登録するかのボタンが届きます。
- 会社名が聞き取れなかったときは「会社名を文字で送ってください」と届きます(2026-10-29〜。以前は「(社名不明)」という会社が作られていました)。
- 既に「(社名不明)」として登録された会社は、台帳の「企業マスタ」の会社名を直接書き換えて直せます。同じ会社が台帳に別にある場合は、管理者に知らせてください(履歴を正しい会社へ移します)。
- 確認のボタンは、届いた日の**翌日の正午**までに確定されないと自動で取り消されます(2026-10-29〜。録音は残っているので、管理者が送り直せます)。

## 録音できなかった面談・入電を残すとき(2026-10-30〜)

台帳の「**福田_履歴インポート**」タブに1行書くと、数分で取り込まれます。台帳に無い会社は新しく登録されます。

| 列 | 書くこと |
|---|---|
| 会社名 | 会社名(台帳に無い会社でもよい) |
| 電話番号 | わかれば(同じ会社の見分けに使う) |
| 架電日 | 面談・入電の日付(「10/29」のような書き方でよい) |
| 通話結果 | 「**面談**」または「**入電**」(「訪問」「アポ」も読める) |
| 備考 | 話の内容・次にやること |

- 対応履歴には、面談は「面談実施」、入電は「入電」として残ります。
- 取り込んだ行は「**福田_履歴インポート_取込済**」タブ(1枚)の末尾へ、取り込んだ日時つきで移ります(2026-10-30〜。以前は取り込むたびにタブが増えていました。増えていた分も1枚にまとめました)。結果は「福田_インポート結果」タブに出ます。

## うまく記録するコツ

- 録音の最初か最後に、**会社名と、次にやること**を一言話す(「◯◯商事さん、次は11月に決算書をもらう」など)。
- ドライブに入れるファイルは、**ファイル名に会社名を入れる**と会社の特定が確実になります(例: 「株式会社◯◯_1026.wav」)。音声の内容と食い違うときは音声を優先します。
- 面談を録音するときは、**冒頭で相手に録音の了承を取る**。
- 1人につき1件ずつ処理します。前の記録の確認ボタンを押す前にLINEで次を送ると「前の記録がまだ完了していません」と返るので、確定(または取り消し)してから送り直してください。ドライブに入れたファイルは、前の確認が終わると自動で次に進みます。

## 前提(最初に一度だけ)

- 「スタッフ」タブに、本人の**メールアドレス**(ドライブにアップロードするGoogleアカウント)と **LINE User ID** が入っていること。
  - LINEに送ったときに「担当者が特定できませんでした」と返ってきた場合は、LINE User ID が未登録です。そのメッセージを管理者(小柳さん)へ転送してください。
- 受付フォルダは、「スタッフ」タブで有効な人に自動で共有されます。

## 仕組み(システム担当向け)

- 入口①: `glow-ma/src/LineVoiceLogRunner.gs`(LINE Webhook → 「音声ログ処理状況」タブ → 毎分のトリガーで処理)。14MBを超えるファイルはGeminiのファイル置き場へ送ってから文字起こしする。
- 入口②: `glow-ma/src/DriveVoiceRunner.gs` / 判断ロジック `glow-ma/src/voiceFileIntake.js`。受け付けたファイルは名前の先頭に「受付済_」が付く。
