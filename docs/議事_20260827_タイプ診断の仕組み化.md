# 議事: MBTI型「経営者タイプ診断」の仕組み化(システム化)

**日付**: 2026-08-27
**発端**: 小柳さんの着想「MBTIを仕組み化してシステムにできる」
**区分**: 掲載方針に関わる新コンテンツ(公開判断は小柳さん決裁が必要)。三名体制議事を必須とする類型①に該当

---

## 論点: MBTI型の16タイプ診断を、ミカタのLINE登録導線として仕組み化するか

### 前提の整理(番号の数え方の確認)

「MBTI」はここでは**16タイプ性格診断の型(4軸×2択→16タイプ)をリード獲得コンテンツに使う**という意味に解釈した。
glow-ma側の顧客タイプ分類(レター文面の出し分け等)への適用は別論点としてベッカイ欄に記載。

### スイシン(推進)

- 16タイプ診断はSNSでシェアされやすい定番フォーマット。既存の「30秒診断」(条件マッチ型)が
  「使える制度を探す人」向けなのに対し、タイプ診断は**まだ補助金を探していない経営者**にも届く入口になる。
  KGI(LINE登録1,000社)の未開拓層への面を広げられる。
- 診断→LINE登録はKPI(診断実施→LINE登録率30%以上)の既存導線と同じ型で、CV単一ルール(絶対ルール4)を守れる。
- 「仕組み化」の実装: 質問・タイプ・推薦をデータ(設定)として分離し、エンジン(採点ロジック)を汎用化する。
  次の診断(例: フクギイロの世帯版タイプ診断)はデータファイルを足すだけで作れる。
- 結果ページの推薦先を**テーマ別ページ(themes/、毎日更新の募集中一覧)への内部リンク**にすることで、
  制度名・金額・締切を静的コピーに書かずに済み、正確性最優先(絶対ルール1)と両立できる。

### ウタガイ(懐疑)

- **商標リスク**: 「MBTI」はMyers & Briggs Foundation系の登録商標。対外的な名称・文面に「MBTI」を使うのは不可。
  → 採用条件: 公開名は「経営者タイプ診断(16タイプ)」とし、対外文面にMBTIの語を出さない(本議事など内部文書のみ可)。
- **占いコンテンツ化の懸念**: タイプと補助金の対応は科学的根拠がなく、「あなたはこの補助金が使える」と読める書き方をすると
  正確性最優先に反する。→ 採用条件: 推薦は「相性がよさそうなテーマ」の傾向表現に限定し、
  制度の断定(必ずもらえる等)を禁止。免責文を結果ページに常設し、テストで断定表現を機械検査する。
- **導線の分散**: 診断が2つになると「どっちをやればいいの」と迷わせる。→ 採用条件: 公開時の置き場所
  (トップに並べるか、SNS企画用の独立URLにするか)は小柳さん決裁。それまで本ページはnoindex・非リンクで留める。
- **工数対効果**: 既存30秒診断の登録率改善が先ではないか。プロトタイプは可逆(ブランチ上・未公開)なので実害はないが、
  運用(SNSでの拡散企画)まで含めた効果はやってみないと不明。見直し期限で効果を測ること。

### ベッカイ(別解)

- 別解1: 対外コンテンツではなく、**glow-ma側の顧客分類**(経営者タイプ→レター文面・アプローチの出し分け)として
  仕組み化する読み方もある。ただしglow-ma実装は❶セッションに一本化されており、本リポジトリから直接触らない。
  必要なら連携メモで❶へ要件を渡す(本議事の実装はミカタの対外診断に限定)。
- 別解2: 16タイプでなく既存30秒診断に「経営スタイル1問」を足すだけでも出し分けはできる。
  ただしシェアされる「読み物」としての強さは16タイプ形式に分がある。
- 別解3: 診断結果をInstagram用画像として自動生成しSNS部の投稿素材にする拡張。今回は見送り、効果が出たら再検討。

### 結論(部門長の裁定)

- 採否: **プロトタイプ実装は採用(未公開・可逆)/ 公開(サイト導線への接続・SNS展開)は保留・小柳さんへ上申**
- 理由: ウタガイの3条件(①MBTIの語を対外に出さない ②断定禁止+免責+機械検査 ③公開判断は決裁待ち)を
  すべて実装に織り込めるため、可逆な範囲で形にして判断材料を揃える。仕組み化(データとエンジンの分離)により
  後続の診断コンテンツへ再利用できる資産になる。
- 見直し期限: **2027-02-27**(最長6ヶ月)。公開した場合は診断実施→LINE登録率を既存診断と比較して効果測定。
