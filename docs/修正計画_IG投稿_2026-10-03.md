## 修正プロセス

### ステップ1: 出典ページの最新確認(遥さん・Claude Code で並行)

```
各投稿について:
1. 出典URLにアクセス
2. 投稿に書いた値(期限・金額など)が「今もそこにあるか」確認
3. 新しい情報が見つかれば、古い投稿テキストとのギャップを記録
```

### ステップ2: テキスト修正

投稿が実際にInstagramに存在する場合(Haruka確認):
- Haruka が新しいテキストで修正投稿またはキャプション編集
- 修正内容を `/docs/投稿実績台帳.md` に記録

投稿が削除された場合:
- 新しい正確な情報で再度投稿

### ステップ3: 制度DB更新

```python
fk-kuni-shogaku-kyufukin-koko:
  "deadline": "2026-10-30",  # 9月30日 → 10月30日に修正
  "verified": True,           # 照合完了にマーク
  "verified_at": "2026-10-03"
```

### ステップ4: 検証記録の追加

```
docs/点検_IG投稿済みの照合状況.md に:
- 確認日時
- 確認者(Haruka / Claude Code)
- 出典ページのどこに情報があったか
- 修正前後の比較
```
