# KachiTalk営業成績データ統合ガイド

**目的**: KachiTalk管理画面からの訪問記録・営業成績データを、品質分析ダッシュボードに統合して、**品質スコア（6段階プロセス）と営業実績（訪問件数・スコア）の相関** を一枚で確認できるようにする

**更新日**: 2026-10-24  
**関連**: docs/enlife_KachiTalk品質管理ダッシュボード_セットアップガイド.md

---

## データフロー

```
KachiTalk管理画面
  ↓
「営業成績データ」エクスポート（Excel）
  ↓
extract_kachitalk_performance.py
  ↓
performance_output.csv
  ↓
Google Sheets「営業成績データ」シートにペースト
  ↓
統合ダッシュボード（品質+パフォーマンス表示）
```

---

## 利用方法（3ステップ）

### ステップ1: KachiTalkからデータをエクスポート

1. KachiTalk管理画面にアクセス
   - URL: `https://kachitalk-line-enlife.azurewebsites.net/admin`
   - APIキー入力

2. フィルタ設定
   - 期間: 8月1日～9月30日（または対象期間）
   - 営業マン: 全員選択

3. 「営業成績データをエクスポート」（Excel形式）でダウンロード
   - ファイル名例: `kachitalk_performance_202609.xlsx`
   - 列: 日付、営業マン、訪問種別、スコア、完了率、ステータス、レポートID、メモ

---

### ステップ2: Pythonスクリプトで変換

**コマンド**:
```bash
python3 /home/user/hojo-hq/enlife/scripts/extract_kachitalk_performance.py \
  --mode excel \
  --file /path/to/kachitalk_performance_202609.xlsx \
  --output /tmp/performance_output.csv
```

**出力ファイル**: `/tmp/performance_output.csv`

**出力内容**（集約形式）:
```csv
営業マン,対象月,訪問件数,平均スコア,平均完了率,OK件数
前原　芳乃,2026-09,15,87.3,92.0,12
下地　健太,2026-09,12,76.5,85.0,10
```

### ステップ3: Google Sheetにインポート

1. 出力CSVをテキストエディタで開く

2. 全てコピー (Ctrl+A → Ctrl+C)

3. Google Sheets「営業品質管理（エンライフ）」を開く

4. **「営業成績データ」シート** をクリック

5. セル **A2** をクリック（ヘッダーは残す）

6. ペースト (Ctrl+V)

## 品質スコア × 営業成績の相関分析（活用例）

### 発見パターン1: 品質高×成績高（理想型）
- 例: 前原芳乃（品質スコア87.3、訪問件数15、完了率92%）
- 評価: ベストプラクティス。やり方を他メンバーへ展開
- 対応: 通話スクリプト・訪問手法を共有

### 発見パターン2: 品質高×成績低（潜在能力型）
- 例: スコア85以上だが訪問件数が少ない
- 評価: プロセスは完璧だが営業活動量が不足
- 対応: 訪問数の増加目標を設定 / 理由ヒアリング

### 発見パターン3: 品質低×成績高（属人性型）
- 例: スコア60台だが訪問件数・完了率は高い
- 警告: プロセスをスキップしているが顧客に恵まれている
- 対応: 標準プロセス厳格化（持続性向上のため）

### 発見パターン4: 品質低×成績低（要改善型）
- 例: スコア60未満、訪問件数も少ない
- 優先度: 最高。教育支援開始
- 対応: ①②③④の基本ステップ定着支援

## よくある質問

### Q1. 営業成績データシートが見つかりません

**A**: 
1. Google Sheets を開く
2. メニュー: 拡張機能 → Apps Script
3. 関数選択: `ensureKachiTalkAnalysisTabs`
4. **▶実行**
5. Google Sheet をリロード → 「営業成績データ」タブが表示される

### Q2. CSVペースト後、統合ダッシュボードにデータが反映されません

**A**: 
1. Apps Script エディタで `buildConsolidatedDashboard()` を実行
2. 「統合ダッシュボード」シートをリロード

### Q3. 毎月自動化できますか？

**A**: 現在は手動です。以下で自動化可能：
- [ ] GitHub Actions で 毎月末に Python スクリプト実行
- [ ] 実行結果をGoogle Sheets API で自動ペースト
- [ ] 統合ダッシュボードを自動更新
（実装は別スコープ。要件書は docs/ へ）

### Q4. 8月と9月の両方を並べて見たいです

**A**: 「営業成績データ」シートに複数月のデータをペーストすると、月別に分かれて表示されます：

```csv
営業マン,対象月,訪問件数,平均スコア,平均完了率,OK件数
前原　芳乃,2026-08,12,84.5,90.0,10
前原　芳乃,2026-09,15,87.3,92.0,12
```

このとき統合ダッシュボードは最新月（9月）を優先表示。過去月の比較は「営業成績データ」シート上で可能。

## トラブルシューティング

| 症状 | 原因 | 対策 |
|------|------|------|
| CSVをペースト後、行がズレる | ヘッダー行を上書きした | ヘッダーを残したまま A2 からペースト |
| 営業マン名が認識されない | スペース形式が違う | 管理画面から「全角スペース1個」のみを使用 |
| ダッシュボードに「-」ばかり | 営業成績データシートが空 | CSVが正しくペーストされているか確認 |
| 「OK件数」がすべて0 | 管理画面の「ステータス」が「OK」以外 | 管理画面でステータス値を確認 |
