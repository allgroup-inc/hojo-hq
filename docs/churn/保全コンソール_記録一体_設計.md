# 保全コンソール（記録一体）設計 ― 全部システム内で・外で管理しない

小柳さん方針（2026-08-18）：**架電リストの表示から対応記録まで、すべてこのシステム内で行う。
あえて外（Excel）では管理しない。** これを実現する操作画面の設計。

## 何をする画面か
1. **今日の要接触**（優先度順・未払消滅目前＞不着＞…）を一覧表示。
2. 各行に**対応記録フォーム（選ぶだけ）**：手段／懸念／返し方／結果／次アクション。
3. **「保存」→ その場でログに追記**（`contact_log.append_contact`）→ 画面に「✅記録しました」。
4. 貯まった記録は、そのまま `dialog`／`talkscript`（教育カード）／`imminent-uplift`／`relapse-uplift`
   の入力になる＝**検知→架電→記録→学習が1つのシステムで閉じる**。

## つくり（重要：外部サービスを使わない）
- **ローカルWebアプリ**：Python標準ライブラリ（`http.server`）だけ。**pip不要・外部サービス不使用**。
- **データはこのPC内**：入力CSV（管理画面から落としたもの）と、記録の追記先（`private/…csv`）は
  すべてローカル。ブラウザで `http://127.0.0.1:8000/` を開いて使う（社内の統制されたPCで）。
- 実装：`scripts/churn/console_app.py`（`render_console`＝表示・`make_handler`＝GET一覧/POST記録）。

## 使い方（統制されたPCで）
```
python -m scripts.churn.cli console-serve \
  --csv <管理画面から落としたCSV> --column-map <column_map.json> \
  --contacts-out private/contacts.csv --contact-map docs/churn/contact_log_column_map.example.json \
  --as-of <当日> --capacity 54
```
→ 表示された `http://127.0.0.1:8000/` をブラウザで開く。上から架電し、その場で記録→保存。
記録は `private/contacts.csv` に貯まる（＝外のExcelに出さない）。

## 規律（変わらない）
- **churn-pii-guard**：実データはこの操作を**統制されたPCでのみ**。記録先は `private/`。公開リポに置かない。
  サーバはローカル（127.0.0.1）限定・アクセスログにPIIを出さない実装。
- 連絡は人が実行／督促にしない／**架電の成績で部下を評価しない**（優先順位づけの道具）。
- 保存する項目は**使うものだけ・選択式**（守り部は全記録可だが、データ最小化で最小限に）。

## エンジニア不在での立ち上げ（現実解）
- これは**1コマンドで起動する一体型アプリ**。エンジニアがいなくても、**Python導入→上のコマンド1行**で動く。
  導入は小柳＋Claudeが画面越しに手取り足取り案内（データはPCから動かさない）。
- 将来、部署の複数PCから使いたい／自動更新したい、となったら社内LAN配信や日次更新を足す（拡張）。
