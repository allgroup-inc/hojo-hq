# 徳元さんへ：架電リストの「拾う順」（いまのやり方に足すだけ）

小柳です。徳元さんが**管理画面から抽出して作っているリスト**、そこに**"拾う順（優先順位）"を
足すだけ**の話です。新しいソフトも、やり方を変える必要もありません。抽出のとき・部署に割り振る
ときに、下の順を意識してもらえれば十分です。

**考え方**：解約は「保険料が払えていない人」から起きます。だから **払えていない度合いが強い人＝
急いで一声かける人**。それを上から順に拾います。目的は「解約させないための、入金・手続きのお手伝い」。
しつこい督促ではありません。

## いまの業務の流れ（徳元さん確認済・2026-08-18）
- 成立情報は**業務管理（別部署）**が取引先システムで確認 → 管理画面に反映（**成立後2〜3日**）。
- **未収（Ⅳ）・不着が分かるのは毎月10日ごろまで**。Ⅳ更新・引受OK→成立済の切替も別部署が随時。
- **架電リストは徳元さんが管理画面から抽出**。**毎月10日以降**に初回引落・未収架電。**1日平均18件**。
- 朝いちばんに各自が割り振りリストを確認して架電。**リストが切れたら保障内容説明の保全架電**へ。

→ だから今回の提案は「**抽出のときに拾う順を足す**」＋「**リストが切れたときの保全架電を"新規の先回り"にする**」の2点だけ。

## リストが切れたら“新規に先回り”（いまの保全架電の中身をこれに）
架電リストが切れると保全架電（保障内容の説明）に回っていますよね。その枠を、**新規への先回り**に
充てるのが一番効きます。新しい申込ほど**初回引落（契約から約1か月後）でつまずくと早期解約**なので、
**引落の前に一声**が効くからです。

| 拾う人 | 見分け方 | 一声の中身 |
|---|---|---|
| **口座確認（引落の前）** | **初回引落予定日が近い新規**で口座が不安（Ⅳに★／口座不備の印） | 引落の前に「口座の準備、大丈夫ですか」。**不着を未然に防ぐ** |
| **初動（契約したて）** | **成立2〜3日〜引落前の口座振替の新規**（まだ接触なし） | 早めのごあいさつ・状況確認。困りごとがないか |

- 迷ったら **口座振替の新規は一度あいさつの一声**、が安全（クレカ新規は対象外）。
- これで「10日以降の未収架電」の前に、**そもそも滞る新規を減らせます**。

## いつ回すか（月のリズムに乗せる）
徳元さんのお話どおり、**未収・不着が分かるのは毎月10日ごろ**。無理に毎日やる必要はありません。
- **毎月10日以降＝メインの架電期**：抽出するリストに、上の**1〜5の順**を足す（未払消滅目前が最優先）。
- **随時（成立2〜3日〜引落前）＝新規の先回り**：リストが切れて保全架電に回るとき、上の「口座確認・初動」を対象に。
- **二度がけ防止**：架電したら「最終架電日」を控える（Ⅳの「済」印でも可）。同じ人を何度も急かさない。
- **これは「締切アラート（LINE）」とは別の連絡**です。混ぜないでください。
- **しつこい引き止め・督促にしない**（1〜2回まで・威圧しない）。解約はお客様の自由。
  やるのは「払える形（コンビニ・口座の直し・引落日の相談）を一緒に整える」ところまで。
- **架電の成績で部下を評価しない**（優先順位づけのための道具です）。

## できれば残してほしい記録（あとで“効いた対応”が分かる）
1行でいいので：**いつ・誰に・どんな話をして・どうなったか（つながった/入金してくれた/等）**。
これが貯まると「どの声かけが解約を防げたか」が数字で見えて、部下の教育にも使えます。
