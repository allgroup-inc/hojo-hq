「本物の数字（当たり具合＝AUC・解約の集中時期・今日の要接触）」を出すための手順。
**専門知識は要りません。詰まったら私（Claude）が画面越しに全部案内します。**
※実データ処理は**統制されたPCでのみ**。氏名なし・出力は private・公開の場には出しません。

## 先に通すゲート（ここが済むまで実データは読ませない）
- [ ] **守り部審査を1回**（保全記録に健康状態が混じり得る＝要配慮個人情報の保管。❺と同じ形式で）。
- [ ] **小柳さんの実データ投入 決裁**。
→ この2つが済むまでは、合成データでの確認までにとどめます（軸の判断3）。

## 用意するもの
- **統制されたPC1台**（ネットに広く晒さない・アクセス制限あり。徳元さんの業務PC等）。
- そのPCに入れる：**Python**（無料）と、**このシステムのコード一式**（`scripts/churn/`）。
- **実データのCSV**（管理画面のExcelを「CSV UTF-8」で保存したもの・氏名なし）。

## 手順（6ステップ・所要 半日）
1. **Pythonを入れる**（1回だけ）
   - Windows：python.org から入手 →インストール時に「**Add Python to PATH**」にチェック。
   - ※ここは私が画面を見ながら一緒にやります。
2. **コードを置く**
   - このリポジトリの `scripts/churn/` 一式を、そのPCのフォルダにコピー（zipで渡します）。
3. **列の対応づけ（column_map）を合わせる**
   - `column_map.real-template.json` を、実Excelの**列名と1文字単位で一致**させる。
   - 徳元さんに列名を教えてもらえれば、**私が調整**します（`column_map_作成メモ.md` 参照）。
4. **実データCSVを置く**
   - Excelを「**CSV UTF-8（カンマ区切り）**」で保存し、決めたフォルダに置く。
5. **コマンド1行で実行**（コピペで動きます）
   - まず門前チェック：
     ```
     python -m scripts.churn.cli preflight --csv <実CSV> --column-map <column_map.json> --as-of <当日>
     ```
     🛑が出たら列名を直して再実行（安全に止まる設計）。
   - 通ったら本番：`run_first_time.sh`（preflight→バックテスト→パイプライン一気通し）か、
     現場で使うなら保全コンソール：
     ```
     python -m scripts.churn.cli console-serve --csv <実CSV> --column-map <column_map.json> \
       --contacts-out private/contacts.csv --contact-map docs/churn/contact_log_column_map.example.json \
       --as-of <当日> --capacity 54
     ```
     → ブラウザで `http://127.0.0.1:8000/` を開くと「今日の要接触」が出ます。
6. **数字だけ小柳さんへ**（顧客情報は共有しない）
   - `backtest` の **AUC / ECE / precision**、コホートの確定率、保険料の件数分布。
   - この数字を見て、残りの設定（帯・金額区分など）を確定。**AUCの合格ラインは0.65で事前固定**（下げない）。

## つまずいたら
- **全部、私が画面越しに伴走**します（Python導入からコマンドまで）。1人でやり切る必要はありません。
- preflightは**安全に止まる**設計。エラーが出ても壊れません。列名を直して再実行するだけ。
