## 1. システムが実際に出すもの（事実・コード）

保全担当に出るのは「きっかけ」＋「手段」＋「今日のひとこと（提案）」だけ。**最終判断は人**。

| きっかけ | 今日やること（`triage._TOPIC`） | 手段 |
|---|---|---|
| 未払消滅目前 | 入金のご相談＋コンビニ用紙（消滅目前） | 高額は訪問／他は架電 |
| 不着／遅延 | 初回引落の不着・支払いの遅れを確認 | 原則 架電 |
| 未収2連続／口座確認 | 入金確認・引落口座を確認 | 架電 |
| 初動 | 初回のごあいさつ・状況確認 | 架電 |
| 高リスク | 様子伺い | 高額は訪問／他は架電 |

- **手段の決定**（`triage.contact_channel`）: 高リスク×守れる金額 ≥ `VISIT_SAVEABLE_MIN`（既定10万・**決裁事項**）
  または未払消滅目前×高額 → **訪問**。それ以外は架電。訪問は重コストなので少数に絞る設計。
- **対話ログ**（任意・`contact_log`）: 接触手段・**懸念**（選択式）・**返し方**（選択式）・次アクション。
  これを解約率と突き合わせて「効いた返し方」を教育カード化（`dialog`／`talkscript`）。
- 「今日のひとこと」の語彙は**すべて既契約のサポート**（入金相談・引落確認・ごあいさつ・様子伺い）。
  新規契約や他社乗換の勧誘は語彙に**存在しない**。

## 2. 募集規制まわりの論点（人＝守り部・専門家が判断）

保険契約の保全・引き止めは、**既契約を担当する有資格の募集人／代理店が行う継続的なサポート**であれば
通常の契約保全に収まると考えられるが、次の点は線引きの確認が要る。

### ★A. 「減額提案」は募集行為か（最重要）
- 合成データの対応内容に **減額提案** がある。既契約の**保障・保険料の見直し（契約内容変更）**は
  募集行為に当たり得る → **有資格の募集人が、所定の説明・書面手続きに沿って**行う必要がある可能性。
- 論点: システムは「減額の相談をきっかけとして出す」だけにとどめ、**実際の見直し提案・成立は
  有資格者の対面手続きに委ねる**設計でよいか。無資格者が減額を勧めることは避ける。

### ★B. 訪問者の資格
- 訪問・保全対応を行うのは誰か。**当該契約を担当する有資格の募集人／代理店の担当者に限定**すべきか。
  リスト（今日の要接触）を無資格の事務・派遣が“架電代行”する場合の線引き。

### ★C. 不当な引き止め・威圧の防止（保険業法・募集ルール）
- 解約は契約者の自由。保全は**情報提供と入金・手続きの支援**にとどめ、**執拗な引き止め・
  不利益の誇張・威圧**にならないこと。訪問は特に配慮が要る。
- 論点: トークスクリプト（教育カード）に**禁止事項**（言ってはいけない引き止め表現）を併記すべきか。

### ★D. 不当な乗換募集の禁止（保険業法300条の趣旨）
- 保全訪問の場で、**他社・新商品への乗換を勧誘しない**。保全と新規募集を混ぜない。
- 論点: 「保全訪問では新規・乗換の話をしない」を運用ルール・スクリプトに明記すべきか。

### ★E. 対話ログの機微情報（#142の延長）
- 懸念（家計・健康・必要性の疑問 等）は**機微になり得る**。
  - **コード側で担保**: ログは**選択式タグ中心**（自由記述を最小化）／出力は `private/` 限定／
    顧客IDベース・氏名なし（`contact_log`・`preflight.forbidden_name_keys`）。
  - **人が判断**: 収集する懸念タグの範囲・保持年数（#142の6年と整合）・要配慮個人情報の扱い。

## 4. 三名体制の議論（CLAUDE.md 規程・ウタガイの反対理由を記録）

- **スイシン（推進）**: 早期解約を3%未満にするには、未払消滅・不着の“消滅前の一手”が要。訪問は
  少数×高額に絞り、語彙は保全限定なので、既契約サポートの範囲で回せる。教育ループで対応品質も上がる。
- **ウタガイ（懐疑・反対）**: **反対理由=「減額提案」と「訪問での対話」は募集行為・不当引き止めに
  滑りやすい。** 無資格者が減額を勧める／訪問で強く引き止める運用が一度でも起きると保険業法リスク。
  教育カードが「解約させない話法」に最適化されると、契約者の自由な解約を妨げる方向に働く懸念。
  → **守り部監修の禁止事項と、実施者の資格要件が確定するまで、訪問・減額の実運用は保留すべき。**
- **ベッカイ（別解・前提を疑う）**: そもそも「訪問して引き止める」を前提にせず、**入金手続きの
  ハードルを下げる**方向（コンビニ用紙・口座再設定の案内・自動化）を主軸にすれば、募集規制に
  触れずに未払消滅を減らせるのでは。訪問は“手段”でなく“最後の少数例外”に。

**部門長裁定（たたき台）**: ベッカイの「まず手続き支援で消滅を止める」を主軸に採用。訪問と減額提案は
ウタガイの条件（守り部監修の禁止事項＋実施者の資格要件）が揃うまで**合成データ検証のみ・実運用は保留**。
