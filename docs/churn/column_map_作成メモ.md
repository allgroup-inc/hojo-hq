# column_map 作成メモ（あなたの実Excelに合わせる）

`column_map.real-template.json` は、このセッションで確認したあなたの実Excel列名を反映した
**たたき台**。実データを入れる前に、下の「要確認」を実ファイルの見出しと突き合わせて確定する。
※これは**列名（schema）だけ**でPIIは含まない。実運用の column_map は hojo-churn の private/ に置く。

## 重要（この前提）
- **顧客名はマップしない＝顧客IDで管理**（氏名系キーは preflight が門前で弾く）。
- 列名は**実ファイルの見出しと1文字単位で一致**させる（全角/半角・空白・「￥」などに注意）。
  ズレていると preflight が「CSVに無い対応列」で止める（＝安全側）。

## そのまま使える見込み（確認して合っていればOK）
| system key | 実列（想定） | 意味 |
|---|---|---|
| customer_id | 顧客ID | 顧客ID |
| apply_date | 契約日 | 開始日 |
| cancel_date | 初回保険料着金日 | 解約日（このセッションで確認済み） |
| product | 申し込み商品 | 商品 |
| channel | リスト種類 | 集客 |
| apply_form | 申込方法 | 申込形態 |
| amount | 保険料￥ | 保険料（月額） |
| gender | 契：性別 | 性別 |
| area | 市町村 | 地域 |
| agent_id | 営業担当者 | 営業マン |
| account_daily | 口座普段使い | 口座が普段使いか |
| debit_result | 初回引落結果 | 初回引落の結果 |
| debit_due | 引落予定日 | 引落予定日 |

## ★要確認（実ファイルで埋める）
1. **age（年齢）＝必須** — テンプレは `年齢＿要確認`。**年齢列があればその見出し名に置換**。
   無く**生年月日しか無い場合**は、取込前に**年齢を算出する前処理**が要る（または年齢列を足す）。
   age が埋まらないと preflight が「不足列」で止まる。
2. **apply_id（申込ID）** — テンプレは暫定で `顧客ID` を流用。**申込単位の一意ID（申込ID等）があれば
   その列に置換**を推奨（同一顧客が同日に複数契約したとき保全ログを契約単位で正しく突合できる）。
   無ければ顧客ID流用のままでよい（同日複数契約だけ突合が粗くなる・既知の制約）。
3. **cancel_reason（解約理由）＝任意** — 列があれば `解約理由` を確認、無ければこのキーを削除。
   理由ドリブンの打ち手（playbook）に使うので、あれば入れておくと良い。

## 使い方（hojo-churn で）
```
# 門前チェック（PIIは出ない・件数と列名だけ）
python -m scripts.churn.cli preflight --csv <実CSV> --column-map <この設定> --as-of <当日>
```
🛑が出たら上の要確認（特に age・列名一致）を直す。✅なら次は初回パイプライン（B群定数の確定へ）。
