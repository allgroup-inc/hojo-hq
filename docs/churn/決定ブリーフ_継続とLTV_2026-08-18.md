## 決定1｜再発（A3）を「今日の要接触」の優先度順に組み込むか

**いまの状態**: 優先度順（決裁済）＝未払消滅目前＞不着＞遅延＞未収2連続＞口座確認＞初動＞高リスク（帯内は守れる金額順）。
A3再発は**独立の監視リスト**。

**選択肢**
- **(a) 組み込まない（現状維持・別枠リスト）**: 決裁済み順序を触らない・単純。／ただし現場が2画面見る＝取りこぼしリスク。
- **(b) 優先度順に一段挿入**: 例「…遅延＞**再発**＞未収2連続…」。今日やることに載る。／決裁順を変える・帯が増え混乱・キャパ(30/日)圧迫。緊急度が低い再発(直近streak=1)も上位に来る。
- **(c) 独立枠のまま「今日の要接触」末尾に併記**: 順序不変・見落とし低減の折衷。
- **(ベッカイ) 順序でなく"帯内の並び"に再発加点**: 順序は変えず、同じトリガー帯の中で再発フラグのある契約を上に。

**三名体制**
- スイシン: 再発は解約前兆。今日やることに載せ取りこぼさない(b)。
- ウタガイ（反対理由）: 優先度順は決裁済。効果未検証で一段足すと現場が混乱しキャパを食う。再発は「監視」であって全部が「今すぐ架電」ではない。**再発への介入効果は段階導入で未検証**。効果が出るか分からぬうちに順位を上げるのは早い。
- ベッカイ: 単独トリガーにせず既存トリガーの**加点要素**に。順序は守り、帯内の並びに効かせる。

**推奨**: **当面(c)＋将来ベッカイ**。まず独立監視リストで運用し、A3の効果を段階導入（再発版uplift）で測る。効果が確認できたら、順序変更でなく「帯内で再発を加点」で組み込む。順序への一段挿入(b)は効果検証前はしない。
（小柳さんが「今すぐ載せたい」なら(b)で**未収2連続の直前**が妥当。）

## 決定2｜「切り替え」の定義（レーンB）

**論点**: 「切り替え案内」は2種類あり、規制の重さが全く違う。

- **(a) 既契約の見直し**（減額・特約調整・払済 等）
  - 中身: いまの契約の枠内で保障・保険料を調整。解約させない代替。
  - 規制: 契約内容変更＝募集行為に当たり得るが**既契約の範囲内**。有資格者が所定手続き。乗換ではないので300条（不当乗換）の直接対象でない。
  - 契約者利益: 「負担で解約」→「減額で継続」。保障を残せる。
  - リスク: 減額誘導が会社都合の引き止めに滑る。無資格者が勧めない線引きが必須。
- **(b) 別商品・上位プランへの乗換／追加**
  - 中身: いまの契約を解約・減額して別商品へ、または追加契約。
  - 規制: **新規募集＝募集行為の本丸**。**300条 不当乗換募集の禁止が直撃**（既契約を不利益に解約させて乗り換えさせない）。乗換で不利になる可能性の明示・比較義務。
  - リスク: 保全システムが「乗換営業装置」に転化する最大リスク。CV単一・事業の信頼と衝突。

**三名体制**
- スイシン: (a)減額で継続はLTV維持と契約者利益の両立。
- ウタガイ（反対理由）: (a)でも「減額して解約を防ぐ」は引き止めに滑る。**減額提案は顧客が負担を訴えたときに限定**し、システムからの能動プッシュにしない。
- ベッカイ: 二択でなく段階＝「まず入金支援(A1)で払える人は払う→それでも重い人だけ(a)減額→商品自体が不適合なら有資格者が(b)を**別枠で**」。切り替えを単独目的にしない。

**推奨**: **当面は(a)既契約の見直しに限定**。(b)別商品乗換は**保全の外・別枠**（有資格者の通常の見直し面談＋守り部・専門家の別判定）。理由: 目的は「早期解約を減らす＝既契約を守る」であり(a)が直結、(b)は規制・信頼リスクが大きく目的から逸れる。

## 決定3｜LTVの測定範囲

**LTVの構成要素と、現データで測れるか**
| 要素 | 中身 | 現データで測れるか |
|---|---|---|
| ① 継続月数 × 月額保険料 | 契約の累積保険料収入（最も基本のLTV） | **測れる**（契約日・保険料・解約日） |
| ② 保全コスト差引の正味 | 架電・訪問工数を引いた正味 | 接触回数（対話ログ）で近似可（貯まってから） |
| ③ 解約後の再加入・復活 | 復活契約の価値 | **現データにない**（復活の追跡が要る） |
| ④ 紹介・クロスの波及 | 士業・GLOW・保険クロス（出口1〜3） | **現データにない**（事業横断の紐付けが要る） |
| ⑤ 割引率 | 将来価値の現在価値化 | 設計判断 |

**三名体制**
- スイシン: まず①継続月数×保険料で十分、効率(工数対効果)が見える。
- ウタガイ（反対理由）: LTVを大きく取り過ぎると「解約させないこと」が自己目的化し、契約者不利益な引き止めを正当化しかねない。**LTVは満足継続の"結果"であって目標そのものにしない**。主KPIは継続率、LTVは従。
- ベッカイ: 金額LTVより「6/12/24ヶ月の**継続率カーブ**」の方が現場に分かりやすく効果も見やすい。金額LTVは経営報告用に別途。

**推奨**: **主KPI＝継続率**（早期解約<3% → 6/12ヶ月継続率）。**補助KPI＝①継続月数×保険料（＝守れた累積保険料）**を段階的に。②は対話ログが貯まってから、③④は事業横断で別途小柳さん判断（現システムの範囲外）。**「LTVを引き止めの口実にしない」歯止めを明記**。

## 決定4｜レーンB（追加提案）とCV単一ルールの関係

**前提整理**: CLAUDE.md 絶対ルール4「CV単一＝導線はLINE登録のみ、他CVは小柳さん承認なしに追加しない」。
これは**企業のミカタ（B2Cサイト）の集客導線**の話＝サイト訪問者をLINE登録に一本化する原則。
レーンB（既契約者への提案）は**すでに顧客の人への対応**でサイトCV導線とは別レイヤー。厳密には
CV単一ルールの直接対象ではない可能性が高いが、**その精神（押し売り導線を増やさない・信頼を守る）は効く**。

**2つに分けて判断**
- **B1 既契約の減額・特約（＝決定2の(a)）**: 契約者利益の既契約対応。新CV導線でない → **CV単一と非抵触**。守り部確認後に可。
- **B3 クロスセル／新商品提案**: CV/営業導線に当たり得る → **CV単一の精神と衝突**。小柳さん決裁事項。

**三名体制**
- スイシン: 満足客への提案はLTV拡大の自然な機会。
- ウタガイ（反対理由）: **保全窓口を売上導線にした瞬間、契約者は「相談したら売り込まれる」と警戒し、保全そのものが機能しなくなる**。CV単一の精神＝導線を濁さない、を保全にも適用。B3はやらない。
- ベッカイ: 追加提案が必要なら保全チームでなく別チーム・別タイミング（保全が一段落した満足客に別導線で）。**保全と提案を同じ接触に混ぜない**。

**推奨**: **B1は守り部確認後に可・CV単一と非抵触**。**B3（クロスセル/新商品）は当面やらない**。やるなら別導線・別チームで、継続率3%未満が安定してから小柳さん決裁。
