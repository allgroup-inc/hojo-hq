小柳です。早期解約を3%未満にする保全システムの準備が整いました。**実データで1回動かして、
設定を確定するための数字を出す**作業を依頼します。半日ほどで終わる想定です。

## この作業の位置づけ（済んでいること）

## 🔴 絶対に守ること（顧客個人情報）
1. **公開リポジトリの作業コピー・個人PCで実データを扱わない**。統制された社内マシン（アクセス制御・
   ネット非露出）で実行する。
2. **顧客名は取り込まない＝顧客IDで管理**（システムが門前で弾く仕様）。
3. 出力（`private/first_run/`）は顧客情報を含む。**コミット禁止・共有禁止**。共有するのは
   下記「持ち帰るもの」の**集計数字だけ**。

## やること（3ステップ）
1. 統制マシンにコードを置く（`scripts/churn/` 一式）。Python 3.11。
2. `docs/churn/column_map.real-template.json` を実Excelの見出しに合わせて確定
   （列名は1文字単位で一致。`docs/churn/column_map_作成メモ.md` 参照。age=年齢列・apply_idは顧客ID流用でOK）。
3. 実データCSVを置いて、**この1コマンド**を実行:
   ```
   sh scripts/churn/run_first_time.sh <実CSV> <column_map.json> <当日YYYY-MM-DD> <分割日YYYY-MM-DD>
   ```
   - 分割日 = 当日の「半年ほど前」を目安（バックテストの学習/検証の区切り）。
   - preflight で🛑が出たら、列名の一致・age列の有無を直して再実行（安全に止まる設計）。
