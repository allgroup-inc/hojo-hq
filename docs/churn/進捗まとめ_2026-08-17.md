# 早期解約リスク保全システム 進捗まとめ（2026-08-17）

契約から6ヶ月以内の早期解約を **3%未満** にする「保全トリガーを常に見つける装置」。
このまとめは現時点の到達点・残タスク・決裁待ちを1枚に。テスト **271件green**。実装は合成データ・TDD。

## 全体像（検知 → 行動 → 記録 → 学習 → 教育の閉ループ）
```
①検知   現ステータス分類 / Ⅳ未収パーサ / リスク採点 / 予防・初動・未払消滅目前トリガー
   ↓
②優先   今日の要接触（未払消滅目前＞不着＞遅延＞未収2連続＞口座確認＞初動＞高リスク・金額順）
   ↓
③行動   架電 or【訪問保全】（高リスク×守れる金額大は訪問に格上げ）＋今日の一手（提案）
   ↓
④記録   対話ログ（接触手段・懸念・返し方・次アクション）／月次スナップショット
   ↓
⑤学習   効果測定(experiment=段階導入で因果)／現ステータス遷移(救えた/失った)
   ↓
⑥教育   対話タイプ別の効き → 「この懸念にはこの返し方」教育カード（対応レベルの蓄積）
   ↓  （最初の一手へ戻る）
```

## 実装済み（主なモジュール／CLI）
- **取込・定義**: `schema`（現ステータス→継続/早期解約/対象外/母集団外・解約日=着金日）、`status`、
  `unpaid`（Ⅳ未収パーサ）、`intake`、`preflight`（門前・顧客名門前禁止）。
- **モデル**: `fit`/`score`/`evaluate`（AUC・較正ECE・精度@キャパ）。未収回数(unpaid_band)を要因に。
- **運用**: `triage`(今日の要接触・訪問エスカレーション・今日の一手)、`triggers`(不着/遅延/口座確認/
  初動/未払消滅目前)、`cohort`(3%スコアボード・除外件数併記)、`timing`(ハザード・架電適期)、
  `snapshot`/`retention`(保持6年削除)、`pipeline`(4層ハーネス・AUCゲート・べき等)。
- **学習・教育**: `experiment`(uplift/段階導入)、`effect_learning`、`transitions`(救えた/失った)、
  `playbook`、`dialog`(対話タイプ別効果)、`talkscript`(教育カード)。
- CLI: fit/score/backtest/cohort/today/pipeline/preflight/retention/hazard/call-timing/
  transitions/uplift/contact-timing/dialog/talkscript/playbook/snapshot 等。

## 現場知の反映（徳元さん・小柳さん）
- **「4か月連続未払で契約消滅」** → 3か月目に**未払消滅目前**を最優先で保全に出す（消滅前に止める）。
- **解約日=初回保険料着金日（成立済は無視）／クレカは対象外／口座振替に限定**。
- **死亡・クーリングオフ・告知解除は分母から除外＋件数併記**（小柳さん決裁）。
- **訪問保全＋対話ログ＋教育ナレッジ**（小柳さん発案）＝対応レベルを積み上げる仕組み。
