# 保全記録 かんたん入力様式（徳元さん・架電部下むけ／選ぶだけ）

架電・訪問したときに、**プルダウンから選ぶだけ**で残せる記録。手打ちは日付くらい。
これが少しずつ貯まると「**この懸念には、この声かけが効いた**」が数字で見えて、新人教育にも使えます。
（徳元さんの「今後の分だけならOK」に合わせています。さかのぼり入力は不要です。）

## いつものExcelに、次の列を足すだけ
顧客IDはいまのExcelにあるので、その行に**6列**足します（うち手打ちは接触日だけ）。

| 列名 | 入れ方 | 何を入れる |
|---|---|---|
| **接触日** | 手打ち | 架電・訪問した日 |
| **接触手段** | 選ぶ | 架電／訪問 |
| **懸念** | 選ぶ | お客様が気にしていたこと |
| **返し方** | 選ぶ | こちらがした声かけ・対応 |
| **結果区分** | 選ぶ | どうなったか |
| **次アクション** | 選ぶ | 次にやること |

> ※列名は上のとおりにしてください（将来、自動集計する時にそのまま使えます）。

## プルダウンの選択肢（この中から選ぶだけ・そのままコピーで設定できます）
Excelの「データの入力規則 → リスト」に貼れば、プルダウンになります。

- **接触手段**：`架電, 訪問`
- **懸念**：`保険料負担, 必要性の疑問, 家計不安, 商品理解, 手続き不明, その他`
- **返し方**：`入金のご相談・コンビニ用紙, 口座の再設定案内, 減額のご相談, 家計の見直し提案, 給付事例のご案内, 再説明・ご納得, ごあいさつ・様子伺い, その他`
- **結果区分**：`つながった, 入金いただけた, 検討中, 解約意向, つながらない`
- **次アクション**：`完了, 再架電, 訪問, 書類送付, 様子見`

## 使い方（かんたん3ステップ）
1. 架電・訪問したら、その顧客の行に **接触日** を打つ。
2. **懸念／返し方／結果区分／次アクション** をプルダウンから選ぶ（迷ったら「その他」でOK）。
3. それだけ。1件あたり10秒くらいのイメージです。

## 守ってほしいこと（少しだけ）
- **正確さより、続けやすさ優先**。分からなければ「その他」で構いません。
- これは**部下の成績評価には使いません**（どの声かけが効くかを知るための記録です）。
- しつこい督促にしない・解約はお客様の自由、は変わりません。

## （社内メモ・自動集計との対応）
この様式の列は保全ログ取込（`scripts/churn/contact_log.py` ／ `contact_log_column_map.example.json`）と
1:1で対応：接触日=contact_date／接触手段=medium／懸念=concern／返し方=approach／結果区分=result／
次アクション=next_action。将来 `dialog`／`talkscript` で「懸念×返し方」別の早期解約率・教育カードを出すとき、
このまま読み込める（作り直し不要）。実データの機械集計は統制環境・審査後。
