新しいソフトも、やり方の変更もいりません。管理画面から抽出するリストに、下の順を意識してもらう。

## パート1：架電する人の「拾う順」

### まず“外す”人（リストに入れない）
- クレジットカード払いの人（未収は口座振替の話。クレカは対象外）
- 現ステータスが：死亡解約／契約取り消し【成立後】／取消・解除【成立後】／謝絶／PL申込
- 顧客IDが空の行（管理画面のID漏れ）

### 次に“上から順に”拾う（上ほど急ぐ）
| 順 | 拾う人 | 見分け方（Ⅳ列・現ステータス） | 一声の中身 |
|---|---|---|---|
| **1（最優先）** | **未払消滅目前** | Ⅳに**直近3か月連続の未収**（例 未26⑤⑥⑦） | 入金のご相談＋コンビニ用紙。**4か月連続で契約が消える前に** |
| **2** | **不着** | 現ステータス＝**引受OK**（初回引落ができなかった） | 初回引落の確認・入金のご案内 |
| **3** | **遅延** | 支払いが遅れている | 支払いの遅れの確認 |
| **4** | **未収2連続** | Ⅳに**直近2か月連続の未収**（例 未26⑥⑦） | 入金確認 |
| **5** | **再発** | Ⅳの未収が**とびとび**（一度止まってまた未収） | また滞りかけの様子伺い |

- 同じ区分の中では**保険料が大きい人から**。
- Ⅳに★（口座不備）が付く人は「**引落口座の再設定のご案内**」も一緒に。
- Ⅳの「済」＝案内済／「●」＝コンビニ用紙送付済、の目印（二重に急かさない）。

### 新規は“先回り”（リストが切れて保全架電に回るとき）
新しい申込ほど、**初回引落（契約から約1か月後）でつまずくと早期解約**になります。引落の前に一声が効きます。
- **口座確認**：初回引落予定日が近い新規で口座が不安（Ⅳに★） → 引落前に「口座の準備、大丈夫ですか」
- **初動**：成立2〜3日〜引落前の口座振替の新規 → 早めのごあいさつ・状況確認
- 迷ったら「口座振替の新規は一度あいさつ」が安全。

### いつやるか
- **毎月10日以降＝メイン**（未収・不着が分かる頃）。抽出リストに上の1〜5の順を足す。
- **随時＝新規の先回り**（リストが切れたとき）。
- 二度がけ防止に「最終架電日」を控える。これは締切アラート（LINE）とは別の連絡。

## パート2：対応の記録（選ぶだけ・今後の分だけでOK）

架電・訪問したら、いつものExcelに**次の列を足して、プルダウンで選ぶだけ**。手打ちは接触日だけ。
これが貯まると「どの声かけが効いたか」が数字で見えて、新人教育にも使えます。

| 列名 | 入れ方 | 内容 |
|---|---|---|
| 接触日 | 手打ち | 架電・訪問した日 |
| 接触手段 | 選ぶ | 架電／訪問 |
| 懸念 | 選ぶ | お客様が気にしていたこと |
| 返し方 | 選ぶ | こちらの声かけ・対応 |
| 結果区分 | 選ぶ | どうなったか |
| 次アクション | 選ぶ | 次にやること |

**プルダウンの選択肢**（Excelの「データの入力規則→リスト」に貼れます。同梱の見本CSVも同じ）
- 接触手段：`架電, 訪問`
- 懸念：`保険料負担, 必要性の疑問, 家計不安, 商品理解, 手続き不明, その他`
- 返し方：`入金のご相談・コンビニ用紙, 口座の再設定案内, 減額のご相談, 家計の見直し提案, 給付事例のご案内, 再説明・ご納得, ごあいさつ・様子伺い, その他`
- 結果区分：`つながった, 入金いただけた, 検討中, 解約意向, つながらない`
- 次アクション：`完了, 再架電, 訪問, 書類送付, 様子見`

※迷ったら「その他」でOK。**続けやすさ優先**です。

## 守ってほしいこと（少しだけ）
- しつこい引き止め・督促にしない（1〜2回まで・威圧しない）。解約はお客様の自由。
  やるのは「払える形（コンビニ・口座の直し・引落日の相談）を一緒に整える」ところまで。
- **架電の成績で部下を評価しない**（優先順位づけの道具です）。
- 記録は**部下の成績評価には使いません**（どの声かけが効くかを知るための記録です）。

困ったこと・やりにくいことがあれば、いつでも言ってください。やりやすい形に一緒に直します。
