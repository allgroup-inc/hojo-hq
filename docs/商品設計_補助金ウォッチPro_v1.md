# 商品設計: 補助金ウォッチPro(企業向け月額)v1

**ドラフト(小柳さん決裁前・数値は全て仮)**

- 器: **フクギイロ経由の法人契約に統一(個人契約は行わない)**
- Grp資産(収集パイプライン・制度DB・個別通知機構)の利用: **2026-07-31 嶺井さん・遥さん了承済み**。覚書等の書面化は守り部→税理士・弁護士確認の流れで別途
- 実証: 収集パイプライン(毎日2回・約1年稼働)+個別通知機構(基準❺・完成済み)。技術的な追加開発は条件マッチングの個社設定が中心と見込む

## 1. 対象・提供価値(仮説)
- 対象: 補助金を「見逃したくない」沖縄の中小企業(将来的に県外・他業界へ横展開余地)
- 提供価値: 自社条件(業種・規模・所在地・投資予定)に合う新着制度と締切を自動監視し、LINE/メールで個別通知。締切逆算の準備リマインド(gBizID等)付き

## 2. 価格案(全て仮・市場検証前)

| A: ライト | 2,980円 | 条件マッチ新着通知(週次まとめ) |

推奨: **B を標準**。100社で月60万規模のポテンシャル(仮)。ただし低単価×多数モデルのため決済・請求の完全自動化(Stripe)がゲート条件。

## 3. 無料版(ミカタ)との線引き — 守り部視点(必須論点)
憲法・絶対ルール4「CV単一: ミカタの導線はLINE登録のみ。広告・他CVは小柳さん承認なしに追加しない」との整合が本商品の最大論点。守り部視点の整理:

1. **ミカタのサイト・LINE上に Pro の販売導線を置かない**(バナー・リンク・配信での告知を含めて禁止)。置く場合はCVが2つになり憲法違反。販売はノビシロ/フクギイロの棚とPro専用LPのみで行う
2. 無料版(ミカタLINE)の提供水準は**下げない**。締切3層ルールのアラートは無料のまま維持し、「無料を劣化させて有料へ誘導」する設計は採らない(ブランド毀損+守り部NG)
3. 線引きの案: 無料=全体向けアラート(3層ルール)/ Pro=**個社条件マッチの即時通知+逆算リマインド**という「個別化」の有無で切る
4. ミカタ登録者リストをProの営業対象にすることは**利用目的明示の範囲外となる可能性が高く、小柳さん決裁+守り部審査なしには行わない**(増設プラン・ガバナンス1項と同旨)
5. 正確性最優先ルールはProにもそのまま適用: 通知は原文URL併記・不明時「要確認」表示・断定しない

## 4. ステージゲート・解約条件
- 最初の3件は手売り(提携部の商工会・金融機関ルート想定。ミカタリードは上記4のため使わない)。合格基準: 有償3社+通知精度クレームゼロで2ヶ月継続
- 月契約・いつでも解約可。解約時は登録条件情報を削除(受託時情報管理規程ドラフト準拠)

## 5. 三名体制議事

### スイシン(推進)
- 限界費用が最も低いモデル。基盤は1年稼働の実績があり、1社追加=設定1件。B-2(士業ホワイトレーベル)・B-4(金融機関OEM)への発展余地も大きい

### ウタガイ(懐疑)
- **月2,980〜9,800円で「誰が」払うのかの一次情報がゼロ**。無料のミカタが既に存在する市場で、個別化にいくら払うかは完全に未検証。無料で十分と判断される可能性が相応にある
- CV単一ルールとの緊張は「導線を分ける」で形式上は回避できても、**同じ制度DBを無料と有料で使う構図自体**が「ミカタは撒き餌だったのか」という信頼毀損リスクを孕む。守り部の形式審査だけでなくブランド影響の評価が要る
- 通知の誤り(締切間違い等)が有料だと損害賠償問題に発展しうる。免責条項と「原文確認は利用者責任」の規約整備が弁護士確認前に売れない理由になる

### ベッカイ(別解)
- 企業直販ではなく**B-2/B-4(士業・金融機関への卸)を第1弾**にすれば、CV単一ルールとの接触面が消え、1契約あたり単価も上がる(月1〜15万)。エンドユーザー課金の検証はその後でよい
- あるいは沖縄以外の「入札ウォッチ」(増設★5)を先行させ、ミカタと市場を分離してから補助金Proに戻る順序も検討価値あり

### 結論(提案・小柳さん上申)
- 採否: **提案・上申(条件付き)** — 価格Bを標準としつつ、**§3の線引き5点の守り部正式審査+利用規約の弁護士確認を開始条件**とする。ベッカイの「士業・金融機関卸を第1弾に繰り上げる」案は有力なため、直販と卸のどちらを先にするかは小柳さんの判断を仰ぐ
- 理由: 技術実証は最強だが、本商品だけは憲法(CV単一)との構造的緊張があり、部門長裁定で進めてよい範疇を超えるため
- 見直し期限: 2026-10-31
