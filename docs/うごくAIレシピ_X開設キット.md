# うごくAIレシピ_X開設キット(小柳さん用・作業約15分)

新路線「うごくAIレシピ」専用のXアカウントを作るキットです。
ミカタ・フクギ・結果マガのアカウントとは完全に別運用にします(名義分離)。

## 0. 2個目アカウントならではの注意(結果マガ用Xがあるため)

- **作り方**: 既存アカウントのアプリから**「アカウントを追加」→新規作成**でOK(1端末で最大5つ切替可)
- **メールアドレスは別のものが必要**(1メール=1アカウント)。電話番号は使い回せますが、
  紐付いたアカウントは片方が凍結されるともう片方も巻き添えになるリスクがあるため、
  **電話番号の登録は認証を求められたときだけ**にするのが安全です
- **新規アカウントは最初の1〜2週間が最も凍結されやすい**: 作成直後の大量フォロー・URL連投・
  同じ文面の連続投稿はスパム判定されます。最初はプロフィール整備+固定ポスト+1日1本まで
- **結果マガ側アカウントとの相互RT・同内容の同時投稿はしない**: 複数アカウントで同じ内容を
  増幅する行為は規約違反(プラットフォーム操作)と判定されるリスクがあり、凍結対象です。
  ブランド分離の方針とも一致
- **投稿前にアイコン確認**: 切り替え式なので、緑のターミナルマークになっているか毎回確認

## 4. 運用ルール(自動化との接続)

- 記事の下書きには**X告知文が3パターン(A数字/B学び/C問い)自動で同梱**されています。
  note公開後、どれか1つを投稿し、**記事URLはリプ欄**に貼る(URL入りポストは表示が伸びにくいため)
- 頻度: **1日1本まで**。公開日以外は無理に投稿しない(自動生成の告知文がある日だけでOK)
- リプライが来たら短くてよいので返信する(エンゲージメント優先の仕様対策)
- 収益や成果の断定はしない(記事本文と同じ基準。禁止語: 必ず/絶対/誰でも/楽して/確実に稼)
