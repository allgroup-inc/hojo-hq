## 4目標のつながり(どこを押すと効くか)
```
❸Instagram・検索  →  ❶サイト流入  →(3分診断)→  ❹LINE登録  →(受給フォロー)→  ❷受給報告
```
- **❷が北極星**: 「制度を知らせた → 実際にもらえた」の証明。事業の存在価値そのもの。
- **❹が主エンジン**: 継続接点。締切アラートで再訪・受給フォローを回す。
- **❶が分母**: 流入が増えないと❹も❷も伸びない。
- **❸が入口**: 沖縄の生活者接点。地域名×制度で第一想起を取る。

## 安全(常に優先・崩さない)
- 正確性最優先(`hojo-accuracy-check`): 締切・金額・要件は原文照合、不明は「要確認」。
- 締切表現(`hojo-deadline-alert`): 3層ルール・「締切の約1か月前から」。「7日前アラート」は誤り。
- 資格業務の線引き(守り部): 申請代行はしない。士業紹介まで。対価は掲載/月額/定額送客料の形式(非弁提携回避)。
- CV単一: 導線はLINE登録のみ。`/go/<チャネル>/` 経由(lin.ee直貼り禁止)。
- 個人情報: PIIを公開リポジトリに置かない。受給報告フローは取得目的をプライバシーポリシーに明記。
