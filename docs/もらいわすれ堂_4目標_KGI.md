## 4目標のつながり(どこを押すと効くか)
```
❸Instagram・検索  →  ❶サイト流入  →(3分診断)→  ❹LINE登録  →(受給フォロー)→  ❷受給報告
```
- **❷が北極星**: 「制度を知らせた → 実際にもらえた」の証明。事業の存在価値そのもの。
- **❹が主エンジン**: 継続接点。締切アラートで再訪・受給フォローを回す。
- **❶が分母**: 流入が増えないと❹も❷も伸びない。
- **❸が入口**: 沖縄の生活者接点。地域名×制度で第一想起を取る。

## 計測ソース(まず「つなぐ」が最優先)
- ❶ サイト人数: GA4 / Plausible(未接続なら接続が第一タスク)
- ❹ LINE登録数: LINE公式アカウント / 台帳
- ❸ IGフォロワー: Instagram(Graph API / 手動)
- ❷ 受給報告: LINE経由の受給報告フロー → 企業/世帯台帳(**要新設・実装**)
- 取れない数字は週次レポで「未接続/取得不可」と明記する。

## 運用(この目標をどう回すか)
- **週次「進捗ループ」Routine**: 毎週、4目標の現在地を測る→ボトルネック1つを特定→AI側でL1/L2を実行(コミット→PR→マージ)→小柳ToDoを更新→報告。
- **週次「成功事例ウォッチ」Routine**: 同業・競合・制度改正を調べ `docs/成功事例ウォッチ_ログ.md` に記録し、使える示唆を取り込む。
- 判断を伴う論点は `hojo-triangle-review`(ウタガイの反対理由必須)で議事化。

## 安全(常に優先・崩さない)
- 正確性最優先(`hojo-accuracy-check`): 締切・金額・要件は原文照合、不明は「要確認」。
- 締切表現(`hojo-deadline-alert`): 3層ルール・「締切の約1か月前から」。「7日前アラート」は誤り。
- 資格業務の線引き(守り部): 申請代行はしない。士業紹介まで。対価は掲載/月額/定額送客料の形式(非弁提携回避)。
- CV単一: 導線はLINE登録のみ。`/go/<チャネル>/` 経由(lin.ee直貼り禁止)。
- 個人情報: PIIを公開リポジトリに置かない。受給報告フローは取得目的をプライバシーポリシーに明記。
