## A. データを安全に出す(ブロッカー1)

**目的**: 私が実データで「当たるか(AUC)」を検証できるようにする。**本物の氏名・住所・生年月日は渡さない**のが安全。

### A-1. 非識別化CSVを作る(利用者側でExcelでできる範囲)
1. いただいたExcelを開く。
2. **直接識別子の列を削るか、丸める**:
   - `氏名`(あれば)→ **列ごと削除**
   - `生年月日` → **西暦の年だけ残す**(または「年代」列を作る)。月日は削除
   - `住所` → **市町村まで**にする(番地・詳細は削除)。`県`と`市町村`だけ残す
   - 電話・メール・証券番号など → **列ごと削除**
3. **名寄せ用のID列を1つ用意**(下記A-3)。
4. 「名前を付けて保存」→ ファイル形式 **CSV UTF-8**(パスワードなし)→ 保存 → アップロード。
5. 申込み台帳と接触履歴が別なら、**2ファイル**アップロード。

> これで、渡すデータは「年代・性別・市町村・商品・金額・申込方法・ステータス・日付・仮ID」だけになり、万一漏れても個人特定が困難になります。

### A-3. 顧客ID(名寄せキー)の確認 ← 重要
- いただいたリストには**顧客ID列が見当たりません**。以前「IDあります」とのことでしたが、
  - **別の列/別リストにID**があれば、それを1列足してください(仮名化は私が行います)。
  - 無ければ、**リスク予測(当たるか)はID無しでも検証可能**ですが、**顧客カルテ・複数契約の束ねはIDが無いとできません**。ここをどうするか教えてください。
