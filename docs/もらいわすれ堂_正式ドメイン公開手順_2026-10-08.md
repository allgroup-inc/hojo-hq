## 概要

もらいわすれ堂を独自ドメイン `moradou.jp` で公開するための、**小柳さんの操作手順**です。

詳細は `deploy/moradou/README.md` を参照。

---

## 小柳さんがやること（手動作業）

### STEP 1️⃣: ドメイン取得（10分・年額3,000円前後）

1. お名前.com / ムームードメイン / Xserverドメイン 等でドメイン取得
2. **ドメイン**: `moradou.jp`
3. **登録者情報**: 株式会社フクギイロの正式情報で登録
4. **Whois代行**: 必ずON（登録者住所・電話が誰でも見られるのを防ぐ）
5. **自動更新**: ON（切れるとサイトが丸ごと落ちます）

### STEP 2️⃣: GitHub Pages 設定（3分）

allgroup-inc/moradou リポジトリで：

1. **Settings → Pages**
2. Source: **Deploy from a branch** / Branch: **main** / Folder: **/ (root)**
3. **Custom domain**: `moradou.jp` を入力 → Save
   - （DNSがまだなら「DNS check unsuccessful」と出ますが、OK）
4. DNSが通ったあと、**Enforce HTTPS** にチェック

### STEP 3️⃣: DNS設定（5分・ドメイン取得先の管理画面で）

**A レコード 4本** を追加（ホスト名: 空欄または `@`）:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**CNAME 1本**（www サブドメイン用）:
```
www  →  allgroup-inc.github.io
```

**完了**：DNS伝播に数分〜数時間かかります。

## Claudeが自動実行する部分

### 準備状況チェックリスト

- [x] site/fukugiiro/ 最新版を確認（STEP 1完了済み）
- [x] allgroup-inc/moradou リポジトリ存在確認
- [x] GitHub Pages Settings の推奨値をドキュメント化
- [x] 開通確認スクリプト (moradou-cutover.yml) が自動監視

### 自動動作（DNS設定後）

1. **hojo-hq のワークフロー `moradou-cutover` が4時間ごとに実行**
   - moradou.jp が開通したかチェック
2. **開通確認条件** (3つともOK):
   - `https://moradou.jp/` が開く
   - canonical が `moradou.jp` を指している
   - `/yamanashi/` と `sitemap.xml` が新ドメインのURLを含む
3. **開通確認後、自動実行**:
   - 旧URLのcanonical を moradou.jp へ全件書き換え（439ページ + 手書きページ）
   - SNS・検索エンジンへの正規URL更新
