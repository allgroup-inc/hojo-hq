- **要確認**:11/10 以降の録音が記録されていない見え方になっている。LINE の受信そのものが止まっているのか、スナップショットが古いのかを、復旧の前に台帳の最新状態で確かめる。
- **取り消しの仕組み**:「受信済み」は放置検知の対象外(取り消されない)。確認待ち(文字起こし済み・企業選択待ち・新規企業確認待ち・最終確認待ち)は、確認期限(翌日の正午)を過ぎると取り消される。復旧の直前に、確認待ちが 0 件であることを再確認する。
- **Gemini の費用・LINE 通知の集中**:受信済みの録音は、毎分、担当者ごとに1件ずつ処理される(1回の実行は開始から3分まで)。大量に溜まっていた場合、通知が連続して届く。
- **BlueBean 同期**:前回の取得時刻(11/18 15:42 ごろ)から今までを取り直す。通話 ID で重複を除くため、二重登録はしない。取り直しが大きいと、毎分の処理の時間(6分)を圧迫しうるため、初回の実行記録の時間を確かめる。
