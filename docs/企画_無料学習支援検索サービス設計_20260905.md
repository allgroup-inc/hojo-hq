## 結論(先に要点)

- **作るもの**: 「サービス名を並べるサイト」ではなく、**質問に答えると"あなたが今使える可能性が高い無料の勉強サービス"が出てくる検索サービス**。
- **一番大事なデータ項目**: 全サービスに「**沖縄県在住者が利用可能か**(○/△/×/?)」を必ず持たせる。ここがこのサービスの存在理由。
- **作り方**: hojo-hq(沖縄企業のミカタ)で既に動いている仕組み(データ収集→Claude整形→静的サイト公開→URL死活監視)を**そのまま流用**すれば、**サーバー費用ほぼ0円・3か月でMVP公開**できる。
- **絶対に守ること**: 正確性最優先(締切・条件は原文照合、不明は「要確認」)、子どもの個人情報を取らない(登録不要・追跡なし)、掲載団体の安全審査。

## 1. サービスコンセプト

**「知らなかったから使えなかった」をゼロにする。**

無料・実質無料の学習支援は全国に山ほどある(NPO、財団、大学、自治体、企業CSR、オンライン家庭教師ボランティア…)。
問題は「存在しないこと」ではなく「**沖縄の当事者に届いていないこと**」。

- 情報が各団体のサイトにバラバラに散らばっている
- 制度名が難しく、検索の仕方が分からない
- 「自分(うちの子)が対象なのか」がページを読み込まないと分からない
- 募集が終わっているのに情報だけ残っている

このサービスは、その全部を1か所に集め、**「何年生? どんな勉強? どんな方法? 家の状況は?」の4問に答えるだけ**で、沖縄から使える可能性が高い順に表示する。

一言で言うと: **無料で勉強できる場所の「乗換案内」**。目的地(勉強したいこと)を入れたら、使える経路(サービス)が出てくる。

対象は「貧困支援サイト」ではなく「**沖縄のぜんぶの子の、学びの入口**」。所得制限のないサービスも同列に載せることで、使うことに引け目を感じない設計にする(NAME CONCEPTの章参照)。

## 4. ユーザー課題

| ユーザー | 課題 | このサービスの答え |
|---|---|---|
| 子ども | 「塾に行けない」で思考停止。無料の選択肢を知らない | 4問で候補が出る。登録不要ですぐ見られる |
| 不登校の子 | 学校経由の情報が届かない。対面がつらい | 「不登校OK」「オンライン」「LINEだけ」で絞れる |
| 保護者 | 制度名が難しい。「うちが対象か」分からない | 専門用語に補足(例:「住民税非課税世帯=家の収入が一定以下の家庭」)。条件マッチで表示 |
| ひとり親家庭 | 探す時間がない | スマホ3分で候補+申込URLまで到達 |
| 教員・SSW・福祉職員 | 紹介できる先の一覧が手元にない。情報が古い | 条件検索+最終確認日表示。印刷用ビューで面談に使える |
| 支援団体 | 沖縄の子に届けたいが広報手段がない | 無料掲載(審査あり)。掲載基準は全公開 |

共通する根っこ: **「情報はある。届いていないだけ」**。だから作るのはコンテンツではなく検索インフラ。

## 10. サービス詳細画面

構成(スマホ縦1カラム):

1. **結論ブロック**: サービス名/一言説明/沖縄から利用可能か(○△×?+理由:「全国対象」「自治体限定」「学校経由のみ」等)/完全無料か(一部無料・条件付きは内容明記)
2. **対象**: 学年・年齢/家庭状況の条件(専門用語に必ず補足)/所得制限の有無
3. **内容**: 科目/指導形式(1対1・少人数・集団・映像・AI・LINE・Zoom・電話・対面)/頻度・期間/先生の属性(大学生・教員・塾講師・社会人・専門家・ボランティア)
4. **対応領域**: 不登校/ひとり親/生活保護世帯/住民税非課税世帯/高校受験/大学受験/発達特性/外国ルーツ 等のバッジ
5. **申込み**: 申込方法/募集状況(募集中・募集終了・次回募集予定・常時募集・不明)/募集期間・定員・待機リスト/申込URL/問い合わせ先
6. **信頼情報**: 運営団体・団体種別(自治体/NPO/一般社団法人/財団/大学/企業/個人団体)/公式URL/**出典URL・最終確認日・情報更新日**
7. 注意表示: 最終確認から60日超は「⚠ 情報が古い可能性があります。公式サイトでご確認ください」を自動表示

## 11. おすすめ機能(説明できるスコアリング。ブラックボックスにしない)

AIの推薦ではなく、**ルール式の加点方式**。理由を全部表示できる。

| 判定 | 加点 | 表示する理由文 |
|---|---|---|
| 沖縄から利用可 ○ | +30 | 「沖縄県から利用できます」 |
| 沖縄から利用 △ | +10 | 「条件によっては沖縄から利用できます」 |
| 沖縄から利用 × | 除外 | (表示しない。ただし「沖縄からは使えないが参考になる」一覧は別枠) |
| 学年が対象 | +20 | 「○年生が対象です」 |
| 希望の勉強内容が合致 | +15 | 「高校受験に対応しています」 |
| 希望の方法が合致 | +10 | 「Zoomでのマンツーマンです」 |
| 家庭状況の条件に合致 | +15 | 「ひとり親家庭が対象です」 |
| 完全無料 | +5 | 「完全無料です」 |
| いま募集中 | +5 | 「いま申し込めます」 |
| 募集終了 | -50 | 「いまは募集していません(次回予告あり)」 |
| 最終確認60日超 | -10 | 「情報が古い可能性があります」 |

おすすめ度% = 得点 ÷ 満点 × 100。**計算式そのものを /about で公開**する(掲載基準の公開と同じ思想)。

## 13. データ収集方法

hojo-hq の運用と同じ規律を適用する。

1. **一次情報のみ**。優先順位: 国 > 自治体 > 団体公式サイト > NPO公式 > 財団公式 > 大学公式 > 企業公式 > 信頼できる報道 > その他。**SNS投稿だけを根拠に登録しない**
2. 全レコードに **出典URL・確認日・最終更新日を必須**(欠けたら公開できない仕組みにする)
3. 締切・金額・条件は原文照合。不明は「要確認」で公開し断定しない(hojo-accuracy-check スキル準拠)
4. クロールは robots.txt と利用規約を守り部が事前承認したサイトのみ(絶対ルール2)
5. 初期データは手作業+Claude整形で100件を目標(下記MVP参照)

## 14. 全国の情報収集戦略

当たる順番(取れ高が大きい順):

1. **中間支援組織のリスト**: 全国こども食堂支援センター・むすびえ、キッズドア、カタリバ、Learning for All 等の大手NPO(1団体で複数プログラムを持つ)
2. **財団の助成先一覧**: ベネッセこども基金、日本財団、ドコモ市民活動団体助成 等の「採択団体リスト」は無料学習支援団体の宝庫
3. **国の事業一覧**: こども家庭庁「地域こどもの生活支援強化事業」、文科省「地域学校協働活動」、生活困窮者自立支援制度の学習支援事業(全自治体分)
4. **47都道府県+市区町村サイト**の「学習支援」「無料塾」ページ(hojo-hqのクローラ資産を流用)
5. **大学のボランティアセンター**(教育学部系は学習支援サークルが定番)
6. **企業CSRページ**(通信教育・出版・IT企業の無償提供プログラム)
7. **常設オンラインサービス**: NHK for School、スタディサプリ無償提供枠、YouTube授業(とある男が授業をしてみた等)、AI学習の無料枠 — ここは沖縄から100%使えるので初期の目玉になる

## 15. 情報更新方法(鮮度管理)

- recruitment_status(募集中/募集終了/次回募集予定/常時募集/不明)を全件必須
- **URL死活チェックを毎日自動実行**(GitHub Actions。404・リダイレクト・タイトル変化を検知して管理画面に列挙)
- ページ内容のハッシュ比較で「料金・対象・申込URLの変更らしきもの」を検知 → 人間が確認
- last_verified から60日で「⚠古い可能性」自動表示、120日で検索結果の順位を下げ、180日で要再確認リスト入り
- 検証部の週次サンプリング(無作為3件を原文照合)を本サービスにも適用

## 16. 安全性・掲載審査

子ども向けであるため、hojo-hq より一段厳しくする。

**掲載前チェックリスト(守り部審査。全項目クリアで公開)**
1. 団体の実在確認(法人番号 or 自治体の登録 or 公式サイト+活動実績2年 or 信頼できる後援)
2. 公式サイト・連絡先が機能している
3. 料金が本当に無料/実質無料(あとから高額教材を売る等の「無料商法」を除外)
4. 宗教・政治・マルチ等の勧誘目的でない
5. **個人が単独で子どもと接触する形態**(個人家庭教師等)は原則掲載しない。掲載する場合は: 運営団体による本人確認/保護者同意の仕組み/オンライン面談の記録ルール/相談窓口 の4点確認
6. 掲載基準は /about で全文公開。却下理由も本人に通知

**サイト自体の安全**: 会員登録なし・個人情報取得なし・広告トラッキングなし・検索条件は端末内処理。プライバシーポリシーは小学生向けの平易文+正式文の2本立て。

## 21. 必要なシステム構成

```
[GitHub リポジトリ(新設・公開)]
  ├ data/services.json          ← データ本体(全件)
  ├ site/                       ← 静的サイト(HTML/CSS/JS)
  ├ scripts/                    ← 整形・検証・死活チェック
  └ .github/workflows/
      ├ build-deploy.yml        ← JSON→ページ生成→GitHub Pages
      ├ link-check.yml          ← 毎日URL死活
      └ freshness.yml           ← 鮮度警告の自動付与
[Google スプレッドシート]        ← 入力・審査台帳(MVPの管理画面)
[Google フォーム]               ← 情報提供・修正依頼・問い合わせ
[Claude API]                   ← 原文→JSON整形(既存パイプライン流用)
```

サーバー・DBサーバー・ログイン基盤: **なし**(MVPでは不要。個人情報を持たないから可能になる構成)。

## 25. 沖縄県での普及方法

お金をかけず「子どもに接する大人」経由で広げる。

1. **学校**: 教育委員会→校長会→進路・生徒指導の先生へ紹介チラシ(印刷ビュー付き)。長期休み前が配布の勝負どき
2. **SSW・自治体福祉窓口**: 面談で使える「条件検索→印刷」を売りに。県・市の子ども未来関連部署へ持ち込み
3. **子ども食堂**(県内200か所超): むすびえ系ネットワーク経由でポスター+QR
4. **児童養護施設・母子生活支援施設**: 施設職員向け説明資料
5. **図書館・公民館**: ポスター掲示
6. 既存資産の活用: もらいわすれ堂のLINE・Instagram(保護者・親世代と接点あり)を主に、ミカタ側SNSも補助で告知(※計測イベントは必ず分離。KGI混同しない)
7. メディア: 「県内の子の教育格差」文脈で地元紙・NHK沖縄に情報提供(非営利なので取材されやすい)

## 26. 学校・自治体・NPOとの連携方法

- **学校**: 「紹介して終わり」にできる導線(チラシQR→登録不要)だから先生の負担ゼロ、を訴求。学校経由でしか申し込めないサービスは「学校経由のみ」と明示し、先生向けページに手順を書く
- **自治体**: 自前の学習支援事業の広報チャネルとして無料で使ってもらう(掲載依頼フォーム)。後援名義が取れれば信頼が跳ね上がるので早期に申請
- **NPO**: 掲載は無料・審査ありを明示。募集状況の更新をセルフ報告できる窓口(フォーム)を用意し、鮮度維持に巻き込む
- 立場の明確化: **申請・入会の代行や仲介はしない。情報の橋渡しまで**(絶対ルール3と同じ線引き)
