# 議事 2026-10-02: みらいひらけ堂 案内ページの起票ルール(三名体制・事後議事)

対象: `.claude/skills/hojo-triangle-review` の3役形式。CLAUDE.md「議事が必須な2類型」のうち
②「技術的でも不可逆な変更(…閾値やルールの変更)」に該当するため、事後でも議事を残す
(2026-09-27に実務判断として先行適用していたものを、本日新たに使えるようになった
hojo-triangle-reviewスキルの形式で正式化する)。

## 論点: 「案内・リンク集ページ」を、そのページ自体として掲載起票してよいか

金融庁「金融経済教育について」(fsa-kyouiku)を照合した際、ページ本体には個別教材への
言及はあるが、対象学年・料金はそのページからは確認できなかった。一方で、「うんこドリル×
金融庁」(fsa-unko)は金融庁ページを経由するが実体(ドリル本体)は外部の文響社サイトにあり、
やはり金融庁ページ単体では料金が確認できなかった。

### スイシン(推進)
- 案内ページにも「教材が存在し無料で使える」という事実は書かれている。収集効率を考えれば、
  案内ページの時点で「存在確認済み」としてdraft起票し、対象学年・料金は「要確認」のまま
  掲載基準の審査で止めればよい。起票自体を止めると、せっかく見つけた候補情報が
  収集候補リストの中に埋もれて追跡されなくなる恐れがある。

### ウタガイ(懐疑)  ← 空欄不可
- 「要確認」のままdraft起票すると、後工程(鮮度チェック・監査)で「出典URLあり」の
  見た目になり、実際には実体未確認のまま塩漬けになるリスクがある(県民会議114件で
  実際に起きた「審査待ちに見えるが実は原文照合すら始まっていない」構造の再発)。
- 案内ページのURLをそのままdata_sourceにすると、将来そのページの構成が変わった場合に
  どの教材を指していたか追跡できなくなる。
- 掲載基準v2.1のフェイルクローズ原則(迷ったら載せない)に照らすと、「ページの存在は
  確認できたが対象・料金は確認できていない」は本質的に「まだ審査可能な状態ではない」。

### ベッカイ(別解)
- そもそも「起票する/しない」の二択ではなく、**リンク先の実体ページまで辿ってから
  起票する**のが前提として正しい。案内ページは「次に取得すべきURLを教えてくれる情報源」
  として収集候補リスト(v1.md)に候補として書き残し、services.jsonには載せない。
- 実際、金融庁の例では案内ページから2つの実体ページ(fsa-koukou-shidou / fsa-unko)を
  特定でき、うち1件(高校向け指導教材)は原文照合でpublishedにできた。もう1件
  (うんこドリル)は実体がさらに外部サイトにあり、そこも辿るまでは起票しない、という
  形で一貫して運用できている。

### 結論(部門長の裁定)
- 採否: **採用(案内ページ自体は起票しない。実体ページまで辿ってから起票する)**
- 理由: ウタガイの指摘(「要確認」起票が塩漬けの温床になる)が、既に県民会議114件で
  実際に発生した問題と同種であり、再発防止の観点で重い。ベッカイの別解(収集候補リストに
  メモとして残し、実体ページを特定してから起票)は、追跡漏れを防ぎつつフェイルクローズを
  維持できる。金融庁の事例(2026-09-27)はこの運用で実際に機能した(1件published・
  1件は次候補として記録)ため、今後の標準ルールとする。
- 適用範囲: `docs/みらいひらけ堂_収集候補リスト_v1.md`「起票のルール」に追記
  (下記反映済み)。既存のdraft 122件のうち、案内ページ由来のものがあれば次回の
  棚卸しで同様に扱う。
- 見直し期限: 2027-04-02(6ヶ月)。期限切れは自動で再議論。

## 反映
- `docs/みらいひらけ堂_収集候補リスト_v1.md` の「起票のルール」に項目5として追記:
  「5. 案内・リンク集ページ(複数の教材へのリンクのみで、対象・料金の記載がないページ)は、
  そのページ自体をservices.jsonに起票しない。収集候補リストに次の当たり先としてメモし、
  リンク先の実体ページ(個別の教材・プログラムのページ)まで辿ってから起票する」
