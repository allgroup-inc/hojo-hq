# 福田さん 100件データ - バリデーション・パイプライン仕様

> このドキュメントは、HistoricalDataImporter.gs に実装された 5段階の
> バリデーション・パイプラインの技術仕様です。
> 
> 用途: 品質チェック実施時の検証ロジック確認用

---

## 概要: 5段階のパイプライン

```
ステップ1: データ取得
   ↓
ステップ2: 形式バリデーション（必須フィールド、日付形式）
   ↓
ステップ3: 重複検出（既存企業との照合、ファイル内重複）
   ↓
ステップ4: データ正規化（電話番号フォーマット、デフォルト値追加）
   ↓
ステップ5: インタラクション記録作成（手紙・架電の履歴ログ化）
```

## ステップ2: 形式バリデーション

### 必須フィールドチェック

#### 企業名

```
チェック: NOT EMPTY
エラー条件: 企業名が空欄
エラーメッセージ: "企業名が入力されていません (行 __)"
修正案: 企業名を入力してください
```

#### 電話番号

```
チェック: NOT EMPTY + 正規化後10～11桁
エラー条件: 電話番号が空欄
エラーメッセージ: "電話番号が入力されていません (行 __)"
修正案: 企業代表電話番号を入力してください

エラー条件: 正規化後に10～11桁ではない
エラーメッセージ: "電話番号が不正な桁数です (行 __): 入力値'098-123-45'"
修正案: 企業代表電話番号を確認してください（10～11桁）
```

### 日付形式チェック

#### 手紙送付日

```
形式: YYYY/MM/DD (例: 2026/09/15)
チェック: 正規表現 /^\d{4}\/\d{2}\/\d{2}$/ にマッチ

エラー条件: 形式が異なる（例: 2026-09-15、令和8年9月15日）
警告レベル: ⚠️ WARNING（自動修正を試みる）
処理: parseDate_() で自動変換試行
  - 2026-09-15 → 2026/09/15 （成功）
  - 2026/9/15 → 2026/09/15 （成功：ゼロパディング）
  - 令和8年9月15日 → 2026/09/15 （成功：暦変換）
  - abc → ERROR （失敗：形式不明）

エラー条件: 存在しない日付（例: 2026/02/30）
エラーレベル: ❌ ERROR
処理: 修正を依頼
```

#### 架電日

```
形式・チェック: 手紙送付日と同じ
追加: 架電日が空欄の場合は「架電なし」として記録
```

### 時系列チェック（論理検証）

```
条件: 手紙送付日と架電日の両方がある場合
チェック: 手紙送付日 ≤ 架電日

エラー条件: 手紙送付日 > 架電日
エラーメッセージ: "時系列エラー (行 __): 手紙2026/09/10、架電2026/09/05"
修正案: 日付の順序をご確認ください（手紙のほうが先です）

OK: 手紙送付日のみ
OK: 架電日のみ
OK: 両方空欄（ただし、企業名・電話番号がある場合のみ）
```

## ステップ3: 重複検出

### 既存企業との照合

```
処理: 入力された「電話番号」を、既存の企業マスタ（3,210社）と照合

マッチング: 電話番号（正規化後・完全一致）

結果:
  ✅ 既存企業と一致した場合
     - 既存企業ID: C000042
     - 既存企業名: 株式会社ABC建設
     - アクション: 既存企業レコードへ「手紙送付」「架電」を新規交互作用として追加
     - 警告レベル: ⚠️ NOTICE（関連企業として記録）
     
  ✅ 既存企業と重複なし
     - アクション: 新規企業として企業マスタに追加
```

### ファイル内重複

```
処理: 福田さんの 100 件内で、同じ電話番号が複数回出現していないか確認

チェック: 電話番号の重複（正規化後）

結果:
  ❌ 同じ電話番号が複数行にある場合
     - エラーメッセージ: "ファイル内重複 (行5, 行42): 098-123-4567"
     - アクション: どちらかに統一、または別企業か確認を依頼
     
  ✅ 重複なし
```

## ステップ4: データ正規化

### 電話番号の正規化

```javascript
// 入力例: 「098-1234-5678」「0981234567」「(098)1234-5678」
function normalizePhoneNumber_(raw) {
  // ステップ1: 数字のみ抽出
  var digits = raw.replace(/\D/g, '');
  
  // ステップ2: 空欄・短すぎる場合は null
  if (digits.length < 10 || digits.length > 11) {
    return null; // エラー
  }
  
  // ステップ3: 正規化完了（数字のみ）
  return digits; // 例: 0981234567
}

出力: 0981234567
```

### デフォルト値の追加

```
フィールド: 流入ルート
デフォルト: 「②手紙DM」
理由: 福田さんが手動で手紙・架電した企業のため

フィールド: ステージ
デフォルト: 「既接触」
理由: 既に手紙または架電済みのため

フィールド: 架電種別（インタラクション種別）
決定: 手紙送付日がある → 「手紙送付」
      架電日がある → 「電話着信」または「架電不応答」（通話結果から判定）
```

### 日付の正規化

```javascript
function formatDate_(raw) {
  // 入力: 「2026-09-15」「2026/9/15」「令和8年9月15日」など
  // 出力: 「2026/09/15」（YYYY/MM/DD 形式）
  
  // 自動検出・変換ロジック
  if (raw.match(/^\d{4}\/\d{2}\/\d{2}$/)) {
    // 既に正しい形式
    return raw;
  }
  
  if (raw.match(/^\d{4}-\d{2}-\d{2}$/)) {
    // ハイフン形式 → スラッシュに変換
    return raw.replace(/-/g, '/');
  }
  
  if (raw.match(/^令和(\d+)年(\d+)月(\d+)日$/)) {
    // 和暦 → 西暦に変換（例: 令和8年 → 2026年）
    return convertWareikiToGregorian_(raw);
  }
  
  // 変換不可の場合
  return null; // エラー
}
```

## ステップ5: インタラクション記録作成

### 架電履歴ログの作成

```
処理: 手紙送付日・架電日それぞれを「対応履歴」タブに記録

レコード形式:

【手紙送付の場合】
フィールド       | 値
────────────────────
対応日            | 手紙送付日（例: 2026/09/01）
架電種別         | 「手紙送付」
メモ             | 備考欄の内容 + 「(過去データインポート)」
記録者名         | 「福田貴史（過去データ）」
記録日時         | インポート実行日時

【架電の場合】
フィールド       | 値
────────────────────
対応日            | 架電日（例: 2026/09/05）
架電種別         | 「電話着信」（繋がった）
                 | 「架電不応答」（不在・繋がらず）
メモ             | 通話結果 + 備考欄の内容
記録者名         | 「福田貴史（過去データ）」
記録日時         | インポート実行日時

【両方ある場合】
2 つの対応履歴が 1 つの企業に記録される
（1企業 = 複数の対応履歴）
```

### インタラクション種別の判定

```
通話結果フィールドの値から自動判定:

「繋がった」「接続」「応答」など
  → 架電種別 = 「電話着信」

「不在」「繋がらず」「応答なし」など
  → 架電種別 = 「架電不応答」

「切られた」「ビジーで切られた」など
  → 架電種別 = 「架電不応答」（通話短時間）

空欄（通話結果が記入されていない）
  → 架電種別 = 「電話着信」（デフォルト）
```

## エラー・警告の分類

### ❌ エラー（修正必須 → インポート不可）

| 種別 | 例 | 対応 |
|---|---|---|
| 必須フィールド空欄 | 企業名が空欄 | 入力してください |
| 電話番号が不正 | 8桁、12桁など | 確認してください |
| 日付が不明 | abc、「今日」 | 正しい形式で入力 |
| 時系列エラー | 架電 < 手紙 | 日付の順序を確認 |
| ファイル内重複 | 同じ電話番号×2行 | どちらかを統一 |

### ⚠️ 警告（自動修正 → インポート可能）

| 種別 | 例 | 修正内容 |
|---|---|---|
| 日付形式異なる | 2026-09-15 | 2026/09/15 に変換 |
| 日付ゼロパディング | 2026/9/15 | 2026/09/15 に修正 |
| 和暦表記 | 令和8年9月15日 | 2026/09/15 に変換 |
| 電話番号形式 | 098-123-4567 | 0981234567 に正規化 |
| 既存企業との重複 | 同じ電話番号あり | 既存企業へ記録追加 |

### ℹ️ 情報（特に対応不要）

| 種別 | 例 | 意味 |
|---|---|---|
| 架電日なし | 手紙送付日のみ | 手紙送付のみ記録 |
| 手紙送付日なし | 架電日のみ | 架電のみ記録 |
| 両方空欄 | 企業名・電話番号のみ | 企業登録のみ |
