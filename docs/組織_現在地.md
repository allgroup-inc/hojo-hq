## 2. ルール(曖昧さを残さない)

### 承認フロー(3層)
| レベル | 対象 | 承認 |
|---|---|---|
| L1 | 定型データ更新・検証・内部実装 | AI即実行 |
| L2 | サイト公開/SNS・LINE配信/対外メール | 三役短評(ウタガイ必須)→AI実行→事後報告 |
| L3 | 予算・提携・掲載方針・法務グレー・PII・外部送信の重大なもの | 小柳さん決裁必須 |

### 品質ゲート(公開前に必ず通す)
`hojo-accuracy-check`(原文照合・要確認・断定禁止) → `hojo-deadline-alert`(3層ルール・
「約1か月前から」) → `humanizer`(AIっぽさ除去・憲法トーン) → `mamori`(法務・資格業務の線引き)

### エスカレーション(機械的トリガー、迷ったら上げる)
- LINE登録が週20社未満**2週連続** / 3ヶ月マイルストーンを**20%以上**下回る
- SNS投稿12本で流入ゼロ / 決裁レイテンシ最古14日超 / 診断→登録CVRがベースライン割れ
- 3役が割れ確信が持てない場合 / 監査・ニドナシ機構が「重大」指摘
- 誤情報発見時は即「要確認」化(事後48h以内に三役レビュー)
