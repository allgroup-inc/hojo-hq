## 実装内容

本システムは、KachiTalk通話ログを6段階営業プロセスチェックリストで自動分析し、各営業マンの品質スコアと売上成績の相関を可視化するものです。

### 6段階営業プロセス分析
```
①アプローチ（名乗り/自己紹介）
  → 顧客との信頼構築・緊張緩和

②ヒアリング（前回のおさらい）
  → 顧客の問題・ニーズ把握

③提案
  → 顧客ニーズに合致した提案内容提示

④クロージング
  → 申込への案内・促進

⑤申込・契約
  → 申込手続き・契約完了

⑥紹介入手
  → 紹介顧客獲得
```

```
①100% ②100% ③100% ④100% ⑤50% ⑥50%

**基本欠落型（名嘉山望）**
```
①100% ②50% ③50% ④50% ⑤50% ⑥0%

## 機能説明

### 1. Google Sheet シート構成

#### 「統合ダッシュボード」シート ★推奨・最初に確認するシート

すべての分析データが1枚にまとめられた統合ビュー。毎月のミーティング資料として使用可能です。

**表示内容**:
- **チーム全体統計**: 平均品質スコア・総通話件数
- **営業マン別ランキング**: 品質スコア順に8人を表示
  - 順位・名前・品質スコア・評価・①～④実施率
  - 色分け: 緑(優秀)・黄(良好)・オレンジ(要改善)
- **改善優先度分析**: ⑤申込・⑥紹介の実施率による課題抽出
  - 緑(◎良好) / 黄(▲要改善) / 赤(◆要注力)

**自動更新**: 
```
analyzeKachiTalkQuality("9月") を実行 → 統合ダッシュボードが自動的に最新データで更新される
```

#### 「カチトークログ」シート
- **入力用**: KachiTalk からエクスポートしたCSVをペースト
- **列**: 営業マン、日時、顧客名、通話時間、通話内容、6段階チェック、品質スコア
- **データ形式**: 営業マン名は正確に記載（「前原　芳乃」全角スペース）

#### 「品質分析」シート
- **自動生成**: analyzeKachiTalkQuality() 実行後に更新
- **内容**: 営業マン別の月別分析
  - 通話件数
  - 平均通話時間
  - 6段階各実施率
  - 平均品質スコア（0〜100）
  - 評価（優秀/良好/要改善/要指導）

#### 「チェックリスト合致度」シート
- **用途**: 各営業マンの6段階実施率を一覧表示
- **形式**: マトリックス（営業マン × 6段階）

#### 「成績相関分析」シート
- **用途**: 品質スコア ×KPI（ANP実績・契約件数）の相関を表示
- **利用**: 「品質が高ければ売上も高いか」を可視化
- **前提**: KPI分析シートが作成されていることが必要

#### 「サマリー」シート
- **用途**: ダッシュボード表示
- **内容**: チーム平均スコア、トップパフォーマー

## Python 分析スクリプト

### 使用方法

```bash
# 9月データを抽出・分析（サマリー表示のみ）
python3 /home/user/hojo-hq/enlife/scripts/extract_kachitalk_logs.py \
  --month "9月" \
  --summary-only

# 8月データをCSVエクスポート
python3 /home/user/hojo-hq/enlife/scripts/extract_kachitalk_logs.py \
  --month "8月" \
  --output /tmp/kachitalk_8月.csv
```

### 処理フロー
1. `enlife/data/kachitalk_sample_logs.json` からログデータ読み込み
2. 6段階プロセスの キーワード検索で実施判定
3. 品質スコア計算
4. CSV フォーマットで出力（Google Sheet にペースト可能）

## 相関分析の活用例

### 発見1: 「品質高×売上低」パターン
- 営業マン: スコア80以上 だが 9月ANP成績がボトム層
- **改善点**: ⑥紹介入手 実施率が低い
- **対応**: クロージング後の「紹介予約」仕込みを強化

### 発見2: 「品質低×売上高」パターン
- 営業マン: スコア60 だが 売上は上位
- **警告**: プロセス を飛ばしているが顧客に恵まれている
- **対応**: プロセス厳格化（将来の持続性向上）

### 発見3: 「品質低×売上低」パターン
- 営業マン: スコア60未満 かつ 成績もボトム
- **優先度**: 最高。教育支援開始

## 技術詳細

### 品質スコア計算式

```
スコア = (実施ステップ数 / 6) × 80 + (通話時間 / 20分) × 20

例:
- 6段階全部実施 + 18分
  = (6/6) × 80 + (18/20) × 20
  = 80 + 18 = 98点

- 4段階実施 + 12分
  = (4/6) × 80 + (12/20) × 20
  = 53.3 + 12 = 65.3点
```

### キーワード検出ロジック

各段階のキーワード:
```
①アプローチ: 「名乗り」「自己紹介」「こんにちは」「申し遅れました」
②ヒアリング: 「前回」「いくつかお聞き」「どのような」「ご状況」
③提案: 「このような保障」「お勧めしたいのは」「いかがでしょう」
④クロージング: 「申込」「次回」「手続き」「契約」「進めさせていただく」
⑤申込契約: 「申込完了」「契約しました」「署名」「捺印」
⑥紹介入手: 「紹介」「お知り合い」「ご親戚」「立替」「どなたか」
```
