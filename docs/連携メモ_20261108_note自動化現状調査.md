## 問題点（詳細）

### 1. Playwright ボタン検出 timeout（critical）

**エラー**:
```
[error] note 投稿失敗: Page.click: Timeout 30000ms exceeded.
        waiting for locator("text=新しい記事を作成") ❌
```

**原因仮説**:
- ダッシュボード JavaScript 初期化が不完全な状態でボタンを探している
- ボタンが存在しても text が空またはレンダリング未完了
- note.com の UI/構造変更の可能性

**対策状況**（試行済み）:
- ✅ セレクタ戦略を 5種類に拡大
- ✅ `wait_until="networkidle"` + 30秒timeout
- ✅ ボタンポーリング 10秒最大
- ✅ 失敗時に全ボタン情報を詳細出力

**次ステップ**:
- ローカルで実際に実行してブラウザ UI をデバッグ
- note.com の実際のセレクタを確認
- Power Automate 移行の検討

### 2. 投稿完了確認なし

**現状**:
```python
await asyncio.sleep(3)
print("[ok] note への投稿に成功しました")  # 確認なし
```

**リスク**: 投稿失敗したまま「成功」と報告される

**必要な実装**:
- 投稿後の記事 URL 取得
- メタデータ取得（公開時刻確認）

### 3. 重複防止なし

- 公開済み記事の履歴管理がない
- 過去記事と同じテーマを再生成する可能性

### 4. リトライ機構なし

- 投稿失敗 → スクリプト終了
- 自動 retry なし（手動ワークフロー再実行のみ）

### 5. マガジン登録未実装

- 記事投稿後、マガジンへの追加が未実装
