# もらいわすれ堂 検証待ちリスト(要確認→検証済みへ)

掲載制度 119件 のうち **要確認 5件 / 検証済み 114件**。公式ページで金額・締切・対象を確認し、問題なければ「検証済み」に上げます。
すべて「金額・締切は要確認」で公開しているため、掲載を止める必要はありません。上から順に、数件ずつ確認していけば大丈夫です。

## 使い方(かんたん)
1. 各行の「公式ページ」を開く
2. 「確認ポイント」の内容が今も合っているかを見る(対象年齢・金額の目安・締切など)
3. 合っていれば **その制度名を教えてください** → こちらで「検証済み」に上げます(まとめてでOK)
4. 内容が変わっていた/ページが消えていた場合も教えてください → 直します or 一旦下げます
