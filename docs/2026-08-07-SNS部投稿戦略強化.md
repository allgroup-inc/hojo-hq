# 2026-08-07: SNS部(ヒロメさん)の投稿戦略強化(social-media-skills活用)

新しく使えるようになった`social-media-skills`(instagram-growth / hashtag-strategy 等)を
`generate_sns.py`と`hirome.md`に適用した結果。

## 見つけた問題と対応

### ① ハッシュタグがInstagramの上限を超過し、かつ固定1ブロックの使い回しだった
- `generate_sns.py`の`HASHTAGS`は全投稿共通で**6個**固定(`#沖縄 #補助金 #助成金 #沖縄経営者 #事業承継 #沖縄企業のミカタ`)
- `hashtag-strategy`スキルによれば、**Instagramは2025年にハッシュタグを5個までにハード制限**しており、
  「同じブロックを毎回使い回す」ことも明示的なアンチパターンとして挙げられている
- **修正**: 話題(制度紹介/事業承継/予告/締切アラート)ごとに5タグ以内のセットを用意し、
  投稿の`slug`に応じて自動的にローテーションする方式に変更(`HASHTAG_SETS`)

### ② KPIがフォロワー数中心で、2026年のInstagramの実態と合っていなかった
- `instagram-growth`スキルによれば、2026年のInstagramは**配信の約94%がAIレコメンド経由**で
  非フォロワーへのリーチが主体になっており、**フォロワー数は虚栄指標(vanity metric)**という診断が明記されている
- `hirome.md`のKPIはフォロワー数(3ヶ月1,000→12ヶ月5,000)を先頭に置いていたが、
  実体に近い「プロフィール→サイト遷移 300/月以上」を最重要指標として明記し直した
- 今後、SNS部の伸び悩みを感じたときは`instagram-growth`スキルで
  「リーチ/フォロー転換/保存・シェア」のどこで詰まっているかを診断してから対策する運用に変更
