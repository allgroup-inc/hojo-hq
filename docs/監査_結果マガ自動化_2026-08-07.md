## 検出した不備と修正(2026-08-07)

**X告知の二重投稿(チェック4・重大)**
- 症状: publish-record を同じ記事ID+URLで2回実行すると、公開記録はスキップされるのに
  X投稿ステップが無条件で走り、同じ告知が二重投稿される(課金も二重)。
- 修正:
  1. `record_publication.py` — 記録済み(idempotency_key=記事ID+公開URL)なら `already=1` を
     出力し、**announce を空にする**(スクリプト層のガード)
  2. `publish-record.yml` — X投稿ステップに `if: already != '1' && announce != ''` を追加
     (ワークフロー層のガード。二層で防御)
  3. LINE通知に「記録済みのためスキップ(二重投稿防止)」の分岐を追加
- 検証: ①記録済み記事の再実行→already=1・告知空 ②未記録→告知あり ③同一入力の再実行→ガード発動、をローカルで確認済み

**X投稿結果の監査ログ欠落(チェック7・軽微)**
- 症状: X投稿の成否・投稿URLがActionsの画面にしか残らない。
- 修正: `scripts/record_x_post.py` を新設。投稿成功時に `x_post_url` / `x_posted_at` を
  お題キューへ記録しコミット(先勝ち・上書きなし)。
