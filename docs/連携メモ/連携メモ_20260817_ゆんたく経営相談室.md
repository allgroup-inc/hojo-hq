## 1. 担当している事業・目的

- **4本柱のうち④「事業構成【GLOW】（通称: ゆんたく経営相談室）」**を担当。手紙アプローチで高齢経営者のM&A潜在ニーズを掘り起こす仕組みの構築
- 位置づけ: 「手紙の受け皿」となる非公開LPと、そこへ至る導線（手紙→QRカード→サイト→電話→訪問→本相談）の設計・実装
- **②glow-ma（営業管理システム）とは表裏一体**。当セッションは②のシステムを実際に使う側であり、8/11以降は②のコード（GAS）にも直接手を入れている。役割分担の整理が必要な状態
- 目標: 2027年7月以降に年間20件以上の成約が生まれる「絶対的な量」を作る。土台完成後は率ではなく**総量**（手紙発送量・電話キャッチ量・訪問総量・代表者との会話量・トークPDCA量）を管理する方針

## 2. これまでに決まったこと

### 導線設計（確定）
- 4ステップ: **お手紙 → お電話（必ず"人"が出る・受付8:00〜19:00）→ ご訪問（ゆんたく）→ 本相談**
- **LP・手紙にM&Aという語を一切使わない**（既存の絶対原則を継続）
- **1通目からQRカードを同封する**（2026-08-11 小柳さん決裁で**プレイブックの鉄則を変更**）
  - 旧: 「1通目の手紙にQRを入れない」（DM感を避けるため）
  - 新: 手紙本文にはQRを刷らず、**名刺サイズの同封カード**にQRを載せる。手紙の空気は維持
  - ウタガイ（反対理由）: 反応率が下がってもカードのせいと切り分けられない → **フェーズCの試験投函20社をカード同封10社/なし10社のA/Bで検証**することを裁定に明記

### スコアリング（実装済み・実データで検証済み）
- 初期スコア = **属性スコア（業種+規模+代表者年齢）+ 事前選定スコア + 流入ルートボーナス**
- 業種: high（建設/運送/介護/美容/理容/飲食/小売）20点 ／ mid 10点 ／ low 0点
- 代表者年齢: 70歳以上15点 / 60代10点 / 50代5点、規模: 10-50名10点 / 5-9名・51-100名5点
- 流入ルート: ①紹介30点 / ②手紙DM 0点 / ③ミカタ経由20点
- 事前選定スコア: 元リストの「仮スコア」列を取り込み（上限50点でクランプ）
- ランク閾値: **A:70 / B:40 / C:15 / それ未満D**
- 反応スコア: レターURLアクセス5 / 返信15 / 入電20 / ゆんたく相談実施25 / 面談実施25 / 資料請求10、意思決定者接触ボーナス15（種別ごと初回のみ加点）

### 対象企業の条件

- 今後の拡大方針（未着手）: 宿泊観光 → 運輸・自動車整備 → 産廃 → 調剤薬局

### DNC（連絡不要）運用

- 人間3段階ゲート（台帳部の目視確認→架電担当のダブルチェック→架電直前の最終サイン）

## 7. 他チームが知っておくべき制約・注意点

### 絶対に守るもの
- **LP・手紙・電話でM&Aという語を使わない**。「経営相談」から入り、相談の中でニーズを掘り起こす設計。LPが先にM&Aを名乗ったら本末転倒
- **「嶺井が直接出る/伺う」と書かない**。受電は事務局、訪問は同行枠確保済みの先のみ
- **DNC違反ゼロは絶対条件**。断られた番号への再架電禁止（「一度だけ」ルール）
- **PIIを公開リポジトリに置かない**。取込CSVはDownloads配下に留置

### 作業上の制約（環境）
- **Node.js未インストール**のため `clasp push` が使えない。GASへの反映は**Apps Script画面での手貼り**が必要
- **Chrome拡張は script.google.com を操作できない**（ドメイン制限）。そのため試験類はスプレッドシートの**メニューから起動できる形**にしてある（`GLOW台帳 → G1フェーズA試験を実行`）。今後のフェーズB・Cも同じ方式を推奨
- Googleスプレッドシートへの貼り付け代行時、**クリップボードが他プロセスに奪われる事象**が発生。重要データはGAS側で生成する方が安全

### 体制について
- 当セッションは**単独AI＋小柳さん決裁の1人称体制**。glow-ma開拓に部門エージェントの割り当てなし
- **独立監査の目がない**。2026-08-17の自己点検で公開リスク・議事欠落を検出したが、本来は監査役の役割
- **三名体制の議事が3件欠落していた**（QRカード同封/全量投入/noindex）。事後追認議事で補完済み。CLAUDE.mdに「決裁者の即断で実行が先行した場合も議事を事後で必ず残す」ルールを追記済み
