## その場で合意したい3点

1. **掲載可否と文言**
   - 社名・拠点(那覇支店)・在籍士業(診断士・行政書士・税理士)・対応領域の表記をその場で確認
   - スマホでサイトの実物を見せながら「この表記でOKか」を確認するのが早い
2. **取次方法**(お客様から相談が来た時の流れ)
   - 候補: ①メール転送(宛先アドレス) ②電話 ③先方フォーム
   - 対応目安(1営業日以内 等)と、取次時に渡す情報(会社名・相談概要・LINE経由である旨)
3. **条件面**
   - 方式は**定額掲載料**(成果報酬は士業法上避ける・CLAUDE.md絶対ルール3)
   - 金額・開始月・請求方法。即決できなければ「文言と取次だけ先に合意→条件は後日」でもOK

## 先方に見せる材料

- サイトの実績: 掲載153件・毎日自動更新・診断→LINE登録の導線稼働中
