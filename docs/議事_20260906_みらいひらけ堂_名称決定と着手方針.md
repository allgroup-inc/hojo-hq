# 議事: みらいひらけ堂(節目まるごとナビ)の名称決定と着手方針

- 日付: 2026-09-06
- 関連文書: docs/企画_みらいひらけ堂_節目まるごとナビ設計_20260906.md
- 決裁済み事項: **サービス名「みらいひらけ堂」= 2026-09-06 小柳さん決定**(もらいわすれ堂の次の無料サービスとして)
- 本議事の対象: 名称決定を受けた着手方針(何から作るか・どこに線を引くか)

## 論点: みらいひらけ堂を「節目まるごとナビ」としてMVP着手してよいか

### スイシン(推進)
- 節目(出産・引越し等)は全県民に起きる普遍の入口で、福祉色がなく、県民10%(14万人)構想と整合する。
- 「相対締切(出来事からn日以内)を本人の日付でリスト化する」はLINE登録の必然性を生み、4目標(❶流入→❹LINE→❷受給報告)に直結する。
- 制度DB・ページ生成・検証/守り部体制・LINEの既存資産を流用でき、節目2つ×5市町村なら費用ほぼ0円・2か月で公開できる。

### ウタガイ(懐疑)  ← 空欄不可
- **市町村差の正確性リスク**: 手続きの期限・窓口・持ち物は市町村ごとに違い、間違えれば「役所で恥をかかせるサイト」になり信頼を失う(絶対ルール1に直撃)。5市町村ですら原文照合の工数は軽くない。収集ペースを楽観視するな。
- **おくやみを安易に載せるな**: 需要最大ゆえ着手を急ぎたくなるが、相続関連は行政書士・司法書士・税理士の業際に近い。守り部の線引き審査前に1行でも公開してはならない。
- **締切3層ルールと矛盾する**: 相対締切には「残り30日以上」が存在しないケースが多く、既存ルールをそのまま適用も無視もできない。配信ルールの追補(不可逆類型)を先に決裁しないと、現場が独自判断で配信を始める事故が起きる。
- **ブランド分散の懸念**: フクギイロはもらいわすれ堂のKGI(LINE1万人・受給報告1,000件)自体がまだ道半ば。「堂」が2つになることで広報・IG運用の弾が割れる。みらいひらけ堂は独自アカウントを作らず、もらいわすれ堂のIG/LINEに相乗りすべき。
- **計測の混線**: 新導線の計測イベントを分けないとLINE登録の出所が判別できなくなる(過去に line_redirect 水増しの再発防止メモあり)。公開前に shipping_gate の TARGET_GROUPS と計測イベント名の追加を確認すること。

### ベッカイ(別解)
- **案A: 独立サイトにせず、もらいわすれ堂サイト内の「節目から探す」タブにする**。ブランドは1つのまま機能だけ得られる。ただし「みらいひらけ堂」という名前の決定と両立させるなら「もらいわすれ堂の中の『みらいひらけ堂』コーナー」という暖簾分け表記が現実解。
- **案B: ページを作る前に、LINE既存登録者へ「最近あった節目は?」アンケート1問を送る**。どの節目に需要が集中するかを実データで確かめてからMVPの2節目を選ぶ(出産・引越しという選定自体が仮説にすぎない)。
- **案C: 市町村を絞らず「県+国の共通制度だけ」で全県版を先に出す**。市町村差の照合コストをゼロにして最速公開し、市町村別は反応を見て足す。

### 結論(部門長の裁定)
- 採否: **一部採用のうえ上申**
- 理由: 名称は小柳さん決定済み。方向性(節目まるごとナビ)は前回提案の推奨案であり、スイシンの資産流用・低コストは事実。ウタガイの指摘は全て実行条件として設計書に反映済み(おくやみはPhase2で審査後/配信ルール追補は別途決裁/計測イベント分離)。ベッカイ案Bのアンケート1問は低コストなのでMVP収集と並行実行を推奨。案A(サイト独立か、もらいわすれ堂内コーナーか)は**ブランド体制の決裁事項として小柳さんへ上申**する。
- 上申事項(小柳さん決裁待ち): ①独立サイトか、もらいわすれ堂内コーナーか(推奨: まずコーナーとして公開し、反応が出たら独立) ②タグライン3案の選定 ③MVP着手のGO
