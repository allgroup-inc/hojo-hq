# 議事: 沖縄市・うるま市の市独自制度を一時非公開(2026-08-18)

背景: 小柳さんより「一旦、今だけ沖縄市とうるま市の制度関係は見れなくしておいて」と指示
(2026-08-18・理由の明示なし)。公開範囲の変更=議事必須類型②のため、決裁者の即断で
実行が先行するケースとして事後議事を残す(CLAUDE.md機密区分ルール)。

## 論点: 非公開の範囲と実装方式

### スイシン(推進)
- 実装は fetch_fukugiiro.py の HIDDEN_AREAS リスト1箇所(area=沖縄市/うるま市のシードを
  seido.json 構築時に除外)。これで市町村ページの市独自セクション・申請準備シート・
  ライフイベント別・3分診断・sitemap すべてから一括で消え、戻すときはリストを空にして
  再構築するだけ。シード(データ)は削除しない=完全に可逆
- 両市の市町村ページ自体は残し、国・県の制度は引き続き表示(既存の「独自の制度は現在、
  掲載準備中です」フォールバックが自動で出る)

### ウタガイ(懐疑)  ← 空欄不可
- **反対理由1**: 理由が記録されていない非公開は、後から「なぜ消えたか」を誰も説明できなく
  なる。苦情・データ誤り・提携交渉など理由により本来の正しい対応(訂正・注記・全ページ
  停止)は異なるはず。小柳さんに理由の一言を追記依頼し、この議事に事後追記すること
- **反対理由2**: 非公開期間が長引くと検索インデックス(準備シート11ページ)が失われ、
  両市住民への情報提供という事業目的も損なう。「今だけ」の言葉どおり短い見直し期限を
  設定し、期限が来たら自動で再確認すること
- **反対理由3**: 掲載を消しても Google キャッシュ・IGネタ等に痕跡は残る。完全な抹消では
  ない旨を決裁者が了解している前提で進めること

### ベッカイ(別解)
- 全消しではなく「内容確認中」表示に切り替える案もあるが、指示は「見れなくして」であり
  表示継続はこれに反する。注記案は理由が判明した時点で再検討すればよい
- 市町村ページごと消す(404にする)案は、国・県の制度まで見えなくなり過剰。市独自制度の
  みの除外が指示の範囲として妥当

### 結論(部門長の裁定)
- 採否: **採用** — HIDDEN_AREAS=["沖縄市","うるま市"] で市独自制度11件を build から除外
  (188→177件・支持KPI150件は維持)。市町村ページは国・県制度のみで存置
- 対象(非公開になる11件): 沖縄市=こども医療費助成/就学援助/産後ケア/保育料軽減/
  住宅リフォーム補助、うるま市=こども医療費助成/就学援助/母子父子医療/産後ケア/
  補聴器助成/浄化槽補助
- 宿題: 理由の一言を小柳さんへ確認(決裁キューに1行)
- 見直し期限: **2026-09-01**(2週間。期限が来たら「戻すか・延長か」を必ず確認する)

## 追記(2026-08-19): うるま市は復活
- 小柳さん指示「うるま市を開示してください」により、うるま市は全面復活
  (市町村ページ・診断の選択肢・市独自制度6件)。**沖縄市は継続して非公開**
- クレーム等ではない旨は2026-08-18に小柳さんが明言済み。見直し期限(2026-09-01)は
  沖縄市についてのみ継続

## 追記2(2026-08-19・最終): 両市とも公開に — 一時非公開は全解除
- 小柳さん「うるま市の一度もどして 沖縄市でした」→ 続けて「うるま市もそのままでいい」により、
  **沖縄市=開示・うるま市=公開のまま**(HIDDEN_MUNISは空に)。本件はこれでクローズ
- データは非公開期間中も削除していないため、両市とも従前の掲載(計11件)がそのまま復帰
