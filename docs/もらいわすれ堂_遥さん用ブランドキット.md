## 2. ロゴの使い方(ここだけ守ってください)

- **主役は「もらいわすれ堂」ロゴ**(朱色の丸タイルに「もら/堂」+黄色の①バッジ)。左上など目立つ位置に。
  - ファイル: `site/fukugiiro/assets/icon-512.png`(円形に切れる場所用)/ `icon-512-tile.png`(四角のまま置く用)
- **運営会社「株式会社フクギイロ」**(緑のフクギの木マーク)は、**最下部に小さく「運営: 株式会社フクギイロ」**として添える程度。主役にしない。
  - ファイル: `site/fukugiiro/assets/fukugiiro-corp-mark-512.png`
- ❌ 絵文字(🌿🌺など)をロゴ代わりに使わない。→ 必ず上の正式ロゴを使う。
- フォント: 太めの丸ゴシック/ゴシック(Web は Noto Sans JP でOK)。

## 3. デザインの OK / NG(見本つき)

**OK(先に送った5枚 ig-1〜5 がお手本です)**
- 大きな見出し(朱)+ やさしい一言(墨)+ 「3分診断」ボタン
- 余白ゆったり。文字はスマホでも読める大きさ
- もらいわすれ堂ロゴが左上にある

**NG(避けたいこと)**
- 🌿🌺などの絵文字をブランドマーク扱いする
- 花や飾りが**フレームから見切れている**(意図が伝わらない)
- 金額や締切を大きく断定で載せる(例:「10万円もらえる!」)→ 事実は下の「4」を参照
- 文字が小さすぎ/多すぎて、スマホで読めない

## 4. 文章(キャプション)はこちらで用意します ← 大事

金額・締切・制度名の言い回しは、事業のルール上ミスできない部分なので、**キャプションは運営(AI+小柳)が作ってお渡しします**。遥さんは画像づくりと投稿に集中してください。

参考までに、画像に文字を入れるときも次だけは守ってください:
- 締切は「**約1か月前から**お知らせ」。※「締切7日前」など短い日数を"間に合う"文脈で書かない
- 「もらえる」と**言い切らない**。「もらえるかも」「使えるかもしれない」
- 申請の代行はしない立場です(専門家=士業へのご案内まで)
- 誘導先は**LINE登録のみ**。リンクは本文に貼らず、**プロフィール(bio)のリンク**に設定
