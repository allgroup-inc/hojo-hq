# 議事 2026-10-16 Instagramのプロフィールリンクを「まとめページ」にする

- 起案: 小柳さん(「投稿の情報からURLを押してサイトや制度ページへそのまま飛べるようにしたい」)
- 決裁: 小柳さん(2026-10-16、まとめページ方式を選択)
- 区分: ①小柳さん決裁事項(CV導線・掲載方針の変更)

## 論点: プロフィールのリンク先を、LINE直行(/go/ig/)から「投稿で紹介中の制度一覧ページ」(/ig/)に変えるか

前提: Instagramは本文・画像・コメントのURLを押せない。押せるのはプロフィールのリンクとストーリーズのリンクスタンプだけ。リンクスタンプはAPIで自動投稿できない。

### スイシン(推進)
- 投稿を見て興味を持った人が、その制度の公募ページへ2タップで着く。今は本文のURLを手で打ち直すしかなく、ほぼ誰もしていないはず。
- まとめページの最上部にLINE登録ボタンを置けば、LINEへの導線は残る。
- 投稿素材そのものから自動生成するため、運用の手間は増えない。

### ウタガイ(懐疑)
- **LINE登録まで1タップ増える。** 今はプロフィールのリンクを押せば即LINEだった。KGI(LINE登録1,000社)に直結する導線を遠回りにする変更で、登録率が下がる恐れがある。
- 制度の公募ページ(国・県のサイト)へ外に出すと、そのまま戻ってこない。サイト外へ人を流す導線を増やすことになる。
- まとめページの制度と投稿の制度がずれると、「投稿にあった制度が無い」となり信頼を落とす。

### ベッカイ(別解)
- LINE直行は維持し、まとめページはストーリーズのリンクスタンプからだけ入れる案。自動化できず、毎回手動で貼る負担が出る。
- 公募ページだけでなく、自サイトの30秒診断ボタンを各制度に並べ、外に出る前に「うちで使えるか」を確かめさせる。

### 結論(裁定)
- 採否: 採用(まとめページ方式。ベッカイの「各制度に30秒診断ボタン」も取り入れる)
- 理由:
  - ウタガイの「1タップ増える」には、最上部にLINEボタンを置き、LINEボタンは従来どおり /go/ig/ 経由にして `line_redirect`(channel=ig)で数え続けることで対応。
  - ずれの懸念には、data から選び直さず**投稿素材(posts/launch・posts/carousel)を直接読む**ことで対応(承認対象を名指しで次工程へ渡す原則と同じ)。
  - 導線ごとに専用イベント名を付けた(`ig_hub_line_click` / `ig_hub_source_click` / `ig_hub_shindan_click`)。`line_redirect` は流用しない。
  - 締切3層ルールに従い、生成日時点で残り30日未満の制度は載せない。
  - 各キャプションに「本文のURLはタップできません。プロフィールのリンクを開くと、この投稿の制度ページへそのまま飛べます」を入れる。
- 効果測定: 週次レポで、IG経由の `line_redirect` 件数を変更前2週と変更後2週で比べる。減っていたらLINE直行へ戻す。
- 見直し期限: 2026-12-16
