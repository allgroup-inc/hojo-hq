# みらいひらけ堂 写真探しガイド(世界観フィルム用)

- 作成: 2026-09-06(小柳さん「写真を探すのでイメージが欲しい」を受けて)
- 使う場所: トップの世界観フィルム(夜→朝の5シーン)。写真は各シーンの背景に**半透明で敷く**ので、「主役」ではなく「空気」をつくる写真が合います
- 差し替え方: 写真が用意できたら本セッションに渡してください。守り部確認のうえ `site/miraihirake/assets/film/` に入れてはめ込みます

## ぜんぶの写真に共通のルール(これだけは必ず)

1. **子どもの顔は写さない**。うしろ姿でも「この子だ」と分かる写真はNG(公開サイトのため)
2. **使っていい写真か確認**: 自分で撮った写真が一番安全。素材サイトの場合は「商用利用OK」「クレジット表記が必要か」を確認してメモを残す(写真AC・ぱくたそ・Unsplash・Pexelsなどは基本OK)
3. **暗め・しずかな写真**が合う(S1〜S3は夜のシーン)。明るくにぎやかな写真は浮きます
4. サイズの目安: **横1600pxくらい・JPG・1枚300KBまで**(大きすぎるとページが重くなる)。横長(16:9〜3:2)

## シーン別の指定(4枚+予備)

### ① S1「星空」 — どの子にも、みらいがある
- **イメージ**: 沖縄の満天の星(できれば天の川)。画面の下1/3は真っ暗な島影や丘。しずかで、少しさびしくて、でもきれい
- **検索ワード**: 「沖縄 星空 天の川」「やんばる 星空」「石垣島 星空 夜」/ 英語: okinawa milky way, starry sky island silhouette
- **避ける**: 大きな月が写っているもの(画面に月のイラストを重ねるため)/街明かりが強いもの/人の顔

### ② S2「手元」 — 学びは、教室の中だけじゃない
- **イメージ**: 暗めの部屋で、ランプの明かりに照らされた**手元だけ**。本をめくる手、工作やブロックを組む手、絵を描く手など。あたたかい光と集中している空気
- **検索ワード**: 「読書 手元 ランプ」「本 めくる 手 夜」「工作 手元 子ども」/ 英語: hands reading book warm lamp night, child hands crafting closeup
- **避ける**: 顔が写っているもの/明るい昼の写真/スマホやゲーム機が主役のもの

### ③ S3「まなびば」 — ささえてくれる人が、こんなにいる
- **イメージ**: 光が差しこむ「学びの場所」の風景。図書館の本棚の通路に差す光、窓から光が入る教室(人なし or 遠くの逆光シルエットのみ)、公民館の入口の明かり
- **検索ワード**: 「図書館 本棚 光」「教室 window light 逆光」「図書館 通路」/ 英語: library aisle sunlight, empty classroom window light
- **避ける**: 顔が判別できる後ろ姿/制服・校章など学校が特定できるもの

### ④ S4「朝焼けの海」 — 沖縄のみらいは、すこし明るくなる
- **イメージ**: 沖縄の海の朝焼け。水平線から昇る朝日、オレンジ〜桃色の空。鳥や小さな船が写っていてもOK。「夜が明ける」希望の一枚
- **検索ワード**: 「沖縄 朝焼け 海」「日の出 水平線 沖縄」「朝日 ビーチ」/ 英語: okinawa sunrise ocean horizon
- **避ける**: 人が大きく写っているもの/ビル・電線などが目立つもの

### (予備)⑤ 「夜の集落の灯り」 — S1の差し替え候補
- **イメージ**: 高台から見た、夜の集落のあたたかい灯り(もらいわすれ堂S1と同系)。家々の小さな明かりがぽつぽつと
- **検索ワード**: 「沖縄 夜景 集落」「島 夜 灯り 高台」/ 英語: village lights night hill okinawa

※ 最後のロゴのシーン(S5)は写真を使いません(朝の光のデザインのみ)。

## AIで画像を作る場合(写真が見つからないとき)

生成画像でもOKです(フィルムは「演出」なので問題なし。実在の場所・人物に見せかける使い方はしない)。プロンプト例:

- S1: 「沖縄の離島の丘から見上げた満天の星空と天の川、画面下は真っ暗な丘の稜線、人物なし、静かで美しい夜、写真風、横長」
- S2: 「暗い部屋でランプの暖かい光に照らされ本のページをめくる子どもの手元のクローズアップ、顔は写らない、あたたかく静かな雰囲気、写真風、横長」
- S3: 「図書館の本棚の間の通路に窓から朝の光が差し込む風景、人物なし、希望を感じる光、写真風、横長」
- S4: 「沖縄の海の水平線から昇る朝日、オレンジと桃色の空、静かな波、人物なし、写真風、横長」
