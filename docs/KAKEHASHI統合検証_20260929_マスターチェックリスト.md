## ✅ 全9システムの検証項目（共通）

すべてのシステムが確認すべき基本項目：

### 1. 認証・権限層
- [ ] 統一フォーム（軸）へのログイン成功
- [ ] 画面表示権限が正しく反映されている
- [ ] 読み取り専用層が適用（必要な場合）
- [ ] トークン有効期限の確認

### 2. 顧客データの受け取り
- [ ] LINE Webhook経由の顧客データが正常に到着
- [ ] 必須フィールド（電話・時間帯・表示名）の検証
- [ ] スペース除去・正規化が機能
- [ ] data_class="real" 分類が自動適用

### 3. ログ・監査記録
- [ ] call-log / field-log が正常に送信される
- [ ] 送信メタ（who / when / why）が記録される
- [ ] 誰が何をしたか追跡可能か

### 4. エラーハンドリング
- [ ] API エラー(400/500等)が適切に処理される
- [ ] ネットワーク障害時のリトライが動く
- [ ] エラー時に進捗が止まらない（非同期で継続）

### 5. データ品質・語彙統一
- [ ] 用語が統一されている（特にズレ#5/12/13対象）
- [ ] 区分値が共有マスタと一致
- [ ] 金額・日付形式が統一
