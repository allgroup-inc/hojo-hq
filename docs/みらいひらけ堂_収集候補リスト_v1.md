## 進捗メモ(2026-09-06 第1回収集)

- **この開発環境(Claude Codeリモート)は外部サイトへ接続できない**(ネットワーク制限)ことが判明。Web検索は可能だが、ページ本文の閲覧=原文照合ができない
- 対応: 原文の取得はGitHub Actions側で行う仕組みを実装した
  - URL待ち行列: `data/miraihirake/source_queue.json`(14件を登録済み)
  - 取得ツール: `scripts/miraihirake/fetch_sources.py`(audit=robots監査 / fetch=承認済みURLの本文保存)
  - 手動実行: Actionsの `miraihirake-fetch` ワークフロー(mainへのマージ後に実行可能)
- **運用の流れ**: ① audit実行 → ②守り部が robots_report.json と各サイト利用規約を確認し queue の robots_approved を true に → ③ fetch実行で `data/miraihirake/sources/` に原文テキストが保存される → ④検証部がそれと照合して services.json を draft→verified に上げる
- Web検索で確定した公式URL(内容はすべて**原文照合前**。検索結果ベースの当たりにすぎない):
  - カタリバ キッカケプログラム(就学援助世帯の小3〜高3・PC/Wi-Fi無償貸与・無料らしい): katariba.online/kikkake
  - カタリバ オンライン不登校支援: futoko.katariba.online
  - キッズドア 学習支援一覧: kidsdoor.net/activity/study/
  - eboard(映像授業+ドリル・家庭利用無料らしい): info.eboard.jp
  - 19ch/とある男が授業をしてみた(小3〜高校の無料授業動画+無料プリント): 19ch.tv

  - Try IT(映像授業): try-it.jp(無料範囲・登録要否は要照合)

## 起票のルール(再掲)

1. 公式ページを開き、対象・料金・申込方法を確認できたものだけ services.json に draft 起票
2. data_source(見たページのURL)と last_verified(見た日)を必ず入れる
3. 原文で確認できない項目は "要確認" と書く。推測で埋めない
4. 料金が確認できないものは起票しても掲載保留(掲載基準1・5)
