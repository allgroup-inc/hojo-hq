## 起票のルール(再掲)

1. 公式ページを開き、対象・料金・申込方法を確認できたものだけ services.json に draft 起票
2. data_source(見たページのURL)と last_verified(見た日)を必ず入れる
3. 原文で確認できない項目は "要確認" と書く。推測で埋めない
4. 料金が確認できないものは起票しても掲載保留(掲載基準1・5)
