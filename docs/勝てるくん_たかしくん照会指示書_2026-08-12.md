# 勝てるくん: たかしくん向け 3社照会の指示書(2026-08-12)

発出: 2026-08-12 小柳さん「§7の文面で3社照会して」(決裁キュー⑤の実行)
担当: たかしくん(GLOW)/ 起案: 守り部
目的: AIで作った提案下書きの「募集文書該当性」を、取扱3社(なないろ生命・FWD生命・チューリッヒ生命)に確認する(実顧客への成果物提示の解禁条件C)

## やること(3ステップ)

1. **下の照会文面をそのまま使い**、3社それぞれの代理店担当(営業担当者または代理店サポート窓口)に送る。メール推奨(回答を文字で残すため)。口頭で聞いた場合は要点をメールで「先ほどの確認ですが〜という理解で合っていますか」と残す
2. 送った日付・宛先(会社名と窓口種別のみ。担当者個人名はここに書かない)を本ファイル末尾の記録表に追記
3. 回答が来たら、要旨を記録表に追記して小柳さん・守り部へ共有(原文メールは非公開の保管場所へ)

## 照会文面(守り部審査§7・そのまま送付可)

```
お世話になっております。募集資料の取扱いについて2点確認させてください。

当店では、お客様への提案品質の向上のため、提案資料の【社内下書き】の作成補助に
AIツールの利用を検討しております。お客様の個人情報(氏名・証券番号等)は
AIツールに入力せず、お客様にお渡しする資料は従来どおり、貴社所定の設計書・
パンフレット、および募集人が内容を確認・作成した資料のみを想定しています。

1. 上記のような社内下書きの作成補助にAIツールを利用すること自体について、
   貴社規程上の届出・承認は必要でしょうか。
2. 募集人が内容を確認・修正のうえお客様にお渡しする自作の補助資料
   (現在ご加入の保障の一覧表など)は、貴社の募集文書審査の対象でしょうか。
   対象となる場合の申請手順をご教示ください。

お手数をおかけしますが、よろしくお願いいたします。
```

## 注意(守り部・ウタガイ記録より)

- 文面を膨らませない(「AIで提案を自動生成」等の表現にしない)。上の文面が実態であり、このまま送るのが一番安全
- 3社で回答が割れる可能性がある。割れた場合は**一番厳しい回答に全社合わせる**(会社ごとに運用を変えると現場で必ず事故る)
- 回答期日の目安は2週間。返事がなければ1回だけ丁寧に催促し、それでも無回答なら「無回答」として記録(勝手に「OKらしい」と解釈しない)
