# note運用規程 — 体制・ルール・エスカレーション(総点検 2026-08-02)

- 起案: 小柳健さん(組織体制とやり切り計画の総点検指示)/ 決裁: 同指示により包括承認
- 対象: note収益化計画v2(docs/note収益化_運営計画.md)の実行体制
- 見直し期限: **2026-11-30**(v2計画と同時レビュー)

## 1. 体制の見直し(三名体制議事)

### 論点: note収益化(月11.8万円+KGI「LINE1,000社」の検索流入200社への貢献)に対し、現行の部門構成で十分か

### スイシン(推進)
- noteは週2本の定期公開・X運用・B2B配布・KPI管理と業務が多面化した。「note編集部」を新部門として設立し、AI編集長を正式なエージェント(担当ファイル)にすることで責任を一点化すべき
- 専任部門があれば週次議論・改善提案の主体が明確になり、放置による自然死(Instagram投稿0本の前例)を防げる

### ウタガイ(懐疑・反対理由の記録)
1. **新部門はボトルネックの誤診である。** 詰まっているのは組織図ではなく人間の手(公開コピペ・X運用・モニター配布)。箱を増やしても手は増えず、むしろ全部門週次議論の対象が1つ増えて統括・監査の負荷が上がる
2. **既存SNS部(ヒロメさん)と職掌が重複**し、Instagram/note/Xの間で「どちらの担当か」の押し付け合いが起きる。部門間の隙間はむしろ増える
3. 「AI編集長」を組織上の役職にすると、**対外ペルソナ(筆名)と内部統制が混線**する。監査(タダスさん)の点検対象が曖昧になり、事故時に責任経路を辿れない

### ベッカイ(別解)
- 部門を増やすのではなく、**「note係」を既存部門への追加ミッションとしてRACIで割り当てる**。SNS部=コンテンツ品質と集客設計、LINE部=会員転換、提携部=B2B、統括=数字監視、監査=抜き取り照合——全部門の既存職掌の延長で吸収できる
- 「AI編集長」は**役職ではなく対外ペルソナ(筆名)**と定義し、管掌はSNS部(ヒロメさん)に置く。これで監査境界は従来どおり部門単位で保たれる
- 人間の手不足は組織図でなく**「担当者名+代行順位」の指名**で解決する(下記RACI)

### 結論(部門長の裁定)
- 採否: **ベッカイ採用(部門新設せず、RACI+代行順位+ペルソナ定義で運用)**
- 理由: ウタガイ1(真のボトルネックは人間の実行)が本質。前例(Instagram投稿0本)の原因も部門の不在ではなく担当・催促の不在だった。よって「箱」でなく「名前と催促の自動化」に投資する
- 見直し期限: 2026-11-30(会員50人到達またはM3時点で、専任化の要否を再判定)

## 3. ルール(曖昧さを残さない判断基準)

### 3-1. 公開可否チェックリスト(公開者が毎回・5項目)
1. 数字・締切・金額がすべてDB転記か(手で足した数字はないか)
2. 締切30日未満の制度名が本文に出ていないか(件数表記のみ可)
3. 出典URL・免責・「AI生成+人間確認」フッターがあるか
4. スポンサー枠が出ている場合【PR】表記があるか(枠は決裁まで出ない設定)
5. 迷ったら公開せず、チャットで相談(「迷ったら止める」が正)

### 3-2. 承認フロー
- 通常公開: 人間一読(チェックリスト)→公開→md先頭に公開URL+3役短評を追記(追記はチャットに「公開した、URLは◯◯」で代行可)
- 公開者が48時間不在: 代行順位(たかしくん→ナナコさん→小柳さん)で繰り上げ。誰も動けない週は「休載」でよい(質の劣る公開より休載が上)
- 価格変更・新コーナー・新提携・ペルソナ変更: 小柳さん決裁(チャット一言で可・docsに記録)

### 3-3. 品質基準
- 機械検査(禁止語・締切3層・総額参考値ルール・検査不合格時フォールバック)は**スクリプトから外さない**。緩和はいかなる理由でも決裁事項
- AI三人会議・AI編集後記が検査に落ちた週は「持ち越し」表示のまま出す(捏造して埋めない)
- 対外文面の新規作成・改稿は humanizer スキルを最終チェックに使う(事実・CV導線は変えない)

### 3-4. エスカレーション条件(発火したら必ず動く)
| 条件 | アクション |
|---|---|
| 外部から誤情報の指摘 | 2時間以内に該当記事を下書きに戻す(タダス即時権限)→小柳さんへ即報告→48時間以内に3役レビュー |
| 個別の申請可否・法律・税務の相談が届く | 回答せず、提携専門家紹介の定型文で返す(資格業務の線引き。テンプレは私が用意) |
| 未公開の下書き4本 | 週次レポが自動警告→アカリがボトルネック報告→継続可否を再議論 |
| KPI未入力8日以上 | 月曜のLINE通知に自動リマインド(実装済み) |
| M3時点で収益がv2計画比50%未満 | レバー発動(上位プラン→B2B増→まとめ売り→価格)を三名体制で審議 |
| メンバー退会が月2割超 | 週報の内容点検を臨時実施 |

## 5.4 改訂 2026-08-04(組織: note編集部の新設 — 小柳さん指示)

小柳さん指示「この事業が月継続で30万達成する為に必要な組織を作っておいて」により、
**§1の裁定(部門新設せず)を改訂し、専任部門「note編集部」(tsuzuru.md・ツヅルさん)を設立**した。

### 三名体制の短評(改訂の議事)
- スイシン: v2(月11.8万)時点では「箱より名前」で足りたが、v3(月30万)は在庫26本・会員135人・B2B8社と管理対象が3倍化する。数字と品質の説明責任を一点化する専任部門が必要
- ウタガイ(反対理由の記録): ①§1ウタガイの懸念(真のボトルネックは人間の手)は未解消のまま。部門を作っても公開コピペとX投稿の手は増えない ②SNS部との職掌重複リスクも§1のまま残る ③統括・監査の週次点検対象が1部門増え、管理コストが上がる
- ベッカイ: 「新設か否か」ではなく職掌の切り方で解決する。**集客(ヒロメ)と収益化(ツヅル)を分離**し、ツヅルは「在庫・品質・数字・お題」の管理に限定、人間の手のRACIは従来のまま変えない。これで重複せず、管理単位も明確になる
- 裁定: **ベッカイの切り分けを採用して新設**(最終決裁: 小柳さん・本指示をもって承認)。対外ペルソナ「AI編集長」の管掌はヒロメ→ツヅルへ移管。§2のRACIで説明責任(A)のうち「記事・白書・週報の生成」「公開記事の品質・出典」をツヅルに変更。実行(R)の人間担当・代行順位は変更なし
- 見直し期限: 2027-02-28(v3計画と同時レビュー。SNS部との職掌摩擦・管理コスト増が実害化していないか点検)
