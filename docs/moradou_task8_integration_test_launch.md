| 症状 | 原因の可能性 | 対応 |
|---|---|---|

### 優先度 MEDIUM（翌営業日対応）

| 症状 | 原因の可能性 | 対応 |
|---|---|---|
| GA4 イベントが記録されない | ga4 トラッキング ID が無効 | 計測 ID G-TQMX3MPFSR を確認 / ブラウザコンソール確認 |
