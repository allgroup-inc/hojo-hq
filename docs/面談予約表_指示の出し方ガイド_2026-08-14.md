## 0. 先に結論

**この文のままで十分です。**思いつきは削らずそのまま送ってください。
ただしこの1文だと、AI側が勝手に決めてしまう(=あとで作り直しになる)点が3つあります。

| 勝手に決まってしまう点 | なぜ危ないか |
|---|---|
| **どこに置くか**(公開サイト or LINEの中 or 社内だけ) | 公開サイトに置くと絶対ルール4「CV単一(LINE登録のみ)」に抵触。KGIの1,000社が落ちる |
| **誰の予定か**(GLOW営業マン / 士業 / 嶺井さん) | 空き枠の取り方も、面談後の出口も変わる |
| **予約後にどうなるか**(通知・カレンダー登録・リマインド) | ここが抜けると「予約したのに連絡が来ない」が起きる。信頼毀損が一番大きい |

なので、次から思いつきを投げるときは **§2の1行を足すだけ** で、こちらが勝手に決めずに済みます。
今回の構想そのものの採否は §4 の議事、決めてほしいことは §5 にまとめました。

## 1. 指示の出し方 5原則(この構想に限らず全部に効く)

1. **思いつきはそのまま送る。整えない。**
   整った指示ほど別解が出せなくなります。「〜みたいなイメージ」で十分です。
2. **「何が良くなってほしいか」を1行足す。**
   ×「予約表がほしい」→ ○「面談が月◯件に増えてほしい。そのために予約表がいいかも」
   目的が書いてあれば、予約表より効く手があるときにそれを出せます。
3. **置き場所を書く。**「公開サイト/LINEの中/社内だけ」の3択で十分です。
   ミカタはCV単一ルールがあるので、置き場所が書いてない構想は必ずそこで止まります。
4. **やって終わりでなく「その後」を書く。**
   予約が入ったら → 誰に通知 → カレンダーに入る → 前日にリマインド。ここまで書くと、作るものが半分決まります。
5. **「今すぐ試したい」か「じっくり作りたい」かを書く。**
   前者なら既製ツール(TimeRex等)で1週間、後者ならglow-maに内製。作る量が10倍変わります。

**全部埋めなくて大丈夫です。**分からないところは「わからない」「任せる」と書いてください。
そう書いてあれば、こちらが選択肢を並べて決裁キューに上げます(黙って決めることはしません)。

## 2. そのまま貼れる型

### 型A: 思いつきを投げるとき(30秒・これが基本)

```
【思いつき】
<やりたいことを、思いついたまま。整えなくていい>

【良くしたいこと】
<例: 面談が増えてほしい / お客様の手間を減らしたい>

【置き場所】公開サイト / LINEの中 / 社内だけ / わからない
【急ぎ度】今すぐ試したい / じっくりでいい

決裁が要る点があれば決裁キューに上げてください。
```

今回のLINEを型Aに直すと、こうなります(これが理想形):

```
【思いつき】
お客様から予約できる面談予約表みたいなのがあるといいかも。
営業マンの顔写真付きで、この営業マン選ぶ→空きアポ情報でてきて選択、みたいなイメージ。

【良くしたいこと】
LINE登録のあと面談まで進む数を増やしたい(今は人力で取りこぼしてる感覚がある)

【置き場所】わからない(公開サイトに置いていいのかが判断つかない)
【急ぎ度】今すぐ試したい

決裁が要る点があれば決裁キューに上げてください。
```

### 型B: 方向性を決めたいとき(壁打ち)

```
<構想>について、三名体制で議論して結論を出してください。
特にウタガイ役には「やらない理由」を厳しめに出させてください。
私が決めるべき点は決裁キューに1行で。
```

### 型C: 実際に作らせるとき

```
<構想>を作ってください。

決まっていること:
- 置き場所: <どこ>
- 対象者: <誰の予定を出すか。人数も>
- 予約後の流れ: <誰に通知 → どこに記録 → リマインドの有無>

決まっていないこと:
- <ここは提案してほしい>

守ること:
- 個人情報・顔写真は公開リポジトリにコミットしない
- 空き枠が取れないときは予約を受け付けない(誤った枠を出さない)
- 完了したらドキュメントに記録を残す
```

型Cの「守ること」3行は、この種の自動で動くものを頼むときは毎回入れてください。
特に2行目は、resilient-agent-design の「取得できないときは止まる(フェイルクローズ)」に当たります。
カレンダーが繋がらないときに古い空き枠を出してしまうのが、この手の仕組みで一番起きる事故です。

## 3. やりがちなNGと直し方

| NGな指示 | 何が起きるか | 直し方 |
|---|---|---|
| 「いい感じの予約システム作って」 | 置き場所を勝手に決めて公開サイトに置く → CV単一違反 | 置き場所を3択で書く |
| 「営業マンの顔写真を載せて」 | 本人同意なしに対外掲載してしまう | 「同意の取り方も含めて提案して」と書く |
| 「Googleカレンダーと繋げて」 | 繋がらなかったときの挙動が決まらない | 「繋がらないときは予約を止める」まで書く |
| 「あとはよろしく」 | 決裁事項もこちらで決めてしまう | 「決裁が要る点はキューに」と1行足す |
