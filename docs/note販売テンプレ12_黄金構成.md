# note販売テンプレ12(黄金構成)— 小柳さん送付資料の正本化とミカタ適用ルール

- 日付: 2026-08-04 / 出所: 小柳健さん送付のスクリーンショット7枚(「❷送付したものに沿って様々なジャンル記事をつくって下さい」)
- 位置づけ: 実例研究シリーズ(posts/note/tanpatsu/)の**無料部分の標準構成**。生成スクリプトのプロンプトにも組込済み
- 大原則: **魚のいる釣り堀(ジャンル)を選び、読者の悩みに効く「薬」のような記事を書き、この12テンプレで営業して購入ボタンを押してもらう**

## 1. 12テンプレの原文(送付資料の転記)

| # | 要素 | ねらい | 送付資料の例文 |
|---|---|---|---|

## 2. ミカタ適用ルール(守り部の線引き)

12個のうち9個はそのまま使う。3個は**事実がある場合のみ**使う(捏造は絶対ルール1・note規約・景表法に抵触)。

| # | 適用 | ルール |
|---|---|---|
| 1,2,3,5,6,9,11,12 | **毎回使う** | ただし#3のギャップは煽らない(不安の誇張・断定はしない。「知らないまま」と「知っている」の差を事実で見せる) |
| 4 自己紹介 | **毎回使う** | 語ってよい実績は**ミカタの実運営の事実のみ**(AI17人・毎日巡回・掲載件数など)。「稼いだ」系の自称実績は使わない |
| 7 口コミ | **実在する声のみ** | 読者・モニターの実際の感想が届くまでは**この枠を置かない**。届いたら本人の許可を得て使用。創作した口コミは掲載禁止(ステマ規制・note規約) |
| 8 特典 | 実物があるときのみ | 例: チェックリストPDF・テンプレ配布など実際に付けられるもの。「つけたつもり」禁止 |
| 10 注意事項(限定) | **事実の限定のみ** | 偽の数量限定・偽の値上げ予告は禁止(有利誤認)。使えるのは実際に決裁された価格改定予定・実際の枠数のみ。無い場合は#10を「データの鮮度」注意書き(「数字は◯月時点」)に置き換える |

追加の全体ルール(既存規程の再掲):
- 禁止語(必ず/絶対/誰でも/楽して/確実に稼)はテンプレ実装後も不使用(機械検査対象)
- 未来を見せる(#3)ときも成果は保証しない。「事例ではこうだった」の形を崩さない
- 他者事例は出典つきリサーチとして書く(体験偽装禁止。v3計画§2)

## 3. 三名体制の短評(L2)

- **スイシン**: 現行記事は「研究報告」として誠実だが営業構造がなく、読ませる力と買わせる力が乖離していた。12テンプレは無料部分の設計図として即効性が高く、全記事・自動生成の両方に一括適用できる
- **ウタガイ(反対理由の記録)**: ①テンプレ例文(ダイエット系)の直訳は情報商材の文法そのもので、ミカタの信頼資産と衝突する。特に#7口コミ・#10数量限定は捏造誘惑が構造的に強く、1回の偽装でメディア全体が終わる ②#3のギャップ訴求は不安商法と紙一重で、note規約のBAN領域に接近する ③テンプレ固定で全記事が同じ匂いになり、「AIが型で書いた」感が読者にバレるリスク
- **ベッカイ**: テンプレの「営業の順番」だけを借り、例文のトーンは借りない。#7#8#10は「事実があるときだけ開く枠」として条件付き運用にすれば、捏造誘惑は構造的に消える(§2の表がその実装)。同型感は、#1の掴みと#12の寸止めを毎回その記事固有の数字・問いにすることで回避する
- **裁定**: 採用(§2の線引きつき)。小柳さん送付資料が原本であり、適用方針のみ本書で明文化。見直し期限: 2027-02-28(v3計画と同時レビュー)
