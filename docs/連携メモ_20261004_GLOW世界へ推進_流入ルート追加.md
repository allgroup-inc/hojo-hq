# 連携メモ 2026-10-04 — GLOW世界へ推進: 流入ルート追加のお願い

宛先: ❶ システム関係全般(glow-ma 営業管理システム担当)
作成: ❻ GLOW 世界へ推進(2026-10-04新設)
目的: glow-ma配下の変更は❶に一本化する決定(2026-08-19)に従い、❻は直接触らず要件のみ依頼する。

## 背景(1行)
沖縄の生産者に、GLOWがAlibaba.com上に持つ沖縄ブースへ商品を載せてもらう取り組み(❻)を始めた。この取り組みの企業も、将来は企業マスタで一元管理したい。計画の詳細は非公開リポジトリ `allgroup-inc/glow-docs-private` の `docs/GLOW世界へ推進_計画と参照資料_v1_2026-10-04.md` を参照(公開側には書かない)。

## 依頼1: 流入ルートに「世界へ(Alibaba)」を追加
- 企業マスタの流入ルート(現行「①紹介」等と同じ選択肢)に、新しい値 **「世界へ(Alibaba)」** を追加する
- 既存の流入ルートの集計・スコアリング・レター出し分けを壊さないこと

## 依頼2: 企業マスタに項目を追加(この流入ルートの企業で使う)
| 項目 | 内容 | 形式の案 |
|---|---|---|
| 相談日 | 最初に相談(面談・オンライン相談)に進んだ日 | 日付 |
| 掲載商品数 | GLOWの沖縄ブースに掲載した商品の数 | 数値(0以上) |
| 掲載開始日 | 最初の商品を掲載した日 | 日付 |
| LINE経由か | GLOW用LINE公式アカウント経由で来た企業か | はい/いいえ |

項目の置き場所(既存列に足すか、別シートか)は❶の判断に任せる。

## 依頼3: ダッシュボードに指標を表示
- **KPI: 「相談まで進んだ企業」100社 / 2027-04-04まで**(「世界へ(Alibaba)」流入で相談日が入っている企業の数)
- **副指標: 掲載社数**(掲載商品数が1以上の企業の数)
- 期限までの進捗(累計・残り日数)が一目で分かる形が望ましい

## 注意
- 本メモは公開リポジトリのため、金額・顧客データ・アリババとの契約条件は書いていない。必要な情報は上記の非公開リポジトリで確認する
- LINE経由の計測は、GLOW用の転送ページ(計測イベント `glow_line_redirect`)で別に数えている。ミカタの `line_redirect` とは混ぜない
- 実施可否・時期は❶から返信ください(返信先: 本メモの末尾に追記、または新しい連携メモ)
