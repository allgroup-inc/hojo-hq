# もらいわすれ堂：LINE配信シナリオガイド

**目的**: LINE登録者を「診断」から「実申請」へ導き、相談・成功事例につなげる

**配信パターン**: 4つのシナリオ（登録直後・定期・トリガー型・成功事例）で段階的にサポート

**計測**：LINE 分析 + GA4 で「登録→相談」のコンバージョンを追跡

---

## パターン 1: ウェルカムメッセージ（登録直後、Day 0）

### 目的
新規登録者に対して、診断結果から実申請までの「次のステップ」を明確に示す。「このアプリで何ができるか」の安心感を与える。

### 配信内容

```
こんにちは！🌺
もらいわすれ堂へようこそ。

診断で見つかった制度について
『準備シート』と『申請ガイド』を
LINEでお届けします。

━━━━━━━━━━━━━━━━

📌 今週中にやること

▪️ 見つかった制度の「準備シート」を確認
  → どんな書類が要るかが分かります

▪️ 相談窓口に電話して詳しく聞く
  → 「本当に自分に該当するか」を確認

▪️ 必要な書類を集め始める
  → 準備シートのチェックリストを使用

━━━━━━━━━━━━━━━━

📥 準備シート（すぐに確認できます）
👉 [準備シートをダウンロード]

📚 よくある質問 TOP 5
👉 [よくある質問を見る]

📞 相談窓口を検索
👉 [近くの窓口を探す]

━━━━━━━━━━━━━━━━

わからないことがあったら
いつでも LINEで質問してください！

このチャットで相談できます → [メッセージ送信]
```

### 配信タイミング
- **タイミング**: ユーザーが LINE 登録完了した直後（即座）
- **最適時間**: 登録した時刻に関わらず、即座に送信

### 計測
- **計測イベント**: `line_welcome_sent`
- **追跡項目**: 準備シート DL クリック率、相談窓口検索クリック率

## パターン 2: 定期配信（毎週木曜 15:00）

### 目的
「準備が進まない」ユーザーへの定期的なリマインドと、つまずきやすい「書類準備」のサポートを提供。

### 配信内容（週ごとにローテーション）

#### 【Week 1】書類準備の進め方

```
📋 準備シート　その後どうですか？

「必要書類をどう集めたらいい？」
これが一番つまずくポイントです。

━━━━━━━━━━━━━━━━━

【3つの集め方】

①  相談窓口に電話する
   「この書類、どこで取ったらいいですか？」
   と聞くのが一番確実

②  自治体ホームページで確認
   PDFで様式がダウンロードできることが多い

③  今は不要でも、書類番号を先にメモ
   例：「戸籍謄本」「世帯票」など

━━━━━━━━━━━━━━━━━

👉 [実際の流れを見る]

相談窓口に電話するときの例文も
用意してあります 👇

[相談窓口の上手な使い方]
```

#### 【Week 2】書類作成のコツ

```
✍️ 「申請書の書き方がわかりません」

これも多い相談です。
でも大丈夫。3つの方法があります。

━━━━━━━━━━━━━━━━━

【書き方で困ったときは】

① 見本をもらう
  相談窓口に「記入例を見せてもらえますか？」
  と聞いて、見本をコピーする

② 手書きでいいか確認
  パソコンがなくても手書きで OK な制度が多い

③ 士業に相談（有料）
  「書類が複雑」なら士業に依頼する選択肢も

━━━━━━━━━━━━━━━━━

👉 [よくある質問：書き方編]

わからない場所があれば
相談窓口に聞いて OK です。
それが相談窓口の仕事です！
```

#### 【Week 3】申請のタイミング

```
⏰ 締め切りに間に合わせるために

「今から申請して間に合いますか？」
この質問、もよくあります。

━━━━━━━━━━━━━━━━━

【チェック】

□ 申請締め切りは？
  （見つかった制度に期限がありますか）

□ 今から何日ある？
  （今日から締め切りまでの日数）

□ 必要書類は全部揃いそう？
  （揃わなそうなら何が必要か）

━━━━━━━━━━━━━━━━━

👉 [診断し直す]

「もしかして別の制度も対象？」
新しく見つかることもあります。

時間に余裕があれば再診断も。
👉 [診断ページへ]
```

#### 【Week 4】士業との相談

```
🤝 「書類が複雑で自分では無理...」

そんなときは士業（社労士・行政書士）の
力を借りる選択肢があります。

━━━━━━━━━━━━━━━━━

【士業に相談するメリット】

✅ 自分で書く時間が短くなる
✅ 書類ミスが減る
✅ 申請窓口に提出したあとも相談できる

【相談費用】
制度によって異なります。
（例：5,000〜30,000円程度）

━━━━━━━━━━━━━━━━━

👉 [提携士業を紹介してもらう]

相談は無料で予約できます。
「この制度の申請、手伝ってもらいたい」
と言ってください。
```

### 配信タイミング
- **タイミング**: 毎週木曜 15:00（仕事の午後。読みやすい時間帯）
- **ローテーション**: Week 1-4 の4パターンを月間で繰り返す

### 計測
- **計測イベント**: `line_weekly_digest`
- **追跡項目**: クリック率、相談窓口への遷移、士業紹介への遷移

## パターン 3: トリガー型配信（期限 1 ヶ月前）

### 目的
「うっかり期限を見落とす」を防ぐ。自動的に期限切れ前の制度について通知。

### 配信内容

```
⏰ 期限が近づいています！

【〇〇補助金】
申請締切：□月 □日
あと約 30 日です

━━━━━━━━━━━━━━━━━

【確認チェックリスト】

□ 必要書類をすべて集めた
□ 申請書に記入した
□ 自治体の相談窓口に確認した
□ 書類を提出した / 郵送した

1 つでも□があれば
今週中に行動を始めてください！

━━━━━━━━━━━━━━━━━

💡 「1 ヶ月あれば大丈夫」と思いがちですが
  書類集めで意外と時間がかかります。
  早めの行動がおすすめです。

👉 [準備シートを見る]
👉 [相談窓口を探す]

質問があればいつでも
メッセージください！
```

### 配信トリガー
- **条件**: 各制度の申請締切が「30日以内」のとき
- **タイミング**: その制度の締切 30 日前の朝 8:00

### 実装の工夫
- Power Automate で「seido.json の deadline フィールド」を参照
- LINE Messaging API で自動送信
- 1日1回チェック（同じ制度に複数回送信しないよう管理）

### 計測
- **計測イベント**: `line_deadline_reminder`
- **追跡項目**: 期限リマインド後の「相談申し込み率」

## パターン 4: 成功事例配信（隔月配信）

### 目的
「実際に受給できた人の話」を聞くことで、「自分もできるかも」という行動動機を高める。

### 配信内容

```
🎉 こんな制度も使えた！

━━━━━━━━━━━━━━━━━

【事例】児童手当の振込が止まっていた
（沖縄県内、3児のお父さん）

「児童手当なんてもらってるもんだと
 思ってました...」

実際には振込が止まっていて
4 ヶ月分さかのぼって受給。

毎月 1.5 万円が再開！

━━━━━━━━━━━━━━━━━

【このお父さんが言いたいこと】

「沖縄の親たちに『申請忘れがないか
 確認してね』って伝えたい。
 知ってるか知らないかだけで
 こんなに変わるんです」

━━━━━━━━━━━━━━━━━

あなたも
「制度をうっかり見落としていた」
かもしれません。

👉 [診断してみる]

すでに診断済みなら
👉 [診断し直す]

新しく対象になる制度が
見つかることもあります。
```

### 配信タイミング
- **タイミング**: 月 2 回（初回：第 2 金曜、第 4 金曜）
- **時間**: 朝 8:00（おすすめ朝読み）

### 配信元
- Task 1 で収集した事例を、Task 2 で整形した Instagram 投稿から抽出
- 月に「事例 4-8 件」の Instagram 投稿があれば、そのうち 2 件を LINE でも紹介

### 計測
- **計測イベント**: `line_success_story`
- **追跡項目**: 成功事例経由の「診断クリック率」「LINE→相談申し込み率」

## AB テスト計画

### 実施期間
- **対象**: 初回 1 ヶ月（11 月全体）
- **実験群**: パターン 2 の定期配信を「週 1 回」で実施
- **対照群**: パターン 2 の定期配信を「隔週」で実施

### 計測項目
1. **配信開封率** （LINE 公式アカウントの分析機能で計測）
   - 開封率が高い = ユーザーが読んでいる
   - 低い = 配信頻度が多い or メッセージが長い

2. **クリック率** （各メッセージの URL クリック数）
   - 準備シート DL
   - 相談窓口検索
   - 診断ページ

3. **ブロック率** （配信を拒否した / ブロックした比率）
   - 高い = 配信が迷惑と感じられている信号

4. **相談申し込み数**
   - 実際に「LINE で相談したい」と返信した件数

### 判定基準
- **パターンを続ける**: クリック率 > 20% かつ ブロック率 < 5%
- **調整する**: クリック率 < 15% または ブロック率 > 10%
- **中止する**: ブロック率 > 20% （ユーザーにとって迷惑）

### 改善サイクル
- **1 週目**: 初期配信。反応を見守る
- **2-3 週目**: 開封率・クリック率を日々確認
- **4 週目**: 月間データをまとめて、改善案を検討
- **12 月**: 新しい配信パターンを試す

## リスク管理

### リスク 1: 配信頻度が多すぎる → ブロック増加

**対策**：
- 初期は「隔週」で様子を見る
- ブロック率を毎日確認（> 10% になったらすぐに頻度を下げる）
- ユーザーに「配信頻度を選べる」リッチメニューを用意

### リスク 2: メッセージが長すぎる → 読まれない

**対策**：
- 1 メッセージは「3-5 行」を目安
- 詳細は「[詳しく見る]」リンク先に記載
- 絵文字を効果的に使って視認性を高める

### リスク 3: 期限トリガーが誤動作 → 不適切な時期に通知

**対策**：
- 最初の 3 件は手動で送信テスト
- 自動化前に「7 日間」確認期間を設ける
- メタデータで「最後の送信時刻」を記録（二重送信防止）

## 特記事項

### トーン
- 「専門用語をやさしく」の姿勢を維持
- 「あなたは大丈夫ですか？」という問いかけで不安を減らす
- 成功事例から「希望」を感じさせる

### 相談への導線
- 毎メッセージに「質問があれば返信してください」のメッセージ
- チャットは「営業時間内（平日 9-17 時）に返信」のルール設定
- 返信が来た場合は「相談申し込み」として計測

### 成功メトリクス
- **最終ゴール**: 「LINEから相談→実際に受給した」件数
- **中間指標**: 準備シート DL 率、相談窓口検索率、士業紹介率
