## 0. 前提(2026-08-11 小柳さん共有・確定)

株式会社フクギイロが関わる事業は次の**3つ**。

| 事業 | 対象 | 顔(ブランド) | 現状 |
|---|---|---|---|
| もらい忘れ(県民向け給付金・制度案内) | B2C(県民) | **もらいわすれ堂** | site/fukugiiro/ で運営中 |
| **webデザイン制作**(受託・遥さん担当) | B2B(事業者) | 未定(会社名で受注中) | 稼働中・収益事業(ポートフォリオ整理§5) |
| **システム経営コンサル**(小柳さん担当) | B2B(事業者) | 未定(会社名) | 稼働中(あいおい生命コンサル・ログ解析教育システムの系譜) |

※ ポートフォリオ整理(2026-07-29時点)の5サイト構築準備等はHPには載せない。
2026-08-11の小柳さん共有により**HPで扱う事業はこの3つ**とする(記録の食い違いは§5に追記済み)。

つまり「株式会社フクギイロのホームページ」= **3事業を紹介するコーポレートサイト**(現在は存在せず新規制作)。
もらいわすれ堂のLPとは別物で、混同表記をしない(ブランドガイド5条)。

## 1. 指示設計の急所(この3点を外すと事故ります)

1. **HP自体が営業ツール**: webデザイン制作を掲げる会社のHPは、それ自体が**実績第1号**。ここが安っぽいと受注に直結してマイナス。「相当安心できるもの」=見た目の華やかさではなく「**実在感+誠実さ+丁寧なつくり**」
2. **読者が2種類いる**: 県民(もらいわすれ堂へ)と事業者(webデザイン相談へ)。入口で迷わせない導線設計を指示に含める
3. **もらいわすれ堂LPには手を入れない**: 会社HPにCVを足したり、もらいわすれ堂側にwebデザイン導線を混ぜるとCV単一原則を壊す。分離を明示する

## 2. 良い指示の型(5要素)

1. **対象の特定**(今回: フクギイロのコーポレートサイト新規制作。2事業構成)
2. **「安心」の定義**(解釈が割れる言葉なので具体化して渡す — 下のテンプレに記載済み)
3. **守るルール**(混同表記禁止・実績は事実のみ・PII/フォームは守り部審査・出荷ゲート)
4. **任せる範囲と決裁に戻す範囲**(料金表・実績掲載・ドメイン・問い合わせ手段)
5. **完了条件と記録**(スクリーンショット目視+docs記録+PR)

## 3. コピペ用プロンプト(推奨版・そのまま貼れます)

```
株式会社フクギイロのコーポレートサイト(ホームページ)を新規制作してください。
「相当安心できるもの」がゴールです。安心の定義は下記の通り。

【前提】
フクギイロの事業は次の3つです。
1. もらいわすれ堂(県民向け・給付金/制度のもらい忘れ案内。site/fukugiiro/ で運営中)
2. webデザイン制作(受託。担当: 遥さん)
3. システム経営コンサル(担当: 小柳さん。ログ解析×教育など、システムで経営数字を動かすコンサル)
このHPはもらいわすれ堂とは別物です。混同表記をせず、site/fukugiiro/ 配下の既存LPには手を入れないこと。

【「安心できる」の定義(この順で優先)】
1. 実在感: 会社概要(所在地・代表)・理念(フクギ=防風林の物語)・運営3事業が一目でわかる
2. 誠実さ: 誇張ゼロ。実績は事実のみ、無いものは「まもなく公開」と正直に書く。断定しない文化はここでも同じ。コンサル成果の数字は顧客の掲載許可があるものだけ
3. つくりの丁寧さ: このHP自体がwebデザイン制作・システムコンサルの実績第1号。読みやすさ・表示速度・スマホ最適・アクセシビリティ(18px・コントラスト4.5:1・タップ44px)で品質を証明する
4. 迷わない導線: 入口で「県民の方(→もらいわすれ堂)/事業者の方(→webデザイン制作・システム経営コンサル)」の2分岐を明確に

【構成案(たたき。三名体制で磨いてよい)】
ヒーロー(会社の一言+県民/事業者の2分岐)/ 事業紹介3枚(もらいわすれ堂・webデザイン制作・システム経営コンサル)/
会社概要・代表 / 理念(防風林の物語)/ 実績(事実のみ)/ お問い合わせ / 個人情報保護方針

【守ること】
- CLAUDE.md絶対ルール。もらいわすれ堂のCV単一(LINE)を壊す相互導線を作らない
- 実績・数字は事実のみ。架空のお客様の声・でっち上げ実績は絶対禁止
- 問い合わせフォームは個人情報を扱うため、設置する場合は守り部の事前審査を通す(それまではメール/LINE案内で代替可)
- 対外文面は出荷ゲート: hojo-accuracy-check → hojo-deadline-alert → humanizer 通過
- 技術は既存と同じ静的HTML+依存ゼロ、GitHub Pages同乗。配置パスは実装前に提案すること

【私(小柳さん)の決裁に戻すもの(勝手に実装しない)】
独自ドメイン / webデザイン制作・システム経営コンサルの料金表 / 実績・お客様の声の掲載内容(顧客名の掲載許可含む)/ 問い合わせ手段(フォーム/メール/LINE)
→ docs/決裁キュー.md に1行ずつ追加すること

【進め方・完了条件】
hojo-triangle-review で構成議事(ウタガイ反対理由必須)→ 実装 → スクリーンショット目視確認 →
変更内容を docs/ に記録し、PRを作成して報告。
```

## 5. 三名体制議事(hojo-triangle-review)v2

## 論点: 「フクギイロHP=2事業(もらい忘れ+webデザイン制作)のコーポレートサイト」の指示をどう設計するか

### スイシン(推進)
- 対象の曖昧さが解消された(会社HP新規制作で確定)。2事業の分岐型コーポレートサイトは構成が素直で、既存の静的HTML+Pages資産にそのまま同乗できる
- webデザイン制作は稼働中の収益事業(ポートフォリオ§5)なのに公開の顔が無い。HP自体を実績第1号として作れば営業ツールと会社の信頼が同時に手に入る

### ウタガイ(懐疑)  ← 空欄不可
- **実績の空白リスク**: 受託実績を公開できる形(顧客名掲載許可)で持っているか未確認。許可なき掲載は信頼を壊す事故。→ プロンプトに「実績は事実のみ・掲載内容は決裁」を明記
- **コンサル実績の守秘リスク(3事業目追加に伴い)**: システム経営コンサルの実績は保険会社・催事企業など顧客の内部数字と密接で、社名・成果数字の無断掲載は守秘義務違反になり得る。→ 「コンサル成果の数字は顧客の掲載許可があるものだけ」を安心定義に明記、掲載内容は決裁事項へ
- **導線汚染リスク**: 会社HPからもらいわすれ堂へ、もらいわすれ堂から会社HP(webデザイン営業)へ相互リンクすると、B2CのCV単一(LINE)が薄まる。→ 「site/fukugiiro/ に手を入れない」を明記
- **問い合わせフォーム=PII**: 公開リポジトリ運営でフォームを安易に置くと個人情報の扱いが発生。→ 守り部事前審査を条件化
- **記録の食い違い**: ポートフォリオ整理にはあいおいコンサル等も記載。黙って書き換えると「やったのに記録がない」の逆(記録が勝手に消える)事故。→ 旧記録は残し、2026-08-11共有を追記する方式に

### ベッカイ(別解)
- webデザイン制作に**別ブランド名を立てる**選択肢もある(もらいわすれ堂方式)。ただしブランド新設は命名・ロゴ・決裁で数週間かかる。会社名受注で稼働中の実態に合わせ、まず会社HPで受け皿を作り、ブランド化は受注が増えてから検討で足りる
- そもそもHPより先に**制作実績ポートフォリオ1枚**(既存制作物の掲載許可取り)を整える方が受注効果は速い、という順序の別解もある。→ HP内の実績セクションとして同時に扱えば二度手間にならない

### 結論(部門長の裁定)
- 採否: **採用**(v2プロンプトに反映)
- 理由: ウタガイの4リスクはすべて指示文の条項で潰した(実績=事実のみ+決裁 / LP不可侵 / フォーム審査 / 記録は追記方式)。ベッカイの別ブランド案は実態(会社名で稼働中)と速度から現時点は不採用、実績ポートフォリオはHP実績セクションに統合
- 見直し期限: 2026-11-11(3ヶ月。公開後の問い合わせ実績でブランド分離の要否を再議論)
