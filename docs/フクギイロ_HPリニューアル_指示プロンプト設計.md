## 0. まず1つだけ決めてください(ここが曖昧だと成果物がズレます)

「株式会社フクギイロのホームページ」は2通りあります。

| 選択肢 | 中身 | 現状 |
|---|---|---|
| **A. もらいわすれ堂のサイト**(推奨) | 県民向けサービスの顔。site/fukugiiro/ | **実装済み・公開中**。強化プラン(docs/もらいわすれ堂_LP強化プラン.md)も承認待ちで存在 |
| B. 会社としてのコーポレートサイト | 株式会社フクギイロの会社案内(理念・会社概要・採用等) | **存在しない**(現在はもらいわすれ堂のフッター表記のみ) |

ブランドガイドの使い分けルール上、県民が見る「安心できるページ」= もらいわすれ堂です。
**迷ったらAを指示してください**(Bが欲しい場合は末尾の短縮プロンプトを使用)。

## 1. 良い指示の型(この5要素を入れると一発で意図が通ります)

1. **対象の特定**: どのサイト・どのページか(「フクギイロのHP」だけだと上の曖昧さで事故ります)
2. **「安心」の定義**: 「安心できるもの」は解釈が割れる言葉です。**見た目の高級感ではなく「正確性の見える化」**だと明示する(下のテンプレに具体化済み)
3. **守るルール**: CLAUDE.md絶対ルール・CV単一・締切「約1か月前」表現・出荷ゲート3スキル
4. **任せる範囲と決裁に戻す範囲**: エージェントが勝手に決めてはいけない事項(顔写真・独自ドメイン等)を先に列挙
5. **完了条件と記録**: 何をもって完了か+docsに記録を残すこと

## 2. コピペ用プロンプト(推奨版: もらいわすれ堂リニューアル)

そのまま貼って使えます。【 】内はお好みで調整してください。

```
site/fukugiiro/(もらいわすれ堂)のホームページを「安心感」最優先でリニューアルしてください。
ゼロから作り直すのではなく、既存実装(CI検査・schema・計測・診断接続)を壊さない段階的な強化です。

【ゴール】
沖縄の世帯が初見3秒で「ここは信用できる・無料で怖くない」と感じ、3分診断に進めるページにする。
数値目標: 診断開始→完了率80%以上、診断→LINE登録率30%以上(憲法KPI)。

【「安心」の定義(この順で優先)】
1. 正確性の見える化: 一次ソースリンク・「要確認」表示・正確性ポリシーの要約1行を各CTA近くにも置く
2. 不安払拭の三点セット「無料・匿名・いつでも解除」を全CTA直下に固定表示
3. 運営者の顔が見える: 株式会社フクギイロの表記・なぜ無料か・「申請代行はしない」の明記
4. やさしい日本語・断定しない(「〜の可能性があります」)。ただし寄り添いは断定する
5. デザインはブランドガイドv1(朱#B9502F・黄#F2B705・漆喰#FFFBF4)の範囲内。装飾より読みやすさ

【実装対象】
docs/もらいわすれ堂_LP強化プラン.md の「すぐやる(Quick Wins)1〜6」を必ず含める。
それ以外に安心感を上げる案があれば hojo-triangle-review で議論して追加提案。

【守ること】
- CLAUDE.md絶対ルール(CV単一=LINE登録のみ・lin.ee直貼り禁止・/go/経由)
- 締切表現は「約1か月前から」で統一(「7日前」は誤り)
- 性能予算(初期表示150KB以下・LCP2.5秒)・アクセシビリティ(18px・コントラスト4.5:1・タップ44px)
- 対外文面は出荷ゲート: hojo-accuracy-check → hojo-deadline-alert → humanizer 通過

【私(小柳さん)の決裁に戻すもの(勝手に実装しない)】
顔写真の掲載 / 独自ドメイン / A/Bテスト開始 / 新しい導線の追加
→ docs/決裁キュー.md に1行ずつ追加すること

【完了条件】
実装+スクリーンショット目視確認+CI通過+変更内容を docs/ に記録し、PRを作成して報告。
```

## 4. 三名体制議事(hojo-triangle-review)

## 論点: 「フクギイロHPリニューアル(相当安心できるもの)」の指示プロンプトをどう設計するか

### スイシン(推進)
- 5要素の型(対象・安心の定義・ルール・決裁境界・完了条件)で指示すれば、解釈のブレなく即着手できる
- 承認待ちの docs/もらいわすれ堂_LP強化プラン.md(Quick Wins 1〜6)を実装対象に組み込めば、調査済みの根拠(固定CTA+15〜25%等)をそのまま活かせて最速

### ウタガイ(懐疑)  ← 空欄不可
- 「相当安心できるもの」を**見た目の話と誤解**すると、装飾過多で行政情報の信頼感を壊す逆効果になる(ブランドガイド4条に反する)。→ 指示文で「安心=正確性の見える化」と定義必須
- 「リニューアル」の語は**全面作り直し**と解釈されやすく、実装済み資産(CI検査・JSON-LD・計測・診断接続・性能予算)を壊すリスクが大きい。→ 「ゼロから作り直さない・段階的強化」を明記必須
- 対象の曖昧さ(サービスLP vs 会社サイト)を放置すると誤った成果物に工数を浪費する
- 顔写真・独自ドメイン等の決裁事項をエージェントが勝手に実装する恐れ。→ 決裁境界の列挙必須

### ベッカイ(別解)
- そもそも「HPのリニューアル」が安心感向上の最短ルートか疑わしい。転換の最重要点は**診断結果画面→LINEの受け渡し**(強化プラン§7)であり、トップページを磨くより効果が大きい可能性がある
- 別解: 「リニューアルして」ではなく「**安心感の監査→改善**」と指示する(現状の何が不安要素かを先に特定させる)。ただし今回はQuick Winsが既に診断済みのため、監査から始め直すのは二度手間

### 結論(部門長の裁定)
- 採否: **採用**(推奨版プロンプトに反映)
- 理由: ウタガイの4リスクはすべて指示文側で潰せる(安心の定義・段階的強化の明記・対象特定・決裁境界)。ベッカイの「診断結果画面が本丸」は正しいが、指示テンプレの【実装対象】に三名体制での追加提案枠を残すことで拾える。監査から始め直す別解は既存の強化プランと重複するため不採用
- 見直し期限: 2026-11-11(3ヶ月。リニューアル実施後の計測数値で指示テンプレ自体を再評価)
