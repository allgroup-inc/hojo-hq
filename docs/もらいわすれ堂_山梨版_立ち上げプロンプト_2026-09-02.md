## いちばん大事な5つの約束(これを破る作りは絶対にしない)

1. **正確さがすべてに優先。** 金額・締切・条件は必ず役所の公式ページと照らし合わせる。
   確認が取れないものは**「要確認」と表示して断定しない**。
   「必ずもらえる」「絶対」という言葉はサイトのどこにも使わない
2. **申請の代行はしない。** 書類を書くのはご本人。こちらは「迷わない準備」までを手伝う。
   行政書士さん・社労士さんにしかできない仕事には踏み込まない
3. **個人情報を集めない。** 診断は匿名。名前・住所・電話番号は聞かない。
   チェックやメモはその人のスマホ・パソコンの中にだけ保存し、こちらには送らない
4. **役所には敬意と負荷ゼロで。** 情報は「出典: ◯◯市ホームページ」と明記して
   必ず公式ページへリンクする形。文章の丸写しはしない。
   **使ってよいか規約で確認できない市町村は、先に電話で確認してから載せる**(勝手に載せない)
5. **登録の入口はLINEひとつだけ。** 広告や他の登録窓口を勝手に足さない

## 締切のお知らせのルール(間違えやすいので特に注意)

利用者向けの表現は**「締切の約1か月前からお知らせします」で統一**する。
「締切7日前にお知らせ」は**誤り**(7日前では書類の準備が間に合わない)。
- SNSでの紹介 = 締切まで30日以上ある制度だけ
- 締切まで7〜29日 = LINEでの個別のお知らせ
- 締切まで7日未満 = その回は案内せず「次回の募集のご案内」に切り替える

## サイトの構成(沖縄版と同じ8点セット)

1. **トップページ(LP)** — 話の並びも沖縄版と同じにする:
   ①こんな「もらい忘れ」、していませんか? →
   ②なぜ「もらいわすれ堂」を始めたのか →
   ③3分診断への誘導 →
   ④「受け取れました」を教えてください(受給報告) →
   ⑤たとえば、こんな制度を掲載しています →
   ⑥正確性へのお約束 →
   ⑦よくあるご質問 →
   ⑧LINE・Instagramへの誘導
2. **3分診断** — 名前も住所も入れず、家族の状況を数問答えるだけで
   「使える可能性のある制度」が出る。結果は**「可能性: 高/中」の2段階**+要確認表示。
   ここでも断定しない。**医療・介護の制度と、障がいだけが対象の制度は
   診断結果には出さず、一覧ページへの案内にとどめる**(デリケートな話題のため。沖縄版で決めたルール)
3. **ライフイベント別の一覧** — 9カテゴリ: 出産/子育て/入学/医療/介護/生活/失業/障がい/住まい
4. **市町村別ページ** — 山梨県は**27市町村**。
   市(13): 甲府市・富士吉田市・都留市・山梨市・大月市・韮崎市・南アルプス市・北杜市・
   甲斐市・笛吹市・上野原市・甲州市・中央市
   町(8): 市川三郷町・早川町・身延町・南部町・富士川町・昭和町・西桂町・富士河口湖町
   村(6): 道志村・忍野村・山中湖村・鳴沢村・小菅村・丹波山村
   ※着手前に山梨県公式サイトで最新の市町村一覧を必ず確認すること(合併等がないか)
5. **申請準備シート** — 制度ごとに「持ち物チェックリスト・窓口で言うひとこと・メモ欄」を
   印刷してそのまま窓口に持っていける1枚
6. **受給報告ページ** — 「受け取れました」の声を集める(この件数が事業の北極星)
7. **プライバシーページ** — 「個人情報を集めない」ことをそのまま説明
8. **訂正窓口ページ** — 間違いを見つけた人が知らせてくれる入口

- スマホ最優先。本文の文字は14px以上、入力欄は16px以上
  (それより小さいとiPhoneで画面が勝手に拡大されて使いにくい)
- 背景のグラデーション(色のぼかし)は使わない

## 進め方(3段階。いきなり全部を作らない)

**第1段階(まずここまで): トップページ+3分診断+国の制度**
- 国の制度(児童手当・出産育児一時金・高額療養費・就学支援・失業給付など約30本)は
  全国共通なので、各省庁の公式ページを出典にすぐ載せられる
- 山梨県庁の制度は、県サイトの利用規約を確認してから載せる
- ここまでで公開してよい(市町村の欄は「準備中」と正直に書く)

**第2段階: 27市町村のページと申請準備シート**
- 各市町村サイトの利用規約・robots.txt(自動確認をしてよいかの取り決め)を1つずつ確認
- 規約で確認しきれない市町村は、電話で確認してから載せる。電話の台本:
  「株式会社フクギイロの◯◯と申します。山梨県民向けに、国や市町村の給付金・手当の情報を
  まとめて無料で案内するサイト『もらいわすれ堂』を運営しております。
  ①御市(町村)のサイトの制度名・窓口・URLを、出典明記+公式ページへのリンクの形で
  ご紹介してよいでしょうか。文章の丸写しはいたしません。
  ②最新に保つためプログラムで1日2回、間隔をあけて該当ページを確認します。問題ないでしょうか」
- 自動確認は1日2回まで・1ページずつ間隔をあける(サーバーに負荷をかけない)

**第3段階: LINE・受給報告の本格運用**
- 締切のお知らせ(上のルール通り「約1か月前から」)
- 「受け取れました」報告の収集

## 公開前チェック(全部YESになるまで公開しない)

- [ ] 「必ず」「絶対」「100%」がサイトのどこにもない
- [ ] すべての制度に出典(公式ページへのリンク)がある
- [ ] 確認が取れていない情報はすべて「要確認」表示になっている
- [ ] 診断が名前・住所・電話番号を聞いていない
- [ ] 診断の入力内容がサーバーに送られていない(端末内だけで完結)
- [ ] 締切のお知らせ表現が「約1か月前から」になっている(「7日前」がどこにもない)
- [ ] 掲載許可の確認が取れていない市町村の制度が載っていない
- [ ] 登録の入口がLINEひとつだけになっている

## 迷ったときの判断基準

- 断定してよいか迷ったら → 「要確認」と書く(安全側に倒す)
- 載せてよいか迷ったら → 載せない(確認が先)
- 機能を足すか迷ったら → 利用者の手間が減るなら足す。増えるなら足さない
- お金・提携・公開範囲にかかわる判断 → 自分で決めず、小柳さんに確認する
