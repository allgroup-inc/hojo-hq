# 沖縄企業のミカタ Instagram投稿テンプレート化・自動生成仕様

**作成日**: 2026-09-28  
**決裁**: 小柳さん承認待ち  
**見直し期限**: 2026-12-28（3ヶ月）

---

## 概要

沖縄企業のミカタのInstagram投稿を「3つのテンプレート」に標準化し、制度データから自動生成する仕組みを構築。初期段階はCanva手作業、Week 5以降は完全自動化。

**目標**：
- Instagram投稿の目を引くデザイン化 → 保存率 20%、シェア率 8%以上
- 企業経営者への「実行可能性」感の向上
- 毎週5投稿を自動・半自動で生成

---

## 1. テンプレート設計

### テンプレート1：「数字と限定感」カルーセル
**用途**: デジタル化・AI導入補助金など、金額が大きく即効性がある制度  
**対象制度**: 上限100万円以上 + 締切30日以上の40制度  
**投稿サイクル**: 週2〜3件

**構成** (4ページカルーセル / 1080×1350px)
- P1: 大型数字（上限金額）+ 業種 | ネイビー#00335C背景 + オレンジ#F88800で数字を強調
- P2: 業種別活用例 Before → 300万円 / After → 100万円
- P3: 業種別活用例（別業種）Before → 500万円 / After → 150万円
- P4: 早見表（補助率・対象条件・締切）

**ビジュアルガイド**
- フォント: Meiryo Bold（大見出し）/ Meiryo Regular（本文）
- 色: ネイビー#00335C（主） + オレンジ#F88800（アクセント） + 白背景
- 数字サイズ: 150pt（上限金額）
- 余白: 上下左右40px

**キャプション**
```
【1行フック】
「うちの業務、自動化に400万円かけてたのが、補助金で実質100万円。」

【本文】
AI導入は「高い」と思ってませんか？
実は、国の補助金なら【上限450万円・補助率最大3/4】で支援されます。

このカルーセルでは、
✓ 実際の活用例（業種別）
✓ 補助率・対象条件
✓ 申請スケジュール

を紹介します。

「うちの業種でも対象かな?」と思ったら、プロフィールのLINEから無料相談できます。

【ハッシュタグ】
#沖縄企業のミカタ #DX補助金 #中小企業支援 #AI導入 #業務効率化
```

### テンプレート2：「トリアージ」シングル投稿
**用途**: 相談窓口・支援制度など、「まず相談」が重要な制度  
**対象制度**: 沖縄県内限定・無料支援サービス（約5〜10制度）  
**投稿サイクル**: 月1〜2件

**構成** (シングル 1080×1350px)
- 上部（40%）: 「沖縄県の中小企業へ 無料デジタル化サポート」大見出し
- 中部（40%）: 3ステップアイコン（相談 → 診断 → 実装支援）
- 下部（20%）: フリーダイヤル + QRコード（LINE友達追加用）

**ビジュアルガイド**
- 背景: グラデーション（ネイビー#00335C → オレンジ#F88800）
- テキスト: 白、Meiryo Bold 80pt
- アイコン: シンプルな線画（相談員、虫眼鏡、実装のイメージ）
- QRコード: 右下40px、サイズ150×150px

**キャプション**
```
【1行フック】
「デジタル化に100万円は必要？いいえ、沖縄県なら無料です。」

【本文】
DX導入したいけど、費用が心配。そんな企業向けに、沖縄県が用意しているのが【小規模事業者等デジタル化支援事業】。

✓ 相談・診断が無料
✓ 専門家による実装サポート付き
✓ 対象は沖縄県内の全業種

「どんなことができるのか」を知りたいだけでも、相談できます。

プロフィールのLINEから「デジタル化相談」とメッセージをもらえば、沖縄県産業振興公社の担当者から連絡があります。

詳細は公式ページで。

【ハッシュタグ】
#沖縄県 #デジタル化支援 #中小企業 #無料相談 #企業のミカタ
```

### テンプレート3：「季節キャンペーン」カルーセル
**用途**: 事業転換・大型補助金など、長期準備が必要な制度  
**対象制度**: 事業再構築補助金GX・DX型ほか（約3〜5制度/年）  
**投稿サイクル**: 月1件

**構成** (6ページカルーセル / 1080×1350px)
- P1: 「事業転換を検討していますか？」の問いかけ
- P2-P4: 業種別転換事例（製造→IoT、小売→EC、飲食→宅配等）
- P5: 準備チェックリスト（6ヶ月前 → 3ヶ月前 → 1ヶ月前 → 申請直前）
- P6: 「GX・DX補助金の詳細」への導線

**ビジュアルガイド**
- 色: ネイビー#00335C（軸） + オレンジ#F88800（ハイライト） + 淡いグレー背景
- チェックリスト: 空欄チェックボックス ☐（9pt）から埋まる ☑（9pt）へ
- フォント: Meiryo 32pt（タイトル）/ 28pt（本文）
- 矢印: 太い線（オレンジ）で転換フロー を表現

**キャプション**
```
【1行フック】
「事業転換は『大きなリスク』と思ってませんか？国が最大1.5億円サポートします。」

【本文】
経営環境が大きく変わる時代。
「今のままじゃ5年後が不安」と感じている経営者へ。

国の【事業再構築補助金 GX・DX型】は、
✓ 事業の根本的な転換を支援
✓ 最大1.5億円の補助
✓ 準備期間は約6ヶ月が目安

このカルーセルでは、
▶ 実際の転換事例（業種別）
▶ 採択企業の声
▶ 準備スケジュール（逆算チェックリスト）

を紹介します。

「うちはどの転換パターン?」と迷ったら、プロフィールのLINEで無料相談できます。

国が応援する事業転換。この機会を逃さないでください。

【ハッシュタグ】
#事業再構築補助金 #GX #DX #沖縄企業 #事業転換支援
```

## 2. 制度データとテンプレートのマッピング

### 制度選定ルール

| テンプレート | 適用条件 | 優先度 | 件数 |
|---|---|---|---|
| テンプレート1 | 金額 ≥ 100万円 AND 締切 ≥ 30日 | 最高 | 約40件 |
| テンプレート2 | 沖縄県限定 OR 無料支援 | 高 | 約5-10件 |
| テンプレート3 | 事業転換 OR 大型補助（≥500万円）AND 年度内単発 | 中 | 約3-5件/年 |

### データ構造（subsidies.json への追加フィールド）

```json
{
  "id": "a0WJ200000CDcQOMA1",
  "name": "小規模事業者持続化補助金＜共同・協業型＞ 第３回公募",
  "ig_template": "template1",        // 推奨テンプレート
  "ig_priority": 1,                  // 投稿優先度（1=最優先）
  "ig_example_industry": "飲食業",   // テンプレート例示に使う業種
  "ig_before_amount": 3000000,       // Before額（例示用）
  "ig_after_amount": 1000000,        // After額（例示用）
  "ig_exclude": false                // SNS非掲載フラグ
}
```

## 3. 実装フェーズ

### フェーズ1: Canvaテンプレート構築（Week 1-2）

**タスク**:
1. Canvaでテンプレート1の4ページを手作成
   - P1: 数字テンプレート（制度名・金額・業種を可変可能な配置に）
   - P2-P3: Before/After テンプレート
   - P4: 早見表テンプレート

2. Canvaでテンプレート2の単一ページを手作成
   - フリーダイヤル・QRコード枠を用意（後から差し替え可能）

3. Canvaでテンプレート3の6ページを手作成
   - 業種別転換事例の枠設計
   - チェックリスト段階表の用意

**成果物**: Canva テンプレート3種（合計11ページ）

**担当**: デザイン担当（ヒロメさん or 外部デザイナー）

---

### フェーズ2: 初投稿テスト（Week 1-2 終盤〜Week 3）

**テスト投稿**:
- テンプレート1: デジタル化・AI導入補助金2026（制度優先度 Top 1）
- テンプレート2: 小規模事業者等デジタル化支援事業（沖縄県）
- テンプレート3: 事業再構築補助金GX・DX型

**評価指標**:
- 保存数 / シェア数 / コメント数
- CTR（LINE導線クリック率）
- フォロワー増減

**月水金の承認ゲート**: humanizer + hojo-accuracy-check を通す

---

### フェーズ3: スクリプト化開発（Week 3-4）

**新規スクリプト作成**: `scripts/generate_ig_posts_mikata.py`

**ロジック**:
1. subsidies.json から `ig_priority` 降順で制度を取得
2. 各制度の `ig_template` に従い、キャプション・ハッシュタグを自動生成
3. JSON形式で `/outbox/ig_posts_mikata_draft.json` に出力
4. Canva API or ファイル形式で画像テンプレート指示を生成

**実装依存スキル**:
- `generate_ig_neta.py`（もらいわすれ堂版）を参考
- `check_ig_neta.py`（正確性検査）と同期
- `audit_ig_history.py`（投稿履歴監査）との連携

**入出力**:
```
入力: subsidies.json（155件）
       ↓
       [ig_template & ig_priority でフィルタ]
       ↓
出力: ig_posts_mikata_draft.json（週5件）
      キャプション + ハッシュタグ + テンプレート指示
```

---

### フェーズ4: 完全自動化・本運用（Week 5+）

**ワークフロー**: `.github/workflows/ig-posts-mikata.yml`

```yaml
name: Generate IG Posts (Mikata)
on:
  schedule:
    - cron: '0 18 * * 0'  # 毎週日曜 18:00 JST（投稿案生成）
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Generate drafts
        run: python scripts/generate_ig_posts_mikata.py
      - name: Verify accuracy
        run: python scripts/check_ig_posts_mikata.py --online
      - name: Commit & notify
        run: |
          git add data/ig_posts_mikata_draft.json
          git commit -m "auto: IG投稿案生成 2026-W$(date +%V)"
          git push
          # LINE通知（承認者へ）
```

**月水金の承認ゲート**: 引き続き humanizer / hojo-accuracy-check を通す（自動化後も）

## 4. 品質管理（Verify検査）

### フェーズ1: Verify検査導入（並行実施）

**優先順**: 
1. テンプレート1対象の40制度 → 即時（Week 1中に完了）
2. テンプレート2対象の5-10制度 → 週内（Week 1-2）
3. テンプレート3対象の3-5制度 → 月末（Week 4中に完了）

**検査スクリプト**: `scripts/verify_mikata_seido.py` (新規作成)

**検査内容**:
- 金額の確認（公式ページと一致）
- 締切の確認（延長・変更を検知）
- 対象条件の確認
- マルチAI連携（Claude + Gemini のダブルチェック）

**検査結果**: `data/subsidies.json` に `verified: true / false` を付記

## 6. リスク & 対策

| リスク | 対策 |
