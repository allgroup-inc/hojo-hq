# 家計のポっ v2.0 UIリニューアル設計書(2026-08-14 小柳さん指示)

小柳さん提示の設計方針に**厳密準拠**してWeb App画面を全面改装する。機能(登録・通知・
遅れそう・代打候補・分析)は一切変えず、見た目と操作効率だけを作り替える。

## 採用する設計方針(小柳さん原文の要旨)

- **余白(Notion式)**: コンテンツ最大幅900px中央固定 / 縦間隔は8・16・32・64pxの4種のみ /
  カード・枠囲み禁止、余白と薄グレー1px線だけで区切る / 見出し左のアイコン禁止
- **入力欄(Stripe式)**: 高さ44px以上 / ラベルは上置き / 角丸6px・薄グレー1px枠 /
  フォーカス時のみブランド色枠+うっすら光 / エラーは欄の下に赤1文 / 必須は「必須」タグ(※禁止) /
  グループ間32px / 送信ボタンは左下・内容幅
- **色**: 白#FFFFFF基調 / 文字#1A1A1A / 補足#6B6B6B / **ブランド色 #F6C83E(公式ロゴの黄)** —
  使用箇所は送信ボタン・フォーカス枠・現在地メニューの3箇所のみ / 例外は警告の赤のみ
- **業務条件**: 1日100件入力前提でクリック数最小 / Tabキーだけで入力完走 /
  危険ボタン(キャンセル等)は離して配置 / 一覧は行を詰めて多表示 / 読み込み中は部分薄表示
- **禁止**: グラデーション背景 / 影付きカード3列 / 見出し絵文字 / 全中央揃え / 中身のないコピー

## v1.5からの主な変更

- ヘッダー: 黄グラデ→**白+下1px線**。ロゴ+「家計のポっ」黒文字。ナビ(本日/週/分析)は
  テキストタブ化し、**現在地のみブランド色の下線+太字**
- 一覧: カード→**罫線区切りの高密度行**(時刻/顧客/場所/営業/温度/状態を1行に)
- ステータス: 色ピル→**テキスト表示**。キャンセルのみ赤(警告例外)、申込みは太字
- フォーム: Stripe式に全面改修。顧客名エラーはトースト→**欄下の赤1文**に変更。
  ダブルブッキング警告も赤1文で欄下に表示(2度押し確定は維持)
- 保存ボタン: 「保存して通知」= ブランド色・左下・内容幅
- 読み込み: 画面差し替え→**該当部分の薄表示**(opacity 0.45)
- ダークモード: 白基調に一本化のため廃止(方針の「ベース白」準拠)
- 分析タブ: 見出しの絵文字を撤去。バーはブランド黄1色+グレー地
- 新規アポ: 固定FAB(黄)→ツールバーの通常ボタン(色ルール準拠のため中立色)

## ウタガイ記録(三名体制・簡易)

- ウタガイ: ①色ピル廃止で外出先スマホの一目判別が弱くなる ②ダークモード廃止は夜間運転前の
  車内で眩しい ③キャンセル操作が減色で目立たなくなる
- 対応: ①状態列は太字/赤/グレーの3段で判別を維持し、行自体の濃淡(終了系は薄く)も残す
  ②③は運用1〜2週の現場の声で再評価(見直し期限 2026-11-14)。機能は無変更なので戻すのも容易
- ベッカイ: PC(アポ入れ係)とスマホ(営業)で画面を分ける案 → 二重メンテになるため見送り。
  1画面のレスポンシブで両立(900px制約はスマホでは全幅相当)
