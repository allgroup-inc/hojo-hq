# もらいわすれ堂：「診断→受給」全体フロー最適化 設計書

**作成日**: 2026-10-21  
**目的**: 沖縄県民の実際の制度受給を最大化するための、サイト・Instagram・LINE の統合戦略  
**最終ゴール**: 「多くの沖縄県民の可処分所得向上」

---

## 1. 戦略の概要

### 1.1 現状の課題

| 段階 | 課題 | 影響 |
|---|---|---|
| **流入** | 診断ツール自体の認知が低い | 県民の大多数がツールの存在を知らない |
| **診断** | 診断実施後の行動が不明確 | 結果を見ただけで終わる |
| **準備** | 「何をするか」がわからない | 準備シートまで到達しない |
| **申請** | 書き方・手続きで詰まる | LINE登録者の多くが実申請に進まない |
| **受給** | サポートがない | 書類不備・期限切れ等で失敗 |

### 1.2 戦略の三本柱

```
アプローチ C：事例発信で認知を広げる（最優先）
       ↓
アプローチ A：来た人を準備シートで確実に支援
       ↓
アプローチ B：LINE登録者を実申請まで導く
```

**実装順序**: C（即座）→ A（2-3週間） → B（並行）

## 2. アプローチ C：事例発信戦略

### 2.1 事例発信の役割

- **最大の課題**: 診断ツール自体の認知が低い
- **解決手段**: 「実際に使った人の物語」を Instagram で素人らしく発信
- **期待効果**: 
  - SNS での有機的な拡散（シェア・保存・検索）
  - 「自分も使えるかも」という県民の行動動機づけ
  - 診断ツール流入の増加

### 2.2 事例収集フロー

#### Phase 1: 対象者の特定（今週中）

**対象条件**:
- 実際にもらいわすれ堂/沖縄企業のミカタで制度情報を知った
- 実際に申請し、**受給成功した**（進行中は含まない）
- 沖縄県民（個人または小規模事業者）
- 話を聞いてくれる意思がある

**探索チャネル**:
1. 既存顧客・提携先からの推薦（士業・商工会・金融機関）
2. LINE・メール問い合わせの過去ログから（許可を得た上で）
3. 小柳さんの知人・ネットワーク（ただし個人つながりではなく、「制度受給の話」として）

**目標**: 初期 5-10 件を 10 月中に確保

#### Phase 2: ヒアリング（10-15 分程度）

**ヒアリング項目**:

1. **背景（2分）**
   - お名前（公開可能か、匿名か）
   - 家族構成（子どもの人数・年齢、親の扶養など）
   - 「当時どんなお金の悩みがあったか」（教育費、保育料、生活費、医療費など）

2. **発見（3分）**
   - 「この制度をどうやって知ったか」
   - 「もらいわすれ堂に来る前に、他で探していたか」

3. **申請プロセス（5分）**
   - 「準備で困ったことは？」
   - 「書類作成で分からなかった点は？」
   - 「相談窓口の対応はどうだったか」
   - 「準備シートは役に立ったか、それとも足りなかったか」

4. **成果（2分）**
   - 「実際に受給できて何が変わったか」（心理的な安心感、子どもへの投資ができた、日々の生活が楽になった、など）
   - 「金額的にはどのくらいの効果があったか」（匿名なら「月1万円程度」「年20万円程度」など）
   - 「同じような状況の沖縄県民へ一言お願いします」

**記録形式**:
- 音声メモ + テキスト化（Notion ページ一覧に蓄積）
- 顔写真・氏名の許可を確認
- 掲載前に「こういう記事で紹介してもいいか」を改めて確認

#### Phase 3: 掲載準備（1-2 日）

**掲載フォーマット確定**:
- テキスト版（Blog・Notion に記録）
- Instagram 投稿版（画像 + キャプション）
- LINE 配信版（月1回の「成功事例」として週末配信）

**チェックリスト**:
- [ ] 個人情報の扱い（許可確認、匿名化）
- [ ] 数値の正確性（「約 100 万円」など幅を持たせる）
- [ ] 事業所名の記載可否
- [ ] SNS 掲載 OK かどうか

## 3. アプローチ A：準備シート戦略

### 3.1 準備シートの役割

- **課題**: 診断結果を見たが「次は何をするか」がわからない県民が多い
- **解決手段**: 制度ごとの「申請準備シート」を診断結果画面からダウンロード
- **期待効果**: 診断利用者の「準備に進む率」を可視化・改善

### 3.2 準備シートの構成

**対象制度**: 掲載中の全制度（現在 260+ 件）

**優先順位**:
1. **High**: 毎年申請が多い制度（児童手当、奨学給付金など）
2. **Medium**: 季節的に申請が集中する制度（雇用関連など）
3. **Low**: 不定期な制度（新規事業立ち上げなど）

**シート項目**（Excel/PDF 1-2 ページ）:

```
【◯◯補助金 申請準備シート】

📋 制度の基本情報
├─ 制度名
├─ 実施自治体
├─ 申請締切
├─ 給付額（自分の場合の概算）
└─ 対象条件チェックリスト

📝 必要書類チェックリスト
├─ [ ] 申請書類
├─ [ ] 決算書・給与台帳など
├─ [ ] 誓約書
├─ [ ] 見積書（設備購入の場合）
└─ その他

📞 次のアクション
├─ 相談窓口：◯◯市 △△課
│  └─ 電話：XX-XXXX-XXXX
│     営業時間：平日 9:00-17:00
├─ 提携士業への相談（有料）：[リンク]
└─ よくある質問：[リンク]

⏰ 申請のステップ
├─ Week 1: 必要書類の集め方を相談窓口に電話で確認
├─ Week 2-3: 書類作成・提出準備
├─ Week 4: 相談窓口に提出 or 郵送
└─ その後: 審査 → 結果通知

💡 ワンポイントアドバイス
└─ 「〇〇で多くの人が詰まります」という注釈
```

### 3.3 シート生成・更新の仕組み

**自動生成**:
- `seido.json` の制度データから、Python スクリプトで Excel/PDF テンプレートを自動生成
- 月 1 回、自治体サイトの更新に合わせて再生成

**検証**:
- 作成後、士業パートナーが「実務的に正しいか」を確認
- 誤記・古い情報があれば即座に修正

## 4. アプローチ B：LINE 配信戦略

### 4.2 配信の制御

**ブロック率低下のため**:
- 最初は「2週 1 回」で様子を見る
- ユーザーが「配信頻度を選択」できる機能を実装
- 「相談したい」「情報を止めたい」ボタンを全メッセージに配置

**AB テスト**:
- 配信内容・時間帯・文言を記録
- 「開封率」「クリック率」「その後の相談申し込み数」を測定
- 月 1 回改善

## 5. 全体の成功指標

### 5.1 測定する指標

| 段階 | 指標 | 目標（3 ヶ月） | 測定方法 |
|---|---|---|---|
| **流入** | 月間診断実施者数 | 500 → 1,000 | GA4 |
| **診断→準備** | 準備シート DL 率 | 30% → 50% | GA4 イベント |
| **準備→申請** | 相談窓口 click 率 | 20% → 40% | GA4 イベント |
| **LINE 登録** | LINE 登録率（診断実施者比） | 30% → 40% | LINE 分析 |
| **LINE→相談** | LINE から相談問い合わせ率 | 10% → 20% | LINE + Form 連携 |
| **受給成功** | 診断利用者の受給成功数 | 月 5-10 件 | ヒアリング・自治体確認 |
| **Instagram** | フォロワー数 | 200 → 500+ | Instagram 分析 |
| **Instagram** | 投稿のリーチ（診断リンク経由） | - | UTM パラメータで追跡 |

### 5.2 検証スケジュール

- **Week 1**: 事例 5-10 件のヒアリング開始 → Instagram 投稿開始
- **Week 2-3**: 準備シート（Top 10 制度）を準備
- **Week 4**: 診断ページ改修（準備シート DL リンク追加）
- **Month 2**: LINE 配信シナリオを構築・配信開始
- **Month 3**: 指標を確認・改善案を洗い出し

## 6. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 事例収集が進まない | C のアプローチが実行できない | 提携先の士業・商工会に協力依頼 |
| Instagram 投稿が続かない | 認知が広がらない | 月に「4-8 件」と決めて習慣化 |
| 準備シートの品質が低い | 「役に立たない」と評判が下がる | 士業に検証させる → 高品質を維持 |
| LINE 配信でブロック増加 | 登録者が流出 | 配信頻度を抑える、選択肢を用意 |
| 受給成功までの追跡が難しい | 実際の効果が測定できない | 定期ヒアリング or アンケートで確認 |

## 9. 結論

**このアプローチの強み:**

1. **即座に始められる** → 事例収集は今週から可能
2. **県民に本当に届く** → 「困った人の声」は最強のマーケティング
3. **小柳さんの負担が小さい** → 月 4-8 回の投稿で OK
4. **スケーラブル** → 事例が増えるほど、認知と信頼が高まる
5. **測定可能** → 各段階の効果が数字で見える

**「多くの沖縄県民の為になる」を実現するために、このアプローチで進めます。**
