|--------|------------|-----------|-----------|-----|----------------|

**Page 5: なぜ小規模案件に対応しないのか？（ビジネスモデル分析）**

ボックス形式で3つの理由を解析：

1. **採算性の壁**
   - 仲介手数料が固定費で採算割れ（例：1億円案件 × 2% = 200万円で営業人件費まかなえず）
   - 大型案件に特化することで単価を上げる戦略

2. **営業効率の最適化**
   - 既存ネットワーク（金融機関、上場企業）からの紹介案件に特化
   - 新規開拓（小規模層）には営業コストがかかりすぎる

3. **リスク回避**
   - 小規模経営者は経営基盤が不安定 → 交渉が長引く傾向
   - 既存業者は確実性の高い大型案件に集中

**→ GLOWの差別化ポイント**：
- 小規模案件専門 + 複数収益柱（M&A + 保険 + 経営相談）で採算化
- 訪問営業で認知 + 段階的営業で成約率向上

### Page 6-7: リスク要因・対策（沖縄特有）

**Page 6: リスク因子マトリックス**

リスク 横軸（影響度 低→高） × 縦軸（発生確度 低→高）で4象限表示：

|--------|-----|--------|------|------|
| **親族承継志向** | 沖縄の経営者は「事業は家族へ」という文化的信念が強い | 高 | 高 | 親族が望まない場合のシナリオ提示 |
| **M&Aリテラシー不足** | 経営者がM&A自体の仕組みを理解していない | 高 | 高 | 段階的教育 + 事例紹介 |
| **観光経済依存** | インバウンド減少時の景気変動リスク | 中 | 中 | 業界別シナリオプラン |
| **農業・建設の高齢化加速** | 経営者の急速な高齢化 → 廃業タイミングの予測難 | 高 | 高 | 早期接触アプローチ（今後1-2年） |
| **金融機関の評価基準** | 小規模企業の融資格付けが低い → 買い手企業が見つかりにくい | 中 | 中 | 複数出口戦略（M&Aだけでなく個人M&A） |

**Page 7: リスク別対策（具体実装）**

3-4つの重点リスクについて、対策を箱詰めで表示：

**対策1: 親族承継志向への対抗戦略**
- アプローチ：「親族が引き継ぎたくない理由」のヒアリング（患者獲得、スタッフ確保）
- 施策：それらの課題を「外部との統合」で解決する提案

**対策2: M&Aリテラシー向上**
- 段階的アプローチ：補助金情報 → 経営相談 → M&Aの仕組み理解 → 提案
- 事例：沖縄での成功事例を3-5件紹介

**対策3: 農業・建設の早期接触**
- タイムリミット：今後1-2年が最後の機会
- 月間訪問数：20-30社/月で市場開拓

### Page 8-9: 経営者心理メカニズム

**Page 8: なぜ後継者不安でもM&Aに踏み切らないのか？**

心理学的解析を3層で表示：

**Layer 1: 矛盾の説明**
- 後継者不安率 65-70% ← でも成約率 2-3%
- 理由：「不安だが、今は大丈夫」という現状維持バイアス
- 心理用語：現状バイアス、喪失回避性、家族への執着

**Layer 2: 沖縄経営者に共通するパターン**

3つのパターンを類型化：

1. **「親族重視型」（40-50%）**
   - 特徴：「事業は子ども・親族へ」という信念が強い
   - 心理：家族企業の誇り、一族繁栄への執着
   - 行動：M&A検討時点で「親族に相談する」→ 反対される → 立ち消え

2. **「保守型」（30-40%）**
   - 特徴：変化回避、既存方法の継続を好む
   - 心理：「今までうまくいった」に依存、リスク認識が低い
   - 行動：「M&Aの話は聞くが、まだ決断時期ではない」と先延ばし

3. **「自己実現型」（10-20%）**
   - 特徴：事業への執着が強い、人生＝経営者
   - 心理：事業への同一化が強い、引き継ぎ＝人生の喪失感
   - 行動：「まだやれる」という過信、廃業・M&Aを避ける

**Page 9: 経営者が「M&Aしたい」と判断するトリガー**

ボックス形式で、実際の決断トリガーを具体的に言語化：

**医療・介護**
- トリガー：患者が減少した / 医師・看護師が逃げた / 負債が増えた
- 心理：「経営環境の急変 = 現状維持不可」という認識転換
- タイミング：危機が現在進行形 → 決断が早い

**建設業**
- トリガー：大型工事が急減した / 下請けから外された / 若い職人が集まらない
- 心理：事業基盤の揺らぎ → 統合で大型案件対応
- タイミング：景気サイクルの悪化時期

**農業・畜産**
- トリガー：体力の限界 / 跡継ぎが明確に拒否 / 借金が増えた
- 心理：加齢とともに「続けられない」という現実認識
- タイミング：経営者が65歳を超えた時期

**→ GLOWの戦略的含意**：
- トリガー発動前の「準備段階」（信頼構築3-6ヶ月）で接触
- トリガー発動時に「即座に対応」できる提案を用意

**GLOW独自の採算モデル（小規模案件への対応可能性）**

複数収益柱を図解：

```
1件のM&A成約（1-5億円）
  ↓
【売上A】M&A仲介手数料（¥2-7M）
【売上B】事前診断・税務相談フィー（¥1-2M）
【売上C】法人保険商品（¥0.5-1M/年 × 3年）
【売上D】経営相談フィー継続（¥0.5M/年 × 継続）

合計：¥6-15M（1件あたり）

→ 既存業者（仲介手数料のみ ¥2-7M）を上回る採算性
→ 小規模案件でも複数柱で利益確保
```

**Page 11: 9ヶ月25-59件の実現可能性**

**月別達成プラン**：

| 期間 | 営業活動 | 月間新規接触 | 月間成約 | 累計成約 | 達成状況 |
|------|---------|-----------|---------|---------|---------|

**実現を支える3要素**：
1. 段階的営業フロー：DM → 電話 → 訪問 → 関係構築 → M&A提案（成約率 40-60%）
2. 3チャネル統合：補助金情報（サイト）+ 訪問営業 + 紹介ルート
3. データドリブン：案件スコアリング + 業界別アプローチの最適化
