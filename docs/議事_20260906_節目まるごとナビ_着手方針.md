# 議事: 節目まるごとナビ(名称未定)の着手方針

- 日付: 2026-09-06
- 関連文書: docs/企画_節目まるごとナビ設計_20260906.md
- **訂正(2026-09-06)**: 当初この議事は「サービス名みらいひらけ堂=決定」と記録したが、これは**エージェント側の解釈誤り**。小柳さんの「みらいひらけ堂」は子ども向け無料学習支援サービス(docs/企画_無料学習支援検索サービス設計_20260905.md)の名称であり、同サービスが「もらいわすれ堂の次の無料サービス」に決定した。本件(節目ナビ)は**名称未定・アイデア保留**に戻す
- 本議事の対象: 将来着手する場合の方針(何から作るか・どこに線を引くか)。ウタガイ・ベッカイの論点は着手時に有効

## 論点: 「節目まるごとナビ」をもらいわすれ堂の追加サービスとしてMVP着手してよいか

### スイシン(推進)
- 節目(出産・引越し等)は全県民に起きる普遍の入口で、福祉色がなく、県民10%(14万人)構想と整合する。
- 「相対締切(出来事からn日以内)を本人の日付でリスト化する」はLINE登録の必然性を生み、4目標(❶流入→❹LINE→❷受給報告)に直結する。
- 制度DB・ページ生成・検証/守り部体制・LINEの既存資産を流用でき、節目2つ×5市町村なら費用ほぼ0円・2か月で公開できる。

### ウタガイ(懐疑)  ← 空欄不可
- **市町村差の正確性リスク**: 手続きの期限・窓口・持ち物は市町村ごとに違い、間違えれば「役所で恥をかかせるサイト」になり信頼を失う(絶対ルール1に直撃)。5市町村ですら原文照合の工数は軽くない。収集ペースを楽観視するな。
- **おくやみを安易に載せるな**: 需要最大ゆえ着手を急ぎたくなるが、相続関連は行政書士・司法書士・税理士の業際に近い。守り部の線引き審査前に1行でも公開してはならない。
- **締切3層ルールと矛盾する**: 相対締切には「残り30日以上」が存在しないケースが多く、既存ルールをそのまま適用も無視もできない。配信ルールの追補(不可逆類型)を先に決裁しないと、現場が独自判断で配信を始める事故が起きる。
- **ブランド分散の懸念**: フクギイロはもらいわすれ堂のKGI(LINE1万人・受給報告1,000件)自体がまだ道半ば。ブランドが増えることで広報・IG運用の弾が割れる。本サービスは独自アカウントを作らず、もらいわすれ堂のIG/LINEに相乗りすべき。
- **計測の混線**: 新導線の計測イベントを分けないとLINE登録の出所が判別できなくなる(過去に line_redirect 水増しの再発防止メモあり)。公開前に shipping_gate の TARGET_GROUPS と計測イベント名の追加を確認すること。

### ベッカイ(別解)
- **案A: 独立サイトにせず、もらいわすれ堂サイト内の「節目から探す」タブにする**。ブランドは1つのまま機能だけ得られる。新しい名前を立てる場合も「もらいわすれ堂の中のコーナー」という暖簾分け表記が現実解。
- **案B: ページを作る前に、LINE既存登録者へ「最近あった節目は?」アンケート1問を送る**。どの節目に需要が集中するかを実データで確かめてからMVPの2節目を選ぶ(出産・引越しという選定自体が仮説にすぎない)。
- **案C: 市町村を絞らず「県+国の共通制度だけ」で全県版を先に出す**。市町村差の照合コストをゼロにして最速公開し、市町村別は反応を見て足す。

### 結論(部門長の裁定)
- 採否: **保留(アイデア保管)**
- 理由: もらいわすれ堂の「次の無料サービス」枠は、小柳さん決裁により子ども向け無料学習支援サービス「みらいひらけ堂」に決定した。本件は優先度を下げてアイデアとして保管する。将来着手する場合、ウタガイの指摘(市町村差の正確性/おくやみの業際/締切3層ルールとの矛盾/ブランド分散/計測混線)は全て実行条件として有効。ベッカイ案B(LINE登録者へ節目アンケート1問)は低コストのため、みらいひらけ堂の運営が軌道に乗った後の再検討材料として推奨する。
