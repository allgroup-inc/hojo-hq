# 集客戦略リサーチ(2026-08-03・一次情報ベース) — 体制総点検の項目8・9

調査担当: 戦略リサーチャー(外部視点エージェント) / 凡例: 【事実】=出典確認済み 【推測】=構造からの推定

## 1. 補助金情報サービスの集客手法(全国系)

- **補助金ポータル**(hojyokin-portal.jp)【事実】: 制度DB+記事+無料会員(メルマガ)+無料診断+士業マッチング。「月間100万人利用」(自社表記)に対し**LINE友だちは6,583人**(page.line.me/456nklet)→流入はSEO・会員化はメール中心でLINEは弱い【推測】。→ **LINE起点のミカタはここが差別化余地**
- **みんなの助成金**【事実】: 士業が選定する編集の権威付け+「名前とメールだけ・1分」の登録摩擦最小化。
- **J-Net21**(中小機構)【事実】: 毎週火曜の新着補助金メルマガ=**定時配信フォーマット**が会員価値の中核。
- **ミラサポplus**【事実】: 自前集客せず**全国の自治体・商工会議所・金融機関が紹介ページを作って送客**する逆リンク網。

## 2. 地域×オフライン連携の実例

- **ライトアップ「Jマッチ」**【事実・最重要ベンチマーク】: 補助金診断システムを金融機関・自治体へ提供し「取引先向け無料サービス」として配布させる。**27自治体・43金融機関・900社超が導入**、47都道府県で年間約600回の経営者勉強会(出典: jmatch.jp / PR TIMES)。→ **1社ずつ集めず機関ごと握るモデル**
- **商工会議所LINE**(札幌・名古屋・武雄)【事実】: 「補助金情報」が主力配信ネタ。名古屋は会員外にも開放。→ ミカタの記事は商工会にとって「欲しい配信ネタ」
- **信用金庫の事例集**【事実】: 補助金支援を取引深耕ツールとして無償提供する型が定着。

## 3. LINEをB2Bで伸ばした実例

## 5. 海外グラント情報サービス

- **GrantWatch**(米)【事実】: 州別サブドメインで地域SEO制圧+「直近7日の新着最大25件」の定型ニュースレター(無料は1地域まで)。
- **Instrumentl**(米)【事実】: 5,500+のNPO利用。無料登録者全員に**オンボーディング担当との戦略相談**を付与+AEO(AI検索最適化)を明記+比較まとめ記事型SEO。
- → 「地域限定の新着定期便」を無料フックに/「登録者全員に30分相談」で送客入口を兼ねる。

## 明日から真似できるトップ5(優先順)

1. **金融機関・商工会への「配信ネタ無償卸」営業(Jマッチ型)** — 琉銀・沖銀・海銀・コザ信金・各商工会議所へ「会員向け週次補助金まとめ+紹介ページ雛形」を渡す。紹介200社は機関ごと獲得
2. **市町村×カテゴリのpSEOページ+月次更新表記+監修者表示** — 検索200社チャネルの本丸(次スプリントで技術部が設計)
3. **「毎週金曜・沖縄の新着補助金定期便」をLINEの中核商品に** — J-Net21/GrantWatch型の定時定型
