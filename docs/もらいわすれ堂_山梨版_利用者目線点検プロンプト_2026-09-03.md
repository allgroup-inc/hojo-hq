# あなたへの依頼: 「もらいわすれ堂 山梨版」を、使う人になりきって点検してください

## 結論(何をしてほしいか)

あなたの仕事は**直すことではなく、気付くこと**です。
「もらいわすれ堂 山梨版」(hojo-hq リポジトリの `site/fukugiiro/yamanashi/`)を、
作った人としてではなく**初めて訪れた山梨県民として実際に操作**し、
「使いにくい」「不安になる」「困る」「嘘になっている」箇所をぜんぶ拾って、
重要度順の一覧にして報告してください。

- 勝手に直さない。まず報告(軽微な誤字などは「すぐ直せる」と付記してよい)
- 褒めなくてよい。困りごとだけを具体的に
- 「たぶん大丈夫」は禁止。**実際に画面を開いて・押して・最後まで進んで**確かめたことだけを書く

## 点検のやり方(必ず実機で)

リポジトリ直下で簡易サーバーを立て、Chromium(Playwright導入済み)で実際に操作する:

```
ln -sfn ../data site/data   # 本番と同じデータ配置を再現(終わったら rm site/data)
cd site && python3 -m http.server 8800 &
# http://127.0.0.1:8800/fukugiiro/yamanashi/ を開く
```

- **スマホ表示(幅390px)を主**に、PC表示(幅1280px)も一通り
- スクリーンショットを撮って、目でも確認する(文字の重なり・はみ出し・小さすぎは
  コードを読むだけでは見つからない)
- JavaScriptのエラーが出ていないかも記録する

## なりきる3人(それぞれの目で1周ずつ)

1. **甲府市の30代・子育て中の方(スマホ)**: インスタで知って初めて開いた。
   時間がない。3分診断→結果→児童手当の準備シート→「窓口に行こう」まで迷わず行けるか。
   途中で「結局なにをすればいいの?」と手が止まる場所はないか
2. **60代の方(スマホ・小さい字が苦手)**: 文字は読めるか。ボタンは押し間違えないか。
   カタカナ語・役所言葉で意味がわからない場所はないか。「診断」と言われて怖くないか
3. **山中湖村の方(電波が弱い・プリンターなし)**: データ読込に失敗したらどうなるか
   (開発者ツールでオフラインにして確認)。印刷できない人への案内は成立しているか。
   人口の少ない村のページでも内容が破綻していないか

## 通しで歩く5つの道(全部最後まで)

1. トップ → 3分診断(5問全部)→ 結果 → 準備シートを開く → チェックを付ける → 印刷プレビュー
2. トップ → 市町村ページ(甲府市と丹波山村の2つ)→ 制度 → 公式ページのリンクを実際に開く(10本抜き打ちでリンク切れ・転送切れを確認)
3. トップ → LINE登録ボタン(全ページの全ボタン)→ 転送ページ → 実際にLINEの友だち追加画面まで着くか
4. 診断結果 → 「受け取った」マーク → もらえた報告 → LINEに報告文が入った状態で開くか/メールでも送れるか
5. 間違い探しの目で全ページ: 「準備中」と書いてあるものは本当に準備中のままか、逆に、もう出来ているのに「準備中」と書き残していないか。日付・件数・県名・市町村名の間違い。「沖縄」が山梨版に紛れていないか

## 約束事との照合(このサイトの命)

- 「必ずもらえる」「絶対」などの断定語が1つもないか
- 確認できていない情報に「要確認」が付いているか。逆に、要確認だらけで不安をあおる見え方になっていないか
- 締切の表現が「約1か月前から」で統一されているか(「7日前」は誤り)
- 診断が名前・住所・電話番号を聞いていないか。回答が送信されていないか(開発者ツールのネットワークタブで実際に確認)
- 登録の入口がLINEだけになっているか
- 本文14px以上・入力欄16px以上(iPhoneの勝手な拡大防止)。実測で確認

## 報告の形式(これで出す)

「困りごとリスト」を重要度順に3段階で:

| 段階 | 意味 |
|---|---|
| 🔴 公開前に直す | 利用者が実害を受ける・約束事に反する・嘘になっている |
| 🟡 早めに直す | 迷う・不安になる・一部の人が使えない |
| ⚪ 余裕があれば | 細かい改善。直すと少し良くなる |

1件ごとに: **①どのページのどこで ②どの利用者が ③何に困るか(実際に起きたこと) ④直し方の案(1行)**。
最後に「今回テストした道と、テストできなかったこと」を正直に書く(できなかったことを
できたことのように書かない)。

報告は `docs/点検_YYYYMMDD_山梨版利用者目線.md` に保存してコミットし、
チャットにも要約を出すこと。**修正は、報告を見た小柳さんの指示があってから。**
