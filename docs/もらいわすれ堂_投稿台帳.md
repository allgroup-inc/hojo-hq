## 検証ルール(2026-10-06 Haruka改善案)

### 投稿提案時のチェック項目
1. **Duplicate Check**: `used_ids`に既に登録されている制度か確認（重複防止）
2. **Source Verification**: 公式サイト最新版と照合し、データ・金額・条件を確認
3. **Caption Accuracy**: 先行版（July validation videos）と文言の一貫性・精度を比較
4. **URL Check**: 誤ったページ版（例：奨学給付金の県立高校版→私立高校版に修正）
5. **Citation**: 「あかりの島」等の主張に公式根拠が存在するか確認

- 文面精度：Haruka（Instagram運用・ユーザー体験）
- 法務・規約：守り部(mamori.md)

## STEP 2: 投稿台帳運用開始フロー図(2026-10-13)

```
【STEP 2 ワークフロー】

新規制度提案
    ↓
[1] Duplicate Check
    ├─ used_ids と照合
    ├─ 過去投稿済み制度か確認
    └─ ⚠️ 重複なし → [2]へ

[2] Source Verification
    ├─ 公式ページへアクセス確認（URL生存確認）
    ├─ 金額・条件・締切を公式と比較
    └─ ✓ or ⚠️ 判定 → [3]へ

[3] Caption Accuracy
    ├─ 先行版(July validated)との言語比較
    ├─ 「対象になる可能性があります」ルール確認
    └─ 一貫性あり → [4]へ

[4] Haruka最終チェック
    ├─ Instagram UX視点での投稿タイミング
    ├─ デザイン稿の納期確認
    ├─ 祝日・季節イベント考慮
    └─ ✓ 承認 → [5]へ

[5] 小柳さん決裁
    ├─ 投稿予定日・時刻確認
    ├─ 全チェック項目 ✓確認
    └─ [6]へ

[6] Instagram投稿実行(Haruka)
    ├─ 投稿実行
    ├─ 台帳に「投稿日」「投稿URL」記録
    └─ 完了
```
