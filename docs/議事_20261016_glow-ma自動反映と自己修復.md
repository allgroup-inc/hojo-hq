# 議事 2026-10-16 glow-maの自動反映と自己点検・修復

- 起案: ❶システム関係全般(本セッション)
- 決裁: 小柳さん(2026-10-16「この部分を承認するので自動で対応して解決させておくように」)
- 区分: ②不可逆な変更(本番設定・外部送信)

## 背景
- BlueBean架電履歴の同期が、少なくとも10/3から台帳に1件も入っていない(「CTI通話履歴」タブが0件)。
  失敗通知はSlack専用で、`SLACK_WEBHOOK_URL` 未設定時は黙ってスキップされるため、誰も気づけなかった。
- 有力な原因: 接続時に設定した作業グループ(返信用封筒の作業グループ。議事_20260819)と、
  福田さんが実際に架電している作業グループ(GLOW法人リスト)が別。APIは作業グループ単位で返すため、
  エラーなしで0件が続く。
- ダッシュボードの修復スクリプトは、小柳さんのPCから `clasp push` しないと反映できず、止まっていた。

## 論点: 本番のApps Scriptへの反映と修復を、人の手を介さずに行うか

### スイシン(推進)
- main にマージされたら GitHub Actions が `clasp push` する。PCを開けない日でも修正が届く。
- 毎分動く音声ログ処理に、6時間に1回の自己点検を相乗りさせる。ダッシュボードの欠落・非表示、
  BlueBean同期と日次メンテナンスのトリガー欠落を自動で直すので、反映後に誰かがエディタで関数を押す必要がない。
- 各処理の結果を台帳の「稼働状況」タブに残す。エディタを開かずに「動いているか・何件取れたか」が分かる。
- 失敗通知はSlackが無ければメールへ代替し、同じ処理は1日1通に抑える。
- BlueBeanの作業グループIDをカンマ区切りで複数指定できるようにし、現場が使うグループをすべて取得する。

### ウタガイ(懐疑)
- **Googleのログイン情報(`.clasprc.json`)をGitHubに預けることになる。** 漏れれば台帳のスクリプトを書き換えられる。
  公開リポジトリのため、Secretsの取り扱いを誤ると致命的。
- **mainへのマージが即本番反映になる。** レビューの甘い変更がそのまま営業の台帳を壊しうる(2026-10-15に共通ライブラリの
  .jsを誤って削除したコミットがあり、PCから反映していれば全機能が止まっていた)。
- `appsscript.json` の権限(スコープ)がライブと違えば、反映直後にトリガーが再承認待ちで止まる。
- 自己修復がトリガーを勝手に作り直すと、意図して止めていたトリガーまで復活させてしまう。
- 作業グループを足しても、操作画面への手入力で発信した通話は顧客データに紐づかず、APIに出てこない可能性がある
  (議事_20260819 ウタガイで既出のBlueBean仕様上の制約)。設定を直しても0件のままかもしれない。

### ベッカイ(別解)
- 自動反映ではなく、PR上で「反映して」とコメントしたときだけ動く方式もある。ただし今回は「PCを開けない日でも直す」が目的。
- 0件が続く根本対策は、福田さんにBlueBeanの顧客リスト(作業グループに取り込んだ企業)から発信してもらう運用変更かもしれない。
  稼働状況タブで「作業グループごとの取得件数」を見てから判断する。

### 結論(裁定)
- 採否: 採用(ウタガイを次の形で反映)
  - Secretsはワークフロー内で一時ファイルに書き、反映後に削除する。ログに出さない。期限切れ・失効時はLINEで通知
  - 反映前に「同名の .gs と .js が並んでいないか」を検査し、並んでいれば止める(10/15の衝突の再発防止)
  - 共通ライブラリの消失はレビュー(PR)で止める。glow-ma/src の変更は必ずPRを通す
  - 自己修復が作り直すのは「BlueBean同期」「日次メンテナンス」の2本だけ。止めたいときは
    スクリプト プロパティから BlueBean の設定を外すか、本議事の見直しで対象から外す
  - 作業グループの変更後も0件なら、稼働状況タブの「グループごとの件数」を根拠に、福田さんへ発信方法の変更を相談する
- 見直し期限: 2027-04-16

## 人の作業(一度だけ)
1. PCで `npx @google/clasp@3.4.1 login` → GitHubのSecretsに `CLASPRC_JSON` と `GLOW_MA_SCRIPT_ID` を登録(手順: glow-ma/README.md「自動反映」)
2. Apps Scriptの「プロジェクトの設定 → スクリプト プロパティ」で `BLUEBEAN_CAMPAIGN_ID` に、福田さんが使う作業グループ(GLOW法人リスト)のIDをカンマで追加
