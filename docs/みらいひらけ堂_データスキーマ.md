# みらいひらけ堂 データスキーマ v1

- 作成日: 2026-09-06 / 元設計: docs/企画_無料学習支援検索サービス設計_20260905.md §12
- データ本体: `data/miraihirake/services.json`(公開サイトは `site/miraihirake/` から `../data/miraihirake/services.json` を読む。update.yml が `data/` を `site/data/` へコピーする既存方式)
- 正確性ルール: **全レコードに data_source(出典URL)と last_verified(最終確認日)が必須**。欠けたレコードはビルド/表示対象外。締切・金額・条件は原文照合し、不明は "要確認"(hojo-accuracy-check 準拠)

## ファイル形式

```json
{
  "updated_at": "2026-09-06",
  "services": [ { ...以下のフィールドを持つオブジェクト... } ]
}
```

## 運用ルール

1. 新規レコードは必ず `review_status: "draft"` で追加 → 検証部の原文照合で `verified` → 守り部の掲載審査(docs/みらいひらけ堂_掲載基準_draft.md)で `published`
2. `last_verified` から60日超は公開画面で「⚠情報が古い可能性」を自動表示、120日超はスコア減点、180日超は要再確認リスト行き
3. bool項目で原文から確認できないものは `"要確認"` を入れる(true/false を推測で埋めない)
4. URL死活チェックの対象に official_url / application_url / data_source を含める
