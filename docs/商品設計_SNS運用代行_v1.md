# 商品設計: SNS運用代行(沖縄中小企業向け)v1

**ドラフト(小柳さん決裁前・数値は全て仮)**

- 器: **フクギイロ経由の法人契約に統一(個人契約は行わない)**
- Grp資産(ミカタの自動投稿パイプライン等)の利用: **2026-07-31 嶺井さん・遥さん了承済み**。覚書等の書面化は守り部→税理士・弁護士確認の流れで別途
- 実証: 沖縄企業のミカタ FB/IG 自動投稿(月水金・Graph API+GitHub Actions)が稼働中。「自社で動いている実物」をデモとして提示できる見込み

## 1. 対象・提供価値(仮説)
- 対象: 「SNSをやりたいが続かない」沖縄中小企業(店舗・サービス業・BtoB問わず)
- 提供価値: 投稿文・画像の自動生成+月水金の自動投稿+週次レポート。人は週1回の抜き取り点検のみ

## 2. 価格案(全て仮・市場検証前)
| 案 | 構築費 | 月額 | 内容 |
|---|---|---|---|
| A: ライト | 5万円 | 3万円 | FB/IG いずれか1媒体・週3投稿・週次レポ |
| B: スタンダード(推奨) | 5万円 | 5万円 | FB+IG 2媒体・週3投稿・週次レポ+月1回の方針すり合わせ30分 |
| C: 手売り検証価格 | 3万円 | 3万円 | 最初の3社限定。ヒアリング協力を条件に割引 |

推奨: **B を標準、C でゲート検証**。単価より件数×継続率を優先(月1〜5万帯に集中する方針に整合)。競合価格の実地調査は未実施のため、3件の手売りで価格弾力性も併せて確認する。

## 3. 提供範囲 / 除外範囲
- 含む: 投稿文・画像の生成 / 予約投稿 / 週次レポート(投稿実績・リーチ) / 障害時の再投稿
- 含まない: コメント・DM返信の代行 / 広告運用 / 炎上対応(発生時は停止+顧客へ即報告まで) / 動画制作(2026-07-31 小柳さん判断で除外領域) / 他社批判・比較を含む投稿
- 顧客アカウントのアクセス権は最小権限で預かり、**受託時情報管理規程(docs/受託時情報管理規程_draft_v1.md)の施行を開始条件**とする

## 4. SLA(週1人的点検)
- 週1回、人の目で全顧客の投稿を抜き取り点検(誤情報・不適切表現・ブランド逸脱の確認)。無検品では売らない
- 自動投稿の失敗検知→24時間以内に再投稿または顧客報告
- 点検工数は1社あたり週15分以内を目安に設計し、超過が続く場合は受注を止めて仕組みを直す(労務集約化ガード)

## 5. ステージゲート
- **最初の3件は手売り**(既存人脈・提携部ルート)。合格基準: 3件受注かつ2ヶ月継続、点検工数が想定内
- 合格→ノビシロの商品棚に掲載し拡大 / 不合格→積み上げ表から外す(点線のまま終了)
- 同時受注上限: ゲート通過まで3社、通過後も当面10社(週1点検の物理限界を先に検証)

## 6. 解約条件
- 月契約・**いつでも解約可**(当月末まで)。違約金なし。最低契約期間なし
- 解約時: アカウント権限の返却・預かり情報の削除を14日以内に完了し報告(規程ドラフト準拠)

## 7. 三名体制議事

### スイシン(推進)
- 完全実証済み・追加開発ほぼゼロ・実物デモが最強の営業資料。ミカタの経営者リード・商工会ルートが販路として既にある。低額+解約自由で沖縄中小の参入障壁が最も低い

### ウタガイ(懐疑)
- 「自社で動く」≠「他社に売れる」。顧客ごとの業種・トーン調整、素材(写真)の受領、承認フローが自社運用には無いコストで、週1点検15分/社の見積りは楽観の可能性が高い
- 顧客アカウントを預かる事故リスク(誤投稿・乗っ取り・情報漏えい)が売上規模に対して過大。規程施行前の受注は1件でも危険
- CV単一ルールとの関係: ミカタのリードへこの商品を営業するのは小柳さん決裁が別途必要(憲法・絶対ルール4)。販路の前提が実は未決裁

### ベッカイ(別解)
- 「代行」でなく**「仕組み構築の売り切り+自走支援」**(構築10万+点検のみ月1万)にすれば、労務集約化と事故リスクが同時に下がる。運用主体を顧客に残す設計も3件検証の比較対象に入れるべき
- 最初の3件は外部でなくGrp内他社(エンライフ・GLOW)への導入から始めれば、事故コストを内部化した状態で検証できる

### 結論(提案・小柳さん上申)
- 採否: **提案・上申** — 価格Bを標準、Cで手売り3件のゲート検証から開始したい。ただし①受託時情報管理規程の施行 ②ミカタリードへの営業可否の決裁 を開始条件とする。ベッカイの「売り切り型」も検証3件のうち1件で試す
- 理由: スイシンの実証優位は認めつつ、ウタガイの規程未施行・工数楽観・販路未決裁は開始条件化で吸収できると考えるため
- 見直し期限: 2026-10-31(ゲート判定と同時)
