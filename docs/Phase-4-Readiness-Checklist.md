### 6️⃣ リスク管理（事前に想定される懸念）

| リスク | 対策 |
|--------|------|
| 監査チームがステージング環境へアクセスできない | 10/30に接続テスト実施、11/11までに解決 |
| Phase 3 のテストが実装と乖離している | Task 3.4 の assertion を11/11までに調整完了 |
| 暗号化されたレコードが監査対象にない | テストデータ作成時に複数パターン（AES-256-GCM, 異なるIV）を用意 |
| Key Vault への Managed Identity アクセスが検証できない | ステージング環境で疑似的に timeout を注入して復帰テスト |
| ログが消失して append-only が検証できない | 試験的に改ざん試行 → 署名検証失敗 を再現 |

6. **リード** → クローズ記録

### 修正ラウンド上限
- **Round 1-3**: 同じ実装チーム、通常対応（24-48時間）
