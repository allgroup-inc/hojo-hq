# もらいわすれ堂 ホスピタリティ設計書 v1
## 「あなたが受け取るまで、いっしょに。」を全体で実現する

**目的**: 沖縄の世帯が「給付金が本当にもらえた」を経験するまで、サイトが付き添い、応援する体験を全員に

---

## 🏠 第1層: サイト全体のトーン & 約束

### ブランド約束
```
「難しい手続きを、わかりやすく。
 書類作成を、一緒に。
 給付金を、確実に受け取るまで。」
```

### トーン(文体)の基本ルール
1. **敬語は使わない** — 「〜です」でなく「〜よ」「〜ね」
   ```
   ❌ 当サイトでは給付金情報を提供いたします
   ✅ 沖縄のあなたが使えそうな給付金を集めました
   ```

2. **専門用語は噛み砕く** — 家計の見直しやさんと同じトーン
   ```
   ❌ 世帯主の合算所得が〇〇万円以下の場合
   ✅ ご家族の収入が年間〇〇万円くらいなら、対象かもね
   ```

3. **応援のトーン** — 「手続きが大変」を認める
   ```
   「申請は少し手間だけど、その分もらえる額も大きい。
    書類作成のコツをお伝えします。」
   ```

4. **沖縄らしさ** — 方言/地元ネタを活用
   ```
   「給付金は『もらい忘れ』しやすいもん。
    このサイトで確認したら、絶対に取り逃さないよ。」
   ```

## 🎯 第2層: ユーザージャーニー全体のホスピタリティ

### ステップ1: 発見〜「あ、これ私たちが使えるかも」
**ここでのホスピタリティ**: 探す手間をゼロに

```
【ランディングページ】
大見出し: 「沖縄で暮らす、あなたのための給付金」

サブテキスト:
「毎月、新しい給付金が沖縄に降りてきてる。
 でも、知らないうちに終わっちゃう。
 ここで確認して、『モレ』をなくそう。」

【3秒診断】← ここが勝負
「あなたの状況を3つ選ぶだけで、
 対象制度が一覧で出てきます」

診断の質問(3問):
 1. 「誰が使いたい?」 → 本人 / お子さん / 親御さん / 小さい子の保護者
 2. 「今、困ってることは?」 → 医療費 / 学費・給食 / 生活費 / 親の介護
 3. 「世帯の年収は?」 → 〇〇万円未満 / 〇〇〜〇〇万円 / 〇〇万円以上

→ 【結果】「あ、この制度が使える!」の確信が必要
```

### ステップ2: 検討〜「本当に大丈夫? 本当にもらえる?」
**ここでのホスピタリティ**: 不安を一つ一つ払う

```
【各制度ページ】
構成:
 ① 一文要約 — 「何がもらえるか」を5秒で
 ② 「こんな人が対象」 — 断定しない(「対象になる可能性があります」)
 ③ よくある質問 TOP 3 
    Q: 「申請しないと絶対にもらえません。本当?」
    A: 「本当です。でも、申請サポートが充実してるから大丈夫。」
    
    Q: 「書類が多くて難しそう...」
    A:「一覧表にまとめました。3つだけ集めればOK。」
    
    Q: 「審査に通らなかったら?」
    A: 「その場合は『落選しました』のみ。追加費用はゼロ。」

 ④ 制度詳細(日本語)
 ⑤ 次のステップ(いますぐ? 時間がある時に?)
```

### ステップ3: 申請〜「さあ、やってみよう」
**ここでのホスピタリティ**: 孤独感をなくす、「誰かが見守ってる」感

```
【申請ガイド】

冒頭:
「申請は難しくない。でも、ひとりでやるのは心細いよね。
 ここでは、書類作成の『コツ』と『よくつまずくポイント』を教えます。」

構成:
① チェックリスト — 用意する書類・印鑑・写真の「見本」付き
② 記入例 — 「あなたの状況」別に書き方を見本提示
③ つまずきやすい箇所 TOP 3 の対策
   「所得証明書がない」→ 「◎◎で無料発行できます」
   「扶養家族の人数が不明」→ 「◎◎を見れば一目瞭然」
   「書類提出の期限を過ぎた」→ 「この制度は大丈夫。ここからでも申請できます」

④ 士業(社労士・行政書士)への紹介 — 有料だけど「心強い」選択肢
   「書類作成が不安な方へ」
   「提携の行政書士が初回相談無料で対応します」
   → 申請代行ではなく『書類作成サポート』であることを明記

⑤ 提出方法の動画(15秒)
   「郵送」「窓口」「オンライン」の3パターンを短動画で
```

### ステップ4: 受給〜「もらった!」を報告→励ます
**ここでのホスピタリティ**: 「あなたの成功が、沖縄の役に立ってる」を伝える

```
【受給報告フロー(LINE)】

受信メッセージ:
「給付金をもらえました」→

返信メッセージ:
「おめでとうございます🎉
 あなたが実際にもらえたことが、
 これから給付金を探す沖縄の人の励みになります。
 
 よかったら『額』と『感想』を教えてもらえますか?」

↓

報告後のメッセージ:
「ありがとう。あなたの『もらえました』という報告が、
 沖縄県にとって大事な『実績』になります。
 
 次にこの制度を知りたい人へ:
 『書類作成は思ったより簡単でした』
 というあなたの言葉が、一番の力になる。」

【効果】
- ユーザーの「もらえた」体験が共有される
- 次のユーザーが「本当にもらえるんだ」と確信
- データが台帳に → 沖縄県への説得材料に
```

## 💬 第3層: AI プロンプト集(コンテンツ生成用)

### プロンプト1: 「診断結果の提示」
```
役割: 沖縄の世帯が「本当に自分たちが使える?」と思わせるメッセンジャー
トーン: 親切で温かい, 断定しない, 希望を与える

ユーザーの診断結果: {diagnosis_result}

指示:
1. 対象制度3〜5個を「見落としやすい順」で並べる
2. 各制度につき、「あ、これ俺たちだ」と気づかせる文を1行
3. 必ず「〜の可能性があります」で留める(断定禁止)
4. 最後に「詳しくは>>」のリンク
5. 全体の温度: 「あ、これ使える!」という小さな喜び

出力例:
「あ、これ気づかなかった!」という3つ:

1️⃣ 就学援助 — 小中学生の給食費・学用品代が出る
   年収がだいたい◎◎万円以下なら、対象の可能性があります。
   (書類作成は一覧表3枚だけ。市町村役場が手伝ってくれます)

2️⃣ 高校生等奨学給付金 — 親が高校生のお子さんがいる世帯向け
   「返さなくていい給付型」で、【年10〜30万円】。
   ...

3️⃣ 児童扶養手当 — ひとり親世帯なら...
```

```
指示:
1. 冒頭で「その不安、よくわかります」と認める

4. 必要に応じて窓口情報・相談先を付ける

回答:
「その気持ち、すごく分かります。

```

```
  ▶ 再婚して兄妹がいる場合
```

## 🎨 第5層: UX/デザイン改善(見やすく・分かりやすく)

### 改善1: 色づけ戦略
```
色彩心理:
 ▶ 「対象になる可能性がある」= 明るい黄色(希望)
 ▶ 「期限が迫っている」= 赤い点滅(注意)
 ▶ 「申請したらOK」= 緑チェック(安心)
 ▶ 「要確認」= オレンジ疑問符(丁寧)

現在の配色(朱#B9502F・黄#F2B705)を活用:
 朱 = 「これは給付金」という確信
 黄 = 「やってみよう」という励まし
```

### 改善2: 情報の層構造
```
見出し(h1): 「あなたの生活を支える給付金」
  ├─ サブ見出し(h2): 「子育て中の方へ」
  │   ├─ 診断 (3問で対象制度が出てくる)
  │   ├─ 制度一覧 (難易度・額・期限が一目)
  │   └─ よくある質問 (不安を払う)
  │
  ├─ サブ見出し(h2): 「申請が初めての方へ」
  │   ├─ ステップガイド (5ステップで完成)
  │   ├─ 書類チェックリスト
  │   └─ つまずき対策
  │
  └─ サブ見出し(h2): 「給付金をもらえた方へ」
      ├─ 受給後の手続き
      ├─ 次に使えそうな制度
      └─ LINEで報告する
```

### 改善3: アクセシビリティ
```
文字サイズ: デフォルト16px(読みやすい)
行間: 1.8以上(沖縄の高齢者向け)
コントラスト比: 4.5以上(目の弱い人向け)
音声読み上げ対応: すべてのテキストに alt属性
タッチ目標: ボタン48px以上(スマホ指での操作)
```
