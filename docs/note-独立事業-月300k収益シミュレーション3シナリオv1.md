# note 独立事業 月¥300k収益シミュレーション 3シナリオ v1

**目的**: 月¥300,000 手数料控除後の達成パスを3シナリオ化  
**対象期間**: 2026-11-02 ~ 2027-02-02（3ヶ月間） + 継続予測（6ヶ月）  
**使用ツール**: note_revenue_final.py（手数料計算ロジック検証済み）  
**作成日**: 2026-11-02

## 前置き：手数料体系（確定値）

```
有料記事・マガジン：
- クレジットカード処理手数料：5%
- プラットフォーム利用料：10%（有料記事・有料マガジン）/ 10%（メンバーシップ）
- 振込手数料：¥270 / 月（複数取引でも月1回のみ）

計算式（1取引）:
  カード手数料 = 売上 × 5%（切り捨て）
  プラット手数料 = (売上 - カード手数料) × 10%（切り捨て）
  振込前ネット = 売上 - カード手数料 - プラット手数料
  最終ネット = 振込前ネット - ¥270（月1回）

例：¥100,000 売上
  カード：5,000 → ¥95,000
  プラット：9,500 → ¥85,500
  振込：270 → ¥85,230 / 月
```

## 5. 重要な仮定と注記

### **データの信頼度**

| 項目 | 信頼度 | 根拠 | 備考 |
|---|---|---|---|
| **手数料体系** | 📊 確定値 | note公式ドキュメント（照合済み） | 変動リスク：低 |
| **購買単価（¥1,500-2,000）** | 🔄 推定値 | 既存9記事の市場観察 + 業界相場 | 実投稿検証が必須。実測で乖離した場合は修正 |
| **マガジン継続率（60-70%）** | ❓ 仮定値 | note内の類似マガジン統計から推定（出典URL明記なし） | **最大リスク要因**。実投稿マガジン1号の購読数を月末に検証 |
| **記事本数の運用負荷** | ❓ 仮定値 | Claude使用での作成時間 1記事 2h（推定） | 実投稿で検証。実際の執筆負荷が異なれば調整 |
| **流入PV数** | ❓ 仮定値 | SEO + SNS成長曲線から推定 | 月1回の実測更新が必須。乖離時は修正 |

### **Scenario B（標準）が推奨される理由**

1. **到達可能性**: 月¥300k を 4 ヶ月で達成（現実的）
2. **持続性**: 記事 5-6 本/月 + マガジン 2 種は「1 人で運用可能」な負荷
3. **リスク分散**: 有料記事 + マガジンの「両建て」で収入源の多角化
4. **修正余地**: Month1-2 で「コンバージョン率が低い」と判明した場合、Month3 で調整可能
5. **SNS負荷**: 週3投稿なら「無理のない継続」が可能

### **Scenario C が高リスクと判定される理由**

1. **運用負荷**: 毎日 SNS 投稿 + 週1本有料記事 + マガジン 3 種は「1 人での持続不可」と判定
2. **品質低下リスク**: 投稿量を追求すると、記事のクオリティが下がる可能性 → 購買率が低下する懸念
3. **燃え尽きリスク**: 2-3 ヶ月の高速成長後、ペースダウン → 読者期待とのギャップが生じる可能性
4. **外部環境変化**: note 内のアルゴリズム変更や AI 競合の急増で、想定値が破壊される可能性
