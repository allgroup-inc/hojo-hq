# 機能仕様書（Task 5）

**10個の主要機能:**

1. **ダッシュボード**: 本日のアポ件数・営業マン稼働状況・最近の変更ログ
2. **日ビュー・週ビュー・月ビュー**: 複数営業マンのスケジュール可視化（リアルタイム更新）
3. **アポ新規作成**: フォーム入力 → バリデーション → DB保存 → 通知送信
4. **アポ編集・キャンセル**: 既存アポの更新 → 監査ログ記録 → 関係者通知
5. **空き時間自動検出**: 営業マンの移動時間・休憩を考慮した「次の空き時刻」表示
6. **ラウンドロビン**: 営業マン間の負荷を均等化し、アポ割り当てを自動提案
7. **権限管理**: ADMIN / APO_STAFF / SALES_REP の3ロール分離
8. **KPI集計**: 日別・営業マン別のアポ件数・完了率・平均訪問時間をレポート出力
9. **イレギュラー対応**: キャンセル・延期時の自動通知（Slack + LINE）
10. **顧客管理**: アポ登録時の顧客名（テキスト）管理、❶入口システムとの連携

**バリデーション規則:**
- 顧客名: 空文字列不可、30文字以上推奨（警告）
- 日時: 過去日時不可、営業時間（7:00-22:00）内のみ
- 営業マン: 同時刻に他のアポがないか確認（警告）
- 想定時間: 営業マンの勤務終了時刻を超えないか確認

**エラーハンドリング:**
- 400 Bad Request: バリデーション失敗（フィールド名 + エラーメッセージ）
- 401 Unauthorized: トークン無効 / 期限切れ
- 403 Forbidden: 権限不足
- 404 Not Found: リソース不存在
- 500 Internal Server Error: サーバーエラー
