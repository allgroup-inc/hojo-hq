# セキュリティ・ガバナンス設計（Task 8）

**認証・認可:**
- Entra ID + OAuth 2.0（企業全体ゲート）
- JWT トークン（RS256署名、1時間有効期限）
- RBAC + リソースベースのアクセス制御

**データ暗号化:**
- **転送中**: HTTPS/TLS 1.3 必須
- **保存時**: PostgreSQL ディスク暗号化（AES-256）
- **キー管理**: Entra ID 管理下（Microsoft Key Vault）

**監査・ログ:**
- **対象**: アポ作成・編集・削除、ログイン・ログアウト、エラー、権限チェック失敗
- **記録形式**: JSONB（old_values + new_values）
- **保持期限**: 操作ログ 3年、エラーログ 1年、アクセスログ 3ヶ月
- **ログ保護**: append-only テーブル、改ざん防止

**インシデント対応:**
- **検知**: 異常なログイン試行、権限昇格試行、大量ダウンロード
- **対応**: アラート → ユーザーセッション強制終了 → インシデント記録
- **エスカレーション**: レベル1 システムアラート → レベル2 メール通知 → レベル3 電話通知

**バックアップ・リカバリ:**
- **バックアップ頻度**: フル週1回、増分毎日
- **保存**: 複数リージョン、3世代保持
- **RTO**: 4時間以内
- **RPO**: 1日（最新バックアップ時点まで）

**GDPR・個人情報保護:**
- **扱う個人情報**: 営業マンのメールアドレス（Entra ID から取得）
- **扱わない情報**: 顧客の電話番号・住所・生年月日（❶入口システムで管理）
- **ユーザー削除時**: ログイン履歴・アクション履歴を匿名化
- **アクセス権付与**: 「自分のアクション履歴を CSV ダウンロード」機能
