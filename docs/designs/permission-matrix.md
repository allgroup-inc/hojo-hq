# 権限管理マトリックス（Task 7）

**3つのロール定義:**

| ロール | 説明 | 権限 |
|---|---|---|
| **ADMIN** | システム管理者・事務責任者 | 全操作（作成・編集・削除）、ユーザー管理、レポート出力 |
| **APO_STAFF** | アポ入れ人 | アポ作成・編集・削除、営業マン選択、レポート参照 |
| **SALES_REP** | 営業マン | 自分のアポを閲覧・ステータス更新（完了/キャンセル）のみ、他人は参照のみ |

**権限マトリックス（10機能 × 3ロール）:**

| 機能 | ADMIN | APO_STAFF | SALES_REP |
|---|---|---|---|
| ダッシュボード表示 | 全員分 | 全員分 | 自分のみ |
| 日ビュー・週ビュー・月ビュー | 全員分 | 全員分 | 自分のみ |
| アポ新規作成 | ○ | ○ | × |
| アポ編集（日時・場所） | ○ | ○ | × |
| アポ削除（キャンセル） | ○ | ○ | ○（自分のみ） |
| アポのステータス更新 | ○ | △（作成者のみ） | ○（自分のみ） |
| 空き時間自動検出 | 全員分 | 全員分 | 自分のみ |
| ラウンドロビン実行 | ○ | ○ | × |
| 権限管理（ユーザー管理） | ○ | × | × |
| KPI集計・レポート出力 | 全営業マン | 統計値のみ | 自分のみ |

**詳細ルール:**

**ルール1: アポの編集権限**
- ADMIN: すべてのアポを編集可
- APO_STAFF: 自分が作成したアポのみ編集可
- SALES_REP: 自分に割り当てられたアポのステータス（完了/キャンセル）のみ更新可

**ルール2: 削除権限**
- ADMIN: すべてのアポを削除可（監査ログに記録）
- APO_STAFF: 自分が作成した未確定のアポのみ削除可
- SALES_REP: キャンセルのみ可、削除は不可（監査ログに「営業マン〇〇がキャンセル」と記録）

**ルール3: ユーザー管理**
- ADMIN のみがユーザー追加・ロール変更・無効化を実行可

**ルール4: レポート・分析**
- ADMIN: 全営業マンの個別データを参照可
- APO_STAFF: 全営業マンの統計値（平均値・合計値）のみ参照可、個人名非表示
- SALES_REP: 自分の個人売上・効率指標のみ参照可

**ルール5: 監査ログ**
- ADMIN: 全員のアクション履歴を参照可
- APO_STAFF: 自分のアクション履歴のみ参照可
- SALES_REP: 自分のアクション履歴のみ参照可
