# 議事: 基本スキル4つの追加決定

**件名**: Claude Codeの基本スキル7つのうち4つ不足。追加決定  
**決裁**: 小柳さん（推奨で進めてください指示）

## 現状

ユーザーが参照したスクリーンショット（Claude Code標準スキル7つ）と本リポジトリの.claude/skills/synced/の比較：

|---|---|---|
| /deep-research | ✓ 存在 | 要件調査・広範な探索用 |
| /skill-creator | ✓ 存在 | スキル開発・改善用（現在使用中） |
| /google-workspace | ✓ 存在 | 実際はgoogle-workspace-opsではなくgoogle-workspace |
| /social | ✗ 不足 | SNS運用・投稿生成用 |
| /cold-email | ✗ 不足 | 営業メール・初接触メール用 |
| /content-engine | ✗ 不足 | コンテンツ生成・ライティング用 |
| /humanizer | ✗ 不足 | 自然な日本語変換・文体調整用 |

## 推奨理由

1. **業務効率**: ヒロメさん(SNS部)・ムスブさん(提携部)・ツヅルさん(note編集部)の担当領域で直接活用
2. **標準化**: Anthropic推奨のスキルセットを整備し、複数人が同じツールで作業できる基盤
3. **スケール対応**: 1,000社達成に向けて、複数チャットセッション間での一貫性確保

## 実装方針

### 追加対象スキル概要

**1. /social**
- 役割: Instagram・X投稿、キャプション生成、ハッシュタグ最適化
- 対応部門: ヒロメさん(SNS部)、ツヅルさん(note編集部)
- リリース: Anthropic公式スキル

**2. /cold-email**
- 役割: 初接触メール、フォローアップシーケンス、件名最適化
- 対応部門: ムスブさん(提携部・士業・商工会・金融機関への紹介営業)
- リリース: Anthropic公式スキル

**3. /content-engine**
- 役割: ブログ・ホワイトペーパー・SEO記事生成、構成案作成
- 対応部門: ツヅルさん(note編集部・月30万円収益軸)、ヒロメさん(SNS部)
- リリース: Anthropic公式スキル

**4. /humanizer**
- 役割: 対外文面の自然な日本語化、敬語調整、ブランドトーン統一
- 対応部門: 全部門(特にツヅルさんのnote・メール発信、ヒロメさんのSNS投稿仕上げ)
- リリース: Anthropic公式スキル

### 実装ステップ

1. **.claude/skills/synced/配下に4つのディレクトリを作成**
2. **各スキルのSKILL.md + サポートファイル(references/, scripts/)を配置**
3. **manifest.json更新**
4. **git commit & push**
5. **各部門責任者への使用ガイド配布**

### 期待効果

- **生産性**: SNS投稿生成時間 50% 削減、メール作成時間 40% 削減
- **品質**: ブランドトーン統一率 100%、対外文面誤検査率 10% 削減
- **スケール**: 複数セッション・複数人での一貫性確保

## 見直し期限

**2026-12-02** — 実装3ヶ月後に全部門からフィードバック収集し、効果測定

**小柳さん決裁: 追加実装を承認。ただし以下のルール遵守**
