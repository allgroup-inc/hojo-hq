# 議事 — 保険引き受け目安ツール・データの公開終了

2026-08-24 / 決裁: 小柳さん(「決裁します」)/ 類型①決裁事項・類型②不可逆(公開範囲の変更)

## 事実

- 引受目安データの原本3点に、提供元による取扱制限の明記があることを原本照合で確認した
  (照合の詳細は非公開側 pamphlet-shelf の検証記録を参照。再現可能なスクリプトあり)
- ファイル名の「公開用」は代理店へ配布してよい版の意味で、一般公開を許す表記ではない
- データとツールの正本は非公開側へ移設済みで、本リポジトリへの依存は無い

## 三役の議論

- **スイシン**: 取扱条件が明確である以上、公開終了は即日。移設済みで失うものは無い
- **ウタガイ(反対理由)**: ①ツールはミカタLPの診断後導線の一部で、削除すると
  「診断→保険チェック」の導線が消える(利用実績の確認を先にすべきだった)
  ②検索エンジンやアーカイブに残った複製までは消えない。公開終了の効果を過大に言うべきでない
  ③git履歴には残るため、完全な抹消には履歴書き換えが要る(別途決裁)
- **ベッカイ**: 削除でなく社内限定版への差し替え(認証付き)も考えたが、
  本リポジトリは認証手段を持たない静的サイトであり実現できない。非公開側で持つのが正

## 裁定(小柳さん決裁に基づき実行)

1. ツールHTML(3か所)・データJSON(2か所+サンプル)・原本PDF2本を削除
2. `docs/index.html`(検索ページ)は公開終了の案内に差し替え
3. LPの誘導バナーとsitemapの項目を撤去
4. `scripts/check_repo_scope.py` の禁止パターンに追加(再掲載をCIで止める)
5. 履歴書き換えの要否は別途決裁(非公開側の決裁待ち一覧に記載)

見直し期限: 2026-11-24(導線の代替=非公開側ツールの社内提供が定着したかを確認)
