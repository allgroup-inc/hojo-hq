# 議事: みらいひらけ堂LPと「堂シリーズ」ブランド展開(2026-09-06)

- 決裁: **小柳さん指示(2026-09-06)** — 「もらいわすれ堂のロゴはそのまま堂シリーズとしてみらいひらけ堂でも使う。サイトの構成や仕組みを使いながら、①お金をかけて選択して可能性をひらく道もあること ②ささえてくれている方々・まなびば・制度があること ③子どものみらいの可能性をさまざまな体験からひらくという価値観、が伝わるサイトにしたい。作っていけるプロンプトが欲しい」
- 種別: ブランド・掲載方針に関わるため議事必須類型①(決裁は上記の小柳さん指示そのもの)

## 三名体制の議論

- **スイシン**: 堂シリーズ共通のロゴ文法(朱タイル+黄バッジ)を流用すれば、もらいわすれ堂で作った信頼感を新サービスが最初から着られる。LPに価値観セクション3本(扉/ささえ/選択)を足し、プロンプトを文書化して❹等の他セッションでも同じ品質で作れるようにする
- **ウタガイ(反対理由の記録)**: ①「お金をかける道」の記述は、一歩間違うと有料塾への誘導・広告と誤解され、無料特化という本サービスの信用の核を傷つける。掲載は無料のみという線を文面とプロンプト両方に明記しない限り反対 ②ロゴ意匠(バッジ「↗」)はエージェント作のv0であり、決裁済みのもら堂ロゴと同格に扱うべきでない ③似たロゴの2サービスを混同し「もらいわすれ堂で学習支援をやっている」と誤認されるおそれ
- **ベッカイ**: LPを別ページに分けず、既存の検索SPAのトップ(view-home)に価値観ブロックを差し込む方が、1ファイル運用・公開判定の仕組みをそのまま使えて安い。プロンプトは「新規用/修正用/堂シリーズ新サービス用」の3段にしておくと将来の3つ目の堂にも効く

## 結論(部門長裁定)

1. ベッカイ案を採用: 既存 index.html のトップに価値観3ブロックを追加(別LPは作らない)
2. ウタガイ①を全面採用: 「このサイトには無料(一部無料・条件付き無料をふくむ)の情報だけをのせています」を本文に明記し、プロンプトの禁止事項にも「有料サービスの掲載や広告は絶対にしない」と記載
3. ウタガイ②を採用: ロゴは**v0(出発点)**と明記し、エガクの月次リファイン+みがきの会審査の対象とする(docs/みらいひらけ堂_LP制作プロンプト.md 補足に記載)
4. ウタガイ③対応: フッター・aboutで姉妹サービスとして相互に名前を明示し、役割の違い(給付金診断/学びの検索)を書き分ける
5. プロンプトは docs/みらいひらけ堂_LP制作プロンプト.md に3段構成で文書化

- 見直し期限: 2027-03-06(公開後の実データでLPの伝わり方を再点検)

## 追記(2026-09-06)— 世界観フィルム(始まりのストーリー)

- 小柳さん指示: 「始まりのストーリー的な写真の流れからロゴまでの流れも作りたい」
- 実装: もらいわすれ堂トップのフィルム(夜→朝)と同じ文法で、みらいひらけ堂版5シーン(星空→好きなこと→ささえ→朝焼け→ロゴ「ひらけ、みらい。」)を絵コンテ(影絵+光)で実装。写真は差し替え枠のみ用意
- **ウタガイ(反対理由の記録)**: ①子どもの写真は肖像権・安全の観点でリスクが大きい(公開リポジトリでもある)。顔が写る写真は使うべきでない ②フィルムが長いと、検索という本来の目的に着くまでが遠くなる
- 対応: ①「顔は写さない(うしろ姿・手元・影・遠景のみ)+写真追加は守り部確認」をプロンプト文書に明記 ②固定の「スキップして探す →」導線を常時表示し、S5のCTAからも1タップで検索へ
- 写真プラン(撮影・収集リスト)は docs/みらいひらけ堂_LP制作プロンプト.md「世界観フィルム用プロンプト」に記載
