# 議事: みらいひらけ堂 小規模公開の条件(上申・2026-11-07)

対象: みらいひらけ堂(株式会社フクギイロ・沖縄の子どもの無料の学びの検索サービス)。
状態: **上申(決裁待ち)**。この議事は公開の条件を決めるためのもので、公開そのものはしない。公開は、条件を満たしたうえで小柳さんの決裁を受けて行う。

## なぜ(背景)

- 2026-09-06 に着手GO(12週計画)。2026-11-07 時点で台帳145件のうち掲載可(published)16件、照合済み(verified)3件、下書き126件。サイトは GitHub Pages の公開成果物から外したまま(未承認コンテンツとして除外)
- 下書きは9月15日以降止まっている。仕分けの結果は `docs/みらいひらけ堂_下書き仕分け_20261107.md`
- 「掲載可30件になったら公開」のような件数だけの条件では、子どもと保護者が使うサービスとして足りない(小柳さんの指摘 2026-11-06)

## 前提

- 掲載基準 v2.1(`docs/みらいひらけ堂_掲載基準.md`)は緩めない。迷ったら載せない(§0 フェイルクローズ)
- 公開範囲の変更は不可逆な変更にあたり、議事と小柳さんの決裁が要る(憲法・三名体制ルール8)

## 提案: 公開の条件(すべて満たしたとき、小柳さんの決裁を受けて公開する)

### 1. 掲載する各件の確認(1件ずつ・公式の一次情報で)

| 確認項目 | 内容 |
|---|---|
| 対象年齢 | 学年・年齢が公式情報で確かめられる |
| 地域 | 沖縄から利用できる(○)。△・? は隠さず表示し、確認方法を案内する |
| 費用 | 無料の範囲と有料部分の境目が原文で確かめられる。「要確認」は載せない |
| 問い合わせ先 | 運営者名・所在地(市区町村まで)・連絡手段の3点が公開されている |
| リンク先 | 公式ページが開く(URL死活の検査を通過)。転送先・所有者の変化が無い |

### 2. 子どもの安全

- 子どもとの関わり方の類型(A〜D)を、取り込み時の初期値ではなく実態で判定している
- C類型(1対1)は安全4点(本人確認・保護者同意・面談の記録と見守り・相談/通報窓口)を確認済み。D類型(個人が単独で接する形態)は1件も含まない
- 子ども向けの通報窓口(掲載基準 §6)が公開時点で動いている。通報は24時間以内に一次対応できる体制がある
- 子どもの個人情報を取らない(登録不要・追跡なし)

### 3. 監査

- 週次の自動監査で、掲載可の全件について問題0件・リンク切れ0件(2026-11-02 時点で文部科学省のページ1件が404。公開前に解消する)
- 鮮度KPI(最終確認60日以内の割合)が80%以上
- 掲載可の各件に、照合(verified)と審査(published)の記録が別々に残っている(§3)

### 4. 最終決裁

- 守り部が上の1〜3を確認し、審査記録(`docs/みらいひらけ堂_守り部審査記録.md`)に残す
- 小柳さんが公開を決裁し、この議事に追記する(公開の場所・時期・最初の掲載件数)

件数の目安(例 30件)は、上の条件を満たした件だけを数える。件数が届いても、条件を1つでも欠けば公開しない。

## 代替案

1. 件数(30件)で公開を判断する(採らない: 安全・情報の確認が担保されない)
2. 掲載可16件のまま、すぐに公開する(採らない: 通報窓口・監査の0件化が未確認)
3. 上の4つの条件を満たしたら公開する(提案)

## 三名体制の議論

- **スイシン(推進)**: 条件を先に決めておけば、審査の作業がそのまま公開の準備になる。「何が揃えば公開できるか」が見えると、止まっていた下書きの審査を再開しやすい。早く届けるほど、無料の学びの場を知らずに過ごす子どもが減る
- **ウタガイ(懐疑・反対理由)**: 条件が厳しすぎると、いつまでも公開できない。とくに県民会議の119件は料金と連絡手段が一次情報で見つからない団体が多く、条件を満たす件が増えない恐れがある。また、通報窓口の24時間以内の一次対応は、今の体制(小柳さんとAI)で本当に守れるかが分からない。守れない約束を公開時に掲げるのは、かえって信用を損なう
- **ベッカイ(別解・前提を疑う)**: 「検索サイトとして公開」の前に、確認済みの少数件だけを1枚の案内(学校・図書館向けの印刷物)にする段階を挟む方法もある。サイトの通報窓口や監査の体制が整うまでの間も、確かな情報を届けられる

## 裁定

- 採否: **上申中(決裁待ち)**
- 決裁で決めること: ①上の4つの条件で良いか ②通報窓口の一次対応の体制(誰が、何時間以内に) ③ベッカイ案(印刷物の段階)を挟むか ④公開の場所(独自ドメイン・moradou.jp の配下など)
- 決裁を受けるまで、公開・掲載データの書き換えはしない

## 見直し条件

- 期限: 2027-05-07
- 前倒しで見直す: 通報が入った / 掲載基準を改訂した / 12週計画の終了時点(2026-11末)で掲載可の件数が増えていない
