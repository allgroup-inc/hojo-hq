# 議事: 受け入れ試験(締切アラートの案内時期)

WikiSkill Phase 1 の受け入れ試験(Session A → Session B)用の決定記録。内容は本番ルール(CLAUDE.md 締切3層ルール)と整合させてある。

## なぜ(背景)
締切7日前では書類とgBizIDの準備が間に合わない。

## 前提
利用者はLINE登録済みで、締切アラートはLINEで届く。

## 代替案
- 締切7日前に通知する案 → 準備が間に合わないため却下。
- 締切30日前のみ通知する案 → 1回だけでは忘れられるため却下。

## 三名体制の議論
- **スイシン**: 「締切の約1か月前」から案内を始めれば、書類準備とgBizID取得が間に合う。
- **ウタガイ(反対理由・必須記録)**: 30日前は早すぎて忘れられる。
  1. 1か月前の1回だけでは、締切直前に思い出せない利用者が出る。
  2. 対策として、1か月前の案内に加えて途中で1回リマインドを入れる前提で受け入れる。
- **ベッカイ**: そもそも「締切」ではなく「準備開始日」を起点に案内すべきでは。

## 裁定
利用者向けの表現は「締切の約1か月前」で統一する(2026-10-06 受け入れ試験として記録)。

## 見直し条件
途中リマインドの開封率が計測できた時点で再議論。
