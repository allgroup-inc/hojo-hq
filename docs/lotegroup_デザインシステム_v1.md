## 1. Brand Concept

**コンセプトワード: 「静かな確信。」(Quiet Confidence)**

保険、不動産、M&A、金融。扱う商品は違っても、LOTEGROUPが届けているものはひとつ。
「これで大丈夫だ」と思える状態、つまり **確かさ** です。

- 売り込まない。選択肢を並べ、判断を支える。
- 大声を出さない。静かで、揺るがない。
- 商品の会社ではなく、**意思決定に立ち会う会社**。

ポジション: 独立系の総合金融グループ/金融のプロフェッショナルファーム。
銀行より近く、代理店より深く、スタートアップより長い時間軸で。

### タグライン(候補)

| 案 | コピー | 意図 |
|---|---|---|
| A(推奨) | 人生と企業の未来に、確かな選択肢を。 | 4事業を「選択肢」で束ねる。B2B/B2C両対応 |
| B | 確かなことを、ひとつずつ。 | 誠実さ・積み上げ。より静かな表現 |
| C | 未来の選び方を、ともに。 | 伴走の姿勢を前に出す |

## 2. Design Philosophy

1. **確かさは、静けさに宿る。** 騒がしいデザインは信用を削る。
2. **装飾ではなく、秩序。** 信用は飾りつけでは作れない。整列・余白・一貫性で作る。
3. **1画面1メッセージ。** 情報量より理解の速さ。迷ったら削る。
4. **余白は空きスペースではなく、態度。** 詰め込まない企業は、焦っていない企業に見える。
5. **10年もつものだけを採用する。** 流行のエフェクト・書体・レイアウトは使わない。

Open(開かれた)・Enduring(長く続く)

- グラデーションは「Navy同士の暗→明」のみ許可(Hero背景の光表現)。多色グラデ禁止。
- Success/Warning/ErrorはUIの状態表示専用。ブランド表現に使わない。

## 5. Typography System

**思想: 大きな見出し+短いコピー+大きな余白。**

### フォントファミリー

| 用途 | 指定 |
|---|---|
| 日本語 | **Noto Sans JP**(300/400/500/700)。印刷も同一。Meiryoは業務資料のみ可 |
| 日本語(理念・引用のみ) | Noto Serif JP 500。使用箇所はPhilosophy・トップの理念引用に限定 |
| 欧文・数字 | **Inter**(300/400/500/600)。数字は必ず `tabular-nums` |
| フォールバック | "Helvetica Neue", Arial, "Hiragino Kaku Gothic ProN", "Noto Sans JP", Meiryo, sans-serif |

### タイプスケール(PC / Mobile)

| Style | Size | Weight | Line Height | Letter Spacing |
|---|---|---|---|---|
| Display | 64px / 40px | 300(欧文)・400(和文) | 1.2 | 和文 .02em・欧文 -.01em |
| H1 | 48px / 32px | 400 | 1.3 | .02em |
| H2 | 36px / 26px | 500 | 1.4 | .02em |
| H3 | 24px / 20px | 500 | 1.5 | .02em |
| Body Large | 18px / 16px | 400 | 1.9 | .03em |
| Body | 16px / 15px | 400 | 1.9 | .03em |
| Caption | 13px / 12px | 400 | 1.6 | .03em(色は Gray) |
| Button | 15px / 15px | 500 | 1 | .08em(欧文は大文字) |

**運用ルール**
- 見出しは全角13〜20字以内。2行まで。3行になるなら文章を削る。
- 本文の1行は全角40字前後(max-width 720px)。
- 太字による強調は1画面1箇所まで。色による強調は使わない。
- 英語ラベル(INSURANCE等)はInter 500・大文字・ls .12em・13px。セクションの「見出しの上の小さな道標」として全媒体共通で使う。これがLOTEGROUPの署名的タイポグラフィ。

## 8. UI Components

影は原則なし(hover時のみ `0 8px 24px rgba(11,31,51,.06)`、モーダルのみ `0 24px 64px rgba(11,31,51,.16)`)。
Glassmorphism・多色グラデ・強い影・バウンドするアニメは全面禁止。

## 9. Photography Direction

**「写真は説明ではなく、世界観。」** 写真だけ見てもLOTEGROUPと分かる状態を目指す。

### トーン&マナー
- 自然光。低彩度・ややクールトーン(彩度-10〜20%目安)。白飛び・ビビッド禁止。
- 構図は「引き」を基本に、余白を大きく残す(被写体は画面の1/3以下でよい)。
- 人物は「働いている横顔・後ろ姿・手元」。カメラ目線と作り笑顔は原則使わない。
- 沖縄: 観光写真(ビーチ・シーサー・ハイビスカス)ではなく、**光と水平線と街**。
  朝の那覇の街並み、雨上がりの舗道、海と空の境界、樹木の影。
- 抽象: 建築の陰影、ガラス越しの光、海面の反射。ダーク面ではNavyのデュオトーン加工可。

### 被写体リスト
推奨: 建築・都市俯瞰・オフィスの静景・経営者の横顔・商談の手元・チームの後ろ姿・沖縄の光と海・書類にペンを走らせる手元
禁止: 腕組みで笑う営業マン/握手のアップ/電卓と虫眼鏡/札束・小判・貯金箱/保険証券のアップ/ガッツポーズ/フリー素材感のある外国人モデル

### 技術仕様
- アスペクト比: 16:9(横)・4:5(人物)・1:1(SNS)の3種に限定。
- 文字を載せる場合はCharcoalのスクリム(`rgba(38,43,49,.35)`)を全面に。グラデスクリム禁止。

## 10. Iconography

- スタイル: **Outline のみ**(Filled禁止)。塗りが必要な場面は文字で解決する。
- Stroke: 1.5px 固定 / 角: 2px round / 端点: round
- サイズ: 20px・24pxの2種のみ(24pxグリッドで作図)
- 色: Ink または Gray のみ。Brass・Navyのアイコンは矢印「→」だけ例外的に許可
- 使用方針: アイコンは補助。**文字で伝わるならアイコンを置かない。** 事業を4つのアイコンで表す、といった「絵文字的使用」は禁止

## 11. Motion System

**「気づくか気づかないか程度の上質さ」**。動きは情報の入場と応答のみに使う。

| 種類 | Duration | Easing | 使用条件 |
|---|---|---|---|
| Hover(色・線) | 200ms | cubic-bezier(.25,.1,.25,1) | 全インタラクティブ要素 |
| Hover(写真scale) | 700ms | 同上 | Service Cardのみ。1.03倍まで |
| Fade + Rise(出現) | 600ms | cubic-bezier(.16,1,.3,1) | スクロール到達時、下から12px。1要素1回のみ。連続要素は80ms間隔 |
| Slide | 使用しない | — | メニュー開閉もfadeで統一 |
| Scale(モーダル等) | 200ms | 同上 | 0.98→1.0のみ |
| Parallax | scroll連動 | linear | **Hero背景のみ**。移動量は高さの8%まで |
| Page Transition | 200ms fade または なし | — | 凝ったトランジション禁止 |

- `prefers-reduced-motion: reduce` では出現アニメ・Parallaxを必ず無効化。
- 自動再生カルーセル・無限ループ・点滅は全面禁止。

## 12. Copywriting System

**声のルール: 短い。強い。わかりやすい。誇張しない。売り込まない。**

- 文体: です・ます調。一文一義、一文は全角50字以内。
- 主語は「私たち」。お客様を「皆様」と持ち上げすぎない。
- 事業ではなく価値を語る。「保険を販売しています」→「万一の前に、備えの設計を。」
- 数字は正確に、時点つきで。**根拠のない「No.1」「最安」「絶対」「必ず」は禁止。**
- 専門用語は1文に1つまで。使ったら次の文でやさしく言い換える。
- 感嘆符「!」は企業サイトでは使わない。三点リーダーで濁さない。
- 断定できないことは「要確認」「〜を目指します」と正直に書く(グループ共通ルール)。

見出しの型: 「名詞+助詞+動詞。」の短文(例: 未来に、確かな選択肢を。/事業の出口を、設計する。)

## 14. Trust Design(信用の設計)

金融企業の信用は「言う」のではなく「開示の仕方」で伝わる。

| 項目 | 見せ方 |
|---|---|
| 会社概要 | 表組みで淡々と。資本金・登録番号・所属団体を省略しない。「淡々と全部書く」が最も信用される |
| 沿革 | 年表を縦罫線で。創業のきっかけを1行だけ物語る(盛らない) |
| 経営陣 | 横顔・自然光の写真+経歴を事実のみ。座右の銘・笑顔アップは不要 |
| 事業実績・数字 | KPIは必ず「時点・算出根拠」を注記。伸び率だけ見せて母数を隠さない |
| 許認可 | フッター全ページに登録番号を常時表示(例: 金融庁・財務局登録番号、宅建免許番号) |
| 取扱企業・パートナー | ロゴ掲載は許諾を得た先のみ。グレースケール統一で並べる |
| コンプライアンス/情報セキュリティ/個人情報保護/顧客本位の業務運営 | それぞれ独立ページ。方針は経営者の名前で署名する。改定日を明記 |
| ニュース | 更新が止まると逆効果。月1件以上を維持できる運用設計とセットで公開 |
| 採用 | 「人に投資している会社」は信用される。社員の仕事風景を等身大で |
| オフィス | 外観・受付・執務の静景写真。所在地は地図+アクセス手順まで丁寧に |

## 15. Do / Don't

**Do**
- 余白を先に確保し、残った場所に情報を置く
- 白・Off White・Navyの3面だけでページを構成する
- 見出しを削って短くする/数字に時点を添える
- 写真は引き・自然光・低彩度/迷ったらテキストと余白だけで組む

**Don't**
- 3色以上のカラフルな面 / 多色グラデ / ガラス風・ネオン風
- 角丸8px以上の「アプリ風」UI / 吹き出し・イラストキャラ
- 握手・腕組み・札束のストックフォト / カメラ目線の作り笑顔
- 「!」「業界No.1」「今だけ」「無料!!」/ 点滅・自動カルーセル
- 1画面に2つ以上のメッセージ / CTAの乱立

## 16. Design Principles(10原則)

1. **Less, but better.** 減らした分だけ、良くする。
2. **信用を装飾しない。** 開示と秩序で伝える。
3. **1画面1メッセージ。** 2つ言いたければ2画面使う。
4. **余白は情報である。** 詰めた瞬間、焦りが伝わる。
5. **写真は説明ではなく世界観を伝える。**
6. **数字には必ず時点と根拠を添える。**
7. **動きは、気づかれない程度に。**
8. **色は3つで足りる。** 白・紺・余白(そして5%の真鍮)。
9. **流行を採用しない。** 10年後に恥ずかしいものは今も使わない。
10. **迷ったら、静かな方を選ぶ。**
