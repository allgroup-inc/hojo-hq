## 1. 見出しテスト(第1週・提携部)— 生産者10人に読ませて記録する

**やり方**: 下の4つを紙1枚に印刷し、1人ずつ順番を変えて見せる。「どれが自分向きだと感じるか」「どれが一番気になるか」「胡散臭いと感じたものは」を聞き、理由を一言メモ。所要3分。

| 記号 | 見出し | 自分向き(人) | 気になる(人) | 胡散臭い(人) | 理由メモ |
|---|---|---|---|---|---|
| A | あなたの商品を探している海外の買い手に、日本語のまま届ける販路。 | | | | |
| B | 畑と工房はそのまま。海外の売り先だけ、増やす。 | | | | |
| C | 沖縄にいながら、200以上の国と地域のバイヤーへ。 | | | | |
| D(B案) | 「英語ができないから」で、世界をあきらめるのは、今日で終わり。 | | | | |

**判定**: 「自分向き」最多をA案の見出しに。「胡散臭い」が3人以上ついた見出しは使わない。Dが「気になる」最多かつ「胡散臭い」2人以下ならB案の見出しは据え置き。
**ついでに聞く**: 「海外に売ると聞いて、まず何が心配?」(費用 / 英語 / 騙されないか / 手間 / その他)。この答えで、比較表と3つのゼロの順番を入れ替える。
