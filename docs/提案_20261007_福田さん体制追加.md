# 提案: 福田さんをLINE・Instagram管理に追加する体制変更

**提案日**: 2026-10-07  
**提案者**: Claude Code  
**決裁者**: 小柳さん

---

## 📌 概要

福田さんが営業現場で集めた企業データ・訪問ログを、リアルタイムでLINE・Instagram管理システムに統合し、アラート対応・配信設定・分析を一貫して担当する新体制を構築。

---

## 🎯 背景・目的

### 現状の課題
- 福田さんの訪問ログ（企業接触、対応状況）が管理システムにリアルタイム反映されていない
- LINE・Instagram配信の現場ニーズが即座に反映されていない
- 訪問企業のアラート設定・分析が分散している

### 実現する効果
- **リアルタイム性**: 訪問→登録→配信設定が同日完了
- **顧客体験向上**: 福田さんの現場知見がLINE配信タイミング・セグメント決定に即反映
- **データ品質向上**: 訪問ログが構造化データとして蓄積され、分析基盤が充実
- **組織効率**: 訪問と配信管理が一気通貫で行われ、引き継ぎロスが削減

---

## 🔧 体制案

### 組織構成の変更

| 項目 | 現状 | 変更後 |
|---|---|---|
| **福田さんの部門** | glow-ma（営業）| LINE部＆SNS部**兼務** |
| **直属上司** | （未定） | **小柳さん直属** |
| **職責** | 企業営業 | 営業・訪問ログ収集＆LINE・Instagram管理 |

### 福田さんの権限範囲

✅ **単独実行可能**:
1. **アラート確認と返信メッセージ作成**
   - 訪問企業からのLINE返信に対応
   - 返信内容の作成（承認は不要）

2. **LINE配信設定（セグメント、タイミング変更）**
   - 訪問企業に対するセグメント設定
   - 配信日時・タイミング変更
   - 配信内容は既存テンプレートから選択

3. **ダッシュボード・分析レポート閲覧**
   - LINE登録数・開封率・クリック率
   - Instagram フォロワー・エンゲージメント
   - 訪問企業ごとの反応・分析

4. **企業マスタデータの登録・修正**
   - 訪問企業の新規登録
   - 既存企業情報の更新（電話番号、住所、代表者等）
   - 訪問ログの記録（訪問日、対応内容、次回接触予定）

❌ **承認が必要**:
- Instagram投稿スケジュール・コンテンツ（ツナグさん＆ヒロメさんが承認）

## 🔐 セキュリティ・ガバナンス

### アクセス制御
- **LINE公式アカウント**: 福田さんに「配信管理者」権限付与
- **Instagram**: 福田さんに「コンテンツ作成者＆分析者」権限付与
- **glow-ma システム**: 福田さん専用アカウント作成、上記の権限スコープに限定

### 監査・承認
- 福田さんのLINE配信設定変更は月次で監査
- 企業データ登録は監査部門がランダムサンプリング検証
- 異常検知時は小柳さんへ即通知

## 💬 想定される質問・リスク

### Q1: 権限が大きすぎないか？
**A**: LINE配信設定は既存テンプレート内での変更のみ。新規テンプレート作成はツナグさんが承認。企業データ登録も監査対象。

### Q2: 他部門（ツナグさん、ヒロメさん）への影響は？
**A**: 
- **ツナグさん（LINE部）**: 福田さんが日常的なセグメント・タイミング設定を行うことで、ツナグさんはより高度な配信戦略に集中可能
- **ヒロメさん（SNS部）**: Instagram投稿の承認フローは変わらず。福田さんはデータ分析・企業セグメント整理を担当

### Q3: 訪問企業のデータ品質は確保できるか？
**A**: 監査部門が月次でランダムサンプリング。エラー率が閾値を超えた場合は福田さんへ改善指導。
