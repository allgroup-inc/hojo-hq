# もらいわすれ堂 情報拡充プラン(沖縄の人が助かる制度・情報を増やす)

現状: 掲載39件(全国29・沖縄県10・**市町村独自=0**)。カテゴリは子育て/医療/生活支援/住まい/教育/仕事/介護/防災。
狙い: 「沖縄に効く情報」を増やす → 診断が当たる → LINE登録(❹)・受給報告(❷)が増える。
鉄則: 金額・締切・要件は**公式URLと照合**(不明は「要確認」)/ 症状は聞かない(介護・障がい・医療は窓口案内まで)/ 誘導はLINEのみ。

## Tier 1:いちばん効く(沖縄特化の核心)

### 1. 41市町村の"独自制度"を段階掲載(最大の伸びしろ)
いまは市町村ページが「掲載準備中」。ここを埋めると、地域specificで信頼が跳ね上がる(先行の「わたしの給付金」型)。
- まず**人口上位**から: 那覇市・沖縄市・うるま市・浦添市・宜野湾市・名護市・豊見城市。
- 拾う制度例: **こども医療費(現物給付)/ 保育料・給食費・水道料金の減免 / 多子世帯支援 / 妊婦・乳児の助成 / 就学援助(市町村版)**。
- 進め方: 市町村サイトのクロールは**守り部の承認+robots/規約確認が必須**。まずは人口上位5市を**手動で公式照合入力**→順次自動巡回。

### 2. 沖縄ならではの課題に効く制度
- **離島支援**: 離島の高校生の下宿・通学費補助(離島留学)、船賃・航空運賃の補助。
- **子どもの貧困対策**(沖縄は全国最上位の課題): 就学援助、こども食堂、無料学習支援、給付型の進学支援。
- **ひとり親支援の網羅**(沖縄はひとり親割合が高い): 児童扶養手当に加え、母子父子寡婦福祉資金、住宅・就業・医療費助成。

## 仕組み(鮮度と網羅を保つ)

- **収集の自動化拡張**: jGrants(国)+ 県・市町村サイトの巡回を段階拡大(守り部承認の範囲で)。
- **制度改正の反映**: 児童手当の拡充など、変更を早く反映(データ鮮度24時間以内が支持KPI)。
- **「要確認」の解消フロー**: 未確定の制度を検証部が順に確定→バッジ解除。
- **診断ロジックの精緻化**: 所得帯・世帯類型の条件を足して、当たる精度を上げる(安全側に倒す)。

## 🔴 小柳さん/守り部の判断が要る点
- どの市町村サイトをクロール対象にするか(robots・利用規約の事前承認)。当面は**人口上位5市を手動入力**なら承認不要で進められる。
- 掲載順(人口順 or ニーズ順)。
- 介護・障がい・医療の扱い(現行どおり"窓口案内まで"で継続)。

## 効果の狙い(なぜやるか)
掲載制度が増える=**診断の「あなたは◯件対象かも」が増える**=結果画面のLINE誘導が効く=❹登録↑・❷受給報告↑。支持KPI「常時150件以上」への道でもある。
