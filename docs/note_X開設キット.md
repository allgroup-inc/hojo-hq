### X自動投稿を有効にする設定(1回だけ・約20分)
未設定の間も動きます(告知文がLINEに届くので手でコピペ投稿)。自動化する場合:
1. https://developer.x.com で @kekka_mag のアカウントでサインアップ(従量課金プラン。投稿1件$0.015=月数十円規模)
2. アプリを作成 → 「Keys and tokens」で4つの値を発行(App Key/Secret・Access Token/Secret ※権限は Read and write)
3. GitHubリポジトリ → Settings → Secrets and variables → Actions → New repository secret で登録:
   `X_API_KEY` / `X_API_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_SECRET`
4. 以後、publish-record 実行時にX告知(本文+リプ欄URL)が自動投稿される
- 自動化の線引き: 公式APIの告知投稿のみ(規約で許可された範囲)。自動返信ボット・自動フォローはしない
