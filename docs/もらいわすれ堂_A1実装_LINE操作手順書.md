**ボタン4 (右下): 「ℹ️ よくある質問」**

## トラブルシューティング

### Q1: リッチメニューがボタン表示されない

**A**: LINE Official の設定に1〜2分のラグがあります。
- 「編集」画面で「保存」をもう一度クリック
- スマートフォンのLINEアプリを再起動
- 1分待ってから再度確認

### Q2: テスト報告がフォームで送信できない

**A**: LINE Insight API の接続を確認してください。
- 技術部に「scripts/line_insight_connect.py」実行を依頼
- `LINE_ACCOUNT_ID` / `LINE_ACCESS_TOKEN` が正しく設定されているか確認

### Q3: 「制度検索」「診断を再度」のURL先が見つからない

**A**: 上記 Step 3-4 の URL は仮URL です。実際のサイト URL に置き換えてください。
- 制度検索: `https://mikata.okinawa/seido-search` → 実際のURLに変更
- 診断: `https://mikata.okinawa/shindan` → 実際のURLに変更
