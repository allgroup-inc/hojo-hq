## 📊 実装タスク分解（kanri_system/配下）

### Task A: 基本フレーム + 契約情報タブ（10/01〜10/08）

**ファイル構成:**
```
kanri_system/
├── index.html          # ページテンプレート（タブナビ含む）
├── css/
│   ├── enlife-theme.css（ブランド色: #F6C83E/#241F14）
│   └── tabs.css
├── js/
│   ├── app.js          # メインアプリケーション
│   ├── api-client.js   # GET /api/customers/dossier 呼び出し
│   └── tabs/
│       ├── contract-info.js
│       ├── intention.js
│       ├── delivery-mgmt.js
│       └── contacts.js
└── customer_detail.html # メインファイル
```

**実装内容:**
- 顧客ID (KM-) をクエリパラメータから取得
- GET /api/customers/dossier を呼び出し
- 4つのタブナビゲーション
- 契約情報タブを表示（簡易版）
  - 契約者情報（氏名、住所、電話）
  - 保障内容（商品、保障額、保険料）
  - 申込・契約日時

**技術スタック:**
- Vanilla JS（Vue/React は不要。シンプルなタブ切り替え）
- Fetch API（CORS対応）
- CSS Grid（レスポンシブ）

### Task B: 受け渡し・管理タブ（10/08〜10/12）

**実装内容:**
- `hozen_board` データ（GET /api/customers/dossier から取得）を表示
- 以下の項目をテーブルで表示：
  - origin（検知/受付）
  - category（受渡・管理の種類）
  - carrier（保険会社）
  - insurer_request
  - crm_sync
  - contact_method
  - disposition
  - checklists

**注意:** 現在の hozen_board は保全CRM から送信される基本情報のみ。
管理画面側の詳細入力フィールド（delivery_date, qa_confirmed等）は、
軸側の API拡張後に対応。

### Task C: 対応記録タブ（10/05〜10/10）

**実装内容:**
- contacts データ（GET /api/customers/dossier から取得）を時系列で表示

  - when（日時）
  - medium（架電/訪問/メール等）
  - result（結果）
  - goal（目的）
  - staff（対応者）
  - system（システム）
