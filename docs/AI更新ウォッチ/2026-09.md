## 2026年9月反映提案(Claude Code / Anthropic / MCP)

**① Messages API の「オンデマンド圧縮」(ベータ)**
- 何が変わったか: 
The Messages API can now compact a conversation on demand on the Claude API, in beta with the compact-2026-09-04 beta header. Send the top-level compaction parameter, and the API returns a signed compaction block that summarizes the messages you sent.
直近の発言は逐語のまま保持できる。
- 何に使えるか: 「原文照合・要約」バッチで長い会話履歴/原文を都度全量送信せず、圧縮ブロック+直近ターンの逐語データだけを送れるため、トークン消費と処理時間を削減できる可能性(ミカタ/glow-ma/家計見直しの要約系チャットに横展開可)。
- 導入コスト: すぐ試せる(ベータヘッダー追加のみ、既存API利用の範囲内・外部サービス接続なし)
- 出典: https://platform.claude.com/docs/en/release-notes/overview

**② Auto modeのサーバー側分類器化(課金対象外)**
- 何が変わったか: 
Changed auto mode for Claude API and Enterprise users, and on Bedrock, Vertex, Foundry and gateways, to default to the server-side classifier, which does not charge for classifier overhead

- 何に使えるか: Auto modeを使っている呼び出しがあれば、分類オーバーヘッド分のコストが自動的に下がる(要約・照合バッチのコスト効率化)。
- 導入コスト: すぐ試せる(バージョン更新のみで自動適用、外部接続なし)
- 出典: https://code.claude.com/docs/en/changelog

**③ Subagent再開時のMCPツール定義キャッシュ破損バグ修正**
- 何が変わったか: 
Fixed resumed subagents and teammates re-rendering the MCP tool definitions they had loaded, which broke prompt caching for that agent

- 何に使えるか: 接続済みMCPをsubagent経由で使うワークフローで、セッション再開時のprompt cache無効化による無駄な再計算・コスト増を回避できる。
- 導入コスト: すぐ試せる(Claude Code CLIを最新版に更新するだけ)
- 出典: https://releasebot.io/updates/anthropic/claude-code
