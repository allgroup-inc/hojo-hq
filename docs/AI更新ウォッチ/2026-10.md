## 2. Claude Sonnet 5.5 への切替(原文照合・要約API)

- **何が変わったか**: Sonnet 5.5 は Sonnet 5 比で 30% 高速、「ほとんどの用途で最大 30% 安い」(9/28 発表)。API 価格は入力 $2 / 出力 $10(100万トークンあたり)で Sonnet 5 と同じ、**キャッシュ読込は $0.20 → $0.10 に半減**(基本入力の 0.05 倍)。
- **何に使えるか**: 複数チャットでの原文照合・要約処理をコスト増なしで高速化でき、長文資料の一括処理にも余裕が出る。キャッシュを効かせている処理ほど安くなる。
- **導入コスト**: すぐ試せる(APIのモデル指定名を変更するだけ)。
- 出典: https://www.anthropic.com/news (2026-09-28 Introducing Claude Sonnet 5.5) / https://platform.claude.com/docs/en/about-claude/pricing (料金表)

## 3. MCP安定性まわりの修正群

- **何が変わったか**: 
バックグラウンド化したMCPツール呼び出しの進捗通知が破棄される不具合、起動中のstdio MCPサーバーがセッション終了後も残る不具合、ステートレスなリモートMCPサーバーの一時的404でセッション中使用不能になる不具合、有効なURLを持たないMCPサーバーでのサインイン失敗時の不透明なエラーを修正
(v2.1.283, 9/25)。
- **何に使えるか**: 現在接続中のMCPサーバーが切断・再接続時に不安定だった場合の体感改善。原因不明のMCPエラーが減る。
- **導入コスト**: すぐ試せる(Claude Codeアップデートのみ、新規接続不要)。
- 出典: https://releasebot.io/updates/anthropic/claude-code

## 4. 非対話モードでのMCP起動待ち時間制御

- **何が変わったか**: 
CLAUDE_CODE_MCP_STARTUP_WAIT_MSが追加され、非対話的な最初のターンが接続中のMCPサーバーを待つ時間を設定可能に(0にすると待たない)
(9/17)。
- **何に使えるか**: GitHub ActionsでClaude Code(`-p`非対話実行)を回す際、MCP起動待ちによるジョブ遅延・タイムアウトを調整できる。
- **導入コスト**: すぐ試せる(環境変数設定のみ、既存ワークフローへの追記)。
- 注: v2.1.284(9/28)以降、`--allowedTools` や `mcp_tool` hook が名指しする MCP サーバーは `0` でも最大 2 秒待つ(changelog 2.1.284)。
- 出典: https://code.claude.com/docs/en/changelog (2.1.274 / 2.1.284) / https://code.claude.com/docs/en/env-vars
