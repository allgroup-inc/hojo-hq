レポート提示後に適用可否を確認する方式で、ファイルは勝手に変更されない

- 出典: https://code.claude.com/docs/en/memory

## 2. Claude Sonnet 5.5 への切替(原文照合・要約API)

- **何が変わったか**: 
Sonnet 5.5は出力速度がSonnet 5比で30%以上高速化し、API価格は入力$2/出力$10/キャッシュ読込$0.20(100万トークンあたり)と据え置き
(9/28)。
- **何に使えるか**: 複数チャットでの原文照合・要約処理をコスト増なしで高速化でき、長文資料の一括処理にも余裕が出る。
- **導入コスト**: すぐ試せる(APIのモデル指定名を変更するだけ)。
- 出典: https://en.wikipedia.org/wiki/Claude_Mythos (Quick Release Table)

## 3. MCP安定性まわりの修正群

- **何が変わったか**: 
バックグラウンド化したMCPツール呼び出しの進捗通知が破棄される不具合、起動中のstdio MCPサーバーがセッション終了後も残る不具合、ステートレスなリモートMCPサーバーの一時的404でセッション中使用不能になる不具合、有効なURLを持たないMCPサーバーでのサインイン失敗時の不透明なエラーを修正
(v2.1.283, 9/25)。
- **何に使えるか**: 現在接続中のMCPサーバーが切断・再接続時に不安定だった場合の体感改善。原因不明のMCPエラーが減る。
- **導入コスト**: すぐ試せる(Claude Codeアップデートのみ、新規接続不要)。
- 出典: https://releasebot.io/updates/anthropic/claude-code

## 4. 非対話モードでのMCP起動待ち時間制御

- **何が変わったか**: 
CLAUDE_CODE_MCP_STARTUP_WAIT_MSが追加され、非対話的な最初のターンが接続中のMCPサーバーを待つ時間を設定可能に(0にすると待たない)
(9/17)。
- **何に使えるか**: GitHub ActionsでClaude Code(`-p`非対話実行)を回す際、MCP起動待ちによるジョブ遅延・タイムアウトを調整できる。
- **導入コスト**: すぐ試せる(環境変数設定のみ、既存ワークフローへの追記)。
- 出典: https://code.claude.com/docs/en/changelog
