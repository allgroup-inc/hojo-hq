# うごくAIレシピ_note開設キット(小柳さん用・作業約10分)

新路線「うごくAIレシピ」用の**新規noteアカウント**を作るためのキットです。
kekka_mag(フクギ側)・ミカタ名義とは完全に別のアカウントにします(混同表記の防止)。

## 0. 2個目アカウントならではの注意(kekka_magがあるため)

- **作り方が1個目と違う**: ログアウトして新規登録ではなく、kekka_magにログインしたまま
  **マイページ →「アカウント切り替え」→「+アカウントを追加」→「新しいアカウントを作成」**が楽です
  (noteは複数アカウント保有OK・切り替え機能あり)
- **メールアドレスは別のものが必要**(kekka_magと同じメールでは作れません)
- **一番の事故は「切り替え忘れの誤投稿」**: 切り替え式なので、記事を貼る前に
  画面右上のアイコンが**緑のターミナルマーク(うごくAIレシピ)**になっているか毎回確認。
  kekka_mag側にAIレシピ記事を貼る事故が最悪パターンです(逆も同じ)
- **アカウント間の相互スキ・相互フォロー・相互宣伝はしない**: スパム的な不自然な操作は
  制限対象になり得るのと、ブランド分離の方針にも反するため
- 振込口座は同じでOK(売上の区別は各アカウントのダッシュボードとKPI台帳で行う)

## 1. アカウント

- クリエイター名(案): **うごくAIレシピ**
- note ID(案・半角英数): `ugoku_ai_recipe`(取れなければ `ai_recipe_lab` / `ugoku_recipe`)
- メールアドレス: 既存の運用メールでOK(kekka_magと同じメールは不可。note は1メール=1アカウント)

## 2. プロフィール文(コピペ用)

```
コピペで使えるAIの仕事レシピを、週2回配っています。
ここのレシピは全部、公開する前に機械で実際に実行して、動いた実行ログごと記事に載せています。
「読んでみたら動かなかった」をなくしたい、それだけのマガジンです。
中の人は自動化の仕組み(生成も検証も機械)+公開前に目を通す人間ひとり。
```

## 2.5 アイコン・ヘッダー画像(作成済み・ダウンロードして設定)

https://github.com/allgroup-inc/hojo-hq/tree/main/assets/airecipe

- アイコン: `icon.png`(1024x1024。ターミナル黒×実行緑のプロンプトマーク)
- ヘッダー: `header_note.png`(1280x670。note用に作成済み)
- 記事の見出し画像: 毎回 `eyecatch_番号.png` が自動生成され、LINE通知にリンクが付きます

配色はターミナル黒#0D1117×実行緑#3FB950×白。「実行ログ」がブランドの核なので、
ミカタ(ネイビー×オレンジ)・結果マガ(墨黒×黄)・フクギイロ(朱×黄)とは重ねていません。

## 3. 質問箱・その他設定

- 質問箱: ON(レシピのリクエスト受付窓口として使う)
- 振込口座: ミカタ側と同じでOK(売上の受け皿。税理士確認は既存ToDoと共通)

## 4. 最初の1週間の動き

1. アカウント開設 → このチャットにID・URLを報告
2. 火・金 09:35 のLINE通知(🍳【AIレシピ】)から記事を確認 → コピペ公開
   - 「ここから先が有料パートです」の直後に**有料ライン**を設定
   - 価格: **980円**(提案値。変更したい場合はチャットで一言)
3. 最初の2本は**無料公開**も選択肢(実行ログ方式の認知づくり)。判断はお任せ、公開時にどちらにしたか一言もらえれば台帳に記録します

## 5. やらないこと(このアカウントでは)

- 沖縄・補助金・ミカタ・フクギイロの話題(ブランド分離)
- 収益や成果の断定・煽り(記事側でも機械的に禁止語チェック済み)
- 非公式ツールでの自動投稿(公開はコピペのみ)
