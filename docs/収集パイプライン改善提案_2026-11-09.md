SNS に使える制度が月2件しかないのは、「沖縄の制度が無い」からではなく、主に次の3つが原因です。

## 2. 原因

| # | 現象 | 原因(コードの場所) |
|---|---|---|
| A | 公社9件が全件「要確認」 | `fetch_local.py` の公社ソースが `fetch_detail: False`。「本文の囲み(`<main>`)が無く、終了判定を誤りやすい」ため詳細ページを読んでいない |
| B | 県6件が「要確認」 | 詳細は読んでいるが、締切の書き方が抽出ルール(「募集期間」等の直後80文字以内の日付)に合わない、または補助金ではないページ |
| C | 補助金でないページが混ざる | 県の一覧に委託・イベントも並ぶが、県ソースには名前の絞り込みが無い(那覇市には有る)。目次ページ(`/index.html`)も除外していない |
| D | 「令和5年…」の古いページが残る | 古い年度の除外は「令和N**年度**」だけを見ており、「令和5**年**」をすり抜ける |
| E | 那覇市が0件 | 9月中旬から。一覧・詳細の取得結果は Actions の一時ファイルにしか残らないため、ここでは特定できない(要: Actions のログ確認) |
| F | 沖縄限定でないのに okinawa | `fetch_jgrants.py` の `decide_tag` が「対象地域に『沖縄』を含むか」で判定。全都道府県を並べた制度も「沖縄」を含むので okinawa になる |
| G | 他県・他市の制度が出る | jGrants 上の対象地域が「全国」になっている(京都市・倉敷市など)。地域の判定は対象地域欄しか見ていない。サイト(`site/index.html`)も全国はそのまま表示する |
| H | 「交付申請等」が出る | 採択後の手続き用の受付も、jGrants では「募集中」として返る。区別していない |
| I | 定番制度が無い | jGrants 以外の窓口(IT導入・省力化・雇用関係)を集める仕組みが無い。それらのサイトは守り部の未審査 |
| J | issuer・業種が空 | 一覧APIの `institution_name`・`industry` が空のことが多い。空のとき `subsidy_catch_phrase`(宣伝文句)で埋めるため、制度名が入る |
| K | 照合結果が消える | `preserve_fields.py` は `data/subsidies.json.backup` から前回値を戻すが、このファイルはリポジトリに無い。CI では毎回「取得後のデータ」でバックアップを作るので、戻すものが無い |

### 注意: 件数の安全装置にかかる

`guard_subsidies.py` は合計が **100件未満**、または前回から **15%を超えて減る** と公開を止める。
案2・3・6を一度に入れると 121 → 約103件(約15%減)で、ぎりぎり止まりかねない。
**除外は2回に分けて入れる**か、除外した件数を「減少」に数えない形で安全装置を直す(閾値・ルールの変更なので議事が要る)。
