# ヤンバルクイナ キャラクター化プロンプト集(Tシャツ / ステッカー用・10方向)

作成: 2026-08-17 / 用途: グッズ(Tシャツ・ステッカー)向けオリジナルキャラクターの画像生成

---

## 0. 前提:世の中で「愛されてバズる」キャラの共通性質

10方向すべてに、下記の性質を意図的に仕込んでいる。

| # | 性質 | 中身 | ヤンバルクイナへの当てはめ |
|---|---|---|---|
| 1 | ベビースキーマ(幼児図式) | 頭が大きい / 目が顔の下half寄り / 目が離れている / 口が小さい / 顎が丸い | 2〜3頭身、目を下寄せ、くちばしを小さく丸く |
| 2 | シルエット認識 | 影だけで誰か分かる | 「丸い体+短い翼+長い赤脚」の輪郭を崩さない |
| 3 | 識別マーク(1つだけ強い記号) | 記憶のフック | **白い眉線** と **腹の白黒ストライプ**。この2つは全方向で残す |
| 4 | 欠点・隙 | 完璧なキャラは愛されない。だらけ・弱い・不器用が刺さる | **「飛べない」**。これが最大の資産。自虐にも励ましにも変換できる |
| 5 | 色数が少ない | 3〜5色。グッズ化コストが下がり、模倣・展開もしやすい | 黒 / 白 / 朱赤 / オリーブ褐色 + 差し色1 |
| 6 | 表情展開できる構造 | スタンプ・シリーズ化の前提 | 目と眉線だけで感情が変わる設計にする |
| 7 | 短く呼べる名前 | 3〜4音 | 名前案: **クイナん / トコトコ / やんばるん / クーイ** |
| 8 | 文脈が一目で分かる | ご当地・自分ごと化 | 沖縄・やんばる・国頭。走る、木に登って寝る |

**素材としてのヤンバルクイナの実物特徴(崩さない範囲で使う)**
飛べない / 走るのが速い / 夜は木に登って寝る / 朱赤のくちばしと脚 / 黒い顔に白い眉線 / 腹に白黒の横縞 / オリーブ褐色の背 / 絶滅危惧種・国頭村周辺のみに生息。

## 0-1. 共通の素体定義(全プロンプトに前置きして使う)

生成モデルにそのまま貼れる「素体ブロック」。方向ごとにこの後ろへスタイル文を足す。

```
An original cute mascot character based on the Okinawa rail (yanbaru kuina),
a flightless ground bird: dark olive-brown back, black face with a crisp white
eyebrow stripe running from the beak back over the eye, bright vermilion-red
beak, bright red legs, black-and-white horizontal stripes across the belly,
short rounded wings that cannot fly.
Chibi proportions, 2.5 heads tall, round body, large eyes placed low and wide
apart on the face, tiny beak-mouth, no nostrils, simplified feet with three toes.
Limited palette of 4-5 flat colors. Centered, full body, plain background.
```

**共通ネガティブ(対応モデルのみ)**
```
realistic feather texture, long thin beak, webbed feet, crest, human hands,
extra limbs, busy background, drop shadow, gradient mesh, watermark,
garbled text, photo-realistic eyes
```

## 1. よわよわミニマル型 —「守りたくなる弱さ」

**狙い**: 性質4(欠点)と1(幼児図式)を最大化。細く均一な線・淡い色・震え線で「弱いけど頑張ってる」を出す。スタンプ展開が最も強い方向。
**向き**: ステッカー◎ / 白・淡色Tに胸ワンポイント小さく

```
[共通素体] + Minimal kawaii illustration style. Very thin uniform black outline
(1px feel), soft off-white body, pale colors, no shading. 2.2 heads tall.
Eyes are two small solid dots placed very low on the face, wide apart. Tiny
"ω"-shaped mouth. Slight tremble lines around the body, tiny sweat drop,
teary shine in the eyes. Standing awkwardly with both stubby wings held up,
as if trying and failing to fly. Naive, hand-drawn, wobbly line quality.
Flat white background. Sticker-friendly, high contrast, 1:1 square.
```

**展開ネタ**: 「とべない」「でも はしれる」「きょうも いきた」

## 2. パステル・ファンシー雑貨型

**狙い**: 性質1+5。文具・雑貨売り場の文脈。淡色ボディのTシャツ、女性向けステッカー。
**向き**: Tシャツ(淡色ボディ)◎ / ステッカー◎

```
[共通素体] + Soft pastel kawaii stationery style. Rounded even outline in warm
dark brown instead of black. Cream body, muted sage-olive back, coral-pink
beak and legs instead of harsh red. Big round blush circles on both cheeks.
Two large highlights in each eye. A small ribbon on the head. Sitting with
legs tucked, wings resting on the belly. Tiny sparkles and one small hibiscus
flower beside it. Flat pastel colors, no gradient. Plain cream background.
1:1 square, sticker die-cut friendly.
```

**展開ネタ**: 月替わりで小物(月桃・さんぴん茶・シーサー)を持たせてシリーズ化

## 3. ゆるキャラ・着ぐるみ型(自治体マスコット系)

**狙い**: 性質2+5。遠目・小サイズでも判別できる太い輪郭。イベント配布・商工会や自治体との協業に耐える体裁。
**向き**: ステッカー(配布用)◎ / Tシャツ胸中央◎ / のぼり・POPにも転用可

```
[共通素体] + Japanese regional mascot (yuru-chara) design, drawn as if it were
a costumed mascot suit. 2 heads tall, very round pot-belly body, short stubby
limbs, thick uniform black outline (heavy weight), completely flat fill,
only 4 colors. Oversized head, permanently smiling closed beak, simple dot
eyes with the white eyebrow stripe as the main identifying mark. Standing
front-facing, arms out, friendly and approachable. Slight seam lines suggesting
a mascot costume. Flat single-color background. Clean vector look, 1:1 square.
```

**ブランド寄せ版**: 差し色をネイビー #00335C とオレンジ #F88800 に置換すると「沖縄企業のミカタ」文脈でそのまま使える(ハチマキ or 小さな帽子で色を乗せる)。

## 4. 脱力・自虐ネタ型(だらけ系)

**狙い**: 性質4を全振り。「飛べない」を明るい自虐に変える。コピー主役のTシャツ用に**余白を空ける構図**で生成する。
**向き**: Tシャツ◎(文字とセット) / ステッカー◎(PC・ノート貼り)

```
[共通素体] + Deadpan lazy mascot style. Lying face-down and sprawled flat on
the ground, both short wings spread out limply, legs stretched behind, cheek
squished against the floor. Half-lidded expressionless eyes, flat mouth, one
tiny sigh puff of air. Muted desaturated palette, soft flat shading, no outline
on the body interior. Deliberately large empty space above the character for a
text line. Plain light background. Simple, calm, comedic. 1:1 square.
```

**展開ネタ(コピー)**: 「とべないので、はしります。」「羽はある。使わないだけ。」「本日、地上勤務。」

## 5. モンスター・進化型(かっこかわいい)

**狙い**: 性質2+3を「強さ」方向へ。走行スピードという実際の特徴を能力に翻訳。男性・キッズ向け。
**向き**: Tシャツ バックプリント◎ / ダイカットステッカー◎

```
[共通素体] + Cute-cool creature design, like a collectible monster. 3 heads
tall, slightly more athletic build, sleek olive-brown back, sharp vermilion
beak, powerful long red legs. Dynamic running pose in profile, one leg forward,
body leaning, motion speed lines trailing behind, small dust puffs at the feet.
Determined confident eyes with a bright highlight, the white eyebrow stripe
drawn as a sharp streak. Bold clean outline of varied weight, cel-shaded with
two tones. Dark background for contrast. Dynamic, energetic. 1:1 square.
```

**展開ネタ**: 「たまご→ヒナ→成鳥」の3段階を並べた進化図デザイン(バックプリント映え)

## 6. 北欧フラット2色型(大人が着られる)

**狙い**: 性質5を極限まで。2色・線一定・余白多め。子供っぽくならず、大人のトートやTシャツに乗る。
**向き**: Tシャツ(生成りボディ)◎ / 上質紙ステッカー◎ / トート・手ぬぐい

```
[共通素体] + Scandinavian flat picture-book illustration style. Only two colors:

## 9. ストリート / カレッジロゴ型

**狙い**: 性質2+3。マスコットヘッドの紋章化。刺繍・シルク印刷に強い版数の少なさ。
**向き**: Tシャツ(胸ワンポイント・バック大)◎ / キャップ刺繍 / ダイカットステッカー

```
[共通素体] + Vintage American college sports mascot logo. Bold head-only bust,
three-quarter angle, confident smirking expression, exaggerated angular white
eyebrow stripe, thick vermilion beak. Heavy black keyline plus a second offset
outline, only three flat colors (navy, cream, vermilion). Screen-print ready,

## 12. 制作・印刷の実務メモ

**ステッカー**
- 生成は 1:1 正方形。実寸 50〜70mm を想定し、**5cm に縮小して潰れないか**を必ず確認
- 白フチ 2〜3mm、線幅は実寸 0.5mm 以上。300〜350dpi
- 背景透過 PNG。生成物は背景が残るので切り抜き必須(Gemini の編集機能 or 手動)

**Tシャツ**
- 胸ワンポイント 幅 90〜100mm / バックプリント 幅 280〜300mm
- シルクスクリーン = 3〜5色に抑える(方向 3・6・9 が最適)。DTF/インクジェットならフルカラー可だが**淡い階調は飛ぶ**
- 濃色ボディに乗せるなら白ベース版が必要。方向 6・9 は色を反転させて対応

**モデルの使い分け**
| 方向 | 推奨モデル | 理由 |
|---|---|---|
| 1・2・4・6 | Gemini(Nano Banana)/ Recraft V3 | フラット・線画・ベクター寄りが安定 |
| 3・5 | Flux Pro / Gemini | ポーズと立体感の再現 |
| 7 | Flux Pro 1.1 | 質感・ライティングの写実性 |
| 8・9(文字入り) | **Ideogram 3.0** | 文字を破綻させずに描ける唯一級 |
| 10 | Midjourney / Flux | 装飾密度と様式美 |

**キャラの一貫性を保つ**
最初の1枚が決まったら、その画像を**参照画像として渡して**(Flux の multi-reference / Gemini の画像入力)以降を生成する。テキストプロンプトだけで同一キャラを再現し続けるのは不可能。

## 13. 権利・表現上の注意(守り部確認事項)

1. **既存キャラ名をプロンプトに書かない**。「◯◯風」と固有名を入れると作風の模倣ではなく複製に近づき、権利上のリスクと出力の類似度が同時に上がる。本書の10方向はすべて**属性の記述のみ**で構成している(意図的)
2. **生成後に必ず類似チェック**。国頭村・沖縄県・環境省などの既存ヤンバルクイナ公式マスコットと酷似していないか、画像検索で目視確認してから商品化する
3. **ヤンバルクイナは国の天然記念物・絶滅危惧種**。「飛べない」は自虐ネタとして使ってよいが、**捕獲・食用・轢死などを想起させる表現は不可**。轢死事故は現実の保護課題であるため、走らせる構図に車を併置しない
4. **商標**。キャラ名を本格運用するなら、J-PlatPat で先行商標を確認してから展開する
5. 生成AIの出力を商用利用する場合、**利用するモデルの商用利用規約を確認**(Midjourney は有料プラン必須など)

## 14. 次の一手(推奨)

まず **方向 3(ゆるキャラ)・方向 4(脱力自虐)・方向 9(カレッジロゴ)** の3本を各4枚ずつ生成して比較する。理由:
- 3 = 配布・協業でいちばん潰しが効く
- 4 = 「飛べない」という最大の資産を最も直接的に使う。バズるならここ
- 9 = Tシャツとして単価を取れるのはこの系統

選定後、表情シート → ステッカー入稿データ → Tシャツ版数調整、の順に落とす。
