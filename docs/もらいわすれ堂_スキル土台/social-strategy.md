# social-strategy — もらいわすれ堂のSNS戦略

## 1. 目標(4目標_KGI 2026-08-02 小柳さん確定)
```
❸Instagram・検索 → ❶サイト流入 →(3分診断)→ ❹LINE登録 →(受給フォロー)→ ❷受給報告
```
| 目標 | 1年後 | 月次ペース |
|---|---|---|
| ❸ Instagram フォロワー | 1,000人 | 約85人 |
| ❶ サイト利用者 | 月1万人 | 逓増(3か月2,500→6か月5,000) |
| ❹ LINE登録 | 1万人 | 約835人 |
| ❷ 受給報告 | 1,000件 | 約85件 |
- ❷が北極星、❹が主エンジン。**フォロワー数は通過点**。SNSで見るのは到達(非フォロワー比率)・送信・保存・プロフィール訪問・LINE登録

## 2. 主戦場と面ごとの役割
- **主戦場は Instagram**(@moradou.okinawa)。LINEは転換と継続の場
- 面ごとの役割(混ぜない):
  - **リール = 到達**(非フォロワーへの発見)。最初の3秒で止め、送りたくなる結末で終える
  - **カルーセル = 保存**(制度の準備シート・チェックリスト型)
  - **ストーリーズ = 継続**(質問・アンケート・受け取れましたのこえ)
  - 写真単体 = 発見は弱い。シリーズのサムネ用途に限る
- 発見の鍵は**キーワード**(キャプション冒頭・画面内文字)+ハッシュタグ5個以内(IG運用v2)。「沖縄 給付金」「児童手当 高校生」など、検索される言葉を1行目に置く

## 3. 動画シリーズの置き方(2026-10-02)
| 動画 | 役割 | 置き場所 |
|---|---|---|
| あかりの島(60秒ブランドアニメ) | 「何のサービスか」を感情で伝える。プロフィール固定1件目 | リール・プロフィール固定 |
| 使い方(118秒) | 調べる→選ぶ→準備する→LINE。固定2件目 | リール・固定 |
| LP紹介(71秒) | サイトの見方をゆっくり | リール |
| 制度メモ #1〜#3(30秒) | 制度ひとつを30秒で。シリーズ化して継続 | リール・固定3件目は#1 |

## 4. 試し方
- **トライアルリール**(非フォロワーにだけ先に出す)で、フック違いの2本を試してから本投稿する
- 同じ動画の冒頭3秒だけ変えた版を作り、どちらが見られたかをインサイトで比べる(audience.md 5)

## 5. 体制と頻度
- 遥さん: 画像・音入れ・投稿・インサイトの数字転記(週1回・5分)
- AI(このリポジトリの週次ループ): ネタ出し・キャプション・ハッシュタグ・出荷ゲート・週次レポ
- 頻度は**週3本(月・水・金)**を上限の目安にし、下限は週1本。守れない週は本数を落として連続を切らない
- 詳細の回し方は content-pillars.md とIG運用v2 §3〜4

## 6. 計測(嘘をつかない)
- Instagramインサイトから: 到達(うち非フォロワー)、送信、保存、プロフィール訪問、フォロー
- サイト側: Plausible(utm_source=instagram)→ 診断実施 → LINE登録(`/go/ig/`)
- 取れない数字は「未接続」と書く。推測の数字を出さない
