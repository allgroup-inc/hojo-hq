# voice — もらいわすれ堂の声

## 1. 指紋(ひと目で「らしい」と分かる特徴)
- **やさしい日本語**。中学生に伝わる。専門用語には言い換えを添える(「被扶養者(扶養に入っている方)」)
- **断定しない、でも寄り添いは断定する**。制度は「〜の可能性があります」。気持ちには「途中でやめても大丈夫」「対象か自信がなくても大丈夫」
- **主語は「あなた」**。私たちの自慢をしない。「はじめました」は言っても「すごい」は言わない
- **短い文。読点で一拍**。「知らなかった。それだけで、受け取りそびれる。」のリズム
- **数字は根拠つきで、ひかえめに**。「200以上」(掲載件数)は言える。金額は言わない(要確認が残るため)
- **誠実さを隠さない**。「要確認」と正直に書く理由を、そのまま語る
- 絵文字は 🌳🌿 を控えめに(動画キャプションでは無しでもよい)

## 2. 1行目(フック)の型 — Instagramは最初の約125字で勝負
OKの型(どれも事実から取る):
- 「知らなかった」だけで、受け取りそびれる。
- 児童手当、いまは高校生年代まで。「うちはもう対象外」のままになっていませんか。
- 名前も住所もいりません。沖縄の給付金・手当を、3分でたしかめる方法。
- 締切の7日前に知っても、書類は間に合いません。(→ だから約1か月前から)

NGの型:
- あいさつ(「こんにちは!」「今日は〜」)、画像の説明、ハッシュタグ始まり
- 「〇〇万円もらえる!」(金額の断定)、「知らないと損!」(煽り)、「誰でも」

## 3. 本文の型
1. 1行目で開いた問いに、短く答える(制度名・だれが対象になりうるか・窓口)
2. 「ぜんぶ覚えなくていい」「まず3分で」と、負担を下げる一言
3. CTAは**1つだけ**: 「3分診断は、プロフィールのリンクから(無料・匿名)。」
4. 締めの注意書き(制度に触れた投稿は必須):
   - ※対象になるかの最終判断は各窓口で行われます。
   - ※金額・手続きは必ず公式ページでご確認ください。(金額に触れたとき)

## 4. 言い換え表
| 言わない | 言う |
|---|---|
| もらえる / 必ず / 確実に / 誰でも | 受け取れるかもしれない / 対象となる可能性があります |
| 締切7日前にお知らせ | 締切の約1か月前からお知らせ |
| 申請を代行します / 書きます | 準備シートがあります / 書くのは本人、専門家は提携先をご紹介 |
| 損 / 損してる | 受け取りそびれる / もらい忘れ |
| 振り込まれました(こえ) | 受け取れました(こえ)。例: 「最初は出来るか心配でしたが、きちんと受け取ることができました」「面倒なことが少なく振込みがありました」 |
| 今すぐ登録! | まずは3分、ためしてみませんか |
| URLをここに | プロフィールのリンクから |

## 5. 文例(そのまま声の見本にする)
- 沖縄の給付金や手当、「知らなかった」だけで受け取りそびれる。それがいちばんもったいない。
- 私たちのサイトには「要確認」という表示がたくさんあります。かっこ悪く見えるかもしれません。でも、確認しきれていないことを断定して書くほうが、ずっと不誠実だと思っています。
- 「診断」と聞くと、個人情報を入れる気がして身構えますよね。もらいわすれ堂の3分診断は、名前も住所もいりません。
- 制度は、自分からは来てくれません。知らなければ、あかりは届かない。

## 6. 機械で止まる表現(`scripts/shipping_gate.py`)
「締切7日前」「7日前にお知らせ」「必ずもらえ/受け取れ」「確実にもらえ/受給」「誰でももらえ/受け取れ/申請できま」「https://lin.ee/」。
出荷前に `python scripts/shipping_gate.py --check <ファイル>` を通す。
