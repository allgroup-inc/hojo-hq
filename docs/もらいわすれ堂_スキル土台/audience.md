## 1. 主な世帯(制度DBの分類と重ねている)

## 2. 共通する気持ち
- 「うちは対象外かも」と思ったまま、何年も経っている
- 「診断」と聞くと個人情報を入れる気がして身構える → 匿名・端末内処理が刺さる
- 役所のページは正しいが、読めない・探せない
- 締切ぎりぎりに知ると書類が間に合わない → 約1か月前からのお知らせ

## 3. だれが、だれに送るか(送信=Instagramの最重要シグナル)
- 子育て中の友人どうし(「これ、うちも対象かも」)
- 娘・息子 → おじい・おばあ(「年金のほかにもあるみたい」)
- 妊娠中の友人へ(「出産のときのお金、知ってた?」)
- 自治体・支援団体の職員が住民へ(「公式リンクつきで分かりやすい」)
→ 動画・投稿の終わりに「そっと送ってあげてください」と、押しつけない一言を添える

## 4. 避けること
- 症状・病名・障がいの程度など要配慮個人情報を聞かない・書かせない
- 「損」「煽り」で動かさない。安心で動いてもらう
- フォロワー数を目的にしない(到達・送信・保存・プロフィール訪問・LINE登録を見る)

## 5. 計測で確かめること(仮説のまま書かない)
- 投稿時間帯・曜日: 仮説は平日夜と週末朝。Instagramインサイトで確かめてから固定する
- 刺さる柱: 保存数・送信数が多い柱を週次レポに1行記録し、次週の比率に反映する
