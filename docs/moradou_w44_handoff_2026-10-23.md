## 【背景】新しい運用プロセス（2026-10-23 決定）

遥さんからの課題報告（2026-10-05: 投稿台帳混乱・重複請求・一次情報未照合等）を受けて、以下の決定を実施:

### 課題と対応
| 課題 | 対応策 |
|---|---|
| 投稿台帳混乱 | メール依頼テンプレート化 → 履歴が自動保存される |
| 重複請求 | 生成スクリプト `generate_ig_neta.py` で自動チェック → 重複防止 |
| 一次情報未照合 | `hojo-accuracy-check` スキル + Gemini ダブルチェック |
| URL誤り・文言不正確 | `humanizer` スキル + 正規表現チェック |
| 根拠不明 | 各投稿に `source_url` を付記（遥さん側で参考可能） |
| 締切管理 | メール件名に期限を明記 + 営業日ベース計算 |

### 新フロー（シンプル化）
1. **自動生成**: `generate_ig_neta.py` が seido.json から投稿案を生成
2. **品質確保**: 検証スクリプト（accuracy/humanizer）が自動チェック
3. **遥さんへ**: メール依頼テンプレート（コピペするだけ）
4. **投稿**: コピペ → 投稿日予定を記入 → 完了報告
5. **計測**: GA4 + Instagram Insights で自動記録

**特徴**:
- Notion や Google Sheets の複雑な台帳が不要
- メールの履歴が自動で投稿台帳になる
- スクリプトが検証を自動で行う
- 遥さんの負荷: コピペと投稿日の記入のみ
