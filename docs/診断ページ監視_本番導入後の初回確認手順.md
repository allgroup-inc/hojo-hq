## 6. LINE(送らずに確かめる)

- [ ] Actions → `diagnosis-line-sender` → Run workflow → mode に `check` を選んで実行(LINE確認モード。送らない・記録も書き換えない)
- [ ] Summary に「送信枠: type=… / 上限=… / 今月の使用=…」「判定: 送れる(残り◯通)」「監視からの送信: 直近24時間 ◯/3通・直近30日 ◯/15通」が出る
- 「判定: 送らない」の場合は理由が出る(残り50通以下・取得できない・形式が想定外)。このとき監視からの通知は Issue にだけ残る
- 児童扶養手当の欠けの知らせ(手順5)は、LINE でも1通届く見込み(監視の上限 24時間3通・30日15通に数える)
- 送る順は 診断ページの障害 → 監視システムの故障 → 制度データの注意。制度データの注意は最後の1通を診断ページの障害のために残すので、24時間に2通まで
- 1回の起動で送るのは1通。複数の通知が重なったときは、次の起動(監視の完了ごと・毎時2回の見回り)で順に送る
- **残る制約**: 優先順位は監視の上限(24時間3通・30日15通)の中での順番。LINE の今月の残りが50通以下になると、診断ページの障害も LINE では送らない(Issue には残る)。確認モードで残り通数を見る
