## 完了した実装

kakei-crm で、限定区画（体況③）の API ベース実装が完了しました。

### ① 基盤層実装

**API エンドポイント**: `POST /api/customers/view-limited-section`
- **入力**: customer_id (必須)、section (デフォルト: "med")、reason (監査ログの理由)
- **出力**: `{"recorded": true, "customer_id": "...", "section": "...", "content": {...}}`
- **権限チェック**: PERMISSION_SENSITIVE_VIEW（fail-closed 設計）
- **監査**: すべての閲覧を `_record()` で自動記録

**method**: `core/api.py` の `view_limited_section()`（line 1403）  
**endpoint**: `core/http_api.py` の POST ルーティング（line 164）

### ② フロントエンド実装（crm_call.html）

3つの限定区画を API経由で実装：

| 項目 | section | 関数 | 権限理由 |
|---|---|---|---|
| 既往症 | `med` | `openMed()` | `架電画面 営業マンリスト管理 既往症開示` |
| 商品提案 | `proposal` | `openProposal()` | `架電画面 営業マンリスト管理 商品提案` |
| 案内時期 | `contact_timing` | `openContactTiming()` | `架電画面 営業マンリスト管理 案内時期` |

**特徴**:
- **非同期 API 呼び出し**: KK.call() で権限チェック
- **権限がない場合**: PermissionDenied（本文は一切返さない）
- **権限がある場合**: 本文を返して限定区画を表示
- **オフライン互換性**: KK.enabled() が false の場合は従来の直接 DOM 操作にフォールバック
- **監査ログ**: すべての閲覧が記録される
