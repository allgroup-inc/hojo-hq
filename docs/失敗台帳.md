## 記入ルール
- 48時間以内に記録(まず事実だけでよい。真因・対策は後から埋める)
- 分類: 事故 / 未達 / 商流 / ヒヤリハット / プロセス

- 行の削除は誰にもできない。クローズ後も残す(この台帳自体が組織の学習資産であり、新エージェント・新施策の必読資料)
- **技術修正・三名体制議事で解決済みでも記録は省略しない**(FK-003・FK-004は個別チームが議事で真因・対策まで完了させた後、本台帳への記録だけが素通りしていたことが2026-08-17の点検で判明。「直したから記録不要」は本台帳の原則「記録されなかった失敗は、必ずもう一度起きる」に反する)
