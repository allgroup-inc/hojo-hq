## 残り(人の作業が要るもの2つ)

### ① LINE公式アカウントの開設(山梨版用)

もらいわすれ堂・沖縄のLINEは沖縄向けの配信をするため、山梨は別アカウントが安全です。

1. LINE公式アカウントを新規作成(名義: 株式会社フクギイロ / 名前案「もらいわすれ堂 山梨」)
2. あいさつメッセージは沖縄版の文面(docs/フクギイロ_LINE運用原稿.md)を山梨向けに差し替え
3. できあがったら**ベーシックID(@〜)と友だち追加URL**をClaudeのセッションへ伝える

→ 伝えてもらえたら、サイト側はこちらで接続します(具体的には: `/go/` に山梨用の
転送ページを新設・計測イベント名は `line_redirect` と**必ず別名**にする
[go-link-discipline準拠]・各ページのLINEボタンを有効化・「もらえた報告」を
ワンタップ送信に切替)。

### ② 山梨県+27市町村への掲載確認(市町村独自の制度を載せるため)

国の制度は各省庁の公開ルール(PDL1.0)で掲載済み。**自治体独自の制度**は、
沖縄版と同じく「先に確認してから載せる」を守ります。

1. まず機械調査: 各自治体サイトの利用規約・robots.txt をこちらで一括確認できます。
   「山梨の自治体サイトの規約調査をやって」とClaudeへ指示してください
   (沖縄版の `audit_terms_fukugiiro.py` と同じやり方。調査は規約ページを読むだけで、
   制度データの収集はまだしません)
2. 規約で確認しきれない自治体は電話(台本は下記)。**OKが取れた自治体名を伝えて
   もらえれば、その自治体の制度データの収集と掲載を始めます**
3. 沖縄版と同じく、確認が取れた自治体から `area==市町村名` のデータを足せば
   市町村ページに自動で混ざる作りになっています

**電話の台本**(そのまま読めます):

> 「株式会社フクギイロの◯◯と申します。山梨県民向けに、国や市町村の給付金・手当の
> 情報をまとめて無料で案内するサイト『もらいわすれ堂』を運営しております。
> 2点だけ確認させてください。
> ① 御市(町村)のサイトに掲載されている制度の名称・窓口・ページのURLを、
> 出典として「◯◯市ホームページ」と明記し、必ず公式ページへリンクする形で
> ご紹介してもよろしいでしょうか。文章の丸写しはいたしません。
> ② 情報を最新に保つため、プログラムで1日2回、間隔をあけて該当ページを自動で
> 確認しています。サーバーに負荷はかけません。こちらも問題ないでしょうか。」

## データの更新のしかた(こちらの作業・メモ)

沖縄版の制度データ(全国ぶん)が更新されたら、次の3つを実行して再コミットする:

```
python3 scripts/build_yamanashi_site.py            # データ抽出+制度一覧
python3 scripts/generate_yamanashi_kit_pages.py    # 申請準備シート53+1
python3 scripts/generate_yamanashi_area_pages.py   # 市町村27+1
```

(沖縄版は fetch のたびに自動再生成される。山梨版の自動化は運用が回り始めてから
組み込む — 先に仕組みだけ増やさない)
