# もらいわすれ堂 ロゴガイド v1(2026-08-07 小柳さん決裁・確定)

## 確定ロゴ:「虹と朝日(おはなのひざし)」
沖縄の空に架かる三色の虹と、花びらのようなひざしを持つ朝日。

- **虹 = 懸け橋**: 制度(ささえ)と県民をつなぐ、もらいわすれ堂の役割
- **三色**: 珊瑚 #D2694A(外)/ 陽 #F2C14E(中)/ 海 #6FAEA4(内)——ブランドの主要3色そのもの
- **朝日(おはなのひざし)**: 花びら状のひざし(#F5CE6E)+中心 #F2C14E。「とどけ、沖縄のみらいへ。」の"のぼる朝日"であり、太陽なのにお花にも見えるかわいさが沖縄の女性層に寄り添う
- **タイル**: 角丸18/64・グラデーション #FAECDC→#F5E0CE(漆喰の暖かさ)

## 使い方のルール
1. 色・形・比率は変更しない(縮小はSVGのまま/最小表示はヘッダーの28px相当まで確認済み)
2. 背景が濃い場所ではタイルつき(icon-512-tile)を使う
3. 虹だけ・朝日だけの単独使用は不可(意味が半分になるため)。例外: フィルム内アニメーション演出
4. 旧ロゴ(フクギの葉と太陽・〜2026-08-07)は今後使用しない
