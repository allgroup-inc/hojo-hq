# ホテル・小売架電リスト自動化ガイド

## 概要
沖縄県内の M&A 有望企業（ホテル・小売）の架電リスト を自動生成・インポートするプロセス

**原則**: 絶対ルール1「原文URL照合」を厳格に守る。公開情報のみ使用。推測・合成は禁止。

## 対象地域
- **本島(沖縄本島)のみ**
- 除外: 石垣島、宮古島など離島

## データ源(公開情報のみ)

### 1. 公的統計・オープンデータ
- **法人番号公表サイト** (国税庁)
  - 業種・所在地・代表者名などを確認可能
  - URL: https://www.houjin-bangou.nta.go.jp/

### 2. 企業公式サイト
- 企業Webサイトのプロフィール、会社情報ページ
  - 客室数、代表者名、電話番号
  - 複数施設情報（地場運営会社の識別に有用）

### 3. 観光庁・県庁の公開DB
- **宿泊施設登録簿**(都道府県観光課公開)
- **観光地の宿泊統計**

### 4. ビジネスディレクトリ
- Yahoo!ビジネス、goo地図、GoogleMap（電話番号確認用）
- 注意: これらは参考情報のみ。最終確認は公式サイト

## ランク付けルール

| ランク | 基準 | 例 |
|---|---|---|
| **A** | 客室100室以上 または 複数施設地場運営 | 大型ホテルチェーン(独立系) |
| **B** | 客室30〜99室 | 中堅ホテル |
| **C** | 客室30室未満 または 規模情報なし | 小規模宿泊施設・ゲストハウス |

**除外条件**:
- 全国大手チェーン直営(Apa, Toyoko Inn, Daiwaロイネット等)
- 外資系資本の運営会社(Accor, Marriott, Hilton等の子会社)
- M&A対象外(親会社が大手で独立性なし)

## インポート手順(Google Apps Script)

### 前提条件
- ImportRunner.gs の IMPORT_COLUMN_MAP が以下を含む:
  ```javascript
  "ランク": "ランク",
  "流入ルート": "流入ルート",
  "備考": "業態メモ"
  ```

### ステップ

1. **CSV を生成**
   ```bash
   python3 generate_hotel_list.py
   # → GLOW法人リスト_ホテル_本島_YYYYMMDD.csv を出力
   ```

2. **スプレッドシートへアップロード**
   - GLOW管理シートの「インポート待ち」タブを開く
   - CSV ファイルの全行をコピー
   - シートへペースト(1行目=見出し)

3. **Apps Script でインポート実行**
   - エディタで `importCompaniesFromStaging()` を実行
   - ログで「インポート完了: 新規読込 XX件」を確認

4. **企業マスタで確認**
   - 「流入ルート」が「④開拓架電」で統一されている
   - ランク(A/B/C)が正しく反映されている

## 品質チェックリスト

インポート前に必ず確認:

- [ ] すべての企業に**電話番号が記載**されている(推測値なし)
- [ ] **法人番号が有効**(国税庁 DB で確認可能)
- [ ] **ランクが正しい**(客室数ベース)
- [ ] **流入ルート**が「④開拓架電」で統一
- [ ] **除外条件**(大手チェーン・外資)に該当しない
- [ ] **本島のみ**(石垣・宮古など離島なし)
- [ ] **出典**が公開情報である(根拠 URL 可視化)

## 質問・トラブル

Q: 法人番号が見つからない企業がある
A: 個人営業の可能性。個人営業は法人番号なしでもインポート可能(IMPORT_OPTIONAL_FIELDS に「法人番号」未登録で OK)

Q: 電話番号が公式サイトに載っていない
A: その企業は**スキップ**(絶対ルール1「電話番号確認済みのみ」)

Q: Aランク案件をもっと増やしたい
A: 本島の独立系ホテルで 100室以上はほぼ尽きている。B ランク(アポ率現況確認後)から成約に至る実績で判定し、必要に応じて 2027-03-18 の見直しで基準を変更する
