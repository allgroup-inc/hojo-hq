## 月次レビューの型(効果検証ループ)
1. KGI(早期解約率)の推移を確認。
2. 効果測定(保全あり/なし)を見る → 効いていなければ保全SOPの型を見直す。
3. モデルを再学習した場合はバックテストAUCを確認(品質ゲート)。
4. 高リスク要因の変化(新しい掛け合わせ)を検証部で点検。
5. 改善案を三名体制で議事化(ウタガイ必須)→ 小柳さん決裁 → 翌月反映。

## エスカレーション(即・上申)
- 効果測定がプラス(保全した方が解約が多い)→ 型を停止・再設計。
- AUC≈0.5 → モデル本番停止。
- 要フォローが処理能力を超過 → 閾値/トリアージ再設定(小柳さん)。
- PII事故 → 即時遮断・48時間以内3役レビュー。
