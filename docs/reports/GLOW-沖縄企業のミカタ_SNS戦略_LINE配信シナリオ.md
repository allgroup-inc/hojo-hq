# 沖縄企業のミカタ SNS戦略
## LINE配信シナリオ（週別配信 + 経営相談導線）

**配信対象：** LINE登録済みの沖縄県内中小企業経営者（1,000-10,000名）  
**配信頻度：** 週3回（月・水・金）+ 臨時〆切アラート  
**目的：** 補助金情報提供 → 経営相談への自然な導線  
**最終ゴール：** 経営相談 → M&A/融資ニーズの喚起

### **Week 3：「経営相談への本格導線」 + ニーズ喚起**

#### 📱 月曜 8:00 - 「なぜ、補助金だけじゃダメなのか」

**形式：** テキスト＋長文（500字程度）

```
🤔 経営者さんへの本音の話

「沖縄企業のミカタ」は、
補助金・助成金の情報屋ではありません。

本当のゴールは、
「あなたの会社の経営を、確実に強くする」
ことです。

【補助金だけの思考の落とし穴】
「この制度があるから、使おう」
→ 目的が「制度の活用」になってる
→ 実は、会社の課題と合ってない
→ 投資しても、売上が増えない

【正しい思考プロセス】
1. 「うちの会社の課題は何か」を考える
   └ 人材不足？ 設備老朽化？ DX遅れ？

2. 「その課題を解決するには」を考える
   └ 必要な投資は何か？ 期間は？ 効果は？

3. 「その投資を、助成金でカバーできるか」を考える
   └ 合致する制度はあるか？ 〆切は？

つまり、
補助金 = 解決策の「手段」であって、「目的」じゃない

【だからこそ】
「あなたの経営課題」をまず知ることが大事

「うちの会社、どうなりたいのか」
「5年後、売上いくらまで伸ばしたいのか」
「後継者育成は進んでるのか」

こういう『経営の本質的な質問』に
一緒に向き合う場が、経営相談です。

その上で、
「その目標を達成するために、
 こんな助成金が使えますよ」

という提案をする。

これが、本来の『最強の経営支援』です。

【相談予約】
補助金を「正しく活用」する経営者さんへ。

来週は「経営相談の実例」をお示しします。
```

**期待効果：** 「補助金は手段」という気づき → 経営相談への重要性を認識

## 💡 運用上のポイント

### 1. **返答速度を極度に重視**
- 相談メッセージ → 24時間以内に返答
- 相談予約希望 → 2時間以内に日程確認
- 融資・M&A相談 → 48時間以内に担当者紹介

### 2. **パーソナライズの継続**
- 利用者の「業種」「相談内容」を記録
- 次回からは「前回の話」を引きずって対応
- 「あ、前のこと覚えてくれてた」という信頼醸成

### 3. **〆切アラートは「朝5時」配信**
- 経営者さんは朝早く起きるので、朝5時
- 「今日中に申請しなきゃ」という緊迫感を醸成

### 4. **月1回は「ボイスメッセージ」も活用**
- 代表からの月1メッセージ（30秒程度）
- 文字より温度感が伝わる → 関係構築を加速
