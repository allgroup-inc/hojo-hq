## 1. 市場機会：ギャップ市場の実相

沖縄県内の経営者を対象とした調査から、後継者問題に関する深刻な課題が浮かび上がっています。

**市場の規模感**
- 後継者不安を抱える企業：約4,000～4,500社（後継者不安率65～70%）
- 実際のM&A成約件数：年間120～150件
- **成約率はわずか2～3%** — つまり、ほぼすべての経営者が成約に至っていない

**潜在的な市場規模**
- 推定市場規模：¥300～500B（市場規模ベース）
- 成長率：過去3年で+50%と拡大傾向
- 未開拓市場：¥200B以上の商機が存在

この「後継者不安は高いのに、成約しない」という矛盾こそが、GLOW事業の最大の機会です。

## 2. なぜギャップが生まれるのか：3つの要因

### 2-1. 既存M&A業者の採算性問題

沖縄県内の中堅・小規模企業向けM&A案件は、既存の大手仲介業者にとって魅力がありません。理由は経済的です。

- 小規模案件（¥1～5B）での仲介手数料（2～3%）= ¥20～150M
- 営業人件費（年¥8～12M）で採算が取れない
- したがって、大型案件（¥5B以上）に特化する戦略が合理的

結果として、大手仲介A（¥5～50B対応）、地域中堅B（¥3～20B対応）、金融系C（¥2～10B対応）といった既存プレイヤーは、揃って小規模層を無視しています。

唯一、地場小規模D（¥1～5B対応）が存在しますが、実績が薄く、営業も不定期です。

**既存業者が小規模対応しない理由の内訳：**
- 採算性の壁：固定費が賄えない
- 営業効率：既存ネットワーク（金融機関・上場企業）からの紹介に依存
- リスク回避：小規模経営者は経営基盤が不安定で、交渉が長引く傾向

### 2-2. 沖縄特有のリスク・文化的抵抗

沖縄県の経営者には、M&A意思決定に大きな心理的障壁があります。

- **親族承継志向の強さ**：「事業は家族へ」という文化的信念
- **M&Aリテラシーの低さ**：経営者がM&A自体の仕組みを理解していない
- **現状維持バイアス**：「今は大丈夫だから、後継者問題は先送りにしよう」という心理

これらの障壁により、たとえ後継者不安があっても、実際の行動（相談・提案受け入れ）に至りません。

### 2-3. 経営者心理の保守性

さらに深刻な問題は、経営者の決断タイミングです。

- **準備段階での接触不足**：トリガー発動前（つまり危機が訪れる前）に、ほとんど接触されていない
- **危機化後の決断**：実際に患者減少・人手不足・負債増加などの危機が現在化してから、初めてM&Aを検討
- **時間的制約**：危機が現在化した時点では、もう書類作成やgBizID申請などの準備時間がない

**結果：** 後継者不安企業は多いが、成約に至るのは危機が現在化した一部のみ

## 4. 沖縄特有のリスク要因と対策

沖縄県でM&A事業を展開する際に想定すべき、固有のリスク要因があります：

### リスク要因１：親族承継志向

**内容**：オーナーの「事業は子ども・親族へ」という文化的信念が強い

**影響度**：高 / **確度**：高

**対策**：シナリオ提示
- 「親族が引き継ぎたくない理由」を丁寧にヒアリング
- その課題を「外部統合（M&A）」で解決する提案
- 具体例：患者獲得が困難、スタッフ確保が困難といった経営課題を言語化し、M&Aでの解決を提案

### リスク要因２：M&Aリテラシー不足

**内容**：経営者がM&A自体の仕組みを理解していない

**影響度**：高 / **確度**：高

**対策**：段階的教育フロー
- 補助金情報（沖縄企業のミカタ）→ 経営相談 → M&A理解 → 提案
- 沖縄での成功事例3～5件を具体的に紹介
- 成功ストーリーで心理的抵抗を低減

### リスク要因３：観光経済依存

**内容**：インバウンド減少時の景気変動リスク

**影響度**：中 / **確度**：中

**対策**：シナリオプランニング
- 景気変動を先読みした営業計画の調整

### リスク要因４：農業・建設の高齢化

**内容**：経営者の急速な高齢化 → 廃業タイミングの予測難

**影響度**：高 / **確度**：高

**対策**：早期接触
- **タイムリミット**：今後1～2年が最後の機会（経営者が急速に高齢化している）
- **月間訪問**：20～30社/月で市場開拓
- **優先業種**：建設5,539社 + 農業推定3,000社以上

## 5. 経営者心理メカニズム：なぜ決断しないのか

### 矛盾の解説

後継者不安は65～70%もあるのに、なぜ成約率は2～3%に留まるのか？

答えは、経営者の心理的バイアスにあります。

**心理学的メカニズム**
- **現状維持バイアス**：現在の状態を変えることへの恐怖
- **喪失回避性**：事業を失うことへの恐怖感
- **家族執着**：家族に事業を継がせたいという願い

これらが相互に作用し、「不安だが、今は大丈夫」という心理状態を生み出しています。

### 沖縄経営者に共通する3つのパターン

#### パターン１：親族重視型（40～50%）
- 特徴：「事業は子ども・親族へ」という信念が非常に強い
- 決断プロセス：親族に相談 → 反対される → M&A検討が立ち消える
- アプローチ方法：親族の懸念（後継難、スタッフ不足など）を言語化し、M&Aでの解決を提案

#### パターン２：保守型（30～40%）
- 特徴：変化回避、既存方法の継続を好む
- 心理：「今までうまくいった」という成功体験への依存
- 行動特性：M&A検討も先延ばしにする傾向が強い
- アプローチ方法：段階的な教育と、成功事例の共有

#### パターン３：自己実現型（10～20%）
- 特徴：事業への執着が強く、「人生＝経営者」という同一性
- 心理：事業の引き継ぎ＝喪失感。「まだやれる」という過信
- 行動特性：高齢化しても経営を継続しようとする傾向
- アプローチ方法：「第二の人生」や「次のステージ」というフレーミング

## 6. M&A決断のトリガー：業界別分析

経営者が実際にM&Aを決断するには、明確な「トリガー（引き金）」が必要です。業界によってトリガーは異なります：

### 医療・介護業

**トリガー**：患者減少 / 医師・看護師の離職 / 負債増加

**心理**：経営環境の急変 = 現状維持が不可能と認識

**決断タイミング**：危機が現在進行形 → 決断が比較的早い（数ヶ月以内）

### 建設業

**トリガー**：大型工事の急減 / 下請けからの外れ / 若い職人の確保難

**心理**：事業基盤の揺らぎ → 統合で大型案件に対応する必要性を認識

**決断タイミング**：景気サイクルの悪化時期（1～2年後）

### 農業・畜産

**トリガー**：体力の限界 / 跡継ぎが明確に拒否 / 借金増加

**心理**：加齢とともに「続けられない」という現実認識が深刻化

**決断タイミング**：経営者が65歳を超えた時期（緊急性が高い）

### GLOW の戦略的な対応

この分析から、GLOW が採るべき戦略が見えます：

**トリガー発動前の準備段階（信頼構築3～6ヶ月）で接触し、トリガー発動時に即座に対応できる提案を用意しておく。** 

つまり、危機が訪れてから相談されるのではなく、その前段階で信頼を構築しておくことで、決断時間を確保し、成約率を高める戦略です。

## 7. GLOW の差別化戦略と採算モデル

### 競争優位性

GLOW が既存業者と異なる競争優位性：

1. **小規模案件専門**：¥1～5B という、既存大手が敬遠する層に特化
2. **段階的営業フロー**：DM → 電話 → 訪問 → 関係構築 → M&A提案（成約率40～60%）
3. **沖縄特化営業**：文化や心理を理解した営業アプローチ
4. **信頼構築3～6ヶ月**：トリガー発動前の準備段階での接触
5. **成約率40～60%**：段階的営業により、既存業者の2～3%を大幅に上回る可能性

### 採算モデル（1件¥1～5B案件あたり）

GLOW が既存業者と異なる採算実現方法：

**売上A：M&A仲介手数料**
- ¥2～7M（取扱額に応じて2～3%）

**売上B：事前診断・相談フィー**
- ¥1～2M（提案前のコンサルティング業務）

**売上C：法人保険（3年間）**
- ¥0.5～1M/年（事業承継・経営者保険の斡旋）

**売上D：経営相談（継続）**
- ¥0.5M/年（M&A後の経営統合支援など）

**合計：¥6～15M/件** — この複数の収入柱により、仲介手数料だけでは採算が取れない小規模案件も、十分な利益を確保できます。

## 10. 結論

### 市場機会の本質

沖縄県内には、後継者問題を抱える4,000社以上の企業が存在しますが、既存のM&A業者はその大多数を無視しています。理由は、採算性の問題と営業効率の最適化にあります。

この「**既存業者が採算取れないと見なす市場層**」こそが、GLOW の最大の機会です。

### GLOW の差別化

1. **採算モデルの革新**：複数の収入柱により、小規模案件でも利益を確保
2. **営業方法論の確立**：段階的営業 + トリガー発動前接触により、成約率を引き上げ
3. **地域特化**：沖縄の文化と経営者心理を深く理解した営業アプローチ

### 経営判断

**GO 判断の根拠：**

- ✅ 市場規模が大きく（¥200B以上）、成長中（+50% / 3年）
- ✅ 既存業者がカバーしていない明確なギャップが存在
- ✅ 採算化の方法論が実装可能で、実現可能性が高い
- ✅ 9ヶ月25～59件という段階的な目標設定により、リスクが限定される
