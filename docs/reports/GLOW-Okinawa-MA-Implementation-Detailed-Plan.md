# GLOW沖縄M&A市場 実装フェーズ詳細計画書

## 第1部：チーム構成・組織体制

### 1.1 推奨チーム構成（PHASE 1）

**チームサイズ：1.5-2名体制**

#### メンバー1：嶺井（統括・初接触）
- **役職：** M&A営業統括
- **時間配分：** 月間営業活動50%、関係構築30%、管理業務20%
- **責務：**
  - 初期接触30-50社/月の対面相談（Zoom を含む）
  - 初回面談～ニーズ確認段階の主導（STAGE 2-3）
  - 既存金融機関ネットワークとの連携
  - 買い手企業との初期接触
- **KPI：** 初回面談実現率60-70%、継続相談率60%、月間接触50社

#### メンバー2：営業事務・リスト管理（新規採用）
- **役職：** M&Aリスト管理・営業事務
- **時間配分：** リスト作成・管理60%、営業サポート30%、事務業務10%
- **責務：**
  - リスト管理システムの運用（沖縄企業30万件 DB から月間30-50社抽出）
  - 嶺井の営業スケジュール管理
  - 初回接触のメール・電話アシスト（事前リサーチ、提案資料作成）
  - 面談記録の整理・CRM 入力
  - 買い手企業との書類作成・調整
- **KPI：** 月間30-50社リスト抽出、面談準備率95%以上、営業資料作成の納期遵守率100%

#### メンバー3：弁護士・税理士アドバイザー（外部顧問契約）
- **役職：** 法務・税務顧問
- **時間配分：** 月5-10時間（初期段階では相談中心）
- **責務：**
  - 資格業務との線引き確認
  - M&A 契約書のレビュー
  - 売却企業・買収企業の法務デューデリジェンス指導
  - 沖縄県商工労働部との事前協議のサポート
- **KPI：** 法的リスクの事前検知率100%、顧客満足度90%以上

### 1.2 PHASE 2 でのチーム拡大（11月-1月）

**チームサイズ：2-3名体制への拡大**

#### 新規採用1：営業人員（第2営業）
- **役職：** M&A営業（初期接触・継続相談担当）
- **時間配分：** 営業活動80%、管理業務20%
- **責務：**
  - 月間30-50社への初期接触（嶺井のサポートを受けながら）
  - STAGE 1-2 の営業（認知・初回相談）
  - STAGE 3-6 は嶺井に引き継ぎ
  - 既存GLOW 融資顧客への買収ニーズ聞き取り
- **採用条件：**
  - 営業経験3年以上（保険・金融・不動産など）
  - 沖縄県内ネットワークがあることが望ましい
  - 対人スキルが高いこと
- **期待給与：** ¥280-350M/月（基本給¥240M + 成績給¥40-110M）

#### 既存メンバーの役割変化
- **嶺井：** STAGE 2-3（初回相談・ニーズ確認）に特化。初期接触は第2営業にシフト
- **営業事務：** リスト管理・CRM 運用に注力。第2営業のバックアップを強化

### 1.3 PHASE 3 でのチーム体制（2月-4月）

**チームサイズ：3-4名体制**

#### 新規採用2：営業人員（第3営業）または士業連携マネージャー
- **オプション1：第3営業（営業多層化）**
  - 役職：M&A営業（初期接触特化）
  - STAGE 1（認知・接触）に特化
  - 月間接触100社達成のための追加投入
  
- **オプション2：士業連携マネージャー（実務統括）**
  - 役職：M&A事業運営マネージャー
  - STAGE 4-6 の実務進行を統括
  - 弁護士・税理士・銀行との調整

**推奨：オプション1 で営業体制を強化**
- 理由：成約数の加速には「初期接触数の増加」が最も効果的

## 第4部：マイルストーン・意思決定ポイント

### 4.1 PHASE 1 終了時（10月末）の意思決定ポイント

**GO/NO-GO 判定基準：**

| 判定項目 | GO 条件 | NO-GO 条件 | 判定 |
|---------|--------|----------|------|
| **初期接触数** | 30社/月以上を3ヶ月継続 | 20社/月以下 | 累計90-150社達成で GO |
| **初回面談実現率** | 60%以上 | 50%以下 | 平均実績により判定 |
| **継続相談進捗** | 10社以上がSTAGE 2 以上に進捗 | 5社未満 | 実績により判定 |
| **買い手ネットワーク** | 県外M&A企業との提携1社以上 | 提携なし | 提携契約により判定 |
| **チーム体制** | 営業事務の採用・研修完了 | スタッフ不足 | 採用状況により判定 |

**GO の場合：PHASE 2 へ移行（営業体制拡大、第2営業採用）**

**NO-GO の場合：**
- 初期接触方法の改善（メールテンプレート、電話スクリプトの最適化）
- 営業アプローチの改善（提案内容の微調整）
- 1ヶ月の試行期間を設定し、改善後に再判定

## 第6部：リスク管理・対応計画

### 6.1 リスク評価マトリクス

| リスク | 発生確度 | インパクト | 対応優先度 | 対応計画 |
|--------|---------|----------|----------|--------|
| 初期接触応答率が40%以下 | 中 | 中 | 高 | メール・電話の内容改善テスト。提案タイミング・曜日の最適化 |
| 嶺井の過負荷（月50社×2h/社 = 100h） | 中 | 高 | 最高 | 営業事務のサポート強化、Zoom 活用による時間短縮 |
| 買い手企業のパイプラインが不足 | 中 | 高 | 最高 | 県外M&A企業との提携加速、既存顧客への聞き取り強化 |
| 成約が0件で終わる（初成約未達） | 低 | 低 | 中 | PHASE 3 での成約加速目標を上方修正。営業ファネルの詳細分析 |
| 営業事務スタッフが辞職 | 低 | 中 | 中 | 業務マニュアルの作成で属人性を排除。2人目採用の前倒し |
| 県内金融機関との関係が悪化 | 低 | 中 | 中 | 常に「紹介元」としての立場を保つ。競争関係ではなく協業関係を構築 |

### 6.2 シナリオプランニング

**シナリオA：楽観的（初期接触実績が目標を上回る場合）**
- 月間初期接触50-70社を達成
- 初回面談実現率70%以上
- PHASE 1 終了時に継続相談が20-25社に
- **対応：** 第2営業の採用を加速。PHASE 2 での成約を5-8件まで引き上げ

**シナリオB：基準（計画通り進行）**
- 月間初期接触30-50社
- 初回面談実現率60-70%
- PHASE 1 終了時に継続相談が12-18社
- **対応：** 計画通りPHASE 2 に移行

**シナリオC：悲観的（初期接触が目標の50%以下）**
- 月間初期接触15-20社
- 初回面談実現率が50%以下に低下
- PHASE 1 終了時に継続相談が5-10社
- **対応：** メール・電話スクリプトの全面見直し。営業アプローチの変更。PHASE 2 への移行を延期し、PHASE 1 を延長
