# GLOW 沖縄企業のミカタ — 実案業種別事例インタビュー質問票

**目的:** Instagram/LINE SNS コンテンツを生成するための実業績のヒアリング質問票  
**対象:** 沖縄県内の経営者（医療・建設・飲食・農業）  
**使用部門:** SNS部（ヒロメさん）/ 提携部（ムスブさん）  
**面接時間:** 1社あたり 45-60分（オンライン推奨）  
**承認フロー:** 回答者確認 → 守り部レビュー → SNS部による記事化 → 回答者最終承認

---

## 📋 事前準備（面接者向け）

### 面接のねらい
「経費を抑えて未来に投資をコツコツと」というテーマで、その企業の実際の取り組みを引き出し、SNS投稿・LINE配信の事例として活用する。個別企業の機密情報（具体的な売上・経営課題）は避け、**一般化・汎用化できる知見・工夫** に焦点を当てる。

### 面接前の確認事項
- [ ] 回答者の基本情報を確認（役職・部署・経歴）
- [ ] 自社の簡単な事業紹介を用意してもらう（売上規模・従業員数は聞かない、業種と年数のみ）
- [ ] 相談実績がある場合は、相談内容の一般化可能な部分をピックアップ
- [ ] 面接内容の SNS 利用許可を事前に書面で取得（フォーマット：docs/同意書_事例公開.md）

## 📝 面接後の処理フロー

### ステップ 1: 情報の鮮度・正確性チェック（守り部）

- [ ] 個社の秘密情報（売上・営業利益・顧客名）が入っていないか確認
- [ ] 補助金制度名が正確か（制度サイトで確認）
- [ ] 業種の一般化が成立しているか（「この企業だけの工夫」→「業界全体で応用可能な知見」に転換できているか）

### ステップ 2: SNS 記事化（SNS部）

**4つの投稿パターンから選択:**

| パターン | 構成 | 例 |
|---------|------|-----|
| **パターンA: 事例紹介** | 経営課題 → 経営者の工夫 → 結果 | 建設業の若手育成話 |
| **パターンB: 補助金の使い方** | 制度紹介 → この企業の活用例 → 他社への示唆 | 医療機器購入で補助金活用 |
| **パターンC: 経営相談の価値** | 経営課題 → 専門家相談で解決した流れ → 次のアクション | 労務トラブルを税理士相談で回避 |
| **パターンD: 後継者・地域** | 世代交代 / 地域連携の工夫 → 実績 → 今後の展望 | 農業の6次産業化で後継者確保 |

### ステップ 3: 回答者の最終確認

- [ ] 掲載予定の記事案を回答者に確認
- [ ] 匿名化 / 企業名公開の希望を確認（自社PR希望の場合のみ企業名掲載）
- [ ] SNS・LINE 掲載の書面同意を再取得

### ステップ 4: 公開・分析

- [ ] Instagram/LINE で投稿
- [ ] エンゲージメント（反応率・クリック数・LINE登録）を計測
- [ ] 2週間後、SNS部が効果検証を実施

## 🎯 面接者向けチェックリスト

**面接前:**
- [ ] 質問票をあらかじめ回答者に送付（時間短縮・深い回答期待）
- [ ] 企業の基本情報（業種・経営年数）を事前リサーチ

**面接後:**

## 📞 よくある質問（回答者からの問い合わせ対応用）

**Q. 企業名は出ますか？**
A. 原則匿名化します。ただし、自社 PR を希望される場合は、あらかじめお伝えした上で企業名と情報を公開することができます。

**Q. 経営数字（売上・利益）が漏れることはないですか？**
A. 個別の経営数字は掲載しません。「改善傾向」など定性的な効果のみのご紹介になります。

**Q. 補助金の内容は正確に書かれますか？**
A. 制度名・条件は我々の守り部が公式サイトで照合し、誤りを防ぎます。

**Q. 記事公開前に確認できますか？**
A. はい。公開予定のテキスト・画像を回答者に確認していただき、修正・削除のご要望があれば対応します。
