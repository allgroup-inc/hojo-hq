既存プレイヤーの限界と市場ギャップ

従来型M&A企業の課題

  • • 大型案件志向： ¥3B以上の大型案件に特化。小中企業（¥100M-1B）を見落とし
  • • 新規開拓能力の不足： 紹介案件に依存（紹介率60-80%）。新規開拓は営業力不足で失敗
  • • 初期接触困難： 経営者は「M&A企業」の営業をブロック。信頼構築に数年要する

沖縄固有の課題

  • • 銀行・支援機関の限界： 地元銀行は融資判断が主。M&A仲介ノウハウなし
  • • 士業との連携不足： 税理士・社労士は相続対策まで。事業承継・売却は専門外
  • • 経営者の認知不足： 「事業売却＝失敗」という古い価値観が根強い

GLOW の3つの競争優位性

🛡️ 優位性1：保険事業による経営基盤

既存の保険委託事業で現在のコストが確保済み。新規開拓M&A事業に純粋な利益として集中可能。競争企業は月2-5件の成約を必要とするが、GLOWは月1件の成約で収支分岐点に到達。資金効率は50-100倍。

🏛️ 優位性2：嶺井の34年沖縄開発金融公庫キャリア

沖縄県政策金融公庫で34年、数千社の沖縄企業と経営相談を重ねた実績。「嶺井さん」は経営者の信頼の象徴。初期接触時の面談実現率60-70%。既存データベースから優良企業への直接提案が可能。

📋 優位性3：他社にないリスト管理マネジメント

沖縄県内企業データベースの精密な分析・セグメンテーション。年間30万件の公開データから沖縄関連企業を自動抽出・更新。後継者年齢・事業規模・収益性を組み合わせた成約確度の高いリストの継続供給。

経営者心理と意思決定トリガー

後継者不安への段階的アプローチ

段階1：「心当たりがある」という認識
後継者不安は高いが、具体的行動に至っていない状態。補助金情報や融資相談を通じた経営サポートで、相談しやすい相手として認識される土台を作る。
段階2：「誰かに相談したい」という欲求
嶺井との「経営相談」という非脅威的な接触を積み重ねることで、後継者問題の相談欲求が高まる。この段階での声かけが重要。
段階3：「選択肢が欲しい」という動機
子息が経営に関心を示さない、または経営悪化の兆しが見えた時、M&A・融資・後継者育成の選択肢が急に魅力的に見える。このタイミングが成約率40-60%に跳ね上がるポイント。
段階4：「実行計画が欲しい」という確信
買い手候補の提示・スキーム提案で、初めて「実現可能性」が理性的に認識される。ここまで来れば成約まで60-80%の確度。

トリガーイベント（成約確度が急上昇）

  • • 後継者の経営離脱宣言
  • • 業績低迷局面（前期比マイナス）
  • • 自社の競争優位が剥落した兆候
  • • 大型顧客の喪失
  • • 経営者の健康悪化

リスク評価と対策

重要リスク項目

市場成熟度
リスク： 年間150件市場で複数企業が参入すると過当競争に。 対策： 小中企業層（¥100M-1B）に特化し、他社と差別化。嶺井の既存ネットワークで先制。
成約タイミング
リスク： 経営者の腹が決まるまで6-12ヶ月要する場合あり。初期目標25件達成に時間がかかる可能性。 対策： 早期接触・段階的信頼構築による「ウォーミング期間」を短縮。月間接触30社以上で数年後の成約パイプラインを先行構築。
チーム構築
リスク： 嶺井依存の営業体制では、経営者の過負荷リスク。スケール時に他の営業人材が育ちにくい。 対策： 嶺井は「初接触・信頼構築」に特化。DD・交渉・実務は士業・銀行と分業。営業人材育成は2-3年計画で重視。
買い手市場
リスク： 買収候補企業（沖縄内・県外）が不足すると、売却ニーズはあるが成約に至らない。 対策： 初期段階から買い手ネットワーク構築。既存GLOW融資顧客の中から経営統合ニーズを発掘。県外M&A企業との提携による買い手紹介。
規制・法務
リスク： 資格業務（申請代行）との線引き曖昧化。沖縄県商工労働部の指導が入る可能性。 対策： 士業との提携構造を明確化。GLOWは「仲介」まで。申請手続は有資格者のみ。事前に県との協議・許認可取得。

業界別売上規模別営業戦略

医療・歯科（¥100M-500M）

  • • 後継者不安が最高峰（医科大進学者が診療所経営に興味なし）
  • • トリガー：医師の体力低下（50代中盤～）。年1回の検診で健康悪化を感知
  • • 営業アプローチ：医師会・歯科医会経由の紹介。嶺井の医療融資実績から信頼構築
  • • 想定成約金額：¥150M-300M（資産評価が明確）

建設・土木（¥200M-2B）

  • • 業績の波が大きく、融資ニーズとセットで接触可能
  • • トリガー：大型工事の喪失、公共投資の削減
  • • 営業アプローチ：沖縄建設業協会経由。若い後継世代の都市移住に対応
  • • 想定成約金額：¥300M-800M（企業規模が大きい分、手数料が高い）

飲食・小売（¥50M-300M）

  • • 経営者自身の消費行動・体験不足から後継者評価が低い傾向
  • • トリガー：新型コロナのような外的ショック、または経営者の年齢上昇（60代後半）
  • • 営業アプローチ：補助金サイト経由の信頼構築。融資相談から段階的に後継者問題へ
  • • 想定成約金額：¥100M-200M

農業・漁業（¥30M-200M）

  • • 後継者不安が深刻（若年世代の業界離脱が加速）
  • • トリガー：市場価格の低下、異常気象による作況不良
  • • 営業アプローチ：農業委員会・JA経由。新しい後継者モデル（法人化・外部マネジメント）を提案
  • • 想定成約金額：¥30M-100M
