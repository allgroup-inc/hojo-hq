## 0. 大原則(フェイルクローズ)

**迷ったら載せない。確認できるまで載せない。問題の疑いが出たら即座に非表示にして、確認してから戻す。**
子ども向けサービスは「載せ損ない」より「危ないものを載せる」方が取り返しがつかない。

## 1. 掲載できるサービスの条件(すべて満たす)

1. **無料であること**: 完全無料/一部無料/条件付き無料のいずれか。無料範囲と有料部分の境目が原文で確認できること。「無料体験のみ」の塾・教材、あとから教材販売等につながる「無料商法」は掲載しない
2. **団体の実在確認(v2で強化・v2.1でA類型を調整)**: 次の(a)(b)いずれか必須 — (a) **法人番号がある**、(b) **自治体の事業・登録団体・委託先である**。(a)(b)を満たさない任意団体は、「国・自治体・主要財団の後援または助成を受けている事実を、後援・助成する側の公式サイトで裏取りできた場合」のみ例外掲載できる。
   **例外(v2.1・2026-09-06 小柳さん指示「全国のオンラインで受けれるものもいれて」を反映)**: **A類型(動画・教材のみで子どもと接触しない)に限り**、法人番号がなくても次の3点で掲載できる — ①運営者名が公開されている ②2年以上の運営実績または広く確認できる利用実績 ③無料商法でないことを確認済み。接触リスクがないため実在確認の趣旨(子どもの安全)を損なわない。審査記録は通常どおり必須
3. **運営情報の公開**: 運営者名・所在地(市区町村まで)・連絡手段の3点が公式サイトで公開されていること
4. **公式サイト・連絡先が機能している**(URL死活チェック通過)
5. **勧誘目的でない**: 宗教・政治・マルチ商法等への勧誘を目的としない
6. **一次情報で内容確認済み**: 対象・料金・申込方法を公式情報と照合済み。**料金・対象のどちらかが「要確認」のものは掲載保留**(v2で強化: v1は料金のみだった)
7. **子どもと接する形態の階層ルール(v2で新設)**:

| 類型 | 形態 | 扱い |
|---|---|---|
| A | 接触なし(動画・教材・アプリのみ) | 通常審査で掲載可 |
| B | 団体運営の集団・少人数(対面/オンライン) | 通常審査で掲載可 |
| C | 1対1(団体の管理下: 大学生ボランティア面談等) | **安全4点**(運営団体による本人確認/保護者同意の仕組み/オンライン面談の記録・見守りルール/相談・通報窓口)を確認できた場合のみ掲載。**年1回の再確認必須** |
| D | 個人が単独で子どもと接する形態 | **掲載禁止**(v1の「原則掲載しない」から格上げ。例外なし) |

## 2. 順位・表示・利益相反のルール

- 並び順は公開している「おすすめ度」の計算式のみ。**金銭・関係性で順位を変えない。広告枠は存在しない**
- **掲載団体から、掲載に関わる金銭・寄付・便益を一切受け取らない**(v2で新設。利益相反の遮断)
- 「×沖縄から利用不可」は検索結果に出さない(参考枠に分離)。「△」「?」は隠さず表示し確認方法を案内

## 3. 掲載の手続き(二重チェック)

- draft(起票)→ verified(検証部が原文照合)→ published(守り部が掲載基準を審査)の3段階。**照合と審査は別の作業として別々に記録**し、1回の作業でdraftからpublishedへ直行させない
- published への昇格は、審査記録(確認した項目・根拠URL・判断)を `docs/みらいひらけ堂_守り部審査記録.md` に残した場合のみ有効。記録なき昇格は監査で差し戻す
- 却下時は理由を記録し、依頼者に通知する

## 4. 掲載後の維持条件(v2で強化)

- **published を維持するには90日ごとの再確認が必要**。last_verified から**90日**で「⚠古い可能性」表示(v1の60日を早める運用は変えず、警告は60日から)、**120日で自動的に verified へ降格=非表示**(週次監査が機械実行)
- 募集終了の確認は24時間以内に反映
- **即時非表示トリガー**: 次のいずれかで当該サービスを直ちに「審査中・非表示」にする — ①利用者・保護者からの通報 ②無料をうたいながらの金銭要求の発覚 ③URLの転送先・所有者の変化を検知 ④団体の解散・不祥事報道。確認が取れるまで戻さない
- **金銭要求が事実と確認された団体は即時削除+1年間再掲載不可**。安全に関わる事案(不適切な接触等)が確認された団体は**永久に再掲載しない**

## 5. 撤退・縮退基準(実装済み: 週次監査が自動判定)

- **黄色信号**: 鮮度KPI(published のうち最終確認60日以内の割合)が**80%を2週連続で下回った**ら、新規掲載を止め再確認に全工数を回す(監査ワークフローが警告で赤くなる)
- **赤信号**: **60%を下回った**ら published 全件を一時非表示にし「更新休止中」を表示。立て直せなければ小柳さん決裁でサービス終了(掲載団体に通知・移行案内を掲示)

## 6. 通報窓口(v2で新設)

- サイトに子ども向け文言の通報フォームを設置する: 「このサービスをつかって、いやなこと・こまったことがあったら、ここからおしえてね」
- 通報は**24時間以内に一次対応**。対象サービスは事実確認の間「審査中・非表示」
- 通報内容に個人情報を書かないよう案内し、書かれてしまった個人情報は対応後に削除する

## 7. 定期監査の仕組み(v2で新設・機械+人の二層)

**機械監査(週1・自動)** — `miraihirake-audit` ワークフロー:
1. 必須項目(出典URL・最終確認日)の欠落、審査段階の不正な値を検査
2. published の鮮度を検査: 60日超→警告リスト、**120日超→自動で非表示(verified降格)**
3. 鮮度KPIを算出し、撤退基準(80%/60%)を割ったらワークフローを赤くして知らせる
4. 掲載URL(公式・申込・出典)の死活チェック。404・転送先変化は「審査中」候補として報告
5. 結果は `data/miraihirake/audit_report.json` に保存

**人の監査(独立・定例)**:
- **週次**: 検証部が published から無作為3件を原文照合(憲法ルール5の週次無作為再点検)
- **月次**: タダスさん(独立監査)が、①無作為3件の審査記録の有無と質 ②昇格手続きの逸脱(記録なきpublished) ③利益相反の兆候 を点検し、月次監査メモを docs に残す
- **年次**: C類型(1対1)全件の安全4点を再確認。全掲載基準そのものも年1回見直し(前提破壊レビュー)
