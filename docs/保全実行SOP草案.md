# 手厚い保全 実行SOP(草案)— 現場が毎日回す手順

作成日: 2026-08-01 / 起案: Claude(churn-retention-ops 準拠)/ 実行オーナー: たかしくん(現場推進)＋保全担当 / 決裁: 小柳さん
位置づけ: リスク予測が出す「誰に手厚くするか」を、**現場が毎日実行する**ための手順書。これが無いとシステムはダッシュボードで終わる(三名体制の穴①)。
※ 草案。トークの型・頻度・担当割りは現場感覚で調整し、小柳さん決裁で確定。

---

## 0. 大原則
- 目的は**早期解約(6ヶ月以内)を減らす**こと。売り込みではなく「安心の再確認・不安の先回り解消」。
- 保全連絡は**制度の締切アラート(SNS/LINE)とは別系統**(混同しない)。
- 営業マン別の傾向は**教育・改善のため**に使い、人を責めない。
- リスク%・要因は参考。**断定しない**(「あなたは解約する」ではなく「初期のフォローを手厚くする対象」)。

## 1. 毎日やること(消し込み運用)
1. コンソール(`private/console/index.html` または要フォロー一覧)を開く。
2. **🔴高リスク × 要フォロー(直近14日接触なし)** を上から消し込む。
3. 各件、下記「型」に沿って接触 → **結果を別システムに記録**(効果測定の素材)。
4. その日のうちに触れない分は翌日最優先。**放置ゼロ**を守る。

## 2. 接触の型(タイミング別)
| タイミング | 誰が | 何を |
|---|---|---|
| 申込直後(7日以内) | 担当/保全担当 | **安心コール**: 申込のお礼＋内容の再確認＋不明点の解消＋次の連絡予告 |
| 〜3ヶ月 | 保全担当 | 定期フォロー(1回以上)。生活変化・支払い状況の確認 |
| 要フォロー検知時 | 保全担当 | 放置になっていた高リスク先へ即フォロー |

## 3. トークの型(ヒット要因別・草案)
- **オンライン申込で上がっている**:「対面での説明が省略されがちなので、内容を1点だけ確認させてください」
- **低単価/家計負担で上がっている**:「無理なく続けられる形かの確認です。負担が大きければ見直しのご相談も」
- **催事きっかけで上がっている**:「その場のご案内だったので、改めてご不明点がないか」
- **20代など若年で上がっている**:「ライフイベントで見直したくなったら、いつでも相談窓口があります」
- ※ 事実(保障内容・金額)は正確に。曖昧にしない(hojo-accuracy-check の精神)。資格業務(募集行為)の線引きを越えない。

## 4. 記録(効果測定のために必須)
接触したら別システムに: **日付・種別(架電/案内/追加案内)・担当・内容・結果**。
→ これが「保全あり群 vs なし群」の効果測定の土台になる(記録が無いと効果が測れない)。

## 5. やってはいけないこと
- 要フォローの**放置**(高リスクを様子見で流す)。
- リスク%を**断定**して雑な対応をする(自己成就予測)。
- 保全を口実にした**過度な売り込み**・資格業務を越えた行為。
- 事実(締切・金額・保障)を語感優先で**曲げる**。

## 6. 効果の見方(月次)
毎月、**保全接触あり群 vs なし群の早期解約率**を比較(効果検証オーナー)。差がマイナス=効いている。差が出ない/プラスなら、型・タイミング・担当割りを見直す。母数が少ない間は「参考」。
