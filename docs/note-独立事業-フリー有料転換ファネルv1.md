## 2. 各ファネルステージの詳細設計

### **Stage 1: Awareness（認知・流入）**

#### **流入チャネル別の目標数値**

| チャネル | 流入元 | 月目標PV | 獲得方法 | 優先度 |
|---|---|---|---|---|
| **Google検索** | オーガニック検索 | 800-1,200 | SEO（既記事+新規記事） | ◎ 最高 |
| **note内検索** | note内「AI」「Claude」検索 | 400-600 | トレンド・ハッシュタグ | ◎ 高 |
| **Instagram** | #noteAI #Claude投稿 | 200-400 | 週2投稿 + リンク設置 | ◎ 高 |
| **Twitter（X）** | AI関連エゴサーチ | 200-400 | 週2ツイート + スレッド | ◎ 高 |
| **紹介・口コミ** | LinkedIn・Slack共有 | 100-200 | 読者シェア（自然増） | ○ 中 |
| **その他** | Reddit・Qiita・Zenn | 100-200 | バックリンク自然発生 | ○ 中 |
| **合計** | - | **1,800-3,000** | - | - |

#### **Awareness段階での具体施策**

| 施策 | 内容 | 実装者 | 開始時期 |
|---|---|---|---|
| **SEO対策** | 既9記事に「内部リンク」を張り直す。新記事は「検索需要が高い中長尾キーワード」で作成。目安：「Claude 使い方」「GPT実装」等の月500-1000検索数層 | AI実装 | Week1 |
| **note内ハッシュタグ** | #Note文学賞 #副業 #AI入門 #Claude #Notionと複合タグ。毎記事3-5個 | コンテンツ | 毎記事 |
| **X（Twitter）戦略** | 記事公開24時間以内に「記事ヘッダー + 3行要約 + リンク」でツイート。リプライ、引用RTで拡散を誘発。ただし週2回まで（毎日投稿は疲れる + follow解除が増える） | SNS実装 | 毎週火・金 |
| **Instagram連動** | 記事内の「Before/After画面」を切り出して「Reels 15秒動画」に。「AI動画生成の様子」も複数ショット撮影して投稿。リンクは「プロフィールのリンク」 | ビジュアル | 毎月2本 |
| **既読者へのリマインド** | note「マガジン」機能で「毎月の新着記事まとめ」をマガジン化（無料）。読者が「購読」すると、毎月の新記事が自動でメンションされる（読者ベースが月2倍に） | リテンション | 毎月月末 |

### **Stage 2: Interest（興味・読了）**

#### **無料記事の充実度**

| 分類 | 現状（2026-11-02） | 3ヶ月後目標 | 利用目的 |
|---|---|---|---|
| **AI基礎・無料版** | 既9本（短編） | 新12本追加 = 計21本 | 「興味層」を「立ち読み層」へ |
| **SNS・無料版** | 0本 | 新6本追加 | Creator層の初期信頼構築 |
| **副業複合・無料版** | 0本 | 新3本追加 | 「給与+副業」層をSegment化 |
| **合計** | 9本 | 42本 | - |

#### **Interest段階での具体施策**

| 施策 | 内容 | 効果 |
|---|---|---|
| **既記事の「予告シリーズ」** | 例：「Claude vs ChatGPT 3部作」→ Part1,2を無料公開、Part3有料化。無料でサスペンス的に引き込み、「続きが見たい」で有料へ誘導 | CTR +30-40% |
| **プロフィール最適化** | 読者が初訪問時に見る場所。「このアカウントが何を書いているのか」を30秒で理解できるようにする。icon画像・フォロー数・「何屋」かを明記 | 初期信頼 |
| **コミュニティ構築（note内）** | 「Claude users in note」というコミュニティを立ち上げ（無料）。毎週火曜、新しい使い方を紹介するスレッドを立てる。そこで「この回答は有料記事化します」と予告。読者が事前投票で「有料にしてほしいテーマ」を提案可能に | 参加感・予約 |
| **「無料→有料」の過程の透明化** | 「この記事は無料版です。完全版（実装コード+テンプレート）は有料です」と明記。「何が違うのか」をプレビュー時点で明示 | 購買意思向上 |

### **Stage 3: Consideration（検討・立ち読み）**

#### **有料コンテンツの「試し読み」仕組み**

note の標準機能:
- **冒頭500字は無料公開**（購入者だけが全文を読める）
- **著者コメント機能**で「なぜこの記事を書いたのか」を記載

#### **Consideration段階での具体施策**

| 施策 | 内容 | 転換率向上 |
|---|---|---|
| **「売上の仕組みを読者に見せる」戦略** | 毎月、「今月の売上構成」を無料記事で公開。「有料記事が月¥50k、マガジン¥100k、その他¥50k」という透明性。「あなたのおかげで月¥200kになりました」という感謝メッセージ。共感や信頼が増す | CTR +20% |
| **「動画リール」での「立ち読み後の全文イメージ」** | Instagram Reel で「無料記事の話の流れ」を15秒で圧縮し、「完全版は有料記事で」と案内。視覚的に「何が得られるのか」をプレビュー | 有料記事ClickThru +25% |
| **マガジン読者の「先行購読」特典** | マガジン購読者だけが「有料記事を1週間早く購読可能」な特典。期間限定の価値感が生まれ、マガジン契約を促進 | マガジン購買 +30% |
| **「購入者限定コミュニティ」の告知** | 有料記事購入者だけが入れる「Discord / Slackコミュニティ」を無料で提供。実装の質問 / 実績報告 / アイデア交換が可能。購入後の満足度 UP | 継続率 +40% |

### **Stage 4: Conversion（購買）**

#### **購買パターン別の動線**

| パターン | ユーザー | 誘導流れ | 平均購買額 |
|---|---|---|---|
| **A: 単発購入層** | 「とりあえず1記事試す」ユーザー | 無料記事 → 有料記事 ¥1,500 | ¥1,500 |
| **B: 複数購入層** | 「このアカウントを信頼した」ユーザー | 有料記事1 → 2 → 3 ... → マガジン検討 | ¥4,500-7,000 |
| **C: マガジン購読層** | 「毎月の更新を待つ」ユーザー | 有料記事試行 → マガジンの「予告記事」 → マガジン購読 ¥2,980/月 | ¥2,980+（継続） |
| **D: VIP層** | 「実装サポートが必要」ユーザー | 複数有料記事 + マガジン + コミュニティ + DM相談（有料） | ¥5,000-8,000 / 月 |

#### **Conversion段階での具体施策**

| 施策 | 内容 |
|---|---|
| **有料記事の「価格帯テスト」** | 最初は ¥1,500 で販売。3ヶ月後、売上データを見て「特に人気の記事」は ¥2,000-2,500 に値上げ検証。需要と供給の均衡点を探る |
| **「マガジン+有料記事」のセット割引** | マガジン購読者は有料記事を ¥1,500 → ¥1,000 で購買可能。「長期購読の方が得」という心理的誘因 |
| **購買後の「自動DM」** | noteの自動メッセージ機能で、購入者に「ご購入ありがとうございます。分からないことがあれば質問をください。返信は月-金の営業時間内です」と送信。顧客満足度を高める |
| **「購入者だけが見える追記」** | 記事内に「2026-11-15追記：この記事の実装方法が新しいClaude APIに対応しました。詳細は本コミュニティで」という購入者限定の「続き情報」。リピート購買を誘発 |

## 4. 各ステージで失敗しないための指標

### **早期警戒系（週単位で監視）**

| KPI | 目標値 | 下限・懸念値 | 対応 |
|---|---|---|---|
| **記事公開から24h以内のPV** | 30-50PV | < 20PV | SEOキーワード再検討 |
| **立ち読み率** | 20-30% | < 10% | 無料部分の冒頭をもっと引きのある内容に |
| **購買率（立ち読み→購買）** | 30-50% | < 15% | 記事内容の品質見直し（実装不足など） |
| **マガジン購読後の継続率（1ヶ月後）** | 70%+ | < 50% | マガジン内容が期待値と乖離 |

### **アクション指標（月単位で調整）**

- Awareness が目標に達しない場合 → Instagram / X 投稿頻度を週3に増やす / SEOキーワード見直し
- Conversion が低い場合 → 有料記事の冒頭文を A/B テスト / 価格を ¥1,200 に一時下げ
- Loyalty が低い場合 → マガジンの「更新を忘れる」ケースが多いので、配信頻度を月2から月4に増やす
