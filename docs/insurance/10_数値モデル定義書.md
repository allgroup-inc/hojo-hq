# 数値モデル定義書 — ALLGROUP 保険対面営業

> 本書は営業参謀本部の共通語彙(正典)。監査・参謀・レポの各成果物はここの定義を参照する。
> 未確定は「要確認」と明記(断定しない)。出所: 受領した ALLGRP board / 管轄別KPIファイル(2026-07-25 時点)。

---

## 1. 用語集

| 用語 | 定義(現状理解) |
|---|---|
| ANP | 年換算新契約保険料(Annualized New Premium)。新契約の保険料を年換算した保険業界の中核指標。 |
| 予算件数 | その月に目標とする契約(申込/開通)件数。 |
| 予算ANP | その月に目標とする ANP。 |
| 想定単価 | 1件あたりの想定 ANP(予算ANP ÷ 予算件数 の水準)。 |
| 保全 | 既契約の維持・管理業務。保全数/保全完了数で進捗を見る。 |
| 戻入(率・金額) | 契約が早期失効等で戻入(クローバック)になる割合・金額。低いほど良い。 |
| 稼動減率(稼動予→減率) | 予定稼働に対する実稼働の減少度合いを表す係数。 |
| 経過必要数 | 月間目標を「稼動日数・経過日数・残日数」で按分した『今の時点であるべき数』。 |
| 現差異 | 実績 − 経過必要数。**負値は正常にあり得る**(遅れを意味するだけ)。 |
| 進捗 | 達成率(実績 ÷ 経過必要数 等)。 |
| CRM / QCM / LTV | board上は「呉屋/徳元/上地管轄」。正式名称・役割は**要確認**。 |

## 2. 営業ファネル(KPIの縦軸)

上流(量)から下流(成果)へ:

```
実稼働時間
  → 発信数・配布数
    → キャッチ数・着座数
      → アポ・前確OK・保全数
        → 訪問・後確OK数・保全完了数
          → 申込数・開通数・戻入金額
            →(予算件数 / 予算ANP / 想定単価 / 返送率 / 戻入)
```

各段の間には変換率がある: 稼動予→減率、時間→発信数、キャッチ数(率)、アポ・パーミ・リーズ化率、訪問数・P説・前確率、申込・後確OK・戻入率、返送率。

## 3. 3階層ロールアップ

```
個人【実数値】A3縦(日次: 1日〜31日の実稼働時間ほか)
  → 管轄/チーム【チーム進捗】A3縦
    → 全体【ALLGRP】A3縦(定例board)
```

- 反映(入力)は手作業の値貼り付け中心(`※反映のやり方`)。**経過日数だけは手打ち(値貼り付け厳禁)**。
- 監査は「個人合計 = 管轄 = 全体」の一致を突合する(→ `scripts/insurance/audit_reflection.py` の `check_rollup`)。

---

## 4. 進捗の4列(各指標に付随)

| 列 | 定義 |
|---|---|
| 実績 | 実際の値。 |
| 経過必要数 | 月間目標を 稼動日数・経過日数・残日数 で按分した『今あるべき数』。 |
| 現差異 | 実績 − 経過必要数。**負値は正常**(遅れ)。 |
| 進捗 | 達成率。 |

board冒頭に **稼動日数 / 経過日数 / 残日数** があり、月中按分の基準になる。

## 5. 符号の約束(監査の根拠)

監査スクリプトの `NONNEG_METRICS` はこの表に基づく。

| 区分 | 指標例 | 符号 |
|---|---|---|
| **実数値系(非負であるべき)** | 実稼働時間 / 発信数・配布数 / キャッチ数・着座数 / アポ・前確OK・保全数 / 訪問・後確OK数・保全完了数 / 申込数・開通数・戻入金額 / 予算件数 / 予算ANP / 時間→発信数 / 想定単価 | **負値は反映エラーの疑い(要確認)** |
| 差分・率の差系 | 現差異 / (各種"率"の差) | 負値は正常にあり得る |

> 例: 7月board の ★ALL委託【島袋管轄】で 実稼働時間=−283、キャッチ数・着座=−2,827 等の負値を検知 → 実数値系のため**要確認**(値貼り付け時の参照ズレの疑い)。断定はしない。

## 6. 責任者現能力図(5能力軸)

管轄長を5軸で採点し S/A/B ランク付け。参謀本部の役割設計の骨格。

| 能力軸 | 意味 | 対応ファネル | 担当参謀 |
|---|---|---|---|
| 稼動管理 | 実稼働時間・稼動減率 | 実稼働時間 | 稼動参謀 |
| 無生産性管理 | 無駄・非生産時間の削減 | 発信〜着座の歩留まり | 生産性参謀 |
| ゼロイチ管理 | 新規の立ち上げ | 発信→キャッチ→アポ | ゼロイチ参謀 |
| 営業管理 | 訪問→申込→ANP | 中核営業 | 営業参謀 |
| 物件管理 | 保全・返送・戻入 | 契約後の維持 | 物件参謀 |
