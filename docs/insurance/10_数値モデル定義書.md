## 4. 単位・符号の約束(**監査の要 / 先の過検知の是正**)

| ルール | 内容 |
|---|---|
| **円単位** | ⑦⑧は **ALL委託・QCMのみ円単位**(÷10,000 で万円に正規化)。 |
| **QCM絶対値** | QCM ⑦(戻入金額)は**絶対値**で扱う。 |
| **QCMは少ないほど良い** | QCMの**解約(⑥)・戻入(⑦)は上限管理 = 少ないほど良い**。**目標もマイナス表記**。保全完了(⑤)を積むほど戻入が減る。戻入 = 546万×673÷保全完了数、上限450万 → 保全完了817件必要。 |

> ⚠ **是正メモ**: 初期の反映監査は「実数値系=非負」という素朴なルールで QCM や ⑦⑧円単位の**意図的マイナスを過検知**した(例: I65 QCM想定単価 −8.58 は仕様上あり得る)。本書§4が符号ルールの正典。監査は部門別の符号を踏まえること(→ `scripts/insurance/audit_reflection.py` の `is_expected_negative`)。

## 5. KPI式(指示書§3準拠)

- 実稼働率 = ① / ★
- 実架電 = ① − (④×11 + ⑤×100 + ⑥×90)/60 − ①×16/60  ※ ≤0 は対象外
- AG = ② / 実架電
- 初動/h = ② / ①
- 次動率 = ③ / ②
- リスト化率 = ④ / ③
- 接点率 = ⑤ / ④
- 決着率 = ⑥ / ⑤
- 実効単価 = (⑦ − ⑧) / ⑥
- **ANP式 = 稼働 × 初動/h × 次動率 × リスト化率 × 接点率 × 決着率 × 返送率 × 平均単価**

**率・チェーン目標はマスター【ALLGRPデータ】の予算チェーン(稼動減率/時間→発信/キャッチ/リーズ化/訪問/申込/返送/単価)を正とする。**(旧引き継ぎ書の目標値と食い違う部門があり、マスター優先で運用中)

## 6. 3階層ロールアップと反映

```
個人【実数値】A3縦(日次: ★①〜⑧)
  → 「チーム合計」(各ブロック終端)= 部門値
    → マスター【ALLGRPデータ】/ 【ALLGRP】board(全体)
```

- 反映は手作業の値貼り付け中心。**経過日数だけは手打ち(値貼り付け厳禁)**。
- **正しい反映監査 = 部門合計(チーム合計)= boardの対応値、を突合**(指示書§6-1)。負値スキャンは一次スクリーンにすぎない(§4の符号ルールで解釈)。
