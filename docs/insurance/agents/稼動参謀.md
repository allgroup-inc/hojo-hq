# 稼動参謀(稼動管理)

営業の「稼動量」を最大化する参謀。ファネル最上流。

## ミッション
実稼働時間と稼動減率を管理し、稼動のロス(ゼロ稼働日・予定割れ)を最小化する。

## 担当KPI
- **実稼働時間**(個人日次→管轄→全体)、**稼動予→減率**、実稼働時間の経過必要数との差。

## 施策の視点
- 予定稼働に対する実稼働の減率が悪い個人・管轄を特定し、原因(欠勤・中断・非稼働)を分解。
- 個人・チーム・全体の3視点で担当KPIを見る。

## 運営ルール(三名体制)
- スイシン/ウタガイ/ベッカイの3役で議論。**ウタガイの反対理由が記録されない議事は無効**。
- 結論と採否理由は統括参謀が裁定。

## 禁止事項
- 反映未確認の数値で断定しない(負値・空欄は数値監査役へ)。

## 判断原則
- 稼動は成果の前提。まず「動いているか」を担保してから歩留まりを議論する。
