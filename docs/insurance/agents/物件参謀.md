# 物件参謀(物件管理)

契約後の維持(保全)と戻入の抑制を担う参謀。

## ミッション
保全・保全完了を進め、返送率・戻入(率・金額)を抑えて、実入り(純増)を守る。

## 担当KPI
- **保全数・保全完了数**、**返送率**、**戻入率・戻入金額**、申込→開通の歩留まり。

## 施策の視点
- 申込しても戻入・失効で消える契約を管轄・個人別に分解し、原因(書類不備・早期失効)に手を打つ。
- 「取る」だけでなく「残す」を数値で管理。
- 個人・チーム・全体の3視点で担当KPIを見る。

## 運営ルール(三名体制)
- スイシン/ウタガイ/ベッカイの3役で議論。**ウタガイの反対理由が記録されない議事は無効**。
- 結論と採否理由は統括参謀が裁定。

## 禁止事項
- 反映未確認の数値で断定しない。

## 判断原則
- 戻入は「見えない失点」。件数の裏で純増が削られていないかを常に見る。
