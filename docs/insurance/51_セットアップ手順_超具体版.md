# 見張り番 セットアップ手順(超具体版・コピペ用)

担当者(Pythonを触れる人)がこの通り進めれば、毎朝の自動監視が動きます。所要 約20〜30分・一回だけ。

---

## 用意するもの
- OneDrive が同期している **Windows PC**(`定例_収集` と `【ALLGRPデータ】` がローカルに見える状態)
- `scripts/insurance/` 一式(このリポジトリの中身。`.py` と `.bat` と `watchdog_config.example.json`)

---

## STEP 0. スクリプトを1フォルダに置く
1. PCに作業フォルダを作る。例: **`C:\allgrp_watchdog`**
2. `scripts/insurance/` の中身を**全部**そのフォルダにコピー。
   - 必要な中身: `allgrp_watchdog.py` / `rollup_check.py` / `audit_reflection.py` / `audit_all.py` / `reflect_teikei_to_board.py` と、`*.bat` / `watchdog_config.example.json`

## STEP 1. Python と openpyxl(setup.bat をダブルクリック)
1. フォルダ内の **`setup.bat`** をダブルクリック。
2. 「Python が見つかりません」と出たら → https://www.python.org/ からインストール。
   **インストール画面で「Add python.exe to PATH」に必ずチェック**。入れ直したら再度 `setup.bat`。
3. 「完了しました。」が出れば準備OK。

## STEP 2. パス3つを設定(make_config.bat で自動作成・手打ち不要)
1. **`make_config.bat`** をダブルクリック。
2. 黒い画面が「1) 定例_収集 フォルダ:」と聞いてくるので、エクスプローラーから **そのフォルダを画面へドラッグ＆ドロップ** → Enter。
   - ドラッグ＆ドロップでパスが自動で入ります(手打ち不要・`\\` も不要)。
3. 同様に「2) 【ALLGRPデータ】.xlsx ファイル」「3) 監視ログの出力先フォルダ」もドラッグ＆ドロップ → Enter。
4. `watchdog_config.json を作成しました。` と中身が表示されればOK。

> 手打ちしたい場合は `watchdog_config.example.json` をコピーして `watchdog_config.json` にリネームし、パスを書く(その場合 `\` は `\\`)。基本は make_config.bat が楽。

## STEP 3. 手動でテスト(test_check.bat をダブルクリック)
1. **`test_check.bat`** をダブルクリック。黒い画面に部門ごとの ✅/🟡/⛔ の表が出れば成功。
2. うまくいかない時:
   - `【実数値】A3縦 が無い` 等 → パスが違う。STEP 2 を見直す。
   - 文字化け → そのままでOK(ファイル出力は正常)。`work_dir\reports\` の `.md` を開いて確認。

## STEP 4. 毎朝9:05に自動実行(タスクスケジューラ登録)
1. スタート → **「タスク スケジューラ」** を開く。
2. 右の **「基本タスクの作成」** をクリック。
3. 名前: `ALLGRP反映監視` → 次へ。
4. トリガー: **「毎日」** → 次へ → 開始時刻 **9:05** → 次へ。
5. 操作: **「プログラムの開始」** → 次へ。
6. 設定:
   - プログラム/スクリプト: **`C:\allgrp_watchdog\run_check.bat`**(自分のフォルダに合わせる)
   - 「開始 (オプション)」: **`C:\allgrp_watchdog`**(スクリプトのフォルダ)← ここ空欄だと動かないので必ず入れる
7. 完了。

これで**毎朝9:05に自動でチェック**し、`work_dir\reports\` にレポート、`work_dir\history.csv` に履歴が残ります。

---

## 日々の運用
- **通常は何もしない。** ⛔(反映異常)が出た日だけ対応。
- ⛔が出たら: フォルダの **`run_fix.bat`** をダブルクリック → バックアップを取ってから自動修正 → 画面で内容を確認。
  - `run_fix.bat` は **バックアップを `work_dir\backups\` に必ず残す**ので、元に戻せます。
- 履歴を見たい: `work_dir\history.csv` を Excel で開く(いつ・どの部門で崩れたか)。
