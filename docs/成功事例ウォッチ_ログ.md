※ 標準ツール(2026-08-07〜): `last30days` スキルを毎回の調査に使う(Reddit/X/YouTube/HN等の直近30日の実際の声を収集)。
  検索テーマの基本セット: 補助金メディア運営 / LINE公式のB2B友だち獲得 / grant-finder系サービスのグロース。
  収集した示唆は従来どおり本ログに記録し、三役(スイシン/ウタガイ/ベッカイ)で取り込み可否を判定する。

## 2026-08-02 週次ウォッチ

今回は初回。基礎ベンチマーク(補助金ポータル=月100万UU・士業月額11,000円、ミツモア成約課金、診断CVR、沖縄制度213事業 等)は
`docs/組織総点検_やり切り計画_2026-08-02.md` §6 に記録済み。ここでは、そこに無い【新規の動き】を追記する。

### 1.【制度改正=供給の名称更新が必要・要確認】主要補助金の改称・統合(令和8/2026年度)
- IT導入補助金 → **「デジタル化・AI導入補助金」**に名称変更。
- ものづくり補助金 + 中小企業新事業進出補助金 → **「新事業進出・ものづくり商業サービス補助金」**に統合。
- 省力化投資補助金・中小企業成長加速化補助金 も実施中。
- **この事業に取り込めること**: 掲載制度の名称を新名称へ更新し、旧名で検索する利用者のために旧名も併記する(収集部shushu・検証部kensho)。年度・回で条件が動くため各制度は原文照合のうえ「要確認」運用。SNS/LINEでは「名前が変わった補助金」自体が関心を引く告知ネタになる。
- 参照: https://hojyokin-portal.jp/columns/hojyokin-chusho-summary / https://seisansei.smrj.go.jp/subsidy_info/schedule.html / https://www.asasimple.jp/it-hojyokin-2026/

### 2.【掲載・SNSネタ】小規模事業者持続化補助金「デジタル化枠」上限150万円・補助率2/3(要確認)
- 小規模事業者(製造業等20名以下/商業・サービス業5名以下)向け。通常枠(上限50万円)に加えデジタル化枠。
- **この事業に取り込めること**: 沖縄の小規模事業者に最も刺さる掲載/投稿テーマ。診断結果からの該当案内にも向く。金額・要件は公募回で変わるため原文照合し「要確認」。
- 参照: https://hojoguide.jp/guides/sme-subsidy-2026

### 3.【供給×出口の交差点】LINE公式アカウント等の導入が「デジタル化・AI導入補助金」の対象になり得る(要確認)
- LINE公式アカウント/配信ツール導入は同補助金の対象枠(例: A類型・最大150万円)で申請できるという解説が複数(※既に有料プラン導入済みは対象外等の条件あり=要確認)。
- **この事業に取り込めること**: (a)「LINEを補助金で導入する」啓発コンテンツは、まさにLINEを基盤にする自社の説得力を高める。(b) IT導入支援事業者(登録された士業・ITベンダー)への送客テーマになる。対価は掲載/月額/定額送客料の形式に固定し、案件別の成功報酬シェア(非弁提携リスク)は取らない。年度・枠で変動するため必ず原文照合・「要確認」。
- 参照: https://carearc.co.jp/blog/2149/ / https://note.com/carearc/n/n1fb4df072b3c

### 4.【一次情報源の追加候補】中小機構「補助金活用ナビ」
- 中小機構が補助金スケジュールを公開(seisansei.smrj.go.jp)。国の一次情報源として収集対象に加える候補(robots/規約は守り部mamoriの事前承認を経る)。
- 参照: https://seisansei.smrj.go.jp/subsidy_guide/subsidy_info/r7_schedule.html

## 2026-08-10 週次ウォッチ

### 1.【大型の制度動向】給付付き税額控除: 2026-08-05に基本方針が閣議決定(要確認)
- 減税と現金給付を組み合わせ、低所得ほど給付が厚くなる仕組み。2027年秋に「つなぎ給付」を先行、2029年度に本格導入の工程。個人単位判定・フリーランスも対象の枠組み。所得ラインは3案併記でまだ未決定。
- **この事業に取り込めること**: もらいわすれ堂の中核テーマ「取りこぼし防止」と完全に一致する国の大改革。①「いつから・誰が・いくら」を追う連載型コンテンツ(LINE/IG/note)の柱にできる ②制度DBに「これから始まる制度」枠を作り先回り登録。断定禁止・毎回原文照合。
- 参照: https://jitsumu-guide.com/refundable-tax-credit-guide-2026/ / https://hojyokin-portal.jp/columns/kyufu_zeigakukojyo_kyogi

### 2.【もらい忘れの実例=発信ネタ】子育て応援手当(児童手当2万円上乗せ)の申請が多くの自治体で6/30終了(要確認)
- 「知らずに締め切られた」実例として発信力が強い。またプッシュ型(申請不要・電子マネー/ポイント型)給付が増加傾向 — ただし口座登録や受取確認が必要なケースがあり、「プッシュ型でも受け取り漏れは起こる」が私たちの新しい訴求点になる。
- 参照: https://hojyokin-portal.jp/columns/kyufukin_shikyujiki / https://senken.co.jp/posts/subsidy-221006

### 3.【沖縄ローカル掲載候補】物価高騰系の県・市町村施策(要確認・次バッチ候補)
- 沖縄市「エイサー商品券」(R8年2月末〜5月中旬配付予定) / 那覇市の物価高騰対応給付群 / 県の食料品物価高騰支援給付金・医療施設等物価高騰対策。
- **この事業に取り込めること**: 拡充ループの次バッチ候補(公式URLで照合の上EXTRA_SEEDSへ)。商品券・免除系は「給付金」検索に出にくい=もらいわすれが起きやすい領域。
- 参照: https://www.city.okinawa.okinawa.jp/k018/form/p00001.html / https://www.pref.okinawa.lg.jp/kensei/shisaku/1014155/1034487.html

### 4.【競合動向】「補助金エージェント」が市町村別ページを展開(沖縄・那覇など)
- hojokin-agent.jp が都道府県×市町村の一覧ページでSEOを取りに来ている。個人ブログ(例: 沖縄の物価高対策まとめ)もローカルまとめ需要を証明。
- **この事業に取り込めること**: 私たちのarea構造(全41市町村)は先行優位。差別化は「照合済み表示・申請準備シート・世界観」。市町村ページに「商品券・減免」カテゴリを足すと競合との差が広がる。
- 参照: https://hojokin-agent.jp/subsidy/okinawa/naha / https://710to58.com/column/okinawa-shouhinken-bukkadaka-taisaku-2026/
