作成: 2026-08-02 / 三名体制検証済み(議事は本文書末尾) / 見直し期限: 2026-11-02(90日レビューと同時)

## 1. 目標(KGI/KPI)

- **KGI**: 2027年8月以降、年間20件以上のM&A成立+不動産トスが常時できる体制。沖縄県内で登録関係合計1万社との接点
- **Year1目標**: 成約3〜6件+ACN持ち込み10件(並行フル対応6枠+磨き上げ5社が上限)
- **行動KPI(定常月)**: レター230通(Tier1直筆30+Tier2 200)/架電540/アポ5〜8/面談4〜6
- **品質KPI**: 想起率30%+/対社アポ率1.5〜3%/転換率50%+/案件化25〜35%/開示交付100%/**DNC違反0**
- **ランプアップ**: 2026年8月=試行(定常の50%目安・契約は受けない)→9月=書面完成・型の確定→10/1=仲介契約受付開始→90日レビューで実測較正

## 3. 規程(判断基準・承認フロー・品質基準・エスカレーション)

### 3-1. 決裁権限表
| 行為 | 権限 |
|---|---|
| 手紙原稿の確定・投函/LP公開/RFQ送付/SNS発信 | 小柳さん決裁必須(エージェントはドラフトまで) |
| 契約・提携・支出・M&A支援機関登録申請 | 小柳さんのみ |
| 「嶺井が伺います」を含む文面 | 同行枠確保済みの先のみ使用可(それ以外は禁止) |
| リスト整備・原稿ドラフト・台帳運用・ダッシュボード | エージェント自走可 |
| glow-maコード変更 | PR+triangle-review必須 |

### 3-2. 品質基準(送付物は全件この順で通す)
1. **書かない言葉チェック**: M&A/売却/買収/譲渡/事業承継/廃業/査定/企業価値/マッチング=対外初期接触物ではゼロ(プレイブック9頁)
2. **正確性チェック**: 事実(数値・肩書・住所・実績表現)は一次情報と照合。不明は「要確認」で止める(hojo-accuracy-check準拠)
3. **過剰約束チェック**: 「本人が出ます/直接伺います」等、実運用と異なる約束を書かない
4. **humanizer仕上げ**: AIっぽさを除去(事実情報・導線は変えない)
5. **故人・代表者交代チェック**: 発送前クロスチェック S/A=全数、B=抜き取り
6. **DNC照合**: 発送・架電リストは台帳のDNCフラグと突合100%(同一電話番号の伝播含む)

### 3-3. エスカレーション条件
| 事象 | 対応 |
|---|---|
| DNC違反(断られた先への再接触)発生 | 即時停止→小柳さんへ当日報告→ニドナシ機構で再発防止 |
| 苦情・クレーム | 24時間以内に小柳さんへ報告 |
| 行動KPI 2週連続未達 | 統括が原因分析+是正案を週次レポに添付 |
| 三名体制で意見が割れ確信が持てない | たかしくん経由で小柳さんへ上申 |
| 嶺井さんの月8時間予算の超過見込み | 事前に小柳さんへ枠の再配分を上申 |

### 3-4. 定例カデンス
- **週次**: 月曜=統括レポ(発送数/架電数/アポ/面談/DNC照合結果/ダッシュボード履歴差分)
- **月次**: 成功事例ウォッチの採用判断(小柳さん15分)・スコア較正・役ローテーション
- **90日**: 2026-10-末にYear1計画を実測で更新(プレイブック既定)

## 6. 三名体制議事(体制見直し)

### 論点: GLOW M&A事業の運用体制はKGIに対して十分か

**スイシン(推進)**
- 人間3名+嶺井の実働にエージェント5部門(兼務)を重ねる二層体制で、ドラフト・検証・台帳を自動側に寄せれば、月230通/540架電の事務負荷は吸収可能。hojo-hqで実証済みの部門型+三名体制をそのまま流用でき、立ち上げコストが最小。

**ウタガイ(懐疑) ※空欄不可**
- **部門を増やしても実働(書く・電話する・訪問する)は人間3名+嶺井月8時間のまま。エージェント組織図は「整った感」を出すだけで、真のボトルネック(人手・決裁待ち)は1ミリも解消しない**。
- glow-ma本番投入前チェック3項目が未完のまま8月試行を始めると、DNC管理が台帳とExcelに分裂し「断られた先への再接触」事故(一発出禁+悪評)が起きる。**台帳の本番投入が終わるまで架電を開始すべきでない**。
- 月230通/540架電のKPIは実測ゼロの机上値。8月から100%を狙うと検品・投函の品質が崩れる。
- GLOW営業基盤がミカタのリポジトリに同居しており、公庫情報遮断(嶺井誓約)の観点で情報の壁が曖昧。アクセス権と記録の分離ルールが必要。
- 決裁がすべて小柳さん一点集中のため、小柳さんの応答が遅れた週はライン全体が止まる。

**ベッカイ(別解)**
- 部門新設ではなく「週次オペカレンダー+チェックリストだけで回す」最小案もある(組織図メンテのコスト削減)。
- 手紙開拓と並行して、公的センター・公庫コネクト・商工会経由の「紹介ルート」を先に太くする選択肢(リスト開拓より成約率が高いのは台帳設計でも紹介=常時Aランク扱いで織り込み済み)。
- Year1目標の二本立て(自社成約+ACN持ち込み)は既に下方修正案が出ている。体制を増やすより目標の実測較正(90日レビュー)を早めpublic化する方が誠実。

### 結論(裁定・小柳さんへの提案)
- 採否: **採用(軽量5部門+統括の二層体制)。ただしウタガイの条件付き**
  1. 架電開始はglow-ma本番投入チェック完了が前提条件(G1が最優先)
  2. 8月は定常KPIの50%目安の試行月とし、100%は9月から
  3. 決裁の一点集中対策として「48時間ルール」: 小柳さん決裁待ちが48時間を超えたものは週次レポ冒頭に滞留として明記
- 理由: 実働のボトルネックは体制図では解けないというウタガイの指摘は正しい。よって体制はドラフト・検証・台帳の自動化に限定し、価値は「人間3名の時間を実働に全振りさせること」に置く。
