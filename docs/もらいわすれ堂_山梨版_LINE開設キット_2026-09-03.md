元にした文書: docs/フクギイロ_LINE開設パッケージ.md(沖縄版・2026-07-24開設済み)

目的: **この文書の文面を貼るだけ**で山梨版LINEの開設が終わる状態にしておく。
所要: 約30分(無料プランで開始可)。
沖縄版と別アカウントにする理由: 配信内容が県で異なるため
(沖縄の締切アラートが山梨の登録者に届くと誤案内になる)。

---

## 1. 開設手順(人間タスク・約10分)

1. 遥さんの **LINE Official Account Manager**(manager.line.biz)にログイン
2. 左上のアカウント名 → **「新規アカウント作成」**(既存のLINEビジネスIDのまま追加作成できます。
   新しくビジネスIDを作り直す必要はありません)
3. アカウント作成:
   - アカウント名: **もらいわすれ堂|山梨の給付金・手当**
   - プロフィール画像: **`site/fukugiiro/assets/icon-512.png`**(沖縄版と同じ全面朱・512px)
   - 業種: 大分類「専門サービス」/小分類「その他専門サービス」
4. 開設できたら、下の2・3・4をコピペで設定

## 2. プロフィール設定(コピペ用)

- ステータスメッセージ(20字以内): `山梨の給付金を3分診断`
- 自己紹介文:
```
山梨のご家庭向けに、給付金・手当の「もらい忘れ」をなくすお手伝いをしています。
・3分の無料診断(名前や住所の入力は不要です)
・締切が近づいたらお知らせ
・「振り込まれた」までいっしょに確認
運営: 株式会社フクギイロ
```

## 4. 応答設定(コピペ用)

- 応答モード: **チャット**(あいさつ・キーワード応答以外は人間が返信)
- 営業時間外の自動応答:
```
メッセージありがとうございます。順番にお返事していますので、少しお待ちください🌳
お急ぎの申請締切のご相談は「締切」と送ってください。優先してご案内します。
```
- キーワード応答「報告」:
```
受給のご報告ありがとうございます!🎉
よろしければ次の3つを教えてください(わかる範囲でOKです):
1. 制度の名前(例: 児童手当)
2. お住まいの市町村
3. 申請してから振り込みまでにかかった日数
あなたの報告は、匿名の統計として「次の誰かのもらい忘れ」を減らすために使わせていただきます。
※お名前・ご住所・口座番号は送らないでください。
```

## 6. 運用ルール(沖縄版と共通・守り部準拠)

- トーク内で氏名・住所・口座・マイナンバーを**尋ねない**(送られてきたら削除依頼+取扱注意)
- 締切アラートは3層ルール: SNS=残り30日以上のみ / 7〜29日=LINE個別 / 7日未満=次回公募のご案内。
  利用者向けの表現は**「締切の約1か月前から」で統一**(「7日前」は誤り)
- 断定しない。「必ずもらえる」「絶対」は使わない
- 配信文面は出荷ゲート(scripts/shipping_gate.py)の検査対象。配信運用を始めるときに
  山梨チャネルを TARGET_GROUPS へ追加する(忘れると検査を素通りするため必須)
