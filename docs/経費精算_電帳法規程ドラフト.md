# スキャナ保存に関する事務処理規程(ドラフト)

作成日: 2026-07-23 / ステータス: **ドラフト(守り部レビュー→顧問税理士確認→小柳さん決裁の順。確認完了まで紙原本は併存保管)**
根拠: 電子帳簿保存法のスキャナ保存制度。国税庁の規程ひな形(「スキャナによる電子化保存規程」)の構成に準拠。

---

## 第1条(目的)
この規程は、当社が受領する領収書等の国税関係書類をスマートフォン等で読み取り、電磁的記録として保存するにあたり、真実性・可視性を確保するための事務処理手続きを定める。

## 第2条(適用範囲)
経費精算に係る領収書・レシートその他これに類する書類に適用する。

## 第3条(管理責任者)
- 管理責任者: 経理担当(氏名は運用開始時に別紙で定める)
- 事務担当者: 各従業員(自らが受領した領収書の読み取り・送信を行う)

## 第4条(入力の方法と期限)
1. 従業員は領収書を受領後、**おおむね7営業日以内**にスマートフォン等で撮影し、所定の宛先(keihi@)に送信する
2. 撮影はカラー・文字が判読できる状態で行う(解像度200dpi相当以上。スマートフォンの標準カメラで通常充足)
3. 判読不能の場合、システムからの依頼により再撮影を行う(最大1回)

## 第5条(訂正および削除の防止)
1. 保存した電磁的記録は、SharePoint のバージョン管理機能により訂正・削除の履歴が自動保全される
2. 保存記録の訂正・削除が必要な場合(誤送信・重複等)は、管理責任者に申請し、管理責任者が理由を記録簿に記載のうえ実施する。履歴の残らない訂正・削除は行わない
3. 承認済み・確定済みの記録は本人による編集を不可とする

## 第6条(検索性の確保)
保存した記録は、取引年月日・取引金額・取引先の各項目で検索できる状態を維持する(SharePoint リストの列により充足)。

## 第7条(原本の取扱い)
1. 本規程の運用開始後、顧問税理士による要件充足の確認が完了するまでの間、**紙の原本は従来どおり保管**する
2. 確認完了後は、システムへの反映を本人が確認した時点で紙原本を廃棄できる(反映連絡前の廃棄は不可)

## 第8条(定期点検)
管理責任者は四半期に1回、無作為に抽出した記録について、画像の判読性・検索性・入力期限の遵守状況を点検し、結果を記録する(週次サンプリング議論の枠組みで実施可)。

## 第9条(改廃)
この規程の改廃は小柳さんの決裁による。

## 【守り部・税理士への確認依頼事項】(規程本文には含めない)
1. 入力期限を「最長2か月+7営業日」の特例(業務処理サイクル方式)にするか、7営業日の原則のままにするかの選択
2. タイムスタンプ不要の要件(訂正削除履歴が残るシステム+本規程の整備)を SharePoint バージョン管理で充足すると整理してよいか
3. 紙原本の廃棄タイミングの妥当性(第7条2項)
4. インボイス(適格請求書)の保存要件との整合(登録番号の記録で足りるか)
