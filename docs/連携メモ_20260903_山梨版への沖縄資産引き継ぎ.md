## 2. そのまま流用できる運用の型(プロンプト・原稿)
- **拡充+鮮度ループ(週2 Routine)**: 話題スキャン→調査エージェント2〜3本(公式ドメイン照合・
  https限定・非断定JSON)→重複除去→EXTRA_SEEDS追記→PR→再構築→検証待ちリスト更新。
  プロンプト原文は本チャットのRoutine「制度拡充+鮮度ループ」を参照(地名を差し替えるだけ)
- **おもてなし総点検(月1 Routine)**: 3ペルソナで実機を歩く→「いいや」ポイント棚卸し→
  三名体制で5〜8件→実装→改善ログ。docs/おもてなし改善ログ.md の形式ごと流用可
- **LINE運用原稿**: docs/フクギイロ_LINE運用原稿.md の §A(あいさつ)/§C(締切3層ルール=
  「約1か月前から」で統一・「7日前」は誤り)/§E(受け皿応答)/§F(診断結果別の最初の1通テンプレ9種)。
  山梨OA開設が決裁されたら、地名と一覧URLを差し替えるだけで開始できる
- **成功事例ウォッチ(週1)/素材ウォッチ(毎日)** のRoutine型も同様に流用可

## 3. 沖縄で踏んだ地雷(先に避けてほしい)
1. **到達性チェックの静かな欠落**: 官公庁サイトが収集ボットを間欠的に弾き、制度が黙って掲載から
   消えることがある(未払賃金立替払で実発生)。手動照合済みシードは assume_reachable=True にし、
   突合レポートで「取得失敗」と「本当のリンク切れ」を区別する
2. **`deadline_type=期限あり` には `deadline`(日付)が必須**(検証器が書き込みを止める。fetch #215で実発生)
3. **年度事業を現行制度のように載せない**: 「令和◯年度・受付終了」ページしか見つからない制度は
   収載せず記録(非課税世帯給付金の照合で全市がこのパターンだった)
4. **検索要約AIの年度誤認**: 検索の要約が「令和8年度実施あり」と誤ることがある。**原文タイトル・URLを優先**
5. **承認フローの日またぎすり替え**・**ブランチ確認**等はCLAUDE.md再発防止メモ参照
6. **市町村クロールは規約確認が先**(依頼文の電話台本を使う)。沖縄は守り部審査記録の形式で残している
