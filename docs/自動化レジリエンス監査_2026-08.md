## 必須事項: Metaトークン期限(2026-09-28)問題

- 長期ページトークンの失効が **9/28前後と推定**(議事_20260731 ウタガイ指摘の通り正確な失効日は未検証。「不明は断定しない」に従い推定として扱う)
- 失効すると月水金のSNS自動投稿が止まる。失敗時LINE通知はあるが、**承認ゲート通過後のpostジョブでしか発火しない**=承認されない週は無言のまま
- 既存の緩和: weekly-report がFB/IG取得不可を毎週表示(実質の死活監視)。決裁キューに「9月下旬再発行+Secrets更新」登録済み
- 改善(原則⑦「文章でなく仕組みで守る」): healthcheck に Graph API `debug_token` チェックを追加し、**期限30日前からIssue+LINEで自動督促**。人のカレンダー記憶に依存させない
