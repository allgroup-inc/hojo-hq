## 🔗 事業軸との連携マッピング

### 軸❶：嶺井さんの紹介案件（M&A・不動産）
- **入口**: kakei-crm / apogen（アポ生成システム）
- **本システムでの役割**: 紹介企業のアポを一元管理し、営業マン12名に自動振り分け
- **API契約**: POST `/api/v1/appointments` で自動登録
- **KPI連携**: 紹介案件の面談転換率をダッシュボードで可視化

### 軸❷：沖縄企業のミカタ（助成金情報・LINE登録）
- **入口**: SNS・検索流入 → 診断ツール → LINE登録
- **本システムでの役割**: LINE登録企業の「要件に合った営業マン」のアポを自動提案
- **API契約**: 企業マスタからの営業マン推薦リスト取得
- **KPI連携**: LINE登録→アポ→商談転換の各段階を追跡

### 軸❸：ゆんたく経営相談室（手紙アプローチ）
- **入口**: 手紙→QRコード→面談申し込み
- **本システムでの役割**: 高齢経営者向けのアポを専任営業（部長等）に優先配置
- **API契約**: 優先度・対象営業の指定が可能な専用エンドポイント
- **KPI連携**: 手紙からの面談実現率をレポート

### 軸❹：営業管理システム（本システム = つなぎ）
- **実装範囲**: スケジュール管理・営業KPI・リアルタイム通知
- **ローカル管理**: PostgreSQL + Node.js + React
- **監視**: 営業マン12名の移動・スケジュール効率・キャンセル率
- **統合ポイ**: 
  - ❶からのアポ取り込み
  - ❂への訪問完了通知
  - ❸への優先度指定
