## ① BlueBean版アップの日程変更可否

### 新情報（三名体制レビューから）

- **Webhook投入予定**: 2026-10-01 朝 9:00-10:00
- **懸念**: BlueBean版アップ（夜間）と同じ週に Webhook 投入すると、トラブル発生時に「どちらの変更が原因か」判別が困難になる

### 検討案

#### **案A: 予定通り実施（水曜夜間）**
**メリット**:
- 計画通り進行（遅延なし）
- ソフツーへの返答・日程確認が完了している

**デメリット**:
- Webhook投入と同週に システム変更が2つ重なる
- トラブル発生時は両方を並行調査する手間
- 夜間なので即座のサポートが難しい可能性

#### **案B: 延期（翌週水曜以降に）**
**メリット**:
- Webhook投入から1週間経過後の延期なので、データ品質確認後に版アップ
- トラブル原因の特定が容易（版アップ単一要因）
- リスク回避

**デメリット**:
- ソフツーに日程変更を連絡する手間（追加コミュニケーション）
- 費用には影響なし（5000円は時間外費用で実装）
- 計画が遅延

## ② 自動応答メッセージ形式の最終確認

### 現状

- **現在の形式（9/23～）**: 2項目形式
  ```
  「お電話番号を入力してください」
  「ご都合のいい時間帯を教えてください」
  （例：090-1234-5678 / 10:00-12:00）
  ```

- **9/30 の結果**: ボタン押下 7 人 → 返信 0 人

### 背景

- 9/22: 上間さんから「アンケート形式にしたらどうか」という提案あり
  - 「まず性別を教えてください」→ 「年代を...」みたいな段階的フロー
  - 長澤さんの提案（業務側）

- 小柳さんの判定: 「2項目形式でいく」と決定（9/23）

- 現在: 2項目形式で 1 週間運用 → 0返信

### 分析

#### **2項目形式を選んだ理由（当時）**
- シンプルで素早く決定できる
- フォーム入力の負担が少ない

#### **現在の課題**
- 7人クリック → 0人返信 = 100% 失敗
- 原因が不明：
  - フォーム画面が表示されていないのか？
  - ユーザーが入力を試みたが失敗したのか？
  - 入力したが送信ボタンが見当たらないのか？
  - **Webhook 受け口がないので、そもそもデータが取られていなかったのか？** ← これが主原因

### 検討案

#### **案A: 2項目形式を継続**
**根拠**:
- アンケート形式よりシンプル
- Webhook 投入（10/1）後に、実際のユーザー行動データが見えてくる
- 1 週間では サンプルサイズが小さすぎる（7人）
- 10/1-10/7 のデータで改めて判定すべき

**手順**:
- 10/1: Webhook 投入開始
- 10/1-10/7: 詳細ログ取得・品質確認
- 10/7: 実データに基づいて「2項目 vs アンケート」を再判定

#### **案B: アンケート形式に変更（今すぐ）**
**根拠**:
- 現在の 2 項目では 0 返信なので、別の形式を試す
- 段階的に質問する方が「ユーザーが答えやすい」可能性
- 長澤さんの提案なので業務側の意図がある

**デメリット**:
- Webhook 投入直前の変更は、原因分析が複雑化（形式変更 + Webhook投入 で何が改善したか判別困難）
- 1 週間で再度変更する手間

### **小柳さんの判断を求める事項**

**Q**: Webhook 投入（10/1）時点で形式をどうしますか？

**パターン①: 2項目形式のまま進める**
- 現在のまま継続
- 10/1-10/7 でデータ品質確認
- 10/7 で改めて判定

**パターン②: アンケート形式に変更して投入**
- 今日中に上間さんに形式変更を依頼（実装はBlueBean版アップ後？）
- 10/1 にアンケート形式で投入開始
- Webhook + 新形式 のダブル変更のため、結果解釈に注意

**パターン③: 10/7 判定まで保留**
- とりあえず 2 項目形式で 10/1-10/7 データを取る
- 10/7 に「2項目」「アンケート」「その他」の中から最適形式を決定

### **推奨**（三名体制レビューより）

**ウタガイ(懐疑)の指摘**:
- 形式変更とシステム変更（Webhook）が同時は原因分析が困難
- 現在の 0 返信は、Webhook がないのが主原因（形式ではない可能性高）

**推奨**: パターン①（2項目のまま、10/7 で改めて判定）
