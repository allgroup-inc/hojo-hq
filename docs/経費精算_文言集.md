# 経費精算 文言集(全通知テンプレート)

作成日: 2026-07-23 / 監修: 社外ホスピタリティ・パネル(型: お預かり→お礼→進捗→完了報告。責める言い回し禁止)
運用ルール: 文言の変更はこのファイルを更新してからフローに反映(ファイルが正・フローが写し)。通知は①と④の2通が基本、③⑤は該当者のみ。

---

## ① お預かり返信(受信後すぐ・全員に必ず送る)

件名: 【経費精算】お預かりしました
```
◯◯さん

領収書をお預かりしました。ありがとうございます。

┌─────────────────────
│ 4月12日  ◯◯商店
│ ¥3,240
└─────────────────────

あとは「目的」を選ぶだけです(10秒で終わります)。
▶ マイページを開く: <リンク>

読み取り内容に間違いがあれば、マイページで直せます。
```
※要対応(読取失敗)のときも同文で送る。カード部分は「内容はこちらで確認して入力します。そのままお待ちください」に差し替え。

## ② 申請受付(「これで申請」を押した直後・画面内メッセージ)

```
申請を受け付けました。承認されましたらお知らせします。
今月もおつかれさまです。
```

## ③ 月末リマインド(未申請の人にだけ・月末3営業日前・月1回まで)

件名: 【経費精算】月末が近づいてまいりました
```
◯◯さん

今月の精算締めが◯月◯日に迫ってまいりました。
お預かり中の領収書が ◯件 ございます。いまなら10秒で終わります。

▶ マイページを開く: <リンク>

もし今月分でなければ、そのままで結構です。来月に繰り越します。
```

## ④ 承認完了(承認された直後)

件名: 【経費精算】承認されました
```
◯◯さん

◯月◯日分(◯◯商店 ¥3,240)が承認されました。
今月の精算は ◯月◯日 のお給料と合わせてお振り込みです。

今月の精算状況: 承認済み ◯件 / 合計 ¥◯◯,◯◯◯
```

## ⑤ 要対応48時間超の状況連絡(正直に・本人へ)

件名: 【経費精算】確認にお時間をいただいています
```
◯◯さん

◯月◯日にお預かりした領収書について、
読み取りの確認にお時間をいただいており、まだ一覧に反映できておりません。
申し訳ありません。担当が確認し、◯日中に反映いたします。

お手元の紙は、反映のご連絡まで捨てずにお持ちください。
```

## ⑥ 差戻し(承認者が拒否したとき)

件名: 【経費精算】1点だけ確認させてください
```
◯◯さん

◯月◯日分(◯◯商店 ¥3,240)について、
承認者から確認のお願いが届いています。

「<承認者のコメント>」

▶ マイページから修正して、もう一度申請できます: <リンク>
お手数をおかけします。
```

## ⑦ 撮り直しのお願い(最大1回まで・どうしても読めないときのみ)

件名: 【経費精算】もう一度だけ撮影をお願いできますか
```
◯◯さん

お預かりした写真が少し光ってしまっていて、金額の確認ができませんでした。
お手数ですが、もう一度だけ撮影して同じ宛先にお送りください。

コツ: 影にならない場所で、真上から撮ると一度で通ります。
```

## 禁止文言(ウタガイ役指摘の反映)
- 「読み取りに失敗しました」「エラー」「無効です」→ 使わない(①の差し替え文か⑦で対応)
- 「至急」「必ず」「してください」の連発 → 依頼は1通につき1つまで
- システム都合の説明(OCR・API・フロー等の用語)→ 画面・メールに出さない
