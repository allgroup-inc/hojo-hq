# 週次チェックポイント テンプレート

**目的**: KAKEHASHI プロジェクトの進捗を毎週追跡し、ボトルネック・リスク・意思決定事項をタイムリーに小柳さんへ報告する

**頻度**: 毎週月曜 10:00 JST  
**対象**: Phase 4（監査）～ Phase 5（デプロイ）～ Phase 6（安定化）  
**報告先**: 小柳さん（CC: アカリさん統括、検証部）  
**記録場所**: `docs/weekly-reports/YYYY-Www_checkpoint.md`

## ✏️ 記入上の注意

1. **進捗は数値で**: 「進んでいる」ではなく「XX/XX完了」と記載
2. **ブロックは具体的に**: 「インフラが遅い」ではなく「Azure Key Vault の Managed Identity 権限設定に3日要す」
3. **SLA は実測値で**: 予想ではなく実測のメトリクス（Application Insights から抽出）
4. **リスク評価は一貫性で**: 週ごとに基準がぶれないよう、過去レポとの比較を確認
5. **決裁申請は選択肢を明示**: 推奨だけでなく代替案も示し、小柳さんが判断しやすくする

## 使用方法

1. **毎週月曜 09:00 JST**: 前週の報告書を `docs/weekly-reports/YYYY-Www_checkpoint.md` に作成
2. **09:30 JST**: 内容を確認し、必要に応じて三名体制で議論
3. **10:00 JST**: 報告書を Slack `#phase4-audit` に投稿（小柳さんへ通知）
4. **10:30 JST**: 小柳さんからのフィードバック・指示受け取り
5. **以降**: その週の対応を指示に従って実施
