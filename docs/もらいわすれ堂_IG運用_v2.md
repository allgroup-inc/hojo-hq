## 3. 1か月投稿カレンダー(第1弾の後・週3ペース)

投稿の柱(ピラー)は4つ。週3本(月・水・金)で回す。ネタは制度DB(143件・確認済み116件)から無限に出せる。

| 柱 | 内容 | 頻度 |
|---|---|---|
| ① 制度ひとつ紹介 | 「◯◯市の給食費、無償化されたの知ってた?」型。18歳拡大・無償化など今年の変更ネタが強い | 週1(月) |
| ② 地域まとめ | 「◯◯市で使えるかもしれない制度、いま◯件」型。市町村ページへ誘導 | 週1(水) |
| ③ やり方・安心 | 申請ナビ(電話台本・持ち物)・匿名診断・要確認の誠実さ | 週1(金) |
| ④ 受給報告(将来) | 「振り込まれました」の声(匿名)。受付開始後に柱④として追加 | 開始後 週1 |

週次の具体ネタ例(9〜12日目以降):
- 沖縄市・宜野湾市など「こども医療費が18歳まで広がった」シリーズ(10市町村ぶんある=10本作れる)
- 給食費無償化シリーズ(浦添・八重瀬・読谷・嘉手納・宜野座・今帰仁…)
- 離島の渡航費助成(座間味・粟国・伊平屋…「島の通院、船賃の助成があります」)
- 申請ナビの「まず電話で聞く3つ」紹介

## 4. 週次運用パイプライン(mindshare-arbitrage 6段を適用)

人が関わるのは**2箇所だけ**。それ以外はAI(このチャット/週2ループ)が用意する。

| 段階 | やること | 担当 |
|---|---|---|
| ① 発見 | 制度DBの新着・変更(週2ループが検知)+`last30days`で話題の制度をスコア化し、投稿候補3〜5本をリストアップ | AI(自動) |
| ② レビュー | 候補リストから「作る価値があるもの」を選ぶ。**5分でOK** | 遥さん(or 小柳さん) |
| ③ 生成 | キャプション+画像の文字+タグセット指定まで作成(writer→humanizer→criticの3段仕上げ・accuracy/deadline照合済みで渡す) | AI(自動) |
| ④ スライド化 | ブランドキットに沿って画像化(Canvaテンプレ) | 遥さん |
| ⑤ 承認・投稿 | 最終チェックして投稿。CVはbioのLINEリンク1点のみ | 遥さん |
| ⑥ 分析 | 保存数・プロフィールアクセス数を週次レポに1行記録→次週の①の重み付けへ | AI+遥さん(数字転記のみ) |

運用ルール(変えないこと):
- 「もらえる」と言い切らない/金額・締切の数字は画像に大きく載せない
- 締切に触れるときは「約1か月前からお知らせ」で統一(「7日前」表現は禁止)
- CVはLINE登録の1点。キャプションにURLは貼らない(bioリンク経由)
- 制度に触れる投稿は、公開前にサイト掲載内容(=公式照合済み)と一致しているか確認
