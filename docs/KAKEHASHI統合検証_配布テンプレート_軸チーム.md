## 📋 軸チーム向けの検証項目

軸チーム自体が確認すべき項目：

### 1. 権限・トークン管理
- [ ] Actor クラスが layer 層分配に対応
- [ ] トークン発行フロー（GAS/API）が動く
- [ ] トークン有効期限チェック（is_expired）が機能
- [ ] 期限切れトークンは 401 を返す

### 2. 顧客マスタ・名寄せ
- [ ] LINE Webhook からの顧客受け取りが正常
- [ ] 名寄せ（judge_match）が 黒/グレー/白 を正しく判定
- [ ] グレーの顧客が自動確定されない（人による確認待ち）
- [ ] 親子構造での重複管理が正しく動く

### 3. アクセス記録・監査
- [ ] access_log に全システムからのアクセスが記録される
- [ ] 理由（reason）が必須で記録される
- [ ] 誰が・いつ・何に・なぜ・どこで が完全に追跡可能
- [ ] システム横断での監査が可能か

### 4. データ品質
- [ ] 電話番号の正規化・重複管理
- [ ] DNC（架電禁止）の種別・強度が正しく管理される
- [ ] 子レコードの DNC が親に正しく伝搬
- [ ] 用語（scope / channel / data_class など）が統一

### 5. API仕様の確認
- [ ] 各システムが呼ぶ API エンドポイントが実装されているか
- [ ] request/response スキーマが 文書・テストと一致
- [ ] エラー時の 400/401/403/500 レスポンスが仕様通り
- [ ] API バージョニング・互換性は問題ないか
