# もらいわすれ堂 個人情報保護方針 弁護士確認ブリーフ

作成: 2026-07-27 / 提出先: (顧問弁護士 or スポット相談) / 依頼者: 株式会社フクギイロ 小柳
公開中の方針: https://allgroup-inc.github.io/hojo-hq/fukugiiro/privacy/

## 0. 依頼のお願い(要旨)
当社は沖縄県の世帯向けに、給付金・手当の「もらい忘れ」を防ぐ情報サイト「もらいわすれ堂」を運営しています。**個人情報の取得を極力しない設計**にしており、公開済みの個人情報保護方針が実態と法令に照らして妥当か、特に下記3論点についてご確認をお願いします。

## 1. データの流れ(1枚で把握)
```
[利用者のスマホ/PC]
   │
   ├─(A) 3分診断 … 市町村・世帯構成・子の年齢帯・ライフイベントを選択
   │        └─ 判定はすべて端末内(ブラウザ)で完結。回答は当社サーバーへ送信しない。
   │           端末内 localStorage にのみ保存(利用者が消去可)。当社は受信・保存しない。
   │
   ├─(B) アクセス解析(Plausible) … Cookie不使用・個人を特定しない匿名のページ閲覧統計のみ
   │
   └─(C) LINE登録(任意・診断後) … LINE公式アカウントの友だち追加
            └─ 当社が取得するのは LINE識別子・表示名等(配信に必要な最小限)
            └─ 用途: 締切リマインド・申請手順・受給フォローの配信
            └─ 配信の技術委託: LINEヤフー(LINE)/ Microsoft(Power Automate)
```
- 取得しない: 氏名・正確な住所(番地)・電話番号・メール・マイナンバー・口座情報・病名等の要配慮個人情報。
- ホスティング: GitHub(GitHub Pages)。制度DB・統計・生成物のみを置き、個人データは置かない。

## 2. ご確認いただきたい3論点
1. **診断の「端末内処理」の説明の十分性**
   - 診断の回答を当社が受信・保存しない旨をサイトに明示しています(「回答や記録はこの端末の中だけに保存され、送信されません」)。この説明で、個人情報保護法上「当社は当該回答を取得していない」と整理して差し支えないか。localStorage 保存に関し追加の注意書きが必要か。
2. **要配慮個人情報の非取得設計の妥当性**
   - 障がい・医療系の制度は「該当の可能性がある窓口の案内」までとし、症状・病名等の入力を一切求めていません。ライフイベント選択(例:介護・出産)から要配慮情報を推知する懸念はないか。現行の非取得設計で十分か。
3. **LINE識別子の取扱い・越境移転**
   - LINE公式アカウント経由で取得する識別子等について、LINEヤフーの規約・プライバシーとの整合、および越境移転(該当する場合)に関する記載の要否・書き方。

## 3. 参考(公開判断の前提)
- 事業者の所在地・代表者名は、法32条の「本人の知り得る状態(求めに応じ遅滞なく回答する場合を含む)」に依拠し、**印字せずLINE窓口での請求時開示**としています。名称(株式会社フクギイロ)は表示。この整理の可否もあわせてご意見ください。
- 現在の収益導線はLINE登録のみ(物販・課金なし)。将来B2Bで課金開始時は特定商取引法により住所・代表者名の表示が必要になる想定です。
