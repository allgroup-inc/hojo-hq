# 議事: みらいひらけ堂 掲載基準v2(厳格化)と定期監査の仕組み

- 日付: 2026-09-06
- 発端: 小柳さん指示「より厳しい基準や定期的監査の仕組みを考えてみて下さい」(掲載基準v1ドラフトへのフィードバック)
- 関連: docs/みらいひらけ堂_掲載基準_draft.md(v2) / scripts/miraihirake/audit_services.py / .github/workflows/miraihirake-audit.yml
- 種別: 掲載方針=小柳さん決裁事項 → 三名体制議事必須

## 論点: 掲載基準をv2(厳格化)とし、機械+人の二層の定期監査を導入するか

### スイシン(推進)
- 子ども向けは「載せ損ない」より「危ないものを載せる」方が取り返しがつかない。**フェイルクローズ(迷ったら載せない・疑いが出たら即非表示)**を大原則に明文化すべき。
- v2の主な強化点: ①実在確認は法人番号または自治体登録を原則必須 ②個人が単独で子どもと接する形態(D類型)は例外なく掲載禁止 ③1対1(C類型)は安全4点確認+年1回再確認 ④料金・対象が要確認のものは掲載保留 ⑤掲載団体からの金銭・寄付・便益の受領を全面禁止(利益相反遮断) ⑥通報窓口(24時間以内一次対応・対象は即非表示) ⑦publishedの維持に90日ごと再確認、120日超は自動非表示。
- 監査は機械+人の二層: 週次の自動監査(必須項目・鮮度・URL死活・自動降格・撤退基準判定。実装済み・テスト済み)と、週次無作為照合(検証部)・月次独立監査(タダスさん)・年次のC類型全件再確認。**人が忘れても機械が止める**構造になる。

### ウタガイ(懐疑)  ← 空欄不可
- **厳格化はミッションと逆行し得る**。「知らなかったから使えなかったをゼロに」が使命なのに、法人番号のない草の根の無料塾・学生サークルを弾けば、いちばん現場に近い支援が載らない。厳しさは安全のためであって、掲載数を絞ること自体が目的ではない。例外ルート(後援・助成の裏取り)が実務で回るかを最初の10件で必ず検証すべき。
- **90日再確認は工数を自ら増やす約束**。100件載せれば毎月30件超の再確認が発生し、回せなければ自動非表示が量産されて「いつ見てもスカスカのサイト」になる。撤退基準(80%/60%)を自分で踏みにいくリスクを認識せよ。載せるペースより先に、再確認を回す体制(誰が・週何時間)を決めるべき。
- **D類型の全面禁止で優良な個人ボランティアを排除する**。ただし個人の善意を装う接触リスクは見分けが付かないため、禁止自体には賛成。その代わり「団体に入って活動してください」と案内する導線(掲載団体のボランティア募集への誘導)を用意しないと、善意の受け皿を潰すだけになる。
- **監査ジョブが「赤くなるだけ」では止まらない**。過去の反省(2026-08-18: 両ジョブsuccessで誰も気づけなかった)の逆で、赤が常態化すると誰も見なくなる。赤になったら誰が・いつまでに対応するかのSLA(週次レポでユイさんが確認、2週連続赤で小柳さんへ上申)を運用規程に書くこと。
- **通報窓口の24時間一次対応は誰がやるのか**。無人で掲げれば「約束したのに放置」で信頼を失う。フォーム通知の受け手(ユイさん統括の週次+緊急はLINE通知)を決めてから公開すること。

### ベッカイ(別解)
- **案A: 掲載可否の二値ではなく「安全情報の表示」にする**。C類型を弾く代わりに「本人確認あり/保護者同意あり/見守りあり」をバッジ表示し、利用者(保護者)が判断する設計。掲載数を保ちながら透明性で安全を担保する。ただし小学生本人が使う前提では「表示を読んで判断せよ」は酷であり、v2のフェイルクローズと両立しない。参考案として記録。
- **案B: 審査を外部と共同にする**。沖縄こどもの未来県民会議や社協の登録団体は「登録済み=実在確認済み」とみなして審査を簡略化(二重審査の無駄を省く)。県内分の審査コストが大きく下がる。
- **案C: 監査の月次無作為点検を、既存の統合週次レポ(§4監査所見欄)に相乗りさせる**。新しい仕組みを増やすより、既存の監査カデンスに「みらいひらけ堂」の行を足す方が確実に回る。

### 結論(部門長の裁定)
- 採否: **v2案+監査二層を上申**(掲載方針のため最終決裁は小柳さん)
- 理由: スイシンのフェイルクローズ原則は子ども向けサービスの性質上正当。ウタガイの指摘は運用条件として採用する — ①例外ルート(後援・助成の裏取り)の実効性を最初の10件で検証 ②再確認体制(担当と週あたり時間)を掲載50件到達前に確定 ③D類型禁止とセットで団体ボランティア募集への誘導導線を用意 ④監査赤のSLA(ユイさん週次確認・2週連続赤で上申)を運用規程化 ⑤通報窓口は受け手を決めてから公開。ベッカイ案B(県民会議・社協登録の簡略化)と案C(統合週次レポへの相乗り)は採用推奨として併記。案Aは不採用(フェイルクローズと両立しないため)だが記録として残す。
