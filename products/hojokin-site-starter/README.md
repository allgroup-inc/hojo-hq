# 補助金・支援制度まとめサイト 構築テンプレ

国の補助金ポータル **jGrants の公開API** から補助金情報を毎日自動取得し、
AIが経営者向けにやさしく整理して、まとめサイトとして自動公開するテンプレート
です。サーバー不要・GitHub 1リポジトリで完結します。

```
GitHub Actions cron(1日2回)
   │
   ▼
[1] collect.py    jGrants公開API(+任意でRSS/HTML)から受付中の制度を取得
   │              ※締切・上限額はAPIの値をそのまま機械転記(AIに書かせない)
   ▼
[2] structure.py  Claude APIが要約・対象者などを経営者向けにやさしく整理
   │
   ▼
[3] validate.py   品質ゲート(締切形式チェック・出典URL必須・不明は「要確認」)
   │
   ▼
[4] build_site.py 締切が近い順の一覧サイトを生成 → GitHub Pagesで公開
```

## このテンプレの特長(汎用スクレイパーとの違い)

1. **公的API利用** — jGrantsの公開APIを使うため、スクレイピングの規約リスクなし
2. **数字をAIに書かせない** — 締切・上限額はAPIの構造化データを機械転記。
   AIの仕事は「要約と平易化」だけ。誤情報を構造的に防ぐ
3. **出典必須・要確認表示** — 出典URLのない情報は公開されない。原文で確認
   できない項目は「要確認」表示(景表法的にも安全側)
4. **締切ファースト設計** — 締切が近い順に表示、30日以内は「締切間近」バッジ。
   受付終了は自動でグレーアウト

## 収益化の型(参考)

- **地域×補助金**(例: 「〇〇県の補助金まとめ」)で検索・SNS流入を作る
- CTAはLINE公式アカウント登録などの1点に絞る(締切リマインドを登録特典に)
- 集まったリードを士業・支援機関へ紹介、または自社サービスへ誘導
- ※申請代行は行政書士の独占業務です。**申請支援そのものには踏み込まず、
  情報提供と専門家への橋渡しまで**にとどめるのが安全です(LICENSE.md参照)

## セットアップ(約15分)

基本手順は `docs/SETUP.md` のとおりです(pipeline-starterと同一手順)。
異なるのは手順3のみ:

`config/sources.yml` の `keyword` を自分のテーマに変更します。

```yaml
sources:
  - id: jgrants-okinawa
    name: jGrants(沖縄関連)
    type: jgrants
    keyword: 沖縄        # ← 地域名や分野(IT導入、省エネ、創業 など)
    enabled: true
```

複数キーワードで並行収集する場合は、idを変えてブロックを複数書きます。

## ディレクトリ構成

```
├── config/
│   ├── sources.yml        # 収集キーワード・情報源の定義
│   └── schema.json        # 制度データの項目定義(締切・上限額・補助率など)
├── scripts/               # 収集→AI整形→品質ゲート→サイト生成
├── site/                  # 生成された公開サイト(自動更新)
├── data/                  # 収集・整形データ(自動更新)
├── .github/workflows/     # 自動実行の設定(1日2回)
└── docs/                  # セットアップ・カスタマイズ・FAQ
```

## 注意事項(必ずお読みください)

- **正確性は運用者の責任で最終担保してください。** 本テンプレートは「原文で
  確認できない値を要確認と表示する」「出典のない情報を公開しない」仕組みを
  備えていますが、掲載内容の最終確認を代替するものではありません
- 利用者向けの文言には「必ずもらえる」等の断定・誇張表現を使わないでください
- jGrants APIの仕様は予告なく変更されることがあります(docs/FAQ.md参照)
- 補助金の**申請代行**は行政書士の独占業務です(2025年6月の行政書士法改正で
  取り扱いが厳格化)。本テンプレートは情報提供サイトの構築用であり、
  申請支援業務への利用は各士業法をご確認ください
