# note/Brain 集客・販売 運用プラン

## 基本方針

Gumroad単体は発見性ゼロ(集客は完全に自分持ち)のため、**発見性のあるnoteを
入口にする**。無料記事で信頼と検索流入を作り、記事末尾から有料商品へ誘導する。

```
無料記事(note)← 検索・note内回遊・X告知
   │  記事末尾に商品リンク
   ▼
有料商品(note有料記事 or Brain)= テンプレZIP添付
   │  商品内・購入者メッセージ
   ▼
セットアップ代行 3〜5万円(アップセル)→ 月額メンテ 1万円(ストック)
```

## 販路の使い分け

| 販路 | 使い方 | 手数料目安 |
|---|---|---|
| note | 無料記事(集客)+有料記事(1,000〜3,000円帯の商品) | 売上の約15〜20% |
| Brain | 8,000円帯のテンプレ本体(紹介料機能で他者に売ってもらえる) | 12%+紹介料設定分 |
| ココナラ | 代行メニュー(構築3〜5万)の受け皿 | 22% |

Brainの紹介料は30〜40%に設定(単価8,000円なら紹介1件で2,400〜3,200円。
AI系インフルエンサーが拾ってくれる水準)。

## 立ち上げ2週間の動き

1. noteアカウント開設(実名 or 屋号。プロフィールに「作ったものを公開する人」と明記)
2. 無料記事1本目を公開(下書き: `note記事1_無料.md`)+ X告知
3. 3日後、無料記事2本目を公開(下書き: `note記事2_無料.md`)
4. 1週間後、商品をBrain/noteに出品し、両記事の末尾リンクを商品に差し替え
5. 以後、週1本の無料記事(制作過程・購入者の活用例・失敗談)を継続

## 記事のネタ帳(3本目以降)

- 「テンプレを買った人がハマるポイント3つ」(FAQの記事化)
- 「Claude APIの請求額、実際いくらだったか公開」(数字公開系は強い)
- 「情報収集サイトを1つ作って1ヶ月放置した結果」(実績報告)
- 「業種別カスタマイズ例: 士業事務所の場合」(B2B導線を兼ねる)
