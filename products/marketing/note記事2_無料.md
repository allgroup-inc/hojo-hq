# 【note無料記事 下書き2本目】

タイトル案(推奨1、予備2):
1. **AIが書いた売上レポート、検算したら数字が違っていた。それも完璧に自信満々な文章で**
2. AIに「数字」を書かせてはいけない——週次レポートを自動化して最初にぶつかった壁

---

AIに先週の売上レポートを書かせたら、流暢で、構成も完璧で、前週比のパーセンテージまで入った文章が返ってきました。

検算したら、その数字が違っていた。

嘘をつく気はないんです。大量の行を「目で足し算」しているようなものだから、ズレる。人間と同じです。怖いのは、間違った数字でも一切ためらいのない文章で書いてくることでした。

いまは毎週月曜の朝、正しい数字のレポートが自動で届いています。作り直しにかけた時間は半日、運用コストは月100円未満。何を変えたのかを書きます。

## 解決: 「計算は機械、文章はAI」に分業する

作り直したバージョンはこうです。

1. **集計はPythonが実行**(前週比・カテゴリ別・件数——すべて普通のプログラムで計算。1円もズレない)
2. **集計済みの数字だけをAIに渡す**
3. AIの仕事は「この数字を見て、所見と提案を書く」ことだけ
4. プロンプトで「渡した数字以外を書くな。要因は断定するな」と縛る

この構造にしてから、数字のミスはゼロです。そしてAIの所見は正直かなり優秀で、「保険カテゴリの件数は横ばいだが単価が下がっている。単価の高い商品の提案数を確認しては」みたいな、ちゃんと使える指摘をしてきます。

## 原則: AIには「AIにしかできないこと」だけをさせる

| 仕事 | 誰がやるべきか |
|---|---|
| 計算・集計 | プログラム(数字をAIに書かせないため) |
| 形式チェック | プログラム(ルールが明確だから) |
| 要約・所見・提案 | AI(ここが人間の代替になる部分) |
| 最終判断 | 人間 |

「全部AIにやらせる」は事故のもとで、「AIを組み込んだ仕組みを作る」のが正解——というのが、いくつか自動化を作ってきた今の結論です。

## この仕組みもテンプレにしました

売上CSVを置くだけで毎週月曜にレポートが届く仕組みを、コード一式と手順書のテンプレートにしています。数字は機械が計算し、AIは文章だけを書く設計そのまま。中身は[こちら](URL)。

顧問先に週次レポートを出している士業・コンサルの方なら、そのまま納品物にも使えます(ライセンスで明示的に許可しています)。
