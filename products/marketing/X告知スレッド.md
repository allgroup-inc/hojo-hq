## スレッド1: 「0円で自動更新サイト」(note記事1・pipeline-starter用)

**1/7**
今朝6時、私のサイトは新しい情報を12件載せて更新を終えていた。私は寝てた。

サーバー代0円、AI代は月数百円。この仕組みの作り方を全部書く。

**2/7**
構成はこれだけ。

GitHub Actionsが1日2回、指定したRSSを見に行く
→ 新着だけをClaude APIに渡す
→ 日付・金額・対象者をJSONで抜き出す
→ 一覧HTMLを生成してGitHub Pagesで公開

サーバーもDBも管理画面もない。だから0円。

**3/7**
一番大事なのは収集でも公開でもなく「検品」の工程。

AIは平気で間違える。だから原文から確認できなかった項目は「要確認」と表示して、断定させない。形式チェックに落ちたデータは公開せず隔離。

AIの出力をそのまま世に出さない構造にしておくこと。これが全部。

**4/7**
失敗も書いておく。

初回実行でAIが過去記事を全部処理しようとして、課金が跳ねかけた。いまは1回の実行で処理する件数に上限を入れてある。

自動化で一番怖いのは「動かないこと」じゃなくて「止まらないこと」だった。

**5/7**
使い道はけっこう広い。

・補助金や入札情報のまとめ(地域×業種で切ると強い)
・業界ニュースのキュレーション
・競合や求人のウォッチ
・社内向けの情報ダッシュボード

「情報が散らばってて追うのが面倒」な分野なら何でもハマる。

**6/7**
かかったお金の内訳。

サーバー: 0円(GitHub無料枠)
ドメイン: 0円(github.io)
AI利用料: 月数百円(従量課金)

「サイト運営=サーバー代」の常識はもう古い。

**7/7**
仕組みの詳細はnoteに全部書いた(無料)。

同じものを作りたい人向けに、コード一式+日本語手順書のテンプレも出してる。プログラミング経験なしで15分セットアップ。

この1投目が役に立ったらRTしてもらえると、続きを書く燃料になります。

## スレッド2: 「AIに数字を書かせるな」(note記事2・report-starter用)

**1/6**
AIに売上レポートを書かせたら、完璧な文章で間違った数字が返ってきた。

検算するまで気づかなかった。これ、経営で使うなら致命傷になる。

どう作り直したかを書く。

**2/6**
AIは嘘をつく気なんてない。大量の行を「目で足し算」してるようなものだから、ズレる。人間と同じ。

怖いのは、間違った数字でも一切ためらいのない文章で書いてくること。読んだ側は疑うきっかけがない。

**3/6**
作り直した設計はシンプル。

計算 → Pythonがやる(1円もズレない)
文章 → AIがやる(集計済みの数字だけを渡す)
判断 → 人間がやる

AIには「渡した数字以外を書くな。要因は断定するな」と縛りを入れる。これで数字のミスはゼロになった。

**4/6**
分業にしたらAIの所見は普通に優秀だった。

「保険カテゴリは件数横ばいだが単価が下がっている。高単価商品の提案数を確認しては」

こういう、月曜の朝に読む価値のある指摘をしてくる。計算をさせなければ、いい参謀になる。

**5/6**
いまは毎週月曜7時に、集計表+AI所見つきのレポートが自動で届く。

作り直しにかけた時間は半日。運用コストは月100円未満。売上CSVを置いておくだけ。

**6/6**
「全部AIにやらせる」は事故のもと。「AIを組み込んだ仕組みを作る」が正解——というのがこの半年の結論。

詳細はnoteに書いた(無料)。同じ仕組みのテンプレも出してる。士業・コンサルの顧問先レポートにも使える設計。
