# 長い資料を貼るだけ、上司報告が3行と質疑対策になる

報告の直前、分厚い資料を読み直して要点を探す。聞かれそうなことを想像して冷や汗をかく。そんな時間の使い方を変えるレシピです。資料を貼るだけで、上司に伝える3行の要約と、想定質問+答えの下書きが同時に出てきます。あとは事実を確認して、自分の言葉に直すだけです。

## このレシピでできること

- 長い資料を上司向けの3行にまとめられる
- 想定質問と答えの下書きを用意できる
- 資料に書かれていない不足情報を洗い出せる

## 実行ログ(抜粋・原文ママ)

サンプル入力(架空の例です):

> (社内調査レポート抜粋)従業員満足度調査の回答率は78%。総合満足度は5点満点で3.4(前年3.6)。低下の主因は「評価制度への納得感」(2.8)と「部署間の情報共有」(2.9)。一方「職場の人間関係」は4.1と高水準を維持。自由記述では在宅勤務日数の拡大要望が最多の42件。20代の離職意向は31%で全社平均の1.6倍。

これを本記事のレシピに渡した、実際の出力がこちらです。

```
【上司向け3行サマリー】
1. 満足度調査(回答率78%)は総合3.4点、前年3.6点から低下。
2. 低い項目は評価制度2.8・情報共有2.9、20代の離職意向31%は全社1.6倍。
3. 評価制度と情報共有、在宅勤務(要望42件)への対応要否を判断願います。

【想定質問と答え】
1. Q. どの項目が下がったのか?
 A. 「評価制度への納得感」2.8、「部署間の情報共有」2.9が低水準です。人間関係は4.1と高いままです。
 根拠:資料内「低下の主因は…」「職場の人間関係は4.1」

2. Q. 調査結果は信頼できる母数か?
 A. 回答率は78%です。回答者数・母集団の内訳は資料に記載がありません。
 根拠:資料内「回答率は78%」

3. Q. 若手の状況は?
 A. 20代の離職意向は31%で、全社平均の1.6倍です(全社平均は約19%と算出、推測)。
 根拠:資料内「20代の離職意向は31%…1.6倍」

4. Q. 現場からの具体的な要望は?
 A. 自由記述で最も多かったのは在宅勤務日数の拡大要望で42件です。他の記述内容は資料になし。
 根拠:資料内「自由記述では在宅勤務日数の拡大要望が最多の42件」

5. Q. 良い点は残っているか?
 A. 「職場の人間関係」が4.1と高水準を維持しています。
 根拠:資料内「一方『職場の人間関係』は4.1」

【資料では答えられない質問】
1. 20代の実際の離職率・退職者数 → 人事の退職者データから取得。
2. 評価制度のどこに不満があるのか(具体的理由) → 自由記述の全文、または若手へのヒアリングで確認。
3. 在宅勤務拡大の業務影響・コスト → 各部門長と総務・情報システム部門に確認。
```

## レシピ全文(コピペ用)

```
あなたは、経営層への報告資料づくりを支援する社内コンサルタントです。忙しい上司が短時間で判断できるよう、長い資料を要点と質疑対策に変換することが目的です。

以下の手順で処理してください。

1. 入力された資料を読み、上司が意思決定するうえで重要な事実を抽出する。
2. 次の形式で出力する。

【上司向け3行サマリー】
1行目:何が起きているか(事実と数字)
2行目:なぜ重要か・何が問題か
3行目:次に何をすべきか、または判断してほしいこと
※各行は60字以内。

【想定質問と答え】
上司から聞かれそうな質問を5つ挙げ、それぞれに資料内の情報だけで答えられる範囲の回答案を3行以内で書く。回答案の末尾に「根拠:資料内の該当箇所」を添える。

【資料では答えられない質問】
上司に聞かれる可能性が高いが、資料に情報がないものを3つ挙げ、どこから情報を取るべきかを一言添える。

制約:
- 資料にない数字や事実を作らない。推測を書く場合は「推測」と明記する。
- 専門用語は社内で通じる平易な表現に置き換える。
- 誇張した表現や断定的な効果予測をしない。
- 出力は日本語、箇条書き中心で簡潔に。

それでは、以下の入力を処理してください。
```

## 手順

1. プロンプト全文をコピーし、AIチャットに貼り付ける
2. 最後の行の下に、報告したい資料の本文を貼る
3. 出力された3行サマリーの数字を原本と照合する
4. 想定質問の回答案を自分の言葉に直し、不足情報を補う

## 自分用にアレンジする

- 「上司」を「役員」「顧客」など相手に書き換えると、質問の切り口が変わります
- 3行を5行に、質問を5つから10個に増やすと、長めの報告会にも対応できます
- 「業界や部署の前提知識がない相手向けに」と1行足すと、用語がさらにやさしくなります

## うまく動かないとき

要約がぼんやりする場合は、資料が長すぎる可能性があります。章ごとに分けて処理し、最後に3行サマリーだけを統合してください。数字が資料と違うときは「資料に書かれた数字だけを使い、計算はしないで」と追記します。質問が的外れなときは、報告相手の役職と関心事(コスト重視など)を1行添えると精度が上がります。
