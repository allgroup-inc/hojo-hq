# 条件の羅列を貼るだけ、求人票が「一日の物語」になる

求人を出しても応募が来ない。仕事内容は「電話応対、データ入力、その他付随業務」、職場は「アットホーム」。書いた本人も、これでは何も伝わらないと薄々わかっている。このレシピは、いまの求人票を貼るだけで、その仕事に就いた人の一日が目に浮かぶ文章に書き直します。誇張ではなく、事実の見せ方を変えるだけです。

## このレシピでできること

- 条件の羅列を、時間軸に沿った一日の描写に変換
- 「アットホーム」など曖昧な表現を具体語に置換
- 応募者が気にする疑問への先回り回答を用意

## 実行ログ(抜粋・原文ママ)

サンプル入力(架空の例です):

> 【募集】事務スタッフ(正社員)。仕事内容: 電話応対、データ入力、書類作成、来客対応、その他付随業務。勤務時間9:00-18:00。土日祝休み。給与: 月給19万円〜。未経験可。アットホームな職場です。

## レシピ全文(コピペ用)

```
あなたは、中小企業の採用支援を専門とする求人ライターです。条件だけが並んだ求人票を、応募検討者が「自分が働く姿」を想像できる文章に書き直すことが役割です。

【目的】
入力された求人票の事実情報を一切変えずに、伝わる順番と言葉づかいを組み替え、読み手が入社後の一日を思い描ける文章にすること。

【出力形式】
1. 冒頭の一文(その仕事の一番の特徴を、誇張せず30字前後で)
2. 働く人の一日(始業から終業まで、時間帯ごとに4〜6場面。入力の業務内容を時間軸に配置し、その場面で何が起きるかを具体的に描写する)
3. この仕事に向いていそうな人(3項目・箇条書き)
4. 逆に、しんどいと感じるかもしれない点(2項目・正直に)
5. 条件のまとめ(勤務時間・休日・給与などを表形式で整理)
6. 情報が足りず書けなかった項目(採用担当者への追加ヒアリング質問を3〜5個)

【制約】
- 入力にない事実(人数、雰囲気、福利厚生など)を創作しない。推測が必要な箇所は【要確認】と明記する。
- 「アットホーム」「やりがい」「風通しが良い」などの抽象語は使わず、具体的な行動や場面に言い換える。書き換えの根拠が入力にない場合は【要確認】とする。
- 「その他付随業務」のような曖昧表現は、そのままにせず追加ヒアリング質問に回す。
- 過度に魅力的に見せる誇張、断定的な将来約束はしない。
- 文章は敬体、一文は短めにする。

それでは、以下の入力を処理してください。
```

## 手順

1. いまの求人票を、原稿や求人サイトの掲載文からそのままコピーする
2. 上のプロンプトを貼り、その下に求人票の全文を貼り付けて送信する
3. 出力の【要確認】と追加ヒアリング質問に、社内の実情を答えて返す
4. 埋まった原稿を現場担当者に見せ、事実と違う描写を修正する
5. 整った文章を求人媒体の仕事内容欄に反映する

## 自分用にアレンジする

- 職種を変える(営業、製造、介護など)場合は、一日の場面数を6〜8に増やすと動きが出ます
- 先輩社員インタビューのメモを一緒に貼ると、描写の具体度が上がり【要確認】が減ります
- 出力形式に「未経験で入った人が最初の1か月に覚えること」を追加すると、未経験者向けに寄せられます

## うまく動かないとき

描写がふわっとして具体性がない場合は、入力情報が少ないことが原因です。使っているソフト名、一日の来客数や電話本数、担当する書類の種類など、思いつく事実を箇条書きで追記して再実行してください。逆に美化されすぎたと感じたら「誇張表現を削り、事実のみで書き直してください」と続けて指示すると調整できます。
