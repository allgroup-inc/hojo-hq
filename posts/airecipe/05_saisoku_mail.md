# 催促メール、3案を貼るだけで用意できる

返事が来ない。でも強くは言えない。この一文をどう書くかで悩んで、メールの下書きを開いたまま時間が過ぎる——そんな経験はありませんか。このレシピは、状況を数行貼るだけで「社内・取引先・目上」の3パターンの催促メールを一度に用意します。相手との距離感に合わせて選び、必要なら数語だけ直して送れます。

## このレシピでできること

- 社内・取引先・目上の3トーンを一度に用意
- 期限の伝え方を角が立たない表現に変換
- 相手が返しやすい選択肢つきの一文を追加

## 実行ログ(抜粋・原文ママ)

サンプル入力(架空の例です):

> 取引先の担当者に2週間前に見積もりの修正版をお願いしたが返事がない。こちらの社内提出期限は今週金曜。先方とは長い付き合いで関係は良好。強くは言いたくないが、期限には間に合わせたい。

これを本記事のレシピに渡した、実際の出力がこちらです。

## レシピ全文(コピペ用)

```
あなたは、社内外の調整を長く担当してきたビジネス文書の編集者です。相手との関係を壊さずに行動をうながす催促メールを作るのが専門です。

【目的】
入力された状況をもとに、返事がない相手へ送る催促メールを、関係性別に3パターン作成してください。

【出力形式】
1) 状況の整理(3行以内。誰に・何を・いつまでに、を箇条書き)
2) 案A:社内の同僚・チーム向け(件名+本文)
3) 案B:取引先・社外パートナー向け(件名+本文)
4) 案C:目上・役職者向け(件名+本文)
5) 送る前チェック(3項目。抜けている情報や確認したい点)

【文章の条件】
・本文は各150〜250字。挨拶、要件、期限、相手への配慮、結びを含める。
・責める語(なぜ/まだ/督促)は使わず、行き違いの可能性を先に置く。
・期限は「こちらの都合」として伝え、相手の落ち度と結びつけない。
・相手が返しやすいよう「◯日までにご一報」「難しければ代替日をご提示」など、選べる形の一文を必ず一つ入れる。
・案Aは簡潔で口語寄り、案Bは丁寧で事務的、案Cは敬語を厚めにし依頼形を強める。
・情報が不足している場合は勝手に作らず、[  ]の空欄にして5)で指摘する。
・誇張表現や感情的な言い回しは使わない。

それでは、以下の入力を処理してください。
```

## 手順

1. 上のプロンプトをコピーし、AIチャットの入力欄に貼る
2. 続けて、相手・依頼内容・経緯・期限・関係性を数行で書き足す
3. 出た3案から、相手との距離感に近いものを1つ選ぶ
4. [  ]の空欄と日付を埋め、送る前チェックを確認して送信

## 自分用にアレンジする

- 「案Bはチャット用に80字で」と足すと、メール以外の連絡手段の文面も用意できます
- 「英語版も併記」と加えると、海外の相手向けの文面を同時に作れます
- 自分の過去メールを2〜3通貼り「この文体に寄せて」と指示すると、口調が自分寄りになります

## うまく動かないとき

文面が硬すぎる・冷たいと感じたら「もう少しやわらかく、相手をねぎらう一文を足して」と追加で伝えてください。逆に伝わりにくいときは「期限の一文だけ強めて」と部分指定すると全体は崩れません。空欄が多い場合は、経緯の日付や依頼した内容を具体的に書き足すと精度が上がります。
