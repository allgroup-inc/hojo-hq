# 契約書を貼るだけ、揉めそうな条文に印がつく

取引先から届いた契約書ドラフト。読んでも「なんとなく不安」で止まってしまい、専門家に相談しようにも何を聞けばいいか分からない——そんな時のレシピです。条文を貼るだけで、あとで争いになりやすい箇所に印を付け、そのまま持っていける質問リストの形に整えます。判断ではなく「気づき」を増やすための下読み用です。

## このレシピでできること

- 揉めやすい条文に印を付けて理由を短く示す
- 専門家にそのまま聞ける質問リストを作る
- 書かれていない項目(抜け)も洗い出す

## 実行ログ(抜粋・原文ママ)

サンプル入力(架空の例です):

> (業務委託契約書ドラフト抜粋)第4条 委託料は月額金30万円とし、乙は毎月末日までに請求書を発行する。甲は翌々月末日までに支払う。第7条 本契約の有効期間は1年とし、期間満了の1ヶ月前までにいずれかから申し出がない場合、同条件で自動更新される。第9条 乙が業務上知り得た情報は契約終了後も第三者に開示してはならない。損害賠償の上限に関する定めはない。

これを本記事のレシピに渡した、実際の出力がこちらです。

## レシピ全文(コピペ用)

```
あなたは、契約実務に明るいビジネス担当者の視点で契約書ドラフトを「下読み」するアシスタントです。法的助言を行う立場ではなく、専門家に相談する前に論点を整理し、質問を準備することが目的です。

【やること】
入力された契約書の条文を読み、後日の解釈違いや紛争の火種になりやすい箇所に印を付け、整理してください。

【出力形式】
1. 全体サマリー(3行以内。どんな契約で、どこに注意が集まるか)
2. 要チェック箇所の一覧(表形式)
   | 印 | 条番号 | 引用(20字程度) | 気になる点 | 専門家への質問案 |
   印は次の3段階を使う:◎=特に確認したい / ○=確認しておきたい / △=念のため
3. 「書かれていないこと」リスト(契約書に見当たらない一般的な条項を、箇条書きで最大7つ。例:上限、解除事由、管轄など)
4. 相談時の持ち込み質問リスト(優先度順に5〜8個。そのまま口頭で聞ける文章で)

【制約】
- 条文に書かれていない事実を추測で補わず、不明な点は「原文では判断できない」と明記する
- 法的な結論(有効/無効、勝ち負け)は述べない。あくまで確認すべき論点として提示する
- 専門用語を使う場合は、かっこ書きで短い言い換えを添える
- 一方の当事者に肩入れせず、入力に立場の指定があればその立場から見た注意点を優先する
- 最後に一行「これは下読みメモです。最終判断は専門家にご確認ください。」と添える

それでは、以下の入力を処理してください。
```

## 手順

1. 上のプロンプトをAIチャットに貼り付ける
2. 続けて契約書ドラフトを条文ごとコピペする(抜粋でも可)
3. 冒頭に「自分は受託者側です」など立場を一行добавить
4. 出た質問リストを印刷し、専門家との相談に持参する

## 自分用にアレンジする

- 「金額と期間に関する条文だけ重点的に」と指定すると、論点を絞った短い出力にできます。
- 出力形式の表に「社内で決めること/相手に聞くこと」の列を足すと、宿題の振り分けが楽になります。
- 秘密保持契約や業務委託など契約の種類を冒頭で伝えると、その類型で頻出の抜け項目を挙げてもらえます。

## うまく動かないとき

出力がぼんやりする時は、条文を丸ごとではなく「第4条〜第9条」のように区切って渡すと精度が上がります。表が崩れる場合は「箇条書きで出して」と指示を変えてください。社外秘の内容は、社名や金額を仮の値に置き換えてから貼るのが安心です。抜けの指摘が少ない時は「他に一般的に入る条項は」と追加で聞いてみてください。
