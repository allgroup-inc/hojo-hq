# 関数名を知らなくていい、日本語で書けば数式が返ってくる

「今月の売上だけ合計したい」——やりたいことは言えるのに、どの関数を使うのかが分からない。検索しても出てくるのは別の状況の例ばかり。このレシピは、日本語で書いた「やりたいこと」をそのまま貼るだけで、貼り付け可能な数式と、どのセルに入れるかの説明を返してもらう形にしたものです。

## このレシピでできること

- やりたいことを日本語で書くと数式が返る
- どのセルに貼るかまで手順で示される
- 数式の意味を一行で説明してもらえる

## 実行ログ(抜粋・原文ママ)

サンプル入力(架空の例です):

> A列に日付、B列に売上金額が入っています。今月の売上だけを合計したい。それと、B列の売上が10万円以上の行だけ数えたい。シートは1枚だけです。

これを本記事のレシピに渡した、実際の出力がこちらです。

```
■やりたいこと:A列の日付が「今月」にあたる行だけ、B列の売上を合計する

・数式:`=SUMIFS(B:B,A:A,">="&DATE(YEAR(TODAY()),MONTH(TODAY()),1),A:A,"<"&DATE(YEAR(TODAY()),MONTH(TODAY())+1,1))`
・貼る場所:D2セル(空いている場所ならどこでも可)
・かんたん解説:今日の日付から「今月の1日」と「翌月の1日」を自動で作り、その間に入る日付の行だけ売上を足しています。
・注意点:A列の日付が「文字として入力された日付風の文字列」だと集計対象から外れます(セルの右寄せになっていれば日付として認識されている目安です)。

【別案:月をセルで指定したい場合】
・数式:`=SUMIFS(B:B,A:A,">="&DATE(YEAR($D$1),MONTH($D$1),1),A:A,"<"&DATE(YEAR($D$1),MONTH($D$1)+1,1))`
・貼る場所:D2セル(D1セルに対象月のどれか1日、例「2025/6/1」を入力)
・かんたん解説:D1に入れた日付の月だけを合計します。月を切り替えて見たいときに便利です。
・注意点:D1が空だと1899年扱いになり、合計が0になります。

■やりたいこと:B列の売上が10万円以上の行が何件あるか数える

・数式:`=COUNTIF(B:B,">=100000")`
・貼る場所:D3セル
・かんたん解説:B列の中で10万以上の数字が入っているマスの個数を数えています。
・注意点:見出し行や合計行など、明細以外の数字がB列にあると一緒に数えてしまいます。その場合は`B:B`を`B2:B1000`のように明細の範囲へ書き換えてください。

【別案:基準額をセルで変えたい場合】
・数式:`=COUNTIF(B:B,">="&$D$1)`
・貼る場所:D3セル(D1セルに`100000`と入力)
・かんたん解説:D1に入れた金額以上の件数を数えます。基準額をあとから変えられます。
・注意点:D1に「10万円」など文字を含めて入れる
(以下略)
```

## レシピ全文(コピペ用)

```
あなたは表計算ソフトの数式に詳しいサポート役です。相手は関数の名前をほとんど知らない一般の事務作業者です。専門用語を使わず、貼り付ければ動く数式を渡すことを目的とします。

【やること】
入力された「やりたいこと」を読み取り、それを実現する数式を作ってください。やりたいことが複数含まれる場合は、それぞれ分けて回答します。

【出力形式】
やりたいことごとに、次の形でまとめてください。

■やりたいこと:(入力を一行で言い換える)
・数式:(そのままコピーできる形で1行。=から始める)
・貼る場所:(例:D2セル など、具体的に)
・かんたん解説:(その数式が何をしているかを、関数名を使わずに1〜2文で)
・注意点:(うまくいかない典型ケースを1つ)

最後に「確認してほしいこと」として、前提が曖昧だった点を最大3つ、箇条書きで質問してください。

【制約】
・列や行の範囲が書かれていない場合は、一般的な形(例:A列全体、2行目以降)を仮置きし、仮置きした旨を明記する。
・古い版でも動きやすい書き方を優先し、新しい関数を使う場合は代替案も併記する。
・日付や条件の指定は、セルを直接指すか、その場で計算する形かを選べるよう、必要なら2案出す。
・動作を保証する表現は使わず、環境によって差が出る点は正直に書く。
・専門用語を出すときは、必ずかっこ書きで平易な言い換えを添える。

それでは、以下の入力を処理してください。
```

## 手順

1. プロンプト全文をコピーし、AIチャットに貼る
2. 続けて「やりたいこと」を日本語で書いて送信する
3. 返ってきた数式を、指定されたセルに貼り付ける
4. 結果がずれたら、実際の列名や行数を伝えて修正を頼む
5. 使えた数式は自分用メモに残しておく

## 自分用にアレンジする

- 出力形式に「別のやり方の案」を1つ追加すると、環境に合わない時の逃げ道が増えます。
- 「解説はいらない、数式だけ返して」と一文足すと、慣れてきた後の作業が短くなります。
- 表の1行目の見出しをそのまま貼り付けると、列の仮置きが減って精度が上がります。

## うまく動かないとき

数式がエラーになるときは、実際の列名・データの開始行・シート名をそのまま伝え、「この構成に合わせて直してください」と頼むと噛み合いやすくなります。日付の合計が0になる場合は、日付が文字として入っていることが多いので、その旨を伝えて別案を出してもらってください。返答が長すぎるときは「数式と貼る場所だけ」と指定します。
