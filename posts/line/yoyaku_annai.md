## ① 初回案内(コピペ用・一斉配信)

```
補助金のことで「うちの場合はどうなんだろう」と迷ったとき、
30分だけ相談できる時間をご用意しました。

・いま使えそうな制度を、一緒に整理します
・書類の書き方や、gBizIDの準備の進め方もお話しします
・相談は無料です

申請の代行はしておりません。
手続きが必要なときは、提携している社労士・行政書士をご紹介します。

空いている時間から選んで予約できます👇
https://allgroup-inc.github.io/hojo-hq/go/yoyaku/

「まだ具体的な話ではないのですが」でも大丈夫です。
制度の見方だけ聞いて帰られる方もいます。
```

## ② リッチメニューのラベル案

- 本命: **相談を予約する**(何が起きるかが一言で分かる)
- 代案: 30分の無料相談 / 面談を予約
- 「予約」だけにしない — 何の予約か分からないとタップされません

## ③ 予約が入ったあとの一言(手送り・任意)

```
ご予約ありがとうございます。

当日は、いま気になっている制度と、事業の状況をうかがいます。
資料のご準備は不要です。手ぶらでお越しください。

日時の変更・キャンセルは、予約完了メールのリンクからお願いします。
```

## ④ 前日リマインド(予約ツールに機能があればそちらを優先)

```
明日◯時からのご相談、お待ちしています。
場所(またはオンラインのURL)は、予約完了メールをご確認ください。
```

## ⑤ 受付を止めるときの表示(フェイルクローズ用)

カレンダー連携が切れた・枠が埋まった場合は、**古い空き枠を出したまま放置しない**。
リッチメニューのリンク先を一時的にこの案内へ差し替える。

```
ただいま相談枠の調整中です。
再開までもう少しお待ちください。

お急ぎのご相談は、このLINEに「相談」と一言お送りください。
担当から個別にご連絡します。
```
